---
title: Thiếu default.js Bắt Buộc cho Parallel Route
---

> Parallel route slots yêu cầu một file `default.js` để phục vụ như một fallback trong quá trình điều hướng.

## Tại Sao Lỗi Này Xảy Ra

Bạn đang sử dụng [parallel routes](https://nextjs.org/docs/app/api-reference/file-conventions/parallel-routes#defaultjs) trong ứng dụng Next.js của bạn, nhưng một trong các parallel route slots của bạn bị thiếu file `default.js` bắt buộc, điều này gây ra lỗi build.

Khi sử dụng parallel routes, Next.js cần biết những gì cần render trong mỗi slot khi:

- Điều hướng giữa các trang có cấu trúc slot khác nhau
- Một slot không khớp với điều hướng hiện tại (chỉ trong quá trình hard navigation)
- Sau khi refresh trang khi Next.js không thể xác định trạng thái active cho một slot

File `default.js` phục vụ như một fallback để render khi Next.js không thể xác định trạng thái active của một slot dựa trên URL hiện tại. Nếu không có file này, build sẽ thất bại.

## Các Cách Có Thể Để Khắc Phục

Tạo một file `default.js` (hoặc `.jsx`, `.tsx`) trong thư mục parallel route slot được đề cập trong thông báo lỗi.

Ví dụ, nếu bạn có cấu trúc này nơi các slots khác nhau có các trang tại các đường dẫn khác nhau:

```
app/
├── layout.js
├── page.js
├── @team/
│   └── settings/
│       └── page.js
└── @analytics/
    └── page.js
```

Bạn cần thêm các file `default.js` cho mỗi slot, ngoại trừ slot children:

```
app/
├── layout.js
├── page.js
├── default.js         // Tùy chọn: thêm file này (cho slot children)
├── @team/
│   ├── default.js     // Thêm file này
│   └── settings/
│       └── page.js
└── @analytics/
    ├── default.js     // Thêm file này
    └── page.js
```

Nếu không có `default.js` gốc, việc điều hướng đến `/settings` sẽ dẫn đến 404, ngay cả khi `@team/settings/page.js` tồn tại. `default.js` trong thư mục gốc cho Next.js biết những gì cần render trong slot children khi không có trang phù hợp tại đường dẫn đó. Nó không bắt buộc như các file default của các slots được đặt tên khác, nhưng tốt hơn hết là nên thêm vào để giúp cải thiện trải nghiệm cho các ứng dụng của bạn.

### Ví dụ file `default.js`:

Implementation đơn giản nhất trả về `null` để không render gì cả:

```jsx filename="app/@analytics/default.js"
export default function Default() {
  return null
}
```

Bạn cũng có thể giữ lại hành vi cũ là trả về 404:

```jsx filename="app/@team/default.js"
import { notFound } from 'next/navigation'

export default function Default() {
  notFound()
}
```

### Khi nào bạn cần `default.js`

Bạn cần một file `default.js` cho mỗi parallel route slot (các thư mục bắt đầu bằng `@`) tại mỗi segment route.
