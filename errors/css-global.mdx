## Tại Sao Lỗi Này Xảy Ra

Một nỗ lực import Global CSS từ một file bên ngoài [`pages/_app.js`](/docs/pages/building-your-application/routing/custom-app) đã được thực hiện.

Global CSS không thể được sử dụng trong các files khác ngoài [file `_app.js` tùy chỉnh](/docs/pages/building-your-application/routing/custom-app) của bạn do các vấn đề về thứ tự và tác dụng phụ (side-effects).

## Các Cách Có Thể Để Khắc Phục

Có hai cách có thể để khắc phục lỗi này:

- Di chuyển tất cả các imports global CSS vào [file `pages/_app.js`](/docs/pages/building-your-application/routing/custom-app) của bạn.
- Nếu bạn không muốn stylesheet của mình là global, hãy cập nhật nó để sử dụng [CSS Modules](/docs/app/getting-started/css). Điều này sẽ cho phép bạn import stylesheet và phạm vi (scope) các styles cho một component cụ thể.

### Ví dụ

Xem xét stylesheet có tên [`styles.css`](/docs/app/getting-started/css)

```css filename="styles.css"
body {
  font-family:
    'SF Pro Text', 'SF Pro Icons', 'Helvetica Neue', 'Helvetica', 'Arial',
    sans-serif;
  padding: 20px 20px 60px;
  max-width: 680px;
  margin: 0 auto;
}
```

**Global CSS**:

Tạo một [file `pages/_app.js`](/docs/pages/building-your-application/routing/custom-app) nếu chưa có. Sau đó import file `styles.css`:

```jsx filename="pages/_app.js"
import '../styles.css'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

**CSS Modules**:

Đổi tên file `styles.css` thành `styles.module.css`. Sau đó import file trong component hoặc page nơi bạn muốn sử dụng các styles.

```jsx filename="pages/index.js"
import styles from '../../styles.module.css'

export default function Home() {
  return <div className={styles.container}>Hello World</div>
}
```
