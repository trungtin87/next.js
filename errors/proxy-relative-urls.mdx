## Tại Sao Lỗi Này Xảy Ra

Bạn đang sử dụng một hàm Proxy sử dụng `Response.redirect(url)`, `NextResponse.redirect(url)` hoặc `NextResponse.rewrite(url)` trong đó `url` là một URL tương đối hoặc URL không hợp lệ. Trước Next.js 12.1, chúng tôi cho phép truyền URL tương đối. Tuy nhiên, việc xây dựng một request với `new Request(url)` hoặc chạy `fetch(url)` khi `url` là URL tương đối **không** hoạt động. Vì lý do này và để mang lại tính nhất quán cho Next.js Proxy, hành vi này đã bị phản đối và hiện đã bị xóa.

## Các Cách Có Thể Để Khắc Phục

Để khắc phục lỗi này, bạn phải luôn truyền URL tuyệt đối cho việc redirect và rewrite. Có một số cách để lấy URL tuyệt đối nhưng cách được khuyến nghị là clone `NextURL` và thay đổi nó:

```ts filename="proxy.ts"
import type { NextRequest } from 'next/server'
import { NextResponse } from 'next/server'

export function proxy(request: NextRequest) {
  const url = request.nextUrl.clone()
  url.pathname = '/dest'
  return NextResponse.rewrite(url)
}
```

Một cách khác để khắc phục lỗi này có thể là sử dụng URL gốc làm base nhưng điều này sẽ không xem xét cấu hình như `basePath` hoặc `locale`:

```ts filename="proxy.ts"
import type { NextRequest } from 'next/server'
import { NextResponse } from 'next/server'

export function proxy(request: NextRequest) {
  return NextResponse.rewrite(new URL('/dest', request.url))
}
```

Bạn cũng có thể truyền trực tiếp một chuỗi chứa URL tuyệt đối hợp lệ.
