## Tại Sao Lỗi Này Xảy Ra

Code trong [Proxy](/docs/pages/api-reference/file-conventions/proxy) hoặc [Edge API Routes](/docs/pages/building-your-application/routing/api-routes) của bạn đang sử dụng một tính năng từ Node.js runtime.

Tuy nhiên, Edge Runtime không hỗ trợ [Node.js APIs và globals](/docs/pages/api-reference/edge#unsupported-apis).

## Các Cách Có Thể Để Khắc Phục

Khi chạy Next.js locally với `next dev`, ứng dụng của bạn sẽ hiển thị trong console và trong trình duyệt của bạn, file nào đang import và sử dụng một module không được hỗ trợ. Module này phải được tránh: bằng cách không import nó, hoặc bằng cách thay thế nó bằng một polyfill.

Ví dụ, bạn có thể thay thế module `crypto` của Node.js bằng [Web Crypto API](https://developer.mozilla.org/docs/Web/API/Web_Crypto_API).
