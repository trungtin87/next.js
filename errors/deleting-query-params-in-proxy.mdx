---
title: Xóa Query Parameters Trong Proxies
---

## Tại Sao Lỗi Này Xảy Ra

Trong các phiên bản trước của Next.js, chúng tôi đã hợp nhất các tham số truy vấn (query parameters) với yêu cầu đến cho các rewrites xảy ra trong proxies, để khớp với hành vi của các rewrites tĩnh được khai báo trong config. Điều này buộc người dùng Next.js phải sử dụng các giá trị tham số truy vấn trống để xóa các keys.

Chúng tôi đang thay đổi hành vi này để cho phép linh hoạt hơn và trải nghiệm hợp lý hơn cho người dùng. Vì vậy từ giờ trở đi, các tham số truy vấn sẽ không được hợp nhất và do đó có cảnh báo.

```ts filename="proxy.ts"
import type { NextRequest } from 'next/server'
import { NextResponse } from 'next/server'

export default function proxy(request: NextRequest) {
  const nextUrl = request.nextUrl
  nextUrl.searchParams.delete('key') // <-- điều này bây giờ là có thể!
  return NextResponse.rewrite(nextUrl)
}
```

## Các Cách Có Thể Để Khắc Phục

Nếu bạn đang dựa vào hành vi cũ, vui lòng thêm các tham số truy vấn thủ công vào URL được viết lại. Sử dụng `request.nextUrl` sẽ tự động làm điều đó cho bạn.

```ts filename="proxy.ts"
import type { NextRequest } from 'next/server'
import { NextResponse } from 'next/server'

export default function proxy(request: NextRequest) {
  const nextUrl = request.nextUrl
  nextUrl.pathname = '/dest'
  return NextResponse.rewrite(nextUrl)
}
```

Cảnh báo này sẽ bị xóa trong phiên bản tiếp theo của Next.js.
