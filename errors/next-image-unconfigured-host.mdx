## Tại Sao Lỗi Này Xảy Ra

Một trong các trang của bạn sử dụng component `next/image`, đã truyền giá trị `src` sử dụng hostname trong URL không được định nghĩa trong `images.remotePatterns` trong `next.config.js`.

Mỗi phần của giá trị `src` được khớp chặt chẽ với các định nghĩa `images.remotePatterns` của bạn. Khớp là chính xác và phân biệt chữ hoa chữ thường, nghĩa là sự không khớp trong bất kỳ phần đơn lẻ nào sẽ làm kiểm tra thất bại.

Đối với một URL như `https://example.org/images/example?v=1234`, các phần sau phải khớp với mẫu bạn đã cấu hình:

- **Protocol**: `http` vs `https` phải khớp chính xác.
- **Hostname**: `example.org` khác với `www.example.org` và khác với các subdomain như `assets.example.org`.
- **Port**: Nếu có (ví dụ: `:3000`), nó phải được bao gồm.
- **Pathname**: Đường dẫn phải được bao phủ bởi glob của bạn, ví dụ: `/**` hoặc `/images/**`.
- **Search**: Nếu được chỉ định trong một mẫu, nó phải khớp chính xác chuỗi search đầy đủ (bao gồm cả `?` đầu tiên). Globs không được hỗ trợ cho search.

Nếu bất kỳ phần nào trong số này khác với `src` thực tế, hình ảnh sẽ bị từ chối.

Các lỗi phổ biến gây ra lỗi này:

- Sử dụng `https` trong `src` nhưng chỉ cho phép `http` (hoặc ngược lại).
- Tải từ một subdomain như `assets.example.com` trong khi chỉ cấu hình `example.com`.
- Thiếu port trong quá trình sử dụng local/dev, ví dụ: `http://localhost:3000`.
- Một mẫu pathname quá hẹp (ví dụ: `/images/` thay vì `/images/**`).
- Khi sử dụng constructor `URL`, nếu không chỉ định `search`, thì thuộc tính `search` được đặt thành chuỗi rỗng `''`, có nghĩa là search params **KHÔNG** được phép.

Xem tham chiếu [Remote Patterns](/docs/pages/api-reference/components/image#remotepatterns) để biết chi tiết.

## Các Cách Có Thể Để Khắc Phục

Thêm protocol, hostname, port và pathname vào cấu hình `images.remotePatterns` trong `next.config.js`:

```js filename="next.config.js"
module.exports = {
  images: {
    remotePatterns: [new URL('https://assets.example.com/account123/**')],
  },
}
```

### Với search params cụ thể

Để cho phép một search param duy nhất, `v=1234`:

```js filename="next.config.js"
module.exports = {
  images: {
    remotePatterns: [
      new URL('https://assets.example.com/account123/**?v=1234'),
    ],
  },
}
```

### Bất kỳ search params nào

Để cho phép bất kỳ search parameter nào, hãy sử dụng đối tượng remote pattern, bỏ qua key `search`.

```js filename="next.config.js"
module.exports = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'assets.example.com',
        port: '',
        pathname: '/account123/**',
      },
    ],
  },
}
```

### Sửa các phiên bản Next.js cũ hơn

<details>
  <summary>Sử dụng Next.js trước 15.3.0?</summary>
  
Các phiên bản Next.js cũ hơn có thể cấu hình `images.remotePatterns` bằng cách sử dụng đối tượng:

```js filename="next.config.js"
module.exports = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'assets.example.com',
        port: '',
        pathname: '/account123/**',
        search: '',
      },
    ],
  },
}
```

</details>

<details>
  <summary>Sử dụng Next.js trước 12.3.0?</summary>
  
Các phiên bản Next.js cũ hơn có thể cấu hình `images.domains` thay thế:

```js filename="next.config.js"
module.exports = {
  images: {
    domains: ['assets.example.com'],
  },
}
```

</details>
