---

## Tại Sao Lỗi Này Xảy Ra

Hàm webpack trong `next.config.js` trả về một promise không được hỗ trợ trong Next.js. Ví dụ, dưới đây không được hỗ trợ:

```js filename="next.config.js"
module.exports = {
  webpack: async function (config) {
    return config
  },
}
```

## Các Cách Có Thể Để Khắc Phục

Trong các phiên bản Next.js trên `12.0.10`, `module.exports = async () =>` được hỗ trợ.

Đối với các phiên bản cũ hơn, bạn có thể kiểm tra `next.config.js` của mình để tìm `async` hoặc `return Promise`.

Có thể một plugin đang trả về `Promise` từ hàm webpack.
