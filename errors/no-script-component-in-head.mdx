---
title: Không có Component Script trong Head
---

> Ngăn chặn việc sử dụng `next/script` trong component `next/head`.

## Tại Sao Lỗi Này Xảy Ra

Component `next/script` không nên được sử dụng trong component `next/head`.

## Các Cách Có Thể Để Khắc Phục

Di chuyển component `<Script />` ra ngoài `<Head>` thay thế.

**Trước**

```jsx filename="pages/index.js"
import Script from 'next/script'
import Head from 'next/head'

export default function Index() {
  return (
    <Head>
      <title>Next.js</title>
      <Script src="/my-script.js" />
    </Head>
  )
}
```

**Sau**

```jsx filename="pages/index.js"
import Script from 'next/script'
import Head from 'next/head'

export default function Index() {
  return (
    <>
      <Head>
        <title>Next.js</title>
      </Head>
      <Script src="/my-script.js" />
    </>
  )
}
```
