## Tại Sao Lỗi Này Xảy Ra

Giá trị được trả về từ function `webpack` tùy chỉnh trong `next.config.js` của bạn là undefined. Điều này có thể xảy ra do giá trị config ban đầu không được trả về.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo trả về `webpack` config từ function `webpack` tùy chỉnh của bạn trong `next.config.js`

```js filename="next.config.js"
module.exports = {
  webpack: (config, { buildId, dev, isServer, defaultLoaders, webpack }) => {
    // Lưu ý: chúng tôi cung cấp webpack ở trên nên bạn không nên `require` nó
    // Thực hiện các tùy chỉnh cho webpack config
    config.plugins.push(new webpack.IgnorePlugin(/\/__tests__\//))

    // Quan trọng: trả về config đã sửa đổi
    return config
  },
}
```
