## Tại Sao Lỗi Này Xảy Ra

Trong Next.js 15, `params` được truyền vào các Page và Layout components và `searchParams` được truyền vào các Page components giờ đây là Promises.

Để hỗ trợ việc di chuyển sang `params` và `searchParams` async, Next.js 15 vẫn hỗ trợ việc truy cập các giá trị param và searchParam trực tiếp trên đối tượng Promise. Tuy nhiên khi `cacheComponents` được bật, việc làm như vậy là một lỗi.

## Các Cách Khắc Phục Có Thể

Nếu bạn chưa làm theo hướng dẫn nâng cấp Next.js 15 bao gồm việc chạy một codemod để tự động chuyển đổi sang dạng async cần thiết của `params` và `searchParams`, hãy bắt đầu từ đó.

[Hướng Dẫn Nâng Cấp Next 15](/docs/app/guides/upgrading/version-15#async-request-apis-breaking-change)

Nếu bạn đã chạy codemod trên dự án của mình, hãy tìm các instance của chuỗi `@next-codemod-error` để xem nơi mà codemod không thể chuyển đổi sang dạng async. Bạn sẽ phải refactor code của mình thủ công ở đây để làm cho nó tương thích với kiểu kết quả mới.

Trước đây:

```jsx filename=".../some-file.js"
// Component này cuối cùng trở thành Page component mặc dù nó được định nghĩa bên ngoài
// page.js do cách nó được reexport trong page.js
export default function ComponentThatWillBeExportedAsPage({ params, searchParams }) {
  const { slug } = params;
  const { page } = searchParams
  return <RenderList slug={slug} page={page}>
}
```

```jsx filename="app/page.js"
// codemod không thể tìm thấy Page component thực tế nên Page vẫn có thể còn
// truy cập đồng bộ vào params và searchParams

// @next-codemod-error
export * from '.../some-file'
```

Sau khi sửa:

```jsx filename=".../some-file.js"
// Component này cuối cùng trở thành Page component mặc dù nó được định nghĩa bên ngoài
// page.js do cách nó được reexport trong page.js
export default async function ComponentThatWillBeExportedAsPage({ params, searchParams }) {
  const { slug } = await params;
  const { page } = await searchParams
  return <RenderList slug={slug} page={page}>
}
```

```jsx filename="app/page.js"
export * from '.../some-file'
```

Không mong đợi rằng bạn sẽ chạy codemod và không chuyển đổi thành công tất cả các instance của `params` và `searchParams` sang async hoặc có một chuỗi đánh dấu để giúp bạn xác định vị trí các trường hợp chưa được chuyển đổi. Nếu bạn thấy mình trong tình huống này, vui lòng báo cáo điều này cho [Next.js trên Github](https://github.com/vercel/next.js/issues).
