title: '`<title>` không nên được sử dụng trong `<Head>` của _document.js'
---

## Tại Sao Lỗi Này Xảy Ra

Thêm `<title>` trong `pages/_document.js` sẽ dẫn đến kết quả không mong muốn với `next/head` vì `_document.js` chỉ được render trong lần pre-render ban đầu.

## Các Cách Có Thể Để Khắc Phục

Đặt `<title>` trong `pages/_app.js` thay thế:

```jsx filename="pages/_app.js"
import React from 'react'
import Head from 'next/head'

function MyApp({ Component, pageProps }) {
  return (
    <>
      <Head>
        <title>My new cool app</title>
      </Head>
      <Component {...pageProps} />
    </>
  )
}

export default MyApp
```
