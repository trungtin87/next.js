---

## Tại Sao Lỗi Này Xảy Ra

Ứng dụng của bạn đang sử dụng một hàm Proxy đang sử dụng các tham số từ API đã bị phản đối.

```ts filename="proxy.ts"
import { NextResponse } from 'next/server'

export function proxy(event) {
  if (event.request.nextUrl.pathname === '/blocked') {
    event.respondWith(
      new NextResponse(null, {
        status: 403,
      })
    )
  }
}
```

## Các Cách Có Thể Để Khắc Phục

Cập nhật để sử dụng API mới cho Proxy:

```ts filename="proxy.ts"
import { NextResponse } from 'next/server'

export function proxy(request) {
  if (request.nextUrl.pathname === '/blocked') {
    return new NextResponse(null, {
      status: 403,
    })
  }
}
```
