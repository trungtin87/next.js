title: Custom Routes phải trả về một mảng
---

## Tại Sao Lỗi Này Xảy Ra

Khi định nghĩa custom routes, một mảng không được trả về từ `headers`, `rewrites`, hoặc `redirects`.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo trả về một mảng chứa các routes.

**Trước**

```js filename="next.config.js"
module.exports = {
  async rewrites() {
    return {
      source: '/feedback',
      destination: '/feedback/general',
    }
  },
}
```

**Sau**

```js filename="next.config.js"
module.exports = {
  async rewrites() {
    return [
      {
        source: '/feedback',
        destination: '/feedback/general',
      },
    ]
  },
}
```
