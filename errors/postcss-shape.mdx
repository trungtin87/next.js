## Tại Sao Lỗi Này Xảy Ra

Cấu hình PostCSS được cung cấp ở dạng không được hỗ trợ.

## Các Cách Có Thể Để Khắc Phục

Cấu hình PostCSS phải được định nghĩa theo dạng sau:

```js filename="postcss.config.js"
module.exports = {
  plugins: [
    // Một plugin không yêu cầu cấu hình:
    'simple-plugin-example',

    // Một plugin cần một đối tượng cấu hình:
    [
      'plugin-with-configuration',
      {
        optionA: '...',
      },
    ],

    // Một plugin được bật hoặc tắt dựa trên môi trường:
    [
      'plugin-toggled',
      process.env.NODE_ENV === 'production'
        ? {
            optionA: '...',
          }
        : false,
    ],

    // Biểu thức Boolean cũng hợp lệ.
    // `true` bật plugin, `false` tắt plugin:
    ['plugin-toggled-2', true /* a === b, etc */],
  ],
}
```

Bạn có thể [đọc thêm về cấu hình PostCSS trong Next.js tại đây](/docs/pages/guides/post-css).

### Các Lỗi Phổ Biến

**Trước: plugin được require()'d**

```js filename="postcss.config.js"
const pluginA = require('postcss-plugin-a')
module.exports = {
  plugins: [require('postcss-plugin'), pluginA],
}
```

**Sau**

```js filename="postcss.config.js"
module.exports = {
  plugins: ['postcss-plugin', 'postcss-plugin-a'],
}
```

---

**Trước: plugin được khởi tạo với cấu hình**

```js filename="postcss.config.js"
module.exports = {
  plugins: [
    require('postcss-plugin')({
      optionA: '...',
    }),
  ],
}
```

**Sau**

```js filename="postcss.config.js"
module.exports = {
  plugins: [
    // Chú ý đến mảng lồng nhau này. Index đầu tiên là tên plugin,
    // index thứ hai là cấu hình.
    [
      'postcss-plugin',
      {
        optionA: '...',
      },
    ],
  ],
}
```

---

**Trước: plugin thiếu cấu hình**

```js filename="postcss.config.js"
module.exports = {
  plugins: [
    [
      'postcss-plugin-1',
      {
        optionA: '...',
      },
    ],
    // Mảng một phần tử này được phát hiện là cấu hình sai vì nó
    // thiếu phần tử thứ hai. Để sửa, hãy unwrap giá trị.
    ['postcss-plugin-2'],
  ],
}
```

**Sau**

```js filename="postcss.config.js"
module.exports = {
  plugins: [
    [
      'postcss-plugin-1',
      {
        optionA: '...',
      },
    ],
    // Chỉ chuỗi:
    'postcss-plugin-2',
  ],
}
```
