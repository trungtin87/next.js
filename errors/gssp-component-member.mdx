## Tại Sao Lỗi Này Xảy Ra

Trên một trong các components trang của bạn, bạn đã gắn `getStaticProps`, `getStaticPaths`, hoặc `getServerSideProps` như một thành viên thay vì như một export riêng biệt.

Các phương thức này không thể được gắn theo cùng cách như `getInitialProps` và phải là export riêng của chúng.

## Các Cách Có Thể Để Khắc Phục

Di chuyển phương thức sang export riêng của nó từ trang của bạn.

**Trước**

```jsx filename="pages/index.js"
function Page(props) {
  return <p>hello world</p>
}

Page.getStaticProps = () => ({
  props: {
    hello: 'world',
  },
})

export default Page
```

**Sau**

```jsx filename="pages/index.js"
function Page(props) {
  return <p>hello world</p>
}

export default Page

export const getStaticProps = () => ({
  props: {
    hello: 'world',
  },
})
```
