## Tại Sao Lỗi Này Xảy Ra

Việc sử dụng [Tối ưu hóa Hình ảnh](/docs/pages/api-reference/components/image) tích hợp của Next.js yêu cầu [sharp](https://www.npmjs.com/package/sharp) như một dependency.

Bạn thấy lỗi này vì hệ điều hành của bạn không thể [cài đặt sharp](https://sharp.pixelplumbing.com/install) đúng cách, hoặc sử dụng các tệp nhị phân dựng sẵn hoặc xây dựng từ nguồn.

## Các Cách Có Thể Để Khắc Phục

Tùy chọn 1: Sử dụng một phiên bản Node.js khác và thử cài đặt `sharp` lại.

```bash filename="Terminal"
npm i sharp
```

```bash filename="Terminal"
yarn add sharp
```

```bash filename="Terminal"
pnpm add sharp
```

```bash filename="Terminal"
bun add sharp
```

Tùy chọn 2: Thử cài đặt biến thể wasm của `sharp` bằng cách chạy `npm install --cpu=wasm32 sharp`.

Tùy chọn 3: Nếu sử dụng macOS, đảm bảo XCode Build Tools đã được cài đặt và thử cài đặt `sharp` lại.

Ví dụ, xem [hướng dẫn macOS Catalina](https://github.com/nodejs/node-gyp/blob/66c0f0446749caa591ad841cd029b6d5b5c8da42/macOS_Catalina.md).

Tùy chọn 4: Sử dụng một hệ điều hành khác và thử cài đặt `sharp` lại.

Ví dụ, nếu bạn đang sử dụng Windows, hãy thử sử dụng [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) (Windows Subsystem for Linux).
