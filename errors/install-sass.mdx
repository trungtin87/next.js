Việc sử dụng [hỗ trợ Sass tích hợp](/docs/pages/guides/sass) của Next.js yêu cầu bạn mang phiên bản Sass của riêng mình.

## Các Cách Có Thể Để Khắc Phục

Vui lòng cài đặt gói `sass` trong dự án của bạn.

```bash filename="Terminal"
npm i sass
# hoặc
yarn add sass
```
