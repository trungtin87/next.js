title: Sử dụng webpack `devtool` không đúng cách trong chế độ development
---

## Tại Sao Lỗi Này Xảy Ra

Next.js chọn `devtool` tối ưu nhất để sử dụng với webpack. Việc thay đổi `devtool` trong chế độ development sẽ gây ra sự suy giảm hiệu suất nghiêm trọng cho ứng dụng của bạn.

## Các Cách Có Thể Để Khắc Phục

Vui lòng xóa ghi đè `devtool` tùy chỉnh hoặc chỉ áp dụng nó cho các bản build production trong `next.config.js` của bạn.

```js filename="next.config.js"
module.exports = {
  webpack: (config, options) => {
    if (!options.dev) {
      config.devtool = options.isServer ? false : 'your-custom-devtool'
    }
    return config
  },
}
```
