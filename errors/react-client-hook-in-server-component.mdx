## Tại Sao Lỗi Này Xảy Ra

Bạn đang sử dụng một React client hook trong Server Component.

## Các Cách Có Thể Để Khắc Phục

Đánh dấu component sử dụng hook là Client Component bằng cách thêm `'use client'` ở đầu file.

### Trước

```jsx filename="app/example.js"
import { useEffect } from 'react'

export default function Example() {
  useEffect(() => {
    console.log('in useEffect')
  })
  return <p>Hello world</p>
}
```

### Sau

```jsx filename="app/example.js"
'use client'

import { useEffect } from 'react'

export default function Example() {
  useEffect(() => {
    console.log('in useEffect')
  })
  return <p>Hello world</p>
}
```
