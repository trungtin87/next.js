## Tại Sao Lỗi Này Xảy Ra

Bắt đầu từ Next.js 13, component `next/image` đã trải qua một số thay đổi lớn.

So với legacy component, component `next/image` mới có các thay đổi sau:

- Xóa wrapper `<span>` xung quanh `<img>` để ưu tiên [native computed aspect ratio](https://caniuse.com/mdn-html_elements_img_aspect_ratio_computed_from_attributes)
- Thêm hỗ trợ cho canonical `style` prop
  - Xóa `layout` prop để ưu tiên `style` hoặc `className`
  - Xóa `objectFit` prop để ưu tiên `style` hoặc `className`
  - Xóa `objectPosition` prop để ưu tiên `style` hoặc `className`
- Xóa implementation `IntersectionObserver` để ưu tiên [native lazy loading](https://caniuse.com/loading-lazy-attr)
  - Xóa `lazyBoundary` prop vì không có tương đương native
  - Xóa `lazyRoot` prop vì không có tương đương native
- Xóa `loader` config để ưu tiên [`loader`](/docs/app/api-reference/components/image#loader) prop
- Thay đổi `alt` prop từ optional thành required

## Các Cách Có Thể Để Khắc Phục

Chạy codemod [next-image-to-legacy-image](/docs/pages/guides/upgrading/codemods#next-image-to-legacy-image) để tự động thay đổi imports `next/image` thành `next/legacy/image`, ví dụ:

```bash filename="Terminal"
npx @next/codemod next-image-to-legacy-image .
```

Sau khi chạy codemod này, bạn có thể tùy chọn nâng cấp `next/legacy/image` lên `next/image` mới với một codemod khác, ví dụ:

```bash filename="Terminal"
npx @next/codemod next-image-experimental .
```

Xin lưu ý codemod thứ hai này là experimental và chỉ bao gồm static usage (như `<Image src={img} layout="responsive" />`) nhưng không bao gồm dynamic usage (như `<Image {...props} />`).
