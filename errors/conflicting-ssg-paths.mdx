## Tại Sao Lỗi Này Xảy Ra

Bạn đã trả về **các đường dẫn xung đột** trong hàm `getStaticPaths` cho một trong các trang của mình. Tất cả các đường dẫn trang phải là duy nhất và không được phép trùng lặp.

## Các Cách Có Thể Để Khắc Phục

Xóa bất kỳ đường dẫn xung đột nào được hiển thị trong thông báo lỗi và chỉ trả về chúng từ một `getStaticPaths`.

Ví dụ đường dẫn xung đột:

```jsx filename="pages/hello/world.js"
export default function Hello() {
  return 'hello world!'
}
```

```jsx filename="pages/[...catchAll].js"
export const getStaticProps = () => ({ props: {} })

export const getStaticPaths = () => ({
  paths: [
    '/hello/world', // <-- điều này xung đột với trang /hello/world.js, xóa để giải quyết lỗi
    '/another',
  ],
  fallback: false,
})

export default function CatchAllPage() {
  return 'Catch-all page'
}
```

Ví dụ đường dẫn xung đột:

```jsx filename="pages/blog/[slug].js"
export const getStaticPaths = () => ({
  paths: ['/blog/conflicting', '/blog/another'],
  fallback: false,
})

export default function Blog() {
  return 'Blog!'
}
```

```jsx filename="pages/[...catchAll].js"
export const getStaticProps = () => ({ props: {} })

export const getStaticPaths = () => ({
  paths: [
    // điều này xung đột với đường dẫn /blog/conflicting ở trên, xóa để giải quyết lỗi
    '/blog/conflicting',
    '/another',
  ],
  fallback: false,
})

export default function CatchAll() {
  return 'Catch-all page'
}
```
