title: Nhiều con đã được truyền vào `<Link>`
---

## Tại Sao Lỗi Này Xảy Ra

Trong mã ứng dụng của bạn, nhiều con đã được truyền vào `next/link` nhưng chỉ hỗ trợ một con:

Ví dụ:

```jsx filename="example.js"
import Link from 'next/link'

export default function Home() {
  return (
    <Link href="/about">
      <a>To About</a>
      <a>Second To About</a>
    </Link>
  )
}
```

## Các Cách Có Thể Để Khắc Phục

Đảm bảo chỉ sử dụng một con khi sử dụng `<Link>`:

```jsx filename="example.js"
import Link from 'next/link'

export default function Home() {
  return (
    <Link href="/about">
      <a>To About</a>
    </Link>
  )
}
```

> **Thông tin hữu ích**:
>
> - Kể từ Next.js 13.0, `<Link>` không còn yêu cầu thẻ con `<a>`. Một [codemod](/docs/app/guides/upgrading/codemods#remove-a-tags-from-link-components) được cung cấp để tự động cập nhật codebase của bạn.
