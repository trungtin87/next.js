> Ngăn chặn việc sử dụng phần tử `<head>`.

## Tại Sao Lỗi Này Xảy Ra

Một phần tử `<head>` đã được sử dụng để bao gồm metadata cấp trang, nhưng điều này có thể gây ra hành vi không mong muốn trong ứng dụng Next.js. Sử dụng component `next/head` tích hợp của Next.js thay thế.

## Các Cách Có Thể Để Khắc Phục

Import và sử dụng component `<Head />`:

```jsx filename="pages/index.js"
import Head from 'next/head'

function Index() {
  return (
    <>
      <Head>
        <title>My page title</title>
        <meta name="viewport" content="initial-scale=1.0, width=device-width" />
      </Head>
    </>
  )
}

export default Index
```
