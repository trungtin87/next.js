## Tại Sao Lỗi Này Xảy Ra

`Math.random()` đã được gọi trong một Server Component trước khi truy cập dữ liệu uncached khác thông qua các API như `fetch()` và native database drivers, hoặc dữ liệu Request thông qua các built-in API như `cookies()`, `headers()`, `connection()` và `searchParams`. Việc truy cập các giá trị ngẫu nhiên theo cách này can thiệp vào khả năng prerendering và prefetching của Next.js.

## Các Cách Khắc Phục Có Thể

Nếu giá trị ngẫu nhiên phù hợp để được prerender và prefetch, hãy xem xét di chuyển nó vào một Cache Component hoặc Cache Function với directive `"use cache"`.

Nếu giá trị ngẫu nhiên được dự định để được tạo ra trên mỗi request của người dùng, hãy xem xét liệu bạn có thể di chuyển việc tạo giá trị ngẫu nhiên về sau, sau khi truy cập dữ liệu uncached hoặc dữ liệu Request hiện có khác. Nếu không có cách nào để làm điều này, bạn luôn có thể đặt trước việc tạo giá trị ngẫu nhiên bằng cách truy cập dữ liệu Request bằng cách sử dụng `await connection()`.

Nếu giá trị ngẫu nhiên đang được sử dụng làm mã định danh duy nhất cho mục đích chẩn đoán như logging hoặc tracking, hãy xem xét sử dụng một phương pháp thay thế để tạo id không dựa vào việc tạo số ngẫu nhiên như tăng dần một số nguyên.

> **Lưu ý**: Đôi khi nơi tạo ra giá trị ngẫu nhiên đồng bộ nằm bên trong code của bên thứ ba. Mặc dù bạn không thể dễ dàng thay thế lệnh gọi `Math.random()` trực tiếp, các chiến lược khác có thể được áp dụng trong code dự án của riêng bạn bất kể việc tạo ngẫu nhiên sâu đến mức nào.

### Cache giá trị ngẫu nhiên

Nếu giá trị ngẫu nhiên của bạn có thể cache được, hãy di chuyển lệnh gọi `Math.random()` vào một function `"use cache"`. Ví dụ, hãy tưởng tượng bạn có một trang sản phẩm và bạn muốn ngẫu nhiên hóa thứ tự sản phẩm định kỳ nhưng bạn ổn với việc thứ tự ngẫu nhiên được sử dụng lại cho các người dùng khác nhau.

Trước đây:

```jsx filename="app/page.js"
export default async function Page() {
  const products = await getCachedProducts()
  const randomSeed = Math.random()
  const randomizedProducts = randomize(products, randomSeed)
  return <ProductsView products={randomizedProducts} />
}
```

Sau khi sửa:

```jsx filename="app/page.js"
export default async function Page() {
  'use cache'
  const products = await getCachedProducts()
  const randomSeed = Math.random()
  const randomizedProducts = randomize(products, randomSeed)
  return <ProductsView products={randomizedProducts} />
}
```

> **Lưu ý**: `"use cache"` là một API mạnh mẽ với một số sắc thái. Nếu cache lifetime của bạn quá ngắn, Next.js vẫn có thể loại trừ nó khỏi prerendering. Xem tài liệu về `"use cache"` để tìm hiểu thêm.

### Chỉ ra giá trị ngẫu nhiên là duy nhất cho mỗi Request

Nếu bạn muốn giá trị ngẫu nhiên được đánh giá trên mỗi Request, hãy đặt trước nó bằng `await connection()`. Next.js sẽ loại trừ Server Component này khỏi HTML được prerender và bao gồm fallback UI từ Suspense boundary gần nhất bao bọc component này thay thế. Khi người dùng thực hiện Request cho trang này, Server Component sẽ được render và UI được cập nhật sẽ stream vào động.

Trước đây:

```jsx filename="app/page.js"
export default async function Page() {
  const products = await getCachedProducts()
  const randomSeed = Math.random()
  const randomizedProducts = randomize(products, randomSeed)
  return <ProductsView products={randomizedProducts} />
}
```

Sau khi sửa:

```jsx filename="app/page.js"
import { connection } from 'next/server'

async function ProductsSkeleton() {
  ...
}

export default async function Page() {
  const products = await getCachedProducts();
  return (
    <Suspense fallback={<ProductsSkeleton />}>
      <DynamicProductsView products={products} />
    </Suspense>
  )
}

async function DynamicProductsView({ products }) {
  await connection();
  const randomSeed = Math.random()
  const randomizedProducts = randomize(products, randomSeed)
  return <ProductsView products={randomizedProducts} />
}
```
