## Tại Sao Lỗi Này Xảy Ra

Một function đang cố gắng đọc từ incoming request hiện tại bên trong scope của một function được chú thích với `"use cache"`. Điều này không được hỗ trợ vì nó sẽ làm cho cache bị invalidated bởi mỗi request, điều này có lẽ không phải là điều bạn dự định.

## Các Cách Có Thể Để Khắc Phục

Thay vì gọi điều này bên trong function `"use cache"`, hãy di chuyển nó ra ngoài function và truyền giá trị vào như một argument. Giá trị cụ thể bây giờ sẽ là một phần của cache key thông qua các arguments của nó.

Trước:

```jsx filename="app/page.js" highlight={5}
import { cookies } from 'next/headers'

async function getExampleData() {
  "use cache"
  const isLoggedIn = (await cookies()).has('token')
  ...
}

export default async function Page() {
  const data = await getExampleData()
  return ...
}
```

Sau:

```jsx filename="app/page.js" highlight={9}
import { cookies } from 'next/headers'

async function getExampleData(isLoggedIn) {
  "use cache"
  ...
}

export default async function Page() {
  const isLoggedIn = (await cookies()).has('token')
  const data = await getExampleData(isLoggedIn)
  return ...
}
```
