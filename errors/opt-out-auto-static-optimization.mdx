## Tại Sao Cảnh Báo Này Xảy Ra

Bạn đang sử dụng `getInitialProps` trong file [Custom `<App>`](/docs/pages/building-your-application/routing/custom-app) của bạn.

Điều này khiến **tất cả các trang** không sử dụng [`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props) chuyển sang Server-side Rendering (tại runtime) và vô hiệu hóa [Tối Ưu Hóa Tĩnh Tự Động](/docs/pages/building-your-application/rendering/automatic-static-optimization).

## Các Cách Có Thể Để Khắc Phục

Xác minh xem bạn có cần sử dụng `getInitialProps` trong `pages/_app` hay không. Có một số trường hợp sử dụng hợp lệ cho điều này, nhưng thường tốt hơn là sử dụng `getInitialProps` trong các trang riêng lẻ.

- Kiểm tra bất kỳ [higher-order components](https://reactjs.org/docs/higher-order-components.html) nào có thể đã thêm `getInitialProps` vào [Custom `<App>`](/docs/pages/building-your-application/routing/custom-app) của bạn.
- Nếu bạn trước đây đã sao chép ví dụ [Custom `<App>`](/docs/pages/building-your-application/routing/custom-app) từ tài liệu cũ, bạn có thể xóa `getInitialProps`.

`getInitialProps` sau đây có thể được xóa:

```jsx filename="pages/_app.js"
class MyApp extends App {
  // Remove me, I do nothing!
  static async getInitialProps({ Component, ctx }) {
    let pageProps = {}

    if (Component.getInitialProps) {
      pageProps = await Component.getInitialProps(ctx)
    }

    return { pageProps }
  }

  render() {
    // ...
  }
}
```
