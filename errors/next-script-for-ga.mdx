title: Sử Dụng Google Analytics Với Next.js (thông qua `next/script`)
---

> Ưu tiên component `next/script` khi sử dụng inline script cho Google Analytics.

## Tại Sao Lỗi Này Xảy Ra

Một inline script đã được sử dụng cho Google Analytics có thể ảnh hưởng đến hiệu suất trang web của bạn. Thay vào đó, chúng tôi khuyến nghị sử dụng `next/script` thông qua thư viện `@next/third-parties`.

## Các Cách Có Thể Để Khắc Phục

### Sử dụng `@next/third-parties` để thêm Google Analytics

**`@next/third-parties`** là một thư viện cung cấp một bộ sưu tập các components và utilities cải thiện hiệu suất và trải nghiệm developer khi tải các thư viện third-party phổ biến trong ứng dụng Next.js của bạn. Nó có sẵn với Next.js 14 (cài đặt `next@latest`).

Component `GoogleAnalytics` có thể được sử dụng để bao gồm [Google Analytics 4](https://developers.google.com/analytics/devguides/collection/ga4) vào trang của bạn thông qua Google tag (`gtag.js`). Theo mặc định, nó fetch các scripts gốc sau khi hydration xảy ra trên trang.

> **Khuyến nghị**: Nếu Google Tag Manager đã được bao gồm trong ứng dụng của bạn, bạn có thể cấu hình Google Analytics trực tiếp bằng cách sử dụng nó, thay vì bao gồm Google Analytics như một component riêng biệt. Tham khảo [tài liệu](https://developers.google.com/analytics/devguides/collection/ga4/tag-options#what-is-gtm) để tìm hiểu thêm về sự khác biệt giữa Tag Manager và `gtag.js`.

Để tải Google Analytics cho tất cả các routes, hãy bao gồm component trực tiếp trong root layout của bạn và truyền vào measurement ID của bạn:

```tsx filename="app/layout.tsx" switcher
import { GoogleAnalytics } from '@next/third-parties/google'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
      <GoogleAnalytics gaId="G-XYZ" />
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import { GoogleAnalytics } from '@next/third-parties/google'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
      <GoogleAnalytics gaId="G-XYZ" />
    </html>
  )
}
```

Để tải Google Analytics cho một route duy nhất, hãy bao gồm component trong file page của bạn:

```jsx filename="app/page.js"
import { GoogleAnalytics } from '@next/third-parties/google'

export default function Page() {
  return <GoogleAnalytics gaId="G-XYZ" />
}
```

> **Cần biết:**
>
> - Nếu bạn đang sử dụng Pages Router, vui lòng tham khảo [tài liệu `pages/`](/docs/pages/guides/third-party-libraries).
> - `@next/third-parties` cũng hỗ trợ [Google Tag Manager](/docs/app/guides/third-party-libraries#google-tag-manager) và các third parties khác.
> - Sử dụng `@next/third-parties` không bắt buộc. Bạn cũng có thể sử dụng component `next/script` trực tiếp. Tham khảo [tài liệu `next/script`](/docs/app/guides/scripts) để tìm hiểu thêm.
