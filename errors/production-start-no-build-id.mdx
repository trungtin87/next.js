title: Không Tìm Thấy Production Build
---

## Tại Sao Lỗi Này Xảy Ra

Khi chạy `next start` hoặc custom server ở chế độ production, cần có một production build.

## Các Cách Có Thể Để Khắc Phục

- Chạy `next build` để tạo production build trước khi khởi động production server.
- Nếu ý định của bạn là chạy development server, hãy chạy `next dev` thay thế.
