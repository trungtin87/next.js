## Tại Sao Lỗi Này Xảy Ra

Một trang không export React Component hợp lệ đã được tìm thấy khi phân tích đầu ra build.

Đây là một lỗi nghiêm trọng vì trang sẽ bị lỗi khi được render, và gây ra hiệu suất build kém.

## Các Cách Có Thể Để Khắc Phục

Điều tra danh sách (các) trang được chỉ định trong thông báo lỗi.
Đối với mỗi trang, bạn sẽ muốn kiểm tra xem file có được dự định là một trang hay không.

Nếu file không được dự định là một trang, và thay vào đó, là một component hoặc file được chia sẻ, hãy di chuyển file đến một thư mục khác như `components` hoặc `lib`.

Nếu file được dự định là một trang, hãy kiểm tra kỹ xem bạn có `export default` với React Component thay vì `export` hay không. Nếu bạn đã sử dụng `export default`, hãy đảm bảo giá trị được trả về là một React Component hợp lệ.

Nếu bạn cần hỗ trợ một phần mở rộng file khác cho một component trang (như `.mdx`) hoặc muốn bao gồm các file không phải trang trong thư mục `pages`, hãy cấu hình [Custom Page Extensions](/docs/pages/api-reference/config/next-config-js/pageExtensions) trong `next.config.js`.
