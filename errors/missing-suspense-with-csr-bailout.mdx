title: Thiếu Suspense boundary với useSearchParams
---

## Tại Sao Lỗi Này Xảy Ra

Đọc các tham số tìm kiếm thông qua `useSearchParams()` mà không có Suspense boundary sẽ chọn tham gia toàn bộ trang vào client-side rendering. Điều này có thể khiến trang của bạn bị trắng cho đến khi JavaScript phía client đã tải xong.

## Các Cách Có Thể Để Khắc Phục

Bạn có một vài tùy chọn tùy thuộc vào ý định của mình:

- Để giữ cho route được tạo tĩnh (statically generated), hãy bọc cây con nhỏ nhất gọi `useSearchParams()` trong `Suspense`, ví dụ bạn có thể di chuyển việc sử dụng nó vào một Client Component con và render component đó được bọc với `Suspense`. Điều này bảo tồn static shell và tránh CSR bailout hoàn toàn.
- Để làm cho route được render động (dynamically rendered), hãy sử dụng hàm [`connection`](/docs/app/api-reference/functions/connection) trong một Server Component (ví dụ: Page hoặc một Layout bao bọc). Điều này chờ một yêu cầu đến và loại trừ mọi thứ bên dưới khỏi việc prerendering.

```tsx filename="app/page.tsx" switcher
import { connection } from 'next/server'

export default async function Page() {
  await connection()
  return <div>...</div>
}
```

```jsx filename="app/page.js" switcher
import { connection } from 'next/server'

export default async function Page() {
  await connection()
  return <div>...</div>
}
```

- Trước khi API `connection` có sẵn, việc đặt `export const dynamic = 'force-dynamic'` trong một Server Component `page.tsx`, hoặc `layout.tsx`, đã chọn tham gia route vào on-demand rendering. Lưu ý rằng việc đặt `dynamic` trong một Client Component (`'use client'`) `page.tsx` không có tác dụng.

```tsx filename="app/layout.tsx" switcher
export const dynamic = 'force-dynamic'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return children
}
```

```jsx filename="app/layout.js" switcher
export const dynamic = 'force-dynamic'

export default function RootLayout({ children }) {
  return children
}
```

- Ngoài ra, một Server Component Page có thể truyền giá trị `searchParams` xuống Client Components. Trong một Client Component, bạn có thể mở gói nó với `use()` của React (đảm bảo một `Suspense` boundary bao quanh). Xem [Sử dụng cái gì và khi nào](/docs/app/getting-started/layouts-and-pages#what-to-use-and-when).

```tsx filename="app/page.tsx" switcher
import { Suspense } from 'react'
import ClientSearch from './client-search'

export default function Page({
  searchParams,
}: {
  searchParams: Promise<{ q?: string }>
}) {
  return (
    <Suspense fallback={<>...</>}>
      <ClientSearch searchParams={searchParams} />
    </Suspense>
  )
}
```

```tsx filename="app/client-search.tsx" switcher
'use client'

import { use } from 'react'

export default function ClientSearch({
  searchParams,
}: {
  searchParams: Promise<{ q?: string }>
}) {
  const params = use(searchParams)
  return <div>Query: {params.q}</div>
}
```

```jsx filename="app/page.js" switcher
import { Suspense } from 'react'
import ClientSearch from './client-search'

export default function Page({ searchParams }) {
  return (
    <Suspense fallback={<>...</>}>
      <ClientSearch searchParams={searchParams} />
    </Suspense>
  )
}
```

```jsx filename="app/client-search.js" switcher
'use client'

import { use } from 'react'

export default function ClientSearch({ searchParams }) {
  const params = use(searchParams)
  return <div>Query: {params.q}</div>
}
```

- Cân nhắc biến Page thành một Server Component một lần nữa và cô lập mã Client-only (sử dụng `useSearchParams`) vào các Client Components con.

```tsx filename="app/search.tsx" switcher
'use client'

import { useSearchParams } from 'next/navigation'
import { Suspense } from 'react'

function Search() {
  const searchParams = useSearchParams()

  return <input placeholder="Search..." />
}

export function Searchbar() {
  return (
    // Bạn cũng có thể có một loading skeleton làm `fallback`
    <Suspense>
      <Search />
    </Suspense>
  )
}
```

```jsx filename="app/search.js" switcher
'use client'

import { useSearchParams } from 'next/navigation'
import { Suspense } from 'react'

function Search() {
  const searchParams = useSearchParams()

  return <input placeholder="Search..." />
}

export function Searchbar() {
  return (
    // Bạn cũng có thể có một loading skeleton làm `fallback`
    <Suspense>
      <Search />
    </Suspense>
  )
}
```

## Vô hiệu hóa

> **Lưu ý**: Điều này chỉ có sẵn với Next.js phiên bản 14.x. Nếu bạn đang ở các phiên bản trên 14, vui lòng sửa nó bằng phương pháp trên.

Chúng tôi không khuyến nghị vô hiệu hóa quy tắc này. Tuy nhiên, nếu bạn cần, bạn có thể vô hiệu hóa nó bằng cách đặt tùy chọn `missingSuspenseWithCSRBailout` thành `false` trong `next.config.js` của bạn:

```js filename="next.config.js"
module.exports = {
  experimental: {
    missingSuspenseWithCSRBailout: false,
  },
}
```

Tùy chọn cấu hình này sẽ bị xóa trong một phiên bản chính trong tương lai.
