## Tại Sao Lỗi Này Xảy Ra

Cấu hình PostCSS tùy chỉnh của dự án cố gắng cấu hình các plugin không cần thiết:

- postcss-modules-values
- postcss-modules-scope
- postcss-modules-extract-imports
- postcss-modules-local-by-default
- postcss-modules

## Các Cách Có Thể Để Khắc Phục

Xóa plugin được chỉ định trong thông báo lỗi khỏi cấu hình PostCSS tùy chỉnh của bạn.

### Làm thế nào để cấu hình CSS Modules?

CSS Modules được hỗ trợ trong [hỗ trợ CSS tích hợp sẵn của Next.js](/docs/pages/guides/post-css).
Bạn có thể [đọc thêm về cách sử dụng CSS Modules tại đây](/docs/pages/guides/post-css).
