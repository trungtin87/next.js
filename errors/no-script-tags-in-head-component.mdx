## Tại Sao Lỗi Này Xảy Ra

Một thẻ `<script>` đã được thêm bằng cách sử dụng component `next/head`.

Để có hiệu suất tốt nhất, chúng tôi khuyến nghị sử dụng `next/script`. Sử dụng `next/script` cũng đảm bảo tương thích với React Suspense và streaming server-rendering.

## Các Cách Có Thể Để Khắc Phục

### Component Script

**Component Script**, [`next/script`](/docs/pages/api-reference/components/script), cho phép bạn tải các script bên thứ ba một cách tối ưu ở bất kỳ đâu trong ứng dụng Next.js của bạn. Nó là một phần mở rộng của phần tử HTML `<script>` và cho phép bạn chọn giữa nhiều chiến lược tải để phù hợp với trường hợp sử dụng của bạn.

```jsx filename="pages/dashboard.js"
import Script from 'next/script'

export default function Dashboard() {
  return (
    <>
      <Script src="https://example.com/script.js" />
    </>
  )
}
```
