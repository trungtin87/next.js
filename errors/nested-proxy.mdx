## Tại Sao Lỗi Này Xảy Ra

Bạn đang định nghĩa một file Proxy ở một vị trí khác với `<root>/proxy`, điều này không được phép.

Trong khi ở bản beta, một file Proxy dưới các trang cụ thể sẽ _chỉ_ được thực thi khi các trang bên dưới khai báo của nó được khớp, cho phép lồng các file Proxy. Dựa trên phản hồi của khách hàng, chúng tôi đã thay thế API này bằng một Proxy gốc duy nhất.

## Các Cách Có Thể Để Khắc Phục

Khai báo Proxy của bạn trong thư mục gốc và sử dụng URL đã phân tích cú pháp của `NextRequest` để xác định đường dẫn nào Proxy nên được thực thi.

Ví dụ, một Proxy tại `pages/about/_proxy.ts` có thể di chuyển logic đến `<root>/proxy.ts` trong thư mục gốc của repository của bạn. Sau đó, một câu lệnh điều kiện có thể được sử dụng để chỉ chạy Proxy khi nó khớp với đường dẫn `about/*`:

```ts filename="proxy.ts"
import type { NextRequest } from 'next/server'

export function proxy(request: NextRequest) {
  if (request.nextUrl.pathname.startsWith('/about')) {
    // Logic này chỉ được áp dụng cho /about
  }

  if (request.nextUrl.pathname.startsWith('/dashboard')) {
    // Logic này chỉ được áp dụng cho /dashboard
  }
}
```

Nếu bạn có nhiều hơn một Proxy, bạn nên kết hợp chúng thành một file duy nhất và mô hình hóa việc thực thi của chúng tùy thuộc vào yêu cầu đến.
