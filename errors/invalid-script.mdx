## Tại Sao Lỗi Này Xảy Ra

Ở đâu đó trong ứng dụng của bạn, bạn đang sử dụng component `next/script` mà không bao gồm một inline script hoặc thuộc tính `src`.

## Các Cách Có Thể Để Khắc Phục

Tìm kiếm bất kỳ việc sử dụng nào của component `next/script` và đảm bảo rằng `src` được cung cấp hoặc một inline script được sử dụng.

**Thuộc tính `src` tương thích**

```jsx
<Script src="https://example.com/analytics.js" />
```

**Inline script tương thích với dấu ngoặc nhọn**

```jsx
<Script id="show-banner">
  {`document.getElementById('banner').classList.remove('hidden')`}
</Script>
```

**Inline script tương thích với `dangerouslySetInnerHtml`**

```jsx
<Script
  id="show-banner"
  dangerouslySetInnerHTML={{
    __html: `document.getElementById('banner').classList.remove('hidden')`,
  }}
/>
```
