## Tại Sao Lỗi Này Xảy Ra

Trong một trong các `getStaticProps` của trang, giá trị trả về có hình dạng không chính xác.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo trả về hình dạng sau từ `getStaticProps`:

```tsx filename="pages/example.tsx"
export async function getStaticProps(ctx: {
    params?: ParsedUrlQuery;
    preview?: boolean;
    previewData?: PreviewData;
}) {
    return {
        props: { [key: string]: any }
    }
}
```
