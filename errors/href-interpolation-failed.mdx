## Tại Sao Lỗi Này Xảy Ra

Ở đâu đó bạn đang sử dụng component `next/link`, `Router#push`, hoặc `Router#replace` với nội suy `href` để xây dựng các routes động nhưng không cung cấp tất cả các params route động cần thiết để nội suy `href` một cách chính xác.

> **Lưu ý**: lỗi này sẽ chỉ hiển thị khi component `next/link` được nhấp vào chứ không phải khi chỉ được render.

**Nội suy `href` không hợp lệ**

```jsx filename="blog-link.js"
import Link from 'next/link'

export default function BlogLink() {
  return (
    <Link
      href={{
        pathname: '/blog/[post]/[comment]',
        query: { post: 'post-1' },
      }}
    >
      <a>Invalid link</a>
    </Link>
  )
}
```

**Nội suy `href` hợp lệ**

```jsx filename="blog-link.js"
import Link from 'next/link'

export default function BlogLink() {
  return (
    <Link
      href={{
        pathname: '/blog/[post]/[comment]',
        query: { post: 'post-1', comment: 'comment-1' },
      }}
    >
      <a>Valid link</a>
    </Link>
  )
}
```

## Các Cách Có Thể Để Khắc Phục

Tìm kiếm bất kỳ việc sử dụng nào của component `next/link`, `Router#push`, hoặc `Router#replace` và đảm bảo rằng `href` được cung cấp có tất cả các params động cần thiết trong query.
