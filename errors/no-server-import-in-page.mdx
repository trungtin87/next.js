> Ngăn chặn việc sử dụng `next/server` bên ngoài `proxy.js`.

## Tại Sao Lỗi Này Xảy Ra

`next/server` đã được import bên ngoài `proxy.{js,ts}`.

## Các Cách Có Thể Để Khắc Phục

Chỉ import và sử dụng `next/server` trong một file nằm trong thư mục gốc của dự án: `proxy.{js,ts}`.

```ts filename="proxy.ts"
import type { NextFetchEvent, NextRequest } from 'next/server'

export function proxy(req: NextRequest, ev: NextFetchEvent) {
  return new Response('Hello, world!')
}
```
