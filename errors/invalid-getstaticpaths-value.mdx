---

## Tại Sao Lỗi Này Xảy Ra

Trong một trong các `getStaticPaths` của trang, giá trị trả về có hình dạng không chính xác.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo trả về hình dạng sau từ `getStaticPaths`:

```js filename="pages/blog/[slug].js"
export async function getStaticPaths() {
  return {
    paths: Array<string | { params: { [key: string]: string } }>,
    fallback: boolean
  }
}
```

Có hai thuộc tính bắt buộc:

### `paths`

Thuộc tính này là một [Mảng](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Array) các URLs ("paths") cần được tạo tĩnh tại thời điểm build. Các paths trả về phải khớp với hình dạng route động.

- Bạn có thể trả về một [Chuỗi](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/String) hoặc một [Đối tượng](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Object) định nghĩa rõ ràng tất cả các `params` URL.

  ```js filename="pages/blog/[slug].js"
  export async function getStaticPaths() {
    return {
      paths: [
        // Biến thể chuỗi:
        '/blog/first-post',
        // Biến thể đối tượng:
        { params: { slug: 'second-post' } },
      ],
      fallback: true,
    }
  }
  ```

### `fallback`

Thuộc tính này có thể là một [Boolean](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Boolean), chỉ định liệu một phiên bản fallback của trang này có nên được tạo hay không, hoặc một chuỗi `'blocking'` để chờ việc tạo:

- Bật `fallback` (thông qua `true`) cho phép bạn trả về một tập hợp con của tất cả các paths có thể cần được tạo tĩnh. Tại runtime, Next.js sẽ tạo tĩnh các paths còn lại **lần đầu tiên chúng được yêu cầu**. Các cuộc gọi liên tiếp đến path sẽ được phục vụ như thể nó đã được tạo tĩnh tại thời điểm build. Điều này giảm thời gian build khi xử lý hàng ngàn hoặc hàng triệu trang.
- Tắt `fallback` (thông qua `false`) yêu cầu bạn trả về bộ sưu tập đầy đủ các paths bạn muốn tạo tĩnh tại thời điểm build. Tại runtime, bất kỳ path nào không được tạo tại thời điểm build **sẽ bị lỗi 404**.
- Nếu `fallback` là `'blocking'`, các paths mới không được trả về bởi getStaticPaths sẽ chờ HTML được tạo, giống hệt như SSR (đó là lý do tại sao gọi là blocking), và sau đó được cache cho các yêu cầu trong tương lai để nó chỉ xảy ra một lần cho mỗi path.
