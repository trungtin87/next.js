## Tại Sao Lỗi Này Xảy Ra

Trong `pages/_document` tùy chỉnh của bạn, một sub-component dự kiến đã không được render.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo import và render tất cả các component `Document` dự kiến:

- `<Html />`
- `<Head />`
- `<Main />`
- `<NextScript />`

Ví dụ:

```tsx filename="pages/_document.tsx"
import Document, { Html, Head, Main, NextScript } from 'next/document'

export default class MyDocument extends Document {
  render() {
    return (
      <Html>
        <Head />
        <body>
          <Main />
          <NextScript />
        </body>
      </Html>
    )
  }
}
```
