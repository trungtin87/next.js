> **Lưu ý**: Bắt đầu từ phiên bản `16`, Next.js không còn hỗ trợ các prop `passHref` và `legacyBehavior` cho component `Link` nữa.

> Đảm bảo `passHref` được sử dụng với các component `Link` tùy chỉnh.

## Tại Sao Lỗi Này Xảy Ra

`passHref` đã không được sử dụng cho một component `Link` bao bọc một component tùy chỉnh. Điều này là cần thiết để truyền `href` cho thẻ con `<a>`.

## Các Cách Có Thể Để Khắc Phục

Nếu bạn đang sử dụng một component tùy chỉnh bao bọc một thẻ `<a>`, hãy đảm bảo thêm `passHref` và `legacyBehavior`:

```jsx filename="nav-link.js"
import Link from 'next/link'
import styled from 'styled-components'

const StyledLink = styled.a`
  color: red;
`

function NavLink({ href, name }) {
  return (
    <Link href={href} passHref legacyBehavior>
      <StyledLink>{name}</StyledLink>
    </Link>
  )
}

export default NavLink
```
