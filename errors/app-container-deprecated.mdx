## Tại Sao Lỗi Này Xảy Ra

Lỗi "App Container Deprecated" thường xảy ra khi bạn đang sử dụng component `<Container>` trong `<App>` tùy chỉnh của mình (`pages/_app.js`). Trước phiên bản `9.0.4` của Next.js, component `<Container>` được sử dụng để xử lý việc cuộn đến các hashes.

Từ phiên bản `9.0.4` trở đi, chức năng này đã được chuyển lên cây component, khiến component `<Container>` trở nên không cần thiết trong `<App>` tùy chỉnh của bạn.

## Các Cách Có Thể Để Khắc Phục

Để giải quyết vấn đề này, bạn cần xóa component `<Container>` khỏi `<App>` tùy chỉnh của mình (`pages/_app.js`).

**Trước**

```jsx filename="pages/_app.js"
import React from 'react'
import App, { Container } from 'next/app'

class MyApp extends App {
  render() {
    const { Component, pageProps } = this.props
    return (
      <Container>
        <Component {...pageProps} />
      </Container>
    )
  }
}

export default MyApp
```

**Sau**

```jsx filename="pages/_app.js"
import React from 'react'
import App from 'next/app'

class MyApp extends App {
  render() {
    const { Component, pageProps } = this.props
    return <Component {...pageProps} />
  }
}

export default MyApp
```

Sau khi thực hiện thay đổi này, `<App>` tùy chỉnh của bạn sẽ hoạt động như mong đợi mà không cần component `<Container>`.
