## Tại Sao Lỗi Này Xảy Ra

Do [sửa lỗi này](https://github.com/vercel/next.js/pull/3849), chúng tôi đã phải xóa hook `Router.onAppUpdated`. Nhưng chức năng mặc định của tính năng này vẫn có hiệu lực.

Chúng tôi sử dụng hook này để phát hiện một triển khai ứng dụng mới khi chuyển trang và hành động tương ứng.

Mặc dù có nhiều thứ bạn có thể làm trong hook này, nó thường được sử dụng để điều hướng trang qua server như được hiển thị bên dưới:

```js filename="example.js"
Router.onAppUpdated = function (nextRoute) {
  location.href = nextRoute
}
```

Trong hook này, bạn không thể chờ một request mạng hoặc một promise được giải quyết. Và bạn không thể chặn điều hướng trang. Vì vậy, những gì bạn có thể làm bị giới hạn.

## Các Cách Có Thể Để Khắc Phục

Một cách sử dụng thực tế của hook này là lưu trạng thái ứng dụng của bạn vào local-storage trước khi điều hướng trang. Để làm điều đó, bạn có thể sử dụng hook [`window.onbeforeunload`](https://developer.mozilla.org/docs/Web/API/WindowEventHandlers/onbeforeunload) thay thế.

Đây là code cho điều đó:

```js filename="example.js"
window.onbeforeunload = function (e) {
  // Get the application state (usually from a store like Redux)
  const appState = {}
  localStorage.setItem('app-state', JSON.stringify(appState))
}
```
