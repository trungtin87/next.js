---
title: Không có con nào được truyền vào `<Link>`
---

> **Lưu ý**: Bắt đầu từ phiên bản `16`, Next.js không còn hỗ trợ prop `legacyBehavior` cho component `Link` nữa. `<Link>` hiện tự động render một phần tử `<a>`, và không giới hạn số lượng con được truyền vào nó.

## Tại Sao Lỗi Này Xảy Ra

Trong mã ứng dụng của bạn, `next/link` đã được sử dụng mà không truyền một con:

Ví dụ:

```jsx filename="pages/index.js"
import Link from 'next/link'

export default function Home() {
  return (
    <>
      <Link href="/about" legacyBehavior></Link>
      // hoặc
      <Link href="/about" legacyBehavior />
    </>
  )
}
```

## Các Cách Có Thể Để Khắc Phục

Đảm bảo sử dụng một con khi sử dụng `<Link>`:

```jsx filename="pages/index.js"
import Link from 'next/link'

export default function Home() {
  return (
    <>
      <Link href="/about">To About</Link>
      // hoặc
      <Link href="/about" legacyBehavior>
        <a>To About</a>
      </Link>
    </>
  )
}
```
