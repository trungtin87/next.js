## Tại Sao Cảnh Báo Này Xảy Ra

Không có object nào được export từ next.config.js hoặc object đó rỗng.

## Các Cách Khắc Phục Có Thể

Kiểm tra xem bạn đã export cấu hình đúng cách trong file `next.config.js` chưa:

```js filename="next.config.js"
module.exports = {
  /* các tùy chọn cấu hình ở đây */
}
```
