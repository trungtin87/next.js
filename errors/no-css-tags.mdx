> Ngăn chặn các thẻ stylesheet thủ công.

## Tại Sao Lỗi Này Xảy Ra

Một phần tử `link` đã được sử dụng để liên kết đến một stylesheet bên ngoài. Điều này có thể ảnh hưởng tiêu cực đến việc tải tài nguyên CSS trên trang web của bạn.

## Các Cách Có Thể Để Khắc Phục

Có nhiều cách để bao gồm styles bằng cách sử dụng hỗ trợ CSS tích hợp của Next.js, bao gồm tùy chọn sử dụng `@import` trong stylesheet gốc được import trong `pages/_app.js`:

```css filename="styles.css"
/* Root stylesheet */
@import 'extra.css';

body {
  /* ... */
}
```

Một tùy chọn khác là sử dụng CSS Modules để import file CSS được phạm vi cụ thể cho component.

```jsx filename="pages/index.js"
import styles from './extra.module.css'

export class Home {
  render() {
    return (
      <div>
        <button type="button" className={styles.active}>
          Open
        </button>
      </div>
    )
  }
}
```

Tham khảo tài liệu [Hỗ trợ CSS Tích hợp](/docs/app/getting-started/css) để tìm hiểu về tất cả các cách để bao gồm CSS vào ứng dụng của bạn.
