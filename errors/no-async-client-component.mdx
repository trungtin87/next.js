title: Không có Client Component Async
---

> Client component không thể là các hàm async.

## Tại Sao Lỗi Này Xảy Ra

Lỗi xảy ra khi bạn cố gắng định nghĩa một Client Component như một hàm async. React Client Components [không hỗ trợ](https://github.com/acdlite/rfcs/blob/first-class-promises/text/0000-first-class-support-for-promises.md#why-cant-client-components-be-async-functions) các hàm async. Ví dụ:

```tsx
'use client'

// Điều này sẽ gây ra lỗi
async function ClientComponent() {
  // ...
}
```

## Các Cách Có Thể Để Khắc Phục

1. **Chuyển đổi thành Server Component**: Nếu có thể, hãy chuyển đổi Client Component của bạn thành Server Component. Điều này cho phép bạn sử dụng `async`/`await` trực tiếp trong component của mình.
2. **Xóa từ khóa `async`**: Nếu bạn cần giữ nó như một Client Component, hãy xóa từ khóa `async` và xử lý data fetching theo cách khác.
3. **Sử dụng React Hooks để fetch dữ liệu**: Sử dụng các hook như `useEffect` để fetch dữ liệu phía client, hoặc sử dụng các thư viện bên thứ ba.
4. **Tận dụng hook `use` với Context Provider**: Truyền promises cho các component con bằng cách sử dụng context, sau đó giải quyết chúng bằng hook `use`.

### Khuyến nghị: Fetch dữ liệu phía server

Chúng tôi khuyến nghị fetch dữ liệu trên server. Ví dụ:

```tsx filename="app/page.tsx"
export default async function Page() {
  const data = await fetch('https://api.vercel.app/blog')
  const posts = await data.json()
  return (
    <ul>
      {posts.map((post) => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  )
}
```

### Sử dụng `use` với Context Provider

Một mẫu khác để khám phá là sử dụng hook `use` của React với Context Provider. Điều này cho phép bạn truyền Promises cho các component con và giải quyết chúng bằng hook `use`. Đây là một ví dụ:

Đầu tiên, hãy tạo một file riêng cho context provider:

```tsx filename="app/context.tsx"
'use client'

import { createContext, useContext } from 'react'

export const BlogContext = createContext<Promise<any> | null>(null)

export function BlogProvider({
  children,
  blogPromise,
}: {
  children: React.ReactNode
  blogPromise: Promise<any>
}) {
  return (
    <BlogContext.Provider value={blogPromise}>{children}</BlogContext.Provider>
  )
}

export function useBlogContext() {
  const context = useContext(BlogContext)
  if (!context) {
    throw new Error('useBlogContext must be used within a BlogProvider')
  }
  return context
}
```

Bây giờ, hãy tạo Promise trong Server Component và stream nó đến client:

```tsx filename="app/page.tsx"
import { BlogProvider } from './context'

export default function Page() {
  const blogPromise = fetch('https://api.vercel.app/blog').then((res) =>
    res.json()
  )

  return (
    <BlogProvider blogPromise={blogPromise}>
      <BlogPosts />
    </BlogProvider>
  )
}
```

Đây là component blog posts:

```tsx filename="app/blog-posts.tsx"
'use client'

import { use } from 'react'
import { useBlogContext } from './context'

export function BlogPosts() {
  const blogPromise = useBlogContext()
  const posts = use(blogPromise)

  return <div>{posts.length} blog posts</div>
}
```

Mẫu này cho phép bạn bắt đầu fetch dữ liệu sớm và truyền Promise xuống các component con, sau đó có thể sử dụng hook `use` để truy cập dữ liệu khi nó sẵn sàng.

### Fetch dữ liệu phía client

Trong các tình huống mà cần fetch phía client, bạn có thể gọi `fetch` trong `useEffect` (không được khuyến nghị), hoặc dựa vào các thư viện React phổ biến trong cộng đồng (như [SWR](https://swr.vercel.app/) hoặc [React Query](https://tanstack.com/query/latest)) để fetch phía client.

```tsx filename="app/page.tsx"
'use client'

import { useState, useEffect } from 'react'

export function Posts() {
  const [posts, setPosts] = useState(null)

  useEffect(() => {
    async function fetchPosts() {
      const res = await fetch('https://api.vercel.app/blog')
      const data = await res.json()
      setPosts(data)
    }
    fetchPosts()
  }, [])

  if (!posts) return <div>Loading...</div>

  return (
    <ul>
      {posts.map((post) => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  )
}
```
