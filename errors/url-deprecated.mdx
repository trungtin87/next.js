## Tại Sao Lỗi Này Xảy Ra

Trong các phiên bản trước 6.x, thuộc tính `url` được tự động chèn vào mọi component `Page` (mọi trang bên trong thư mục `pages`).

Lý do điều này bị loại bỏ là vì chúng tôi muốn làm cho mọi thứ trở nên rất dự đoán được và rõ ràng. Việc có một thuộc tính url kỳ diệu xuất hiện từ đâu không giúp ích cho mục tiêu đó.

> **Lưu ý**: ⚠️ Trong một số trường hợp, việc sử dụng React Dev Tools có thể kích hoạt cảnh báo này ngay cả khi bạn không tham chiếu `url` ở bất kỳ đâu trong code của mình. Hãy thử tạm thời vô hiệu hóa extension và xem liệu cảnh báo có còn tồn tại không.

## Các Cách Khắc Phục Có Thể

Kể từ Next 5, chúng tôi cung cấp một cách để chèn rõ ràng đối tượng router của Next.js vào các trang và tất cả các component con của chúng.
Thuộc tính `router` được chèn vào sẽ giữ các giá trị giống như `url`, như `pathname`, `asPath`, và `query`.

Đây là một ví dụ về việc sử dụng `withRouter`:

```jsx filename="pages/index.js"
import { withRouter } from 'next/router'

class Page extends React.Component {
  render() {
    const { router } = this.props
    console.log(router)
    return <div>{router.pathname}</div>
  }
}

export default withRouter(Page)
```

Chúng tôi cung cấp một codemod (một chuyển đổi từ code sang code) để tự động thay đổi các cách sử dụng thuộc tính `url` thành `withRouter`.

Bạn có thể tìm thấy codemod này và hướng dẫn về cách chạy nó tại đây: [Sử dụng `withRouter`](/docs/pages/guides/upgrading/codemods#url-to-withrouter)
