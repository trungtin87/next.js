---
title: Đã Bắt Lỗi Static Bail Out
---

## Tại Sao Lỗi Này Xảy Ra

Khi Partial Prerendering (PPR) được bật, việc sử dụng các API chọn Dynamic Rendering như `cookies`, `headers`, hoặc `fetch` (chẳng hạn như với `cache: 'no-store'` hoặc `revalidate: 0`) sẽ khiến React throw một error object đặc biệt để biết phần nào của trang không thể được tạo tĩnh - trong khi vẫn để phần còn lại của nó là partial static. Nếu bạn bắt lỗi này, việc tạo bất kỳ dữ liệu tĩnh nào là không an toàn và build của bạn sẽ thất bại.

## Các Cách Có Thể Để Khắc Phục

- Đảm bảo rằng bạn không bọc các API Next.js chọn dynamic rendering trong một khối `try/catch`.
- Nếu bạn bọc các API này trong try/catch, hãy đảm bảo bạn re-throw lỗi gốc để nó có thể được Next.js bắt.
- Ngoài ra, chèn [`unstable_noStore()`](/docs/app/api-reference/functions/unstable_noStore) trước try/catch.

```js
import { unstable_noStore } from 'next/cache'

async function fetchData() {
  unstable_noStore() // opt out trước khi chúng ta đến try/catch
  try {
    const response = await fetch(url);
    ...
  } catch (x) {
    ...
  }
}
```
