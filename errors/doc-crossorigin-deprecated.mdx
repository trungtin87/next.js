## Tại Sao Lỗi Này Xảy Ra

Tùy chọn này đã được chuyển sang `next.config.js`.

## Các Cách Có Thể Để Khắc Phục

Thêm tùy chọn cấu hình:

```js filename="next.config.js"
module.exports = {
  crossOrigin: 'anonymous',
}
```
