## Tại Sao Lỗi Này Xảy Ra

Server đã được khởi động trên một port dành riêng. Ví dụ, `4045` được dành riêng cho Network Paging Protocol (npp).

```bash filename="Terminal"
next start -p 4045
```

hoặc

```bash filename="Terminal"
next dev --port 4045
```

Khởi động server trên một port dành riêng sẽ dẫn đến lỗi.

## Các Cách Có Thể Để Khắc Phục

Thay đổi port được cung cấp để đảm bảo nó không được liệt kê trong phần [Port Blocking](https://fetch.spec.whatwg.org/#port-blocking) của fetch spec của WHATWG.
