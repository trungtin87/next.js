## Tại Sao Lỗi Này Xảy Ra

Trong một trong các API routes của bạn, mã trạng thái 204 hoặc 304 đã được sử dụng đồng thời gửi một body phản hồi.

Điều này là không hợp lệ vì mã trạng thái 204 hoặc 304 quy định không nên có body phản hồi.

## Các Cách Có Thể Để Khắc Phục

Gửi một body trống khi sử dụng mã trạng thái 204 hoặc 304 hoặc sử dụng một mã trạng thái khác trong khi gửi một body phản hồi.

Trước

```js filename="pages/api/example.js"
export default function handler(req, res) {
  res.status(204).send('invalid body')
}
```

Sau

```js filename="pages/api/example.js"
export default function handler(req, res) {
  res.status(204).end()
}
```
