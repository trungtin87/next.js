## Tại Sao Lỗi Này Xảy Ra

Dự án của bạn đang sử dụng một phiên bản cũ của `react` hoặc `react-dom` không đáp ứng yêu cầu phiên bản tối thiểu được đề xuất.

Next.js đề xuất sử dụng tối thiểu `react@18.2.0` và `react-dom@18.2.0`.
Các phiên bản cũ hơn của `react` và `react-dom` vẫn hoạt động với Next.js, tuy nhiên, chúng không kích hoạt tất cả các tính năng của Next.js.

Ví dụ, các tính năng sau không được kích hoạt với các phiên bản React cũ:

- [Fast Refresh](/docs/architecture/fast-refresh): xem ngay các chỉnh sửa đối với ứng dụng của bạn mà không làm mất trạng thái component
- Component stack trace trong development: xem cây component dẫn đến lỗi
- Cảnh báo không khớp hydration: truy tìm các sự khác biệt trong React tree của bạn gây ra vấn đề hiệu suất

Danh sách này không đầy đủ, nhưng minh họa giá trị của việc nâng cấp React!

## Các Cách Có Thể Để Khắc Phục

**Thông qua npm**

```bash filename="Terminal"
npm upgrade react@latest react-dom@latest
```

**Thông qua Yarn**

```bash filename="Terminal"
yarn add react@latest react-dom@latest
```

**Thủ công** Mở `package.json` của bạn và nâng cấp `react` và `react-dom`:

```json filename="package.json"
{
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0"
  }
}
```
