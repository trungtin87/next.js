---
title: 'Ném ra `undefined` / `null`'
---

## Tại Sao Lỗi Này Xảy Ra

Ở đâu đó trong code của bạn, bạn `throw` một giá trị `undefined` hoặc `null`. Vì đây không phải là một lỗi hợp lệ nên không có stack trace. Chúng tôi hiển thị lỗi này để cho bạn biết cần tìm kiếm điều gì.

```js filename="pages/index.js"
function getData() {
  let error
  throw error
}

function Page() {
  const error = data?.error || null
  throw error
}
```

## Các Cách Khắc Phục Có Thể

Tìm trong các trang của bạn và tìm nơi mà một lỗi có thể ném ra các giá trị `undefined` hoặc `null` và đảm bảo sử dụng `new Error()` thay thế.
