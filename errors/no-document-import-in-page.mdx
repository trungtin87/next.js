title: Không Import Document trong Page
---

> Ngăn chặn việc import `next/document` bên ngoài `pages/_document.js`.

## Tại Sao Lỗi Này Xảy Ra

`next/document` đã được import trong một trang bên ngoài `pages/_document.js` (hoặc `pages/_document.tsx` nếu bạn đang sử dụng TypeScript). Điều này có thể gây ra các vấn đề không mong muốn trong ứng dụng của bạn.

## Các Cách Có Thể Để Khắc Phục

Chỉ import và sử dụng `next/document` trong `pages/_document.js` (hoặc `pages/_document.tsx`) để ghi đè component `Document` mặc định:

```jsx filename="pages/_document.js"
import Document, { Html, Head, Main, NextScript } from 'next/document'

class MyDocument extends Document {
  //...
}

export default MyDocument
```
