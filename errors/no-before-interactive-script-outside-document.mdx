---
title: Không có Script Before Interactive bên ngoài Document
---

> Ngăn chặn việc sử dụng chiến lược `beforeInteractive` của `next/script` bên ngoài `app/layout.jsx` hoặc `pages/_document.js`.

## Tại Sao Lỗi Này Xảy Ra

Bạn không thể sử dụng component `next/script` với chiến lược `beforeInteractive` bên ngoài `app/layout.jsx` hoặc `pages/_document.js`. Đó là vì chiến lược `beforeInteractive` chỉ hoạt động bên trong **`app/layout.jsx`** hoặc **`pages/_document.js`** và được thiết kế để tải các script cần thiết cho toàn bộ trang web (tức là script sẽ tải khi bất kỳ trang nào trong ứng dụng đã được tải phía server).

## Các Cách Có Thể Để Khắc Phục

### App Router

Nếu bạn muốn một script toàn cục, và bạn đang sử dụng App Router, hãy di chuyển script vào trong `app/layout.jsx`.

```jsx filename="app/layout.jsx"
import Script from 'next/script'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
      <Script
        src="https://example.com/script.js"
        strategy="beforeInteractive"
      />
    </html>
  )
}
```

### Pages Router

Nếu bạn muốn một script toàn cục, và bạn đang sử dụng Pages Router, hãy di chuyển script vào trong `pages/_document.js`.

```jsx filename="pages/_document.js"
import { Html, Head, Main, NextScript } from 'next/document'
import Script from 'next/script'

export default function Document() {
  return (
    <Html>
      <Head />
      <body>
        <Main />
        <NextScript />
        <Script
          src="https://example.com/script.js"
          strategy="beforeInteractive"
        ></Script>
      </body>
    </Html>
  )
}
```
