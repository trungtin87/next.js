## Tại Sao Lỗi Này Xảy Ra

Bạn đã truyền một tham số null hoặc undefined vào lệnh gọi `next()`.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo bạn đang truyền các biến đúng cách:

```js filename="server.js"
const app = next()
```

Và đảm bảo bạn đang truyền dev như được hiển thị trong các ví dụ bên dưới:

```js filename="server.js"
const app = next({ dev: boolean })
```
