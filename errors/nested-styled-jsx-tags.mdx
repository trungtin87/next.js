## Tại Sao Lỗi Này Xảy Ra

Bạn đã lồng các thẻ `<style jsx>` trong một component. Các thẻ `<style jsx>` phải ở gốc của phạm vi `styled-jsx`.

## Các Cách Có Thể Để Khắc Phục

**Trước**

```jsx filename="example.js"
const Component = () => (
  <div>
    <p>
      Hello world
      <style jsx>{`
        p {
          color: white;
        }
      `}</style>
    </p>
    <style global jsx>{`
      body {
        background: black;
      }
    `}</style>
  </div>
)
```

**Sau**

```jsx filename="example.js"
const Component = () => (
  <div>
    <p>Hello world</p>
    <style jsx>{`
      p {
        color: white;
      }
    `}</style>
    <style global jsx>{`
      body {
        background: black;
      }
    `}</style>
  </div>
)
```
