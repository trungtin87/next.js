## Tại Sao Lỗi Này Xảy Ra

Lỗi không tìm thấy module có thể xảy ra vì nhiều lý do khác nhau:

- Module bạn đang cố gắng import không được cài đặt trong dependencies của bạn
- Module bạn đang cố gắng import nằm trong một thư mục khác
- Module bạn đang cố gắng import có casing (chữ hoa/thường) khác
- Module bạn đang cố gắng import sử dụng các module cụ thể của Node.js, ví dụ `dns`, bên ngoài `getStaticProps` / `getStaticPaths` / `getServerSideProps`

## Các Cách Có Thể Để Khắc Phục

### Module bạn đang cố gắng import không được cài đặt trong dependencies của bạn

Khi import một module từ [npm](https://npmjs.com), module này phải được cài đặt cục bộ.

Ví dụ khi import gói `swr`:

```js filename="example.js"
import useSWR from 'swr'
```

Module `swr` phải được cài đặt bằng trình quản lý gói.

- Khi sử dụng `npm`: `npm install swr`
- Khi sử dụng `yarn`: `yarn add swr`

### Module bạn đang cố gắng import nằm trong một thư mục khác

Đảm bảo rằng đường dẫn bạn đang import tham chiếu đến đúng thư mục và file.

### Module bạn đang cố gắng import có casing khác

Đảm bảo casing của file là chính xác.

Ví dụ:

```jsx filename="components/MyComponent.js"
export default function MyComponent() {
  return <h1>Hello</h1>
}
```

```jsx filename="pages/index.js"
// Lưu ý cách `components/MyComponent` tồn tại nhưng `Mycomponent` không có chữ `c` viết hoa được import
import MyComponent from '../components/Mycomponent'
```

Casing không chính xác sẽ dẫn đến lỗi build trên các môi trường phân biệt chữ hoa chữ thường như hầu hết các tích hợp liên tục (CI) dựa trên Linux và có thể gây ra sự cố với Fast Refresh.

### Module bạn đang cố gắng import sử dụng các module cụ thể của Node.js

`getStaticProps`, `getStaticPaths`, và `getServerSideProps` cho phép sử dụng các module chỉ có thể chạy trong môi trường Node.js. Điều này cho phép bạn thực hiện các truy vấn cơ sở dữ liệu trực tiếp hoặc đọc dữ liệu từ Redis để nêu tên một vài ví dụ.

Tree shaking chỉ chạy trên các trang cấp cao nhất, vì vậy nó không thể được dựa vào trong các React components riêng biệt.

Bạn có thể xác minh tree shaking trên [next-code-elimination.vercel.app](https://next-code-elimination.vercel.app/).

Ví dụ về mã được tree-shaken chính xác:

```js filename="lib/redis.js"
import Redis from 'ioredis'

const redis = new Redis(process.env.REDIS_URL)

export default redis
```

```jsx filename="pages/index.js"
import redis from '../lib/redis'

export async function getStaticProps() {
  const message = await redis.get('message')
  return {
    message,
  }
}

export default function Home({ message }) {
  return <h1>{message}</h1>
}
```

Ví dụ về mã sẽ bị lỗi:

```js filename="lib/redis.js"
import Redis from 'ioredis'

const redis = new Redis(process.env.REDIS_URL)

export default redis
```

```jsx filename="pages/index.js"
// Redis là một thư viện cụ thể của Node.js không thể chạy trong trình duyệt
// Cố gắng sử dụng nó trong mã chạy trên cả Node.js và trình duyệt sẽ dẫn đến lỗi không tìm thấy module cho các module mà ioredis dựa vào
// Nếu bạn gặp phải lỗi như vậy, bạn nên di chuyển mã sang `getStaticProps` hoặc `getServerSideProps` vì các phương thức đó đảm bảo rằng mã chỉ được chạy trong Node.js.
import redis from '../lib/redis'
import { useEffect, useState } from 'react'

export default function Home() {
  const [message, setMessage] = useState()
  useEffect(() => {
    redis.get('message').then((result) => {
      setMessage(result)
    })
  }, [])
  return <h1>{message}</h1>
}
```

Ví dụ về mã sẽ bị lỗi:

```js filename="lib/redis.js"
import Redis from 'ioredis'

// Các module chứa mã chỉ dành cho Node.js cũng không thể export React components
// Tree shaking của getStaticProps/getStaticPaths/getServerSideProps chỉ được chạy trên các file trang
const redis = new Redis(process.env.REDIS_URL)

export function MyComponent() {
  return <h1>Hello</h1>
}

export default redis
```

```jsx filename="pages/index.js"
// Trong thực tế, bạn sẽ muốn cấu trúc lại `MyComponent` thành một file riêng biệt để tree shaking đảm bảo rằng import cụ thể đó không được bao gồm cho quá trình biên dịch trình duyệt
import redis, { MyComponent } from '../lib/redis'

export async function getStaticProps() {
  const message = await redis.get('message')
  return {
    message,
  }
}

export default function Home() {
  return <MyComponent />
}
```
