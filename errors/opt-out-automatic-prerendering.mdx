## Tại Sao Cảnh Báo Này Xảy Ra

Bạn đang sử dụng `getInitialProps` trong [Custom `<App>`](/docs/pages/building-your-application/routing/custom-app) của bạn.

Điều này khiến **tất cả các trang** được thực thi trên server -- vô hiệu hóa [Tối Ưu Hóa Tĩnh Tự Động](/docs/pages/building-your-application/rendering/automatic-static-optimization).

## Các Cách Có Thể Để Khắc Phục

Hãy chắc chắn rằng bạn có ý định sử dụng `getInitialProps` trong `pages/_app`!
Có một số trường hợp sử dụng hợp lệ cho điều này, nhưng thường tốt hơn là xử lý `getInitialProps` trên cơ sở _từng trang_.

Nếu bạn trước đây đã sao chép ví dụ [Custom `<App>`](/docs/pages/building-your-application/routing/custom-app), bạn có thể xóa `getInitialProps` của mình.

`getInitialProps` sau đây không làm gì và có thể được xóa:

```jsx filename="pages/_app.js"
class MyApp extends App {
  // Remove me, I do nothing!
  static async getInitialProps({ Component, ctx }) {
    let pageProps = {}

    if (Component.getInitialProps) {
      pageProps = await Component.getInitialProps(ctx)
    }

    return { pageProps }
  }

  render() {
    // ...
  }
}
```
