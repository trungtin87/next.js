## Tại Sao Lỗi Này Xảy Ra

Giá trị `redirect` được trả về từ hàm `getStaticProps` hoặc `getServerSideProps` của bạn có các giá trị không hợp lệ.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo bạn trả về các giá trị thích hợp cho giá trị `redirect`.

```tsx filename="pages/index.tsx" switcher
import type { InferGetStaticPropsType, GetStaticProps } from 'next'

type Repo = {
  name: string
  stargazers_count: number
}

export const getStaticProps = (async (context) => {
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const repo = await res.json()

  if (!repo) {
    return {
      redirect: {
        permanent: false, // hoặc true
        destination: '/404',
      },
    }
  }

  return { props: { repo } }
}) satisfies GetStaticProps<{
  repo: Repo
}>

export default function Page({
  repo,
}: InferGetStaticPropsType<typeof getStaticProps>) {
  return repo.stargazers_count
}
```

```jsx filename="pages/index.js" switcher
export async function getStaticPaths() {
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const repo = await res.json()

  if (!repo) {
    return {
      redirect: {
        permanent: false, // hoặc true
        destination: '/404',
      },
    }
  }

  return { props: { repo } }
}

export default function Page({ repo }) {
  return repo.stargazers_count
}
```
