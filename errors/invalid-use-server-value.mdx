## Tại Sao Lỗi Này Xảy Ra

Lỗi này xảy ra khi một file `"use server"` export một giá trị không phải là một hàm async. Điều này có thể xảy ra khi bạn vô tình export một cái gì đó như một đối tượng cấu hình, một giá trị tùy ý, hoặc bỏ lỡ từ khóa `async` trong khai báo hàm được export.

Các hàm này được yêu cầu phải được định nghĩa là async, bởi vì `"use server"` đánh dấu chúng là [Server Actions](/docs/app/getting-started/updating-data) và chúng có thể được gọi trực tiếp từ client thông qua một yêu cầu mạng.

Ví dụ về mã không chính xác:

```js
'use server'

// ❌ Điều này là không chính xác: chỉ các hàm async được phép.
export const value = 1

// ❌ Điều này là không chính xác: bỏ lỡ từ khóa `async`.
export function getServerData() {
  return '...'
}
```

Mã chính xác:

```js
'use server'

// ✅ Điều này là chính xác: một hàm async được export.
export async function getServerData() {
  return '...'
}
```

## Các Cách Có Thể Để Khắc Phục

Kiểm tra tất cả các giá trị được export trong file `"use server"` (bao gồm `export *`) và đảm bảo rằng tất cả chúng đều được định nghĩa là các hàm async.
