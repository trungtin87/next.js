---
title: '`future.webpack5` đã được chuyển sang `webpack5`'
---

## Tại Sao Lỗi Này Xảy Ra

Tùy chọn `future.webpack5` đã được chuyển sang `webpack5` trong `next.config.js`.

## Các Cách Có Thể Để Khắc Phục

Nếu bạn có giá trị `true`, bạn có thể xóa tùy chọn này vì webpack 5 hiện là mặc định cho tất cả các ứng dụng Next.js trừ khi chọn không tham gia.

Nếu bạn có giá trị `false`, bạn có thể cập nhật `next.config.js`:

Thay đổi `future.webpack5` thành `webpack5`.

`next.config.js` hiện tại:

```js filename="next.config.js"
module.exports = {
  future: {
    webpack5: false,
  },
}
```

`next.config.js` đã cập nhật:

```js filename="next.config.js"
module.exports = {
  webpack5: false,
}
```
