## Tại Sao Lỗi Này Xảy Ra

Một trong các dependencies (`node_modules`) của bạn import một file CSS.

Điều này thường xảy ra khi các file nguồn của một gói (package) vô tình được sử dụng, thay vì gói đã được build.

## Các Cách Có Thể Để Khắc Phục

Liên hệ với người bảo trì (maintainer) và yêu cầu họ xuất bản một phiên bản đã biên dịch của dependency của họ.

Các dependencies đã biên dịch không có tham chiếu đến các file CSS, hoặc bất kỳ file nào khác yêu cầu tích hợp cụ thể của bundler.

Dependency cũng nên cung cấp hướng dẫn về những CSS nào cần được import bởi bạn, trong ứng dụng của bạn.

Việc import các file CSS trong `node_modules` không thể được hỗ trợ vì chúng tôi không thể biết hành vi chính xác:

- File có nên được sử dụng như Global CSS hay CSS Modules không?
- Nếu là Global, file cần được inject theo thứ tự nào?
- Nếu là Modules, tên class được phát ra là gì? Giữ nguyên, camel-case, snake case?
- Vân vân.
