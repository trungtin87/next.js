## Tại Sao Lỗi Này Xảy Ra

Trong một trong các trang hoặc API Routes của bạn, bạn đã sử dụng `export const config` với một giá trị không hợp lệ.

## Các Cách Có Thể Để Khắc Phục

- `config` của trang phải là một object được khởi tạo trực tiếp khi được export và không được sửa đổi động.
- Object `config` chỉ được chứa các literal hằng số tĩnh mà không có biểu thức.

  <tr>
    <th>Không Được Phép</th>

```js
// `config` nên là một object
```

```js
// `config.runtime` chứa một biểu thức động
export const config = {
```

```js
export const config = {
  runtime: 'nodejs',
}
export const config = {
  runtime: `edge`,
}
```
