---
title: Cấu Hình PostCSS Là Một Function
---

## Tại Sao Lỗi Này Xảy Ra

Cấu hình PostCSS tùy chỉnh của dự án export một function thay vì một object.

## Các Cách Có Thể Để Khắc Phục

Điều chỉnh cấu hình PostCSS tùy chỉnh để không export một function. Thay vào đó, trả về một plain object.

Nếu bạn cần thông tin môi trường, hãy đọc nó từ `process.env`.

**Trước**

```js filename="postcss.config.js"
module.exports = ({ env }) => ({
  plugins: {
    'postcss-plugin': env === 'production' ? {} : false,
  },
})
```

**Sau**

```js filename="postcss.config.js"
module.exports = {
  plugins: {
    'postcss-plugin': process.env.NODE_ENV === 'production' ? {} : false,
  },
}
```
