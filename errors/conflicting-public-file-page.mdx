---

## Tại Sao Lỗi Này Xảy Ra

Một trong các public files của bạn có cùng đường dẫn với một page file, điều này không được hỗ trợ. Vì chỉ có một tài nguyên có thể tồn tại tại URL, cả public files và page files đều phải là duy nhất.

## Các Cách Có Thể Để Khắc Phục

Đổi tên hoặc public file hoặc page file đang gây ra xung đột.

Ví dụ xung đột giữa public file và page file

```bash filename="Cấu trúc thư mục"
public/
  hello
pages/
  hello.js
```

Public file và page file không xung đột

```bash filename="Cấu trúc thư mục"
public/
  hello.txt
pages/
  hello.js
```
