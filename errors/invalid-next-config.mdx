---

## Tại sao lỗi này xảy ra

Trong file `next.config.js` của bạn, bạn đã truyền các tùy chọn không hợp lệ, hoặc là sai kiểu dữ liệu hoặc là một trường không xác định. Cảnh báo này được hiển thị để giúp bắt các lỗi chính tả, các tùy chọn đã lỗi thời hoặc đã được cập nhật.

## Các cách có thể để khắc phục

Bạn có thể sử dụng kiểu `NextConfig` để giúp đảm bảo config của bạn là chính xác.

```js filename="next.config.js"
/**
 * @type {import('next').NextConfig}
 */
const nextConfig = {
  /* các tùy chọn config ở đây */
}

module.exports = nextConfig
```

Ngoài ra, bạn có thể sử dụng `next.config.ts` để có an toàn kiểu và tự động hoàn thành tốt hơn:

```ts filename="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  /* các tùy chọn config ở đây */
}

export default nextConfig
```

### Các tùy chọn đã lỗi thời hoặc đã được cập nhật

Một số tùy chọn cấu hình đã bị xóa hoặc cập nhật trong các phiên bản gần đây của Next.js. Ví dụ:

- Tùy chọn cấu hình `eslint` đã bị xóa khỏi `next.config`. Xóa tùy chọn `eslint` và sử dụng ESLint CLI thay thế. Xem tài liệu [ESLint](/docs/app/api-reference/config/eslint).
- Cấu hình `experimental.turbo` đã chuyển sang cấu hình `turbopack` cấp cao nhất. Xem tài liệu [tùy chọn `turbopack`](/docs/app/api-reference/config/next-config-js/turbopack).

Xem [tài liệu `next.config.js`](/docs/app/api-reference/config/next-config-js) để biết danh sách tất cả các tùy chọn có sẵn và cũ.
