## Tại Sao Lỗi Này Xảy Ra

Ứng dụng của bạn đang tương tác với `req.ua` đã bị phản đối (deprecated).

```ts filename="proxy.ts"
import { NextRequest, NextResponse } from 'next/server'

export function proxy(request: NextRequest) {
  const viewport = request.ua.device.type === 'mobile' ? 'mobile' : 'desktop'

  request.nextUrl.searchParams.set('viewport', viewport)
  return NextResponse.rewrite(request.nextUrl)
}
```

## Các Cách Có Thể Để Khắc Phục

Logic nội bộ đã được chuyển vào một hàm `userAgent` riêng biệt mà bạn có thể import từ `next/server` và bọc request của bạn thay thế.

```ts filename="proxy.ts"
import { NextRequest, NextResponse, userAgent } from 'next/server'

export function proxy(request: NextRequest) {
  const { device } = userAgent(request)
  const viewport = device.type === 'mobile' ? 'mobile' : 'desktop'

  request.nextUrl.searchParams.set('viewport', viewport)
  return NextResponse.rewrite(request.nextUrl)
}
```
