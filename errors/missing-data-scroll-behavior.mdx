title: Thiếu thuộc tính data-scroll-behavior cho Smooth Scroll
---

## Tại Sao Cảnh Báo Này Xảy Ra

Ứng dụng của bạn đã bật cuộn mượt mà (smooth scrolling) thông qua CSS (`scroll-behavior: smooth`), nhưng bạn chưa thêm thuộc tính `data-scroll-behavior="smooth"` vào phần tử `<html>` của mình.

Next.js tự động cố gắng phát hiện cấu hình cuộn mượt mà để đảm bảo rằng việc điều hướng quay lại/tiến tới thông qua router không kích hoạt hành vi cuộn mượt mà, vì điều này thường không mong muốn.

## Các Cách Có Thể Để Khắc Phục

Thêm `data-scroll-behavior="smooth"` vào phần tử `<html>` của bạn nếu bạn muốn vô hiệu hóa cuộn mượt mà khi định tuyến qua Next.js.

```tsx filename="app/layout.tsx" switcher
export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" data-scroll-behavior="smooth">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
export default function RootLayout({ children }) {
  return (
    <html lang="en" data-scroll-behavior="smooth">
      <body>{children}</body>
    </html>
  )
}
```

## Tại Sao Tối Ưu Hóa Này Quan Trọng

Next.js sẽ chỉ cố gắng sửa đổi kiểu `scroll-behavior` trên phần tử `<html>` khi thuộc tính data có mặt để đảm bảo cuộn mượt mà không được kích hoạt. Điều này tránh việc tính toán lại kiểu không cần thiết trừ khi được chọn tham gia một cách rõ ràng.
