title: Re-export tất cả các exports từ một trang bị cấm
---

## Tại Sao Lỗi Này Xảy Ra

Việc export sau đây có khả năng phá vỡ quá trình biên dịch các trang của Next.js:

```jsx filename="pages/example.js"
export * from '...'
```

Điều này là do mã Node.js có thể bị rò rỉ sang bản build trình duyệt, gây ra lỗi. Ví dụ, hai trang sau:

```jsx filename="pages/example-a.js"
import fs from 'fs'

export default function A() {
  return <main />
}

export function getStaticProps() {
  fs
  return { props: {} }
}
```

```jsx filename="pages/example-b.js"
export * from './example-a'
```

Sẽ gây ra lỗi sau:

```txt
Module not found: Can't resolve 'fs' in './pages/example-b.js'
```

## Các Cách Có Thể Để Khắc Phục

Cập nhật trang của bạn để chỉ re-export component mặc định:

```jsx filename="pages/example-a.js"
export { default } from './example-b'
```

Nếu trang khác sử dụng `getServerSideProps` hoặc `getStaticProps`, bạn cũng có thể re-export chúng riêng lẻ:

```jsx filename="pages/example-a.js"
export { default, getServerSideProps } from './example-b'
// hoặc
export { default, getStaticProps } from './example-b'
// hoặc
export { default, getStaticProps, getStaticPaths } from './example-b/[dynamic]'
```
