---
title: Không có Script trong Document
---

> Ngăn chặn việc sử dụng `next/script` trong `pages/_document.js`.

> **Lưu ý**: ⚠️ Lỗi này không liên quan trong các phiên bản Next.js 12.1.6 trở lên. Vui lòng tham khảo [thông báo lỗi đã cập nhật](/docs/messages/no-before-interactive-script-outside-document).

## Tại Sao Lỗi Này Xảy Ra

Bạn không nên sử dụng component `next/script` trong `pages/_document.js` trong các phiên bản Next.js trước 12.1.6. Đó là vì trang `pages/_document.js` chỉ chạy trên server và `next/script` có chức năng phía client để đảm bảo thứ tự tải.

## Các Cách Có Thể Để Khắc Phục

Nếu bạn muốn một script toàn cục, hãy sử dụng `next/script` trong `pages/_app.js` thay thế.

```jsx filename="pages/_app.js"
import Script from 'next/script'

function MyApp({ Component, pageProps }) {
  return (
    <>
      <Script src="/my-script.js" />
      <Component {...pageProps} />
    </>
  )
}

export default MyApp
```
