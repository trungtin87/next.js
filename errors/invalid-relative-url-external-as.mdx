## Tại Sao Lỗi Này Xảy Ra

Ở đâu đó bạn đang sử dụng component `next/link`, `Router#push`, hoặc `Router#replace` với một route tương đối trong `href` của bạn có giá trị `as` bên ngoài. Giá trị `as` cũng phải là tương đối hoặc chỉ `href` nên được sử dụng với một URL bên ngoài.

> **Lưu ý**: lỗi này sẽ chỉ hiển thị khi component `next/link` được nhấp vào chứ không phải khi chỉ được render.

**`href` và `as` không tương thích**

```jsx filename="pages/example.js"
import Link from 'next/link'

export default function Page(props) {
  return (
    <>
      <Link href="/invalid" as="mailto:john@example.com">
        <a>Invalid link</a>
      </Link>
    </>
  )
}
```

**`href` và `as` tương thích**

```jsx filename="pages/example.js"
import Link from 'next/link'

export default function Page(props) {
  return (
    <>
      <Link href="mailto:john@example.com">
        <a>Invalid link</a>
      </Link>
    </>
  )
}
```

## Các Cách Có Thể Để Khắc Phục

Tìm kiếm bất kỳ việc sử dụng nào của component `next/link`, `Router#push`, hoặc `Router#replace` và đảm bảo rằng các giá trị `href` và `as` được cung cấp là tương thích.
