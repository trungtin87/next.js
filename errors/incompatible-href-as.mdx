---

## Tại Sao Lỗi Này Xảy Ra

Ở đâu đó bạn đang sử dụng component `next/link`, `Router#push`, hoặc `Router#replace` với một route động trong `href` của bạn có giá trị `as` không tương thích. Giá trị `as` không tương thích khi đường dẫn không cung cấp chỉ các tham số mong đợi cho route động.

> **Lưu ý**: lỗi này sẽ chỉ hiển thị khi component `next/link` được nhấp vào chứ không phải khi chỉ được render.

**`href` và `as` không tương thích**

```jsx filename="pages/blog.js"
import Link from 'next/link'

export default function Page(props) {
  return (
    <>
      <Link href="/[post]" as="/post-1/comments">
        <a>Invalid link</a>
      </Link>
    </>
  )
}
```

**`href` và `as` tương thích**

```jsx filename="pages/blog.js"
import Link from 'next/link'

export default function Page(props) {
  return (
    <>
      <Link href="/[post]" as="/post-1">
        <a>Valid link</a>
      </Link>
    </>
  )
}
```

## Các Cách Có Thể Để Khắc Phục

Tìm kiếm bất kỳ việc sử dụng nào của component `next/link`, `Router#push`, hoặc `Router#replace` và đảm bảo rằng các giá trị `href` và `as` được cung cấp là tương thích.
