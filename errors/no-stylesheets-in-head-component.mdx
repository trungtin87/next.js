## Tại Sao Lỗi Này Xảy Ra

Một thẻ `<link rel="stylesheet">` đã được thêm bằng cách sử dụng component `next/head`.

Chúng tôi không khuyến nghị mẫu này vì nó có khả năng bị lỗi khi sử dụng với Suspense và/hoặc streaming. Trong các ngữ cảnh này, các thẻ `next/head` không:

- được đảm bảo được bao gồm trong phản hồi SSR ban đầu, vì vậy việc tải có thể bị trзадержка cho đến khi render phía client, làm giảm hiệu suất.

- được tải theo bất kỳ thứ tự cụ thể nào. Thứ tự mà các ranh giới Suspense của ứng dụng được giải quyết sẽ xác định thứ tự tải của các stylesheet của bạn.

## Các Cách Có Thể Để Khắc Phục

### Document

Thêm stylesheet trong component `Document` tùy chỉnh.

```jsx filename="pages/_document.js"
import { Html, Head, Main, NextScript } from 'next/document'

export default function Document() {
  return (
    <Html>
      <Head>
        <link rel="stylesheet" href="..." />
      </Head>
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  )
}
```

Lưu ý rằng cú pháp hàm cho `Document` ở trên được ưu tiên hơn cú pháp `class`, để nó tương thích với React Server Components trong tương lai.
