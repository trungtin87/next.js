## Tại Sao Lỗi Này Xảy Ra

Trong error overlay, một thông báo đã được hiển thị rằng phiên bản Next.js được phát hiện đã lỗi thời.

Để có được các tính năng mới nhất và sửa lỗi, bạn nên cập nhật thường xuyên.

## Các Cách Có Thể Để Khắc Phục

Nếu bạn đang thử nghiệm một bản phát hành canary, hãy nâng cấp Next.js bằng một trong các lệnh sau:

```bash filename="Terminal"
npm i next@canary
```

```bash filename="Terminal"
yarn add next@canary
```

```bash filename="Terminal"
pnpm add next@canary
```

```bash filename="Terminal"
bun add next@canary
```

Nếu bạn đang sử dụng bản phát hành ổn định, hãy nâng cấp Next.js bằng một trong các lệnh sau:

```bash filename="Terminal"
npm i next@latest
```

```bash filename="Terminal"
yarn add next@latest
```

```bash filename="Terminal"
pnpm add next@latest
```

```bash filename="Terminal"
bun add next@latest
```

Nếu bạn đang đến từ một phiên bản chính cũ hơn, hãy xem [hướng dẫn nâng cấp](/docs/pages/guides/upgrading) của chúng tôi.

### Lưu Ý

Nếu bạn muốn báo cáo lỗi trên GitHub, bạn nên nâng cấp lên bản phát hành canary mới nhất của Next.js trước, để xem liệu lỗi đã được sửa trong canary chưa.
