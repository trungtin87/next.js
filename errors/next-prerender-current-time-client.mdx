## Tại Sao Lỗi Này Xảy Ra

Một Client Component đang truy cập thời gian hiện tại với `Date.now()`, `Date()`, hoặc `new Date()`.

Client Components chủ yếu chạy trong trình duyệt tuy nhiên khi truy cập trang lần đầu, Next.js sẽ phục vụ một trang HTML được tạo ra bằng cách mô phỏng môi trường client trên server. Quá trình này được gọi là Server Side Rendering hay SSR. Next.js sẽ cố gắng prerender HTML này trước thời gian tuy nhiên nếu một Client Component truy cập thời gian hiện tại trong quá trình prerender này, nó không thể bao gồm component này trong HTML được prerender, nếu không nó có thể chứa nội dung dựa trên thời gian rất khác so với khi HTML được gửi đến người dùng. Next.js sẽ sử dụng Suspense boundary gần nhất xung quanh component này để prerender một fallback thay thế tuy nhiên trong trường hợp này không có Suspense boundary.

Có một số cách bạn có thể khắc phục vấn đề này tùy thuộc vào chi tiết của trường hợp sử dụng của bạn.

## Các Cách Khắc Phục Có Thể

### Cung Cấp Fallback UI

Nếu bạn muốn giá trị thời gian là một phần của HTML được render trên server, bạn có thể thêm một Suspense boundary xung quanh component cho phép Next.js prerender một fallback UI trước request của người dùng và điền vào nội dung thực tế khi request của người dùng xảy ra.

Trước đây:

```jsx filename="app/article.js"
'use client'

export function RelativeTime({ timestamp }) {
  const now = Date.now()
  return (
    <span suppressHydrationWarning>{computeTimeAgo({ timestamp, now })}</span>
  )
}

export default function Article({ articleData }) {
  return (
    <article>
      <h1>...</h1>
      <RelativeTime timestamp={articleData.publishedAt} />
    </article>
  )
}
```

Sau khi sửa:

```jsx filename="app/article.js"
'use client'

import { Suspense } from 'react'

export function RelativeTime({ timestamp }) {
  const now = Date.now()
  return <span>{computeTimeAgo({ timestamp, now })}</span>
}

export default function Article({ articleData }) {
  return (
    <article>
      <h1>...</h1>
      <Suspense fallback={<span>...</span>}>
        <RelativeTime timestamp={articleData.publishedAt} />
      </Suspense>
    </article>
  )
}
```

### Chỉ truy cập thời gian trong trình duyệt

Nếu bạn không muốn cung cấp fallback UI, bạn có thể di chuyển việc truy cập thời gian vào một effect. React không chạy effects trong quá trình server rendering nên việc truy cập thời gian sẽ chỉ xảy ra trong trình duyệt.

Trước đây:

```jsx filename="app/article.js"
'use client'

export function RelativeTime({ timestamp }) {
  const now = Date.now()
  return (
    <span suppressHydrationWarning>{computeTimeAgo({ timestamp, now })}</span>
  )
}

export default function Article({ articleData }) {
  return (
    <article>
      <h1>...</h1>
      <RelativeTime timestamp={articleData.publishedAt} />
    </article>
  )
}
```

Sau khi sửa:

```jsx filename="app/article.js"
'use client'

import { useState, useEffect } from 'react'

export function RelativeTime({ timestamp }) {
  const [timeAgo, setTimeAgo] = useState('')
  useEffect(() => {
    // Effect sẽ không chạy trong khi render trên server
    const now = Date.now()
    setTimeAgo(computeTimeAgo({ timestamp, now }))
  }, [timestamp])
  return <span>{timeAgo}</span>
}

export default function Article({ articleData }) {
  return (
    <article>
      <h1>...</h1>
      <RelativeTime timestamp={articleData.publishedAt} />
    </article>
  )
}
```

### Cache thời gian trong Server Component

Trong khi Next.js sẽ xử lý việc đọc thời gian hiện tại trong Server Component giống như trong Client Component, bạn có tùy chọn bổ sung là cache thời gian đọc bằng cách sử dụng `"use cache"`. Với cách tiếp cận này, giá trị thời gian có thể được bao gồm trong HTML được prerender vì bạn đang chỉ định rõ ràng rằng giá trị không cần phản ánh thời gian của request của người dùng.

Trước đây:

```jsx filename="app/home/layout.js"
'use client'

export default function Layout({ children }) {
  return (
    <>
      <main>{children}</main>
      <footer>
        <span>Copyright {new Date().getFullYear()}</span>
      </footer>
    </>
  )
}
```

Sau khi sửa:

```jsx filename="app/home/layout.js"
async function getCurrentYear() {
  'use cache'
  return new Date().getFullYear()
}

export default async function Layout({ children }) {
  return (
    <>
      <main>{children}</main>
      <footer>
        <span>Copyright {await getCurrentYear()}</span>
      </footer>
    </>
  )
}
```

### Trường hợp sử dụng hiệu suất

Nếu bạn đang sử dụng thời gian hiện tại để theo dõi hiệu suất với thời gian đã trôi qua, hãy sử dụng `performance.now()`.

Trước đây:

```jsx filename="app/page.js"
"use client"

export default function Page() {
  const start = Date.now();
  const data = computeDataSlowly(...);
  const end = Date.now();
  console.log(`computeDataSlowly took ${end - start} milliseconds to complete`)

  return ...
}
```

Sau khi sửa:

```jsx filename="app/page.js"
"use client"

export default async function Page() {
  const start = performance.now();
  const data = computeDataSlowly(...);
  const end = performance.now();
  console.log(`computeDataSlowly took ${end - start} milliseconds to complete`)
  return ...
}
```

> **Lưu ý**: Nếu bạn cần báo cáo thời gian tuyệt đối cho một công cụ observability, bạn cũng có thể sử dụng `performance.timeOrigin + performance.now()`.
