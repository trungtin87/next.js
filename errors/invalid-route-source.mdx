## Tại Sao Lỗi Này Xảy Ra

Một mẫu không thể được phân tích cú pháp khi định nghĩa các custom routes hoặc một proxy `matcher`.

Điều này có thể là do cố gắng sử dụng cú pháp `RegExp` thông thường như negative lookaheads (`?!exclude`) mà không tuân theo cú pháp của [`path-to-regexp`](https://github.com/pillarjs/path-to-regexp).

## Các Cách Có Thể Để Khắc Phục

Bao bọc phần `RegExp` của `source` của bạn như một tham số không tên (un-named parameter).

### Custom Routes

**Trước**

```js
{
  source: '/feedback/(?!general)',
  destination: '/feedback/general'
}
```

**Sau**

```js
{
  source: '/feedback/((?!general).*)',
  destination: '/feedback/general'
}
```

### Proxy

**Trước**

```ts filename="proxy.ts"
const config = {
  matcher: '/feedback/(?!general)',
}
```

**Sau**

```ts filename="proxy.ts"
const config = {
  matcher: '/feedback/((?!general).*)',
}
```
