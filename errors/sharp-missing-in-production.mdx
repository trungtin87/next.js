## Tại Sao Lỗi Này Xảy Ra

Loader mặc định của component `next/image` sử dụng [`squoosh`](https://www.npmjs.com/package/@squoosh/lib) vì nó nhanh chóng để cài đặt và phù hợp cho môi trường development.

- Đối với môi trường production sử dụng `next start`, bạn nên cài đặt [`sharp`](https://www.npmjs.com/package/sharp).

Bạn đang thấy lỗi này vì Image Optimization trong production mode (`next start`) đã được phát hiện.

- Đối với môi trường production sử dụng `output: "standalone"`, bạn phải cài đặt [`sharp`](https://www.npmjs.com/package/sharp).

Bạn đang thấy lỗi này vì Image Optimization trong standalone mode (`output: "standalone"`) đã được phát hiện.

## Các Cách Có Thể Để Khắc Phục

- Cài đặt `sharp` bằng cách chạy một trong các lệnh sau trong thư mục dự án của bạn:

```bash filename="Terminal"
npm i sharp
```

```bash filename="Terminal"
yarn add sharp
```

```bash filename="Terminal"
pnpm add sharp
```

```bash filename="Terminal"
bun add sharp
```

Sau đó, build dự án của bạn với `next build`. Cuối cùng, khởi động lại server với `next start` cho production mode hoặc `node .next/standalone/server.js` cho standalone mode.

- Nếu `sharp` đã được cài đặt nhưng không thể được resolve, hãy đặt biến môi trường `NEXT_SHARP_PATH` như `export NEXT_SHARP_PATH=/tmp/node_modules/sharp`. Sau đó, build dự án của bạn với `next build`. Cuối cùng, khởi động lại server với `next start` cho production mode hoặc `node .next/standalone/server.js` cho standalone mode.

> **Lưu ý**: Điều này không cần thiết cho deployments trên Vercel, vì `sharp` được cài đặt tự động cho bạn.
