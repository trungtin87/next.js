## Tại Sao Lỗi Này Xảy Ra

Lỗi "API Routes Response Size Limited to 4MB" phát sinh khi API Route của bạn đang cố gắng gửi một phản hồi lớn hơn kích thước cho phép là `4MB`. API Routes trong Next.js được thiết kế để cung cấp phản hồi nhanh chóng và không được xây dựng để hỗ trợ truyền tải lượng dữ liệu lớn.

## Các Cách Có Thể Để Khắc Phục

Nếu bạn không sử dụng Next.js trong môi trường serverless và bạn hoàn toàn nhận thức được những tác động về hiệu suất, bạn có thể vô hiệu hóa giới hạn này trong API Route của mình. Dưới đây là cách bạn có thể đặt `responseLimit` thành `false`:

```js filename="pages/api/example.js"
export const config = {
  api: {
    responseLimit: false,
  },
}
```

Ngoài ra, `responseLimit` cũng có thể chấp nhận một giá trị số (tính bằng bytes) hoặc bất kỳ định dạng chuỗi nào được hỗ trợ bởi module `bytes`. Đây có thể là một giá trị như `1000`, `'500kb'`, hoặc `'3mb'`. Giá trị này sẽ đặt kích thước phản hồi tối đa trước khi một cảnh báo được hiển thị. Ví dụ, để đặt giới hạn thành 8MB:

```js filename="pages/api/example.js"
export const config = {
  api: {
    responseLimit: '8mb',
  },
}
```

> **Lưu ý**: Việc tăng giới hạn phản hồi có thể có những tác động đáng kể đến hiệu suất và chỉ nên được thực hiện sau khi cân nhắc kỹ lưỡng.
