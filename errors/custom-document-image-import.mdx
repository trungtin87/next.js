## Tại Sao Lỗi Này Xảy Ra

Một nỗ lực import một file hình ảnh vào [`pages/_document.js`](/docs/pages/building-your-application/routing/custom-document) đã được thực hiện.

Custom documents không được biên dịch cho trình duyệt và các hình ảnh được import tĩnh như thế này sẽ không được hiển thị.

## Các Cách Có Thể Để Khắc Phục

Nếu hình ảnh của bạn cần được hiển thị trên mọi trang, bạn có thể di chuyển nó đến file [`pages/_app.js`](/docs/pages/building-your-application/routing/custom-app) của bạn.

### Ví dụ

```jsx filename="pages/_app.js"
import yourImage from 'path/to/your/image'
import Image from 'next/image'

function MyApp({ Component, pageProps }) {
  return (
    <>
      <Image src={yourImage} alt="your_image_description" />
      <Component {...pageProps} />
    </>
  )
}

export default MyApp
```

Nếu ứng dụng của bạn không sử dụng image imports với `next/image`, bạn có thể vô hiệu hóa built-in loader với `next.config.js` sau:

```js filename="next.config.js"
module.exports = {
  images: {
    disableStaticImages: true,
  },
}
```
