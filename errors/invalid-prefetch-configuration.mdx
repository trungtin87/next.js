---

## Tại Sao Thông Báo Này Xuất Hiện

Bạn đã cung cấp một cấu hình không hợp lệ cho `export const unstable_prefetch` trong một file Layout hoặc Page.

### Ví dụ về Cách Sử Dụng Đúng

#### Static Prefetching

```tsx filename="app/.../layout.tsx"
export const unstable_prefetch = {
  mode: 'static',
}
```

#### Runtime Prefetching

```tsx filename="app/[slug]/page.tsx"
export const unstable_prefetch = {
  mode: 'runtime',
  samples: [
    {
      cookies: [{ name: 'experiment', value: 'A' }],
      params: { slug: 'example' },
    },
  ],
}
```
