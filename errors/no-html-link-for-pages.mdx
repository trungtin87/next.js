---
title: Không có HTML link cho pages
---

> Ngăn chặn việc sử dụng phần tử `<a>` để điều hướng đến các trang Next.js nội bộ.

## Tại Sao Lỗi Này Xảy Ra

Một phần tử `<a>` đã được sử dụng để điều hướng đến một route trang mà không sử dụng component `next/link`, gây ra việc làm mới toàn bộ trang không cần thiết.

Component `Link` là bắt buộc để kích hoạt các chuyển đổi route phía client giữa các trang và cung cấp trải nghiệm ứng dụng một trang.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo import component `Link` và bọc các phần tử anchor route đến các route trang khác nhau.

**Trước:**

```jsx filename="pages/index.js"
function Home() {
  return (
    <div>
      <a href="/about">About Us</a>
    </div>
  )
}
```

**Sau:**

```jsx filename="pages/index.js"
import Link from 'next/link'

function Home() {
  return (
    <div>
      <Link href="/about">About Us</Link>
    </div>
  )
}

export default Home
```

### Tùy Chọn

#### `pagesDir`

Quy tắc này thường có thể tự động xác định thư mục `pages` của bạn.

Nếu bạn đang làm việc trong một monorepo, chúng tôi khuyên bạn nên cấu hình cài đặt [`rootDir`](/docs/pages/api-reference/config/eslint#specifying-a-root-directory-within-a-monorepo) trong `eslint-plugin-next`, mà `pagesDir` sẽ sử dụng để xác định thư mục `pages` của bạn.

Trong một số trường hợp, bạn cũng có thể cần cấu hình quy tắc này trực tiếp bằng cách cung cấp thư mục `pages`. Đây có thể là một đường dẫn hoặc một mảng các đường dẫn.

```json filename="eslint.config.json"
{
  "rules": {
    "@next/next/no-html-link-for-pages": ["error", "packages/my-app/pages/"]
  }
}
```
