> Thực thi hành vi font-display với Google Fonts.

## Tại Sao Lỗi Này Xảy Ra

Đối với một Google Font, bộ mô tả font-display bị thiếu hoặc được đặt thành `auto`, `block`, hoặc `fallback`, những giá trị này không được khuyến nghị.

## Các Cách Có Thể Để Khắc Phục

Trong hầu hết các trường hợp, chiến lược hiển thị font tốt nhất cho các font tùy chỉnh là `optional`.

```jsx filename="pages/index.js"
import Head from 'next/head'

export default function IndexPage() {
  return (
    <div>
      <Head>
        <link
          href="https://fonts.googleapis.com/css2?family=Krona+One&display=optional"
          rel="stylesheet"
        />
      </Head>
    </div>
  )
}
```

Việc chỉ định `display=optional` giảm thiểu rủi ro văn bản ẩn hoặc thay đổi bố cục (layout shift). Nếu việc chuyển đổi sang font tùy chỉnh sau khi nó đã tải là quan trọng đối với bạn, thì hãy sử dụng `display=swap` thay thế.

### Khi Nào Không Nên Sử Dụng Nó

Nếu bạn muốn hiển thị cụ thể một font bằng cách sử dụng chiến lược `auto`, `block`, hoặc `fallback`, thì bạn có thể vô hiệu hóa quy tắc này.
