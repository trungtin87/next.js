---
title: Không có phần tử img
---

> Ngăn chặn việc sử dụng phần tử `<img>` do LCP chậm hơn và băng thông cao hơn.

## Tại Sao Lỗi Này Xảy Ra

Một phần tử `<img>` đã được sử dụng để hiển thị hình ảnh thay vì `<Image />` từ `next/image`.

## Các Cách Có Thể Để Khắc Phục

1. Sử dụng [`next/image`](/docs/pages/api-reference/components/image) để cải thiện hiệu suất với [Tối ưu hóa Hình ảnh](/docs/pages/api-reference/components/image) tự động.

> **Lưu ý**: Nếu triển khai lên [nhà cung cấp hosting được quản lý](/docs/pages/getting-started/deploying), hãy nhớ kiểm tra giá của nhà cung cấp vì hình ảnh được tối ưu hóa có thể được tính phí khác với hình ảnh gốc.
>
> Giá nền tảng tối ưu hóa hình ảnh phổ biến:
>
> - [Giá Vercel](https://vercel.com/pricing)
> - [Giá Cloudinary](https://cloudinary.com/pricing)
> - [Giá imgix](https://imgix.com/pricing)

> **Lưu ý**: Nếu tự hosting, hãy nhớ cài đặt [`sharp`](https://www.npmjs.com/package/sharp) và kiểm tra xem máy chủ của bạn có đủ dung lượng lưu trữ để cache các hình ảnh được tối ưu hóa hay không.

```jsx filename="pages/index.js"
import Image from 'next/image'

function Home() {
  return (
    <Image
      src="https://example.com/hero.jpg"
      alt="Landscape picture"
      width={800}
      height={500}
    />
  )
}

export default Home
```

2. Nếu bạn muốn sử dụng các tính năng của `next/image` như placeholder mờ dần nhưng vô hiệu hóa Tối ưu hóa Hình ảnh, bạn có thể làm như vậy bằng cách sử dụng [unoptimized](/docs/pages/api-reference/components/image#unoptimized):

```jsx filename="pages/index.js"
import Image from 'next/image'

const UnoptimizedImage = (props) => {
  return <Image {...props} unoptimized />
}
```

3. Bạn cũng có thể sử dụng phần tử `<picture>` với phần tử `<img>` lồng nhau:

```jsx filename="pages/index.js"
function Home() {
  return (
    <picture>
      <source srcSet="https://example.com/hero.avif" type="image/avif" />
      <source srcSet="https://example.com/hero.webp" type="image/webp" />
      <img
        src="https://example.com/hero.jpg"
        alt="Landscape picture"
        width={800}
        height={500}
      />
    </picture>
  )
}
```

4. Bạn có thể sử dụng [custom image loader](/docs/pages/api-reference/components/image#loader) để tối ưu hóa hình ảnh. Đặt [loaderFile](/docs/pages/api-reference/components/image#loaderfile) thành đường dẫn của loader tùy chỉnh của bạn.

```js filename="next.config.js"
module.exports = {
  images: {
    loader: 'custom',
    loaderFile: './my/image/loader.js',
  },
}
```
