---

## Tại Sao Lỗi Này Xảy Ra

Khi `cacheComponents` được bật, Next.js yêu cầu rằng `generateViewport()` không phụ thuộc vào dữ liệu uncached hoặc dữ liệu Request trừ khi bạn chọn rõ ràng có một trang hoàn toàn động. Nếu bạn gặp lỗi này, điều đó có nghĩa là `generateViewport` phụ thuộc vào một trong các loại dữ liệu này và bạn chưa chỉ định cụ thể rằng route bị ảnh hưởng nên hoàn toàn động.

## Các Cách Khắc Phục Có Thể

Để khắc phục vấn đề này, trước tiên bạn phải xác định mục tiêu của mình cho route bị ảnh hưởng.

Thông thường, cách bạn chỉ ra cho Next.js rằng bạn muốn cho phép đọc Request data hoặc dữ liệu bên ngoài uncached là bằng cách thực hiện việc truy cập dữ liệu này bên trong một component với một Suspense boundary tổ tiên. Tuy nhiên với Viewport, bạn không trực tiếp kiểm soát việc bao bọc vị trí mà metadata này sẽ được render, và ngay cả khi bạn có thể bao bọc nó trong một Suspense boundary, việc render nó với một fallback sẽ không đúng. Điều này là do metadata này rất quan trọng để tải đúng các resources như images và phải là một phần của App Shell ban đầu (HTML ban đầu chứa document head cũng như UI có thể vẽ đầu tiên).

### Nếu bạn phải truy cập Request Data hoặc dữ liệu bên ngoài của bạn không thể cache

Cách duy nhất để sử dụng Request data hoặc dữ liệu bên ngoài không thể cache trong `generateViewport` là làm cho route này hoàn toàn động. Mặc dù Next.js có thể hoạt động ở chế độ này, nó không cho phép sử dụng khả năng prerendering của Next.js trong tương lai, vì vậy bạn nên chắc chắn rằng điều này là cần thiết cho trường hợp sử dụng của bạn. Để chỉ ra route nên hoàn toàn động, bạn phải thêm một Suspense boundary phía trên nơi bạn render document body.

Trước đây:

```jsx filename="app/layout.tsx"
import { cookies } from 'next/headers'

export async function generateViewport() {
  const cookieJar = await cookies()
  return {
    themeColor: cookieJar.get('theme-color'),
  }
}

export default function RootLayout({ children }) {
  return (
    <html>
      <body>{children}</body>
    </html>
  )
}
```

Sau khi sửa:

```jsx filename="app/layout.tsx"
import { Suspense } from 'react'
import { cookies } from 'next/headers'

export async function generateViewport() {
  const cookieJar = await cookies()
  return {
    themeColor: cookieJar.get('theme-color'),
  }
}

export default function RootLayout({ children }) {
  return (
    <Suspense>
      <html>
        <body>{children}</body>
      </html>
    </Suspense>
  )
}
```

### Caching Dữ Liệu Bên Ngoài

Khi dữ liệu bên ngoài được cached, Next.js có thể prerender với nó, điều này đảm bảo rằng App Shell luôn có metadata viewport đầy đủ khả dụng. Hãy xem xét sử dụng `"use cache"` để đánh dấu function tạo ra dữ liệu bên ngoài là có thể cache.

Trước đây:

```jsx filename="app/.../layout.tsx"
import { db } from './db'

export async function generateViewport() {
  const { width, initialScale } = await db.query('viewport-size')
  return {
    width,
    initialScale,
  }
}

export default async function Layout({ children }) {
  return ...
}
```

Sau khi sửa:

```jsx filename="app/.../layout.tsx"
import { db } from './db'

export async function generateViewport() {
  "use cache"
  const { width, initialScale } = await db.query('viewport-size')
  return {
    width,
    initialScale,
  }
}

export default async function Layout({ children }) {
  return ...
}
```
