## Tại Sao Lỗi Này Xảy Ra

Lỗi "Built-in CSS Support Disabled" thường xảy ra khi một cấu hình CSS tùy chỉnh được thêm vào file `next.config.js`. Hành động này vô hiệu hóa hỗ trợ CSS/SCSS tích hợp sẵn để tránh xung đột trong cấu hình.

Nếu bạn đã thêm một plugin cũ như `@zeit/next-css` trong file `next.config.js` của mình, bạn có thể gặp thông báo lỗi này.

## Các Cách Có Thể Để Khắc Phục

Nếu bạn muốn sử dụng hỗ trợ CSS/SCSS tích hợp sẵn, bạn cần xóa bất kỳ cấu hình CSS tùy chỉnh hoặc plugins nào như `@zeit/next-css` hoặc `@zeit/next-sass` trong file `next.config.js` của bạn. Chúng tôi khuyên bạn nên sử dụng cách tiếp cận này.

Mặt khác, nếu bạn chọn không sử dụng hỗ trợ tích hợp sẵn, bạn có thể bỏ qua cảnh báo này một cách an toàn.
