## Tại Sao Lỗi Này Xảy Ra

Bạn đang render một React Class Component trong một Server Component, `React.Component` và `React.PureComponent` chỉ hoạt động trong Client Components.

## Các Cách Có Thể Để Khắc Phục

Sử dụng một Function Component.

### Trước

```jsx filename="app/page.js"
export default class Page extends React.Component {
  render() {
    return <p>Hello world</p>
  }
}
```

### Sau

```jsx filename="app/page.js"
export default function Page() {
  return <p>Hello world</p>
}
```

Đánh dấu component render React Class Component là một Client Component bằng cách thêm `'use client'` ở đầu file.

### Trước

```jsx filename="app/page.js"
export default class Page extends React.Component {
  render() {
    return <p>Hello world</p>
  }
}
```

### Sau

```jsx filename="app/page.js"
'use client'

export default class Page extends React.Component {
  render() {
    return <p>Hello world</p>
  }
}
```
