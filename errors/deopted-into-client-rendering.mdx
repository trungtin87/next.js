## Tại Sao Lỗi Này Xảy Ra

Trong quá trình render tĩnh (static rendering), toàn bộ trang đã bị chuyển sang (deopted) client-side rendering bởi `useSearchParams` vì không có [Suspense boundary](/docs/app/api-reference/functions/use-search-params#static-rendering) nào bắt được nó.

Nếu một route được render tĩnh, việc gọi `useSearchParams()` sẽ khiến cây lên đến [Suspense boundary](/docs/app/api-reference/functions/use-search-params#static-rendering) gần nhất được render phía client.

Điều này cho phép một phần của trang được render tĩnh trong khi phần động sử dụng `searchParams` có thể được render phía client.

## Các Cách Có Thể Để Khắc Phục

Bạn có thể giảm phần của route được render phía client bằng cách bao bọc component sử dụng useSearchParams trong một Suspense boundary.

Ví dụ nếu `app/dashboard/search-bar.tsx` sử dụng `useSearchParams`, hãy bao bọc component trong một [Suspense boundary](/docs/app/api-reference/functions/use-search-params#static-rendering) như được hiển thị trong `app/dashboard/page.tsx`.

```tsx filename="app/dashboard/search-bar.tsx"
'use client'

import { useSearchParams } from 'next/navigation'

export default function SearchBar() {
  const searchParams = useSearchParams()

  const search = searchParams.get('search')

  // Điều này sẽ không được log trên server khi sử dụng static rendering
  console.log(search)

  return <>Search: {search}</>
}
```

```tsx filename="app/dashboard/page.tsx"
import { Suspense } from 'react'
import SearchBar from './search-bar'

// Component này được truyền dưới dạng fallback cho Suspense boundary
// sẽ được render thay cho search bar trong HTML ban đầu.
// Khi giá trị có sẵn trong quá trình React hydration, fallback
// sẽ được thay thế bằng component `<SearchBar>`.
function SearchBarFallback() {
  return <>placeholder</>
}

export default function Page() {
  return (
    <>
      <nav>
        <Suspense fallback={<SearchBarFallback />}>
          <SearchBar />
        </Suspense>
      </nav>
      <h1>Dashboard</h1>
    </>
  )
}
```
