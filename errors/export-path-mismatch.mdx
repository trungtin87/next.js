## Tại Sao Lỗi Này Xảy Ra

Một path `exportPathMap` đã được khớp không đúng với một trang được định tuyến động.
Điều này sẽ dẫn đến trang thiếu các URL parameters của nó.

## Các Cách Có Thể Để Khắc Phục

Thay đổi function `exportPathMap` của bạn trong `next.config.js` để có một path khớp với trang được định tuyến động.

```js filename="next.config.js"
module.exports = {
  exportPathMap: function () {
    return {
      '/': { page: '/' },
      // '/blog/nextjs': { page: '/blog/[post]/comment/[id]' },        // sai
      '/blog/nextjs/comment/1': { page: '/blog/[post]/comment/[id]' }, // đúng
    }
  },
}
```
