## Tại Sao Lỗi Này Xảy Ra

Trong một trong các `getServerSideProps` của trang, giá trị trả về có hình dạng không chính xác.

## Các Cách Có Thể Để Khắc Phục

Đảm bảo trả về hình dạng sau từ `getServerSideProps`:

```tsx filename="pages/example.tsx"
export async function getServerSideProps(ctx: GetServerSidePropsContext) {
  return {
    props: { [key: string]: any }
  }
}
```
