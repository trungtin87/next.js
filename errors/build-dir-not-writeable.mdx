## Tại Sao Lỗi Này Xảy Ra

Lỗi "Build Directory Not Writeable" thường xảy ra khi hệ thống tệp không cho phép ghi vào thư mục được chỉ định. Một kịch bản phổ biến cho lỗi này là khi bạn khởi tạo một [custom server](/docs/pages/guides/custom-server) ở chế độ development trên một server production.

Các server production này thường không cho phép ghi vào hệ thống tệp sau khi ứng dụng của bạn được build, gây ra lỗi này.

## Các Cách Có Thể Để Khắc Phục

Nếu bạn đang triển khai một custom server với một file server (giả sử nó được đặt tên là `server.js`), bạn nên sửa đổi khóa scripts trong `package.json` của mình thành như sau:

```json filename="package.json"
{
  "scripts": {
    "dev": "node server.js",
    "build": "next build",
    "start": "NODE_ENV=production node server.js"
  }
}
```

Đảm bảo rằng custom server của bạn khởi động Next.js ở chế độ production khi `NODE_ENV` được đặt thành `production`:

```js filename="server.js"
const dev = process.env.NODE_ENV !== 'production'
const app = next({ dev })
```
