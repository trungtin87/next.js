## Tại Sao Lỗi Này Xảy Ra

Một Client Component đang gọi `Math.random()`.

Client Components chủ yếu chạy trong trình duyệt tuy nhiên khi truy cập trang lần đầu, Next.js sẽ phục vụ một trang HTML được tạo ra bằng cách mô phỏng môi trường client trên server. Quá trình này được gọi là Server Side Rendering hay SSR. Next.js sẽ cố gắng prerender HTML này trước thời gian tuy nhiên nếu một Client Component truy cập nguồn ngẫu nhiên trong quá trình prerender này, nó không thể bao gồm component này trong HTML được prerender, nếu không giá trị sẽ được cố định trên mỗi request của người dùng và không ngẫu nhiên như mong đợi. Next.js sẽ sử dụng Suspense boundary gần nhất xung quanh component này để prerender một fallback thay thế tuy nhiên trong trường hợp này không có Suspense boundary.

Có một số cách bạn có thể khắc phục vấn đề này tùy thuộc vào chi tiết của trường hợp sử dụng của bạn.

## Các Cách Khắc Phục Có Thể

### Cung Cấp Fallback UI

Thông thường không thể sử dụng `Math.random()` trong một Client Component được Server Rendered mà không gây ra lỗi hydration. Tuy nhiên nếu bạn thấy mình có một component gọi `Math.random()` trong quá trình rendering, và bạn đã xử lý trường hợp khó khăn của việc hydrating giá trị này một cách nhất quán, thì bạn có thể thêm một Suspense boundary xung quanh component gọi `Math.random()` để cho phép Next.js prerender một fallback UI và điền vào giá trị ngẫu nhiên thực tế khi người dùng request trang.

Trước đây:

```jsx filename="app/user-avatar.js"
'use client'

export function UserAvatar({ avatar }) {
  let backgroundColor = avatar.preferredBackground
  if (!backgroundColor) {
    const randomColor = `#${Math.random().toString(16).slice(2, 8)}`
    // tưởng tượng safelyGetRandomColor là một function xử lý đồng bộ hóa
    // màu ngẫu nhiên được chọn giữa SSR và hydration để tránh lỗi hydration
    backgroundColor = safelyGetRandomColor(randomColor)
  }
  return <Avatar background={backgroundColor} src={avatar.src} />
}
```

Sau khi sửa:

```jsx filename="app/user-avatar.js"
"use client"

export function UserAvatar({ avatar }) {
  return (
    <Suspense fallback={<AvatarSkeleton />}>
      <DynamicUserAvatar avatar={avatar} />
    </Suspense>
  )
}

function AvatarSkeleton() {
  ...
}

function DynamicUserAvatar({ avatar }) {
  let backgroundColor = avatar.preferredBackground
  if (!backgroundColor) {
    const randomColor = `#${Math.random().toString(16).slice(2, 8)}`

```

### Chỉ truy cập `Math.random` trong trình duyệt

Nếu giá trị ngẫu nhiên của bạn chỉ được dự định để sử dụng trong trình duyệt, bạn có thể di chuyển lệnh gọi vào một effect hoặc event handler. React không chạy effects trong quá trình server rendering và không có events trong quá trình server rendering nên cả hai tùy chọn đều không yêu cầu prerender loại trừ component này.

Trước đây:

```jsx filename="app/workflow.js"
'use client'

export default function Workflow({ currentStep, onNext, onPrev }) {
  const [id] = useState(() => Math.random().toString(36).slice(2))

  const next = onNext
    ? () => {
        trackEvent(id, 'forward')
        onNext()
      }
    : null

  const previous = onPrev
    ? () => {
        trackEvent(id, 'previous')
        onPrev()
      }
    : null

  return (
    <>
      {currentStep}
      {next ? <button onClick={next}>Next</button> : null}
      {previous ? <button onClick={previous}>Previous</button> : null}
    </>
  )
}
```

Sau khi sửa:

```jsx filename="app/workflow.js"
'use client'

import { useRef } from 'react'

function getOrCreateId(ref) {
  if (!ref.current) {
    ref.current = Math.random().toString(36).slice(2)
  }
  return ref.current
}

export default function Workflow({ currentStep, onNext, onPrev }) {
  const idRef = useRef(null)

  const next = onNext
    ? () => {
        trackEvent(getOrCreateId(idRef), 'forward')
        onNext()
      }
    : null

  const previous = onPrev
    ? () => {
        trackEvent(getOrCreateId(idRef), 'previous')
        onPrev()
      }
    : null

  return (
    <>
      {currentStep}
      {next ? <button onClick={next}>Next</button> : null}
      {previous ? <button onClick={previous}>Previous</button> : null}
    </>
  )
}
```
