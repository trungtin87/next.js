## Tại Sao Lỗi Này Xảy Ra

Bạn đã quên định nghĩa các thẻ `<html>` và/hoặc `<body>` trong Root Layout của mình.

## Các Cách Có Thể Để Khắc Phục

Để khắc phục lỗi này, hãy đảm bảo rằng cả `<html>` và `<body>` đều có mặt trong Root Layout của bạn.

```diff filename="app/layout.tsx"

export default function Layout({ children }: { children: React.ReactNode }) {
-  return children
+  return (
+    <html>
+      <body>
+        {children}
+      </body>
+    </html>
+  )
}
```
