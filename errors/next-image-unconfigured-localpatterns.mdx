## Tại Sao Lỗi Này Xảy Ra

Một trong các trang của bạn sử dụng component `next/image`, đã truyền một giá trị `src` sử dụng URL không được định nghĩa trong thuộc tính `images.localPatterns` trong `next.config.js`.

## Các Cách Có Thể Để Khắc Phục

Thêm một entry vào mảng `images.localPatterns` trong `next.config.js` với URL pattern mong đợi. Ví dụ:

```js filename="next.config.js"
module.exports = {
  images: {
    localPatterns: [
      {
        pathname: '/assets/**',
      },
    ],
  },
}
```

Bỏ qua `search` sẽ cho phép tất cả các query strings.

Nếu bạn muốn ngăn query string khớp, bạn có thể sử dụng chuỗi rỗng, ví dụ:

```js filename="next.config.js"
module.exports = {
  images: {
    localPatterns: [
      {
        pathname: '/assets/**',
        search: '',
      },
    ],
  },
}
```
