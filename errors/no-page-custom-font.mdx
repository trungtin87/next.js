---
title: Không có Font Tùy Chỉnh cho Page
---

> Ngăn chặn font tùy chỉnh chỉ dành cho page.

## Tại Sao Lỗi Này Xảy Ra

- Font tùy chỉnh bạn đang thêm đã được thêm vào một page - điều này chỉ thêm font vào trang cụ thể đó chứ không phải toàn bộ ứng dụng.
- Font tùy chỉnh bạn đang thêm đã được thêm vào một component riêng biệt trong `pages/_document.js` - điều này vô hiệu hóa tối ưu hóa font tự động.

## Các Cách Có Thể Để Khắc Phục

Tạo file `./pages/_document.js` và thêm font vào một Custom Document:

```jsx filename="pages/_document.js"
import Document, { Html, Head, Main, NextScript } from 'next/document'

class MyDocument extends Document {
  render() {
    return (
      <Html>
        <Head>
          <link
            href="https://fonts.googleapis.com/css2?family=Inter&display=optional"
            rel="stylesheet"
          />
        </Head>
        <body>
          <Main />
          <NextScript />
        </body>
      </Html>
    )
  }
}

export default MyDocument
```

Hoặc dưới dạng function component:

```jsx filename="pages/_document.js"
import { Html, Head, Main, NextScript } from 'next/document'

export default function Document() {
  return (
    <Html>
      <Head>
        <link
          href="https://fonts.googleapis.com/css2?family=Inter&display=optional"
          rel="stylesheet"
        />
      </Head>
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  )
}
```

### Khi Nào Không Sử Dụng Quy Tắc Này

Nếu bạn có lý do để chỉ tải font cho một trang cụ thể hoặc không quan tâm đến tối ưu hóa font, thì bạn có thể vô hiệu hóa quy tắc này.
