---

> Ngăn chặn việc sử dụng `<title>` với component `Head` từ `next/document`.

## Tại Sao Lỗi Này Xảy Ra

Một phần tử `<title>` đã được định nghĩa trong component `Head` được import từ `next/document`, component này chỉ nên được sử dụng cho bất kỳ code `<head>` nào chung cho tất cả các trang. Thẻ title nên được định nghĩa ở cấp trang bằng cách sử dụng `next/head` thay thế.

## Các Cách Có Thể Để Khắc Phục

Trong một trang hoặc component, import và sử dụng `next/head` để định nghĩa tiêu đề trang:

```jsx filename="pages/index.js"
import Head from 'next/head'

export function Home() {
  return (
    <div>
      <Head>
        <title>My page title</title>
      </Head>
    </div>
  )
}
```
