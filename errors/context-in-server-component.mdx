## Tại Sao Lỗi Này Xảy Ra

Bạn đang sử dụng `createContext` trong một Server Component nhưng nó chỉ hoạt động trong Client Components.

## Các Cách Có Thể Để Khắc Phục

Đánh dấu component sử dụng `createContext` là một Client Component bằng cách thêm `'use client'` ở đầu file.

### Trước

```jsx filename="app/example-component.js"
import { createContext } from 'react'

const Context = createContext()
```

### Sau

```jsx filename="app/example-component.js"
'use client'
import { createContext } from 'react'

const Context = createContext()
```
