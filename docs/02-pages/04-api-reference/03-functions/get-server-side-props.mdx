title: getServerSideProps
description: Tài liệu tham khảo API cho `getServerSideProps`. Tìm hiểu cách fetch data trên mỗi request với Next.js.
---

Khi export một hàm có tên `getServerSideProps` (Server-Side Rendering) từ một trang, Next.js sẽ pre-render trang này trên mỗi request bằng cách sử dụng dữ liệu được trả về bởi `getServerSideProps`. Điều này hữu ích nếu bạn muốn fetch data thay đổi thường xuyên, và có trang cập nhật để hiển thị dữ liệu mới nhất.

```tsx filename="pages/index.tsx" switcher
import type { InferGetServerSidePropsType, GetServerSideProps } from 'next'

type Repo = {
  name: string
  stargazers_count: number
}

export const getServerSideProps = (async () => {
  // Fetch data từ external API
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const repo: Repo = await res.json()
  // Truyền data cho trang thông qua props
  return { props: { repo } }
}) satisfies GetServerSideProps<{ repo: Repo }>

export default function Page({
  repo,
}: InferGetServerSidePropsType<typeof getServerSideProps>) {
  return (
    <main>
      <p>{repo.stargazers_count}</p>
    </main>
  )
}
```

```jsx filename="pages/index.js" switcher
export async function getServerSideProps() {
  // Fetch data từ external API
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const repo = await res.json()
  // Truyền data cho trang thông qua props
  return { props: { repo } }
}

export default function Page({ repo }) {
  return (
    <main>
      <p>{repo.stargazers_count}</p>
    </main>
  )
}
```

Bạn có thể import các modules trong top-level scope để sử dụng trong `getServerSideProps`. Các imports được sử dụng sẽ **không được đóng gói cho phía client**. Điều này có nghĩa là bạn có thể viết **mã server-side trực tiếp trong `getServerSideProps`**, bao gồm cả việc fetch data từ database của bạn.

## Tham số Context

Tham số `context` là một object chứa các keys sau:

| Tên             | Mô tả                                                                                                                                                                                                         |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `params`        | Nếu trang này sử dụng [dynamic route](/docs/pages/building-your-application/routing/dynamic-routes), `params` chứa các route parameters. Nếu tên trang là `[id].js`, thì `params` sẽ trông như `{ id: ... }`. |
| `req`           | [Object `HTTP` IncomingMessage](https://nodejs.org/api/http.html#http_class_http_incomingmessage), với một prop `cookies` bổ sung, là một object với string keys ánh xạ đến string values của cookies.        |
| `res`           | [Object `HTTP` response](https://nodejs.org/api/http.html#http_class_http_serverresponse).                                                                                                                    |
| `query`         | Một object đại diện cho query string, bao gồm các dynamic route parameters.                                                                                                                                   |
| `preview`       | (Không dùng nữa cho `draftMode`) `preview` là `true` nếu trang đang ở [Preview Mode](/docs/pages/guides/preview-mode) và `false` nếu không.                                                                   |
| `previewData`   | (Không dùng nữa cho `draftMode`) Dữ liệu [preview](/docs/pages/guides/preview-mode) được đặt bởi `setPreviewData`.                                                                                            |
| `draftMode`     | `draftMode` là `true` nếu trang đang ở [Draft Mode](/docs/pages/guides/draft-mode) và `false` nếu không.                                                                                                      |
| `resolvedUrl`   | Một phiên bản chuẩn hóa của request `URL` loại bỏ tiền tố `_next/data` cho client transitions và bao gồm các giá trị query gốc.                                                                               |
| `locale`        | Chứa locale đang hoạt động (nếu được kích hoạt).                                                                                                                                                              |
| `locales`       | Chứa tất cả các locales được hỗ trợ (nếu được kích hoạt).                                                                                                                                                     |
| `defaultLocale` | Chứa locale mặc định được cấu hình (nếu được kích hoạt).                                                                                                                                                      |

## Giá trị trả về của getServerSideProps

Hàm `getServerSideProps` nên trả về một object với **bất kỳ một trong các** thuộc tính sau:

### `props`

Object `props` là một cặp key-value, trong đó mỗi giá trị được nhận bởi page component. Nó phải là một [serializable object](https://developer.mozilla.org/docs/Glossary/Serialization) để bất kỳ props nào được truyền, có thể được serialize với [`JSON.stringify`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/JSON/stringify).

```jsx
export async function getServerSideProps(context) {
  return {
    props: { message: `Next.js is awesome` }, // sẽ được truyền cho page component như props
  }
}
```

### `notFound`

Boolean `notFound` cho phép trang trả về trạng thái `404` và [404 Page](/docs/pages/building-your-application/routing/custom-error#404-page). Với `notFound: true`, trang sẽ trả về `404` ngay cả khi có một trang được tạo thành công trước đó. Điều này nhằm hỗ trợ các trường hợp sử dụng như nội dung do người dùng tạo bị xóa bởi tác giả của nó.

```js
export async function getServerSideProps(context) {
  const res = await fetch(`https://.../data`)
  const data = await res.json()

  if (!data) {
    return {
      notFound: true,
    }
  }

  return {
    props: { data }, // sẽ được truyền cho page component như props
  }
}
```

### `redirect`

Object `redirect` cho phép chuyển hướng đến các tài nguyên nội bộ và bên ngoài. Nó phải khớp với hình dạng của `{ destination: string, permanent: boolean }`. Trong một số trường hợp hiếm hoi, bạn có thể cần gán một mã trạng thái tùy chỉnh cho các `HTTP` clients cũ để chuyển hướng đúng cách. Trong những trường hợp này, bạn có thể sử dụng thuộc tính `statusCode` thay vì thuộc tính `permanent`, nhưng không cả hai.

```js
export async function getServerSideProps(context) {
  const res = await fetch(`https://.../data`)
  const data = await res.json()

  if (!data) {
    return {
      redirect: {
        destination: '/',
        permanent: false,
      },
    }
  }

  return {
    props: {}, // sẽ được truyền cho page component như props
  }
}
```

## Lịch sử phiên bản

| Phiên bản | Thay đổi                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------------- |
| `v13.4.0` | [App Router](/docs/app/getting-started/fetching-data) hiện đã ổn định với data fetching được đơn giản hóa |
| `v10.0.0` | Các tùy chọn `locale`, `locales`, `defaultLocale`, và `notFound` được thêm vào.                           |
| `v9.3.0`  | `getServerSideProps` được giới thiệu.                                                                     |
