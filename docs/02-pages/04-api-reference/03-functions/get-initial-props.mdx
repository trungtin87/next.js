---

> **Nên biết**: `getInitialProps` là một legacy API. Chúng tôi khuyến nghị sử dụng [`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props) hoặc [`getServerSideProps`](/docs/pages/building-your-application/data-fetching/get-server-side-props) thay thế.

`getInitialProps` là một hàm `async` có thể được thêm vào React component được export mặc định cho trang. Nó sẽ chạy trên cả server-side và lại trên client-side trong quá trình chuyển đổi trang. Kết quả của hàm sẽ được chuyển tiếp đến React component dưới dạng `props`.

```tsx filename="pages/index.tsx" switcher
import { NextPageContext } from 'next'

Page.getInitialProps = async (ctx: NextPageContext) => {
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const json = await res.json()
  return { stars: json.stargazers_count }
}

export default function Page({ stars }: { stars: number }) {
  return stars
}
```

```jsx filename="pages/index.js" switcher
Page.getInitialProps = async (ctx) => {
  const res = await fetch('https://api.github.com/repos/vercel/next.js')
  const json = await res.json()
  return { stars: json.stargazers_count }
}

export default function Page({ stars }) {
  return stars
}
```

> **Nên biết**:
>
> - Dữ liệu được trả về từ `getInitialProps` được serialize khi server rendering. Đảm bảo đối tượng được trả về từ `getInitialProps` là một `Object` thuần túy, và không sử dụng `Date`, `Map` hoặc `Set`.
> - Đối với lần tải trang ban đầu, `getInitialProps` sẽ chỉ chạy trên server. `getInitialProps` sau đó cũng sẽ chạy trên client khi điều hướng đến một route khác với component [`next/link`](/docs/pages/api-reference/components/link) hoặc bằng cách sử dụng [`next/router`](/docs/pages/api-reference/functions/use-router).
> - Nếu `getInitialProps` được sử dụng trong một `_app.js` tùy chỉnh, và trang đang được điều hướng đến đang sử dụng `getServerSideProps`, thì `getInitialProps` cũng sẽ chạy trên server.

## Đối tượng Context

`getInitialProps` nhận một đối số duy nhất gọi là `context`, là một đối tượng với các thuộc tính sau:

| Tên        | Mô tả                                                                                                |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| `pathname` | Route hiện tại, path của trang trong `/pages`                                                        |
| `query`    | Query string của URL, được parse thành một đối tượng                                                 |
| `asPath`   | `String` của path thực tế (bao gồm query) được hiển thị trong trình duyệt                            |
| `req`      | [HTTP request object](https://nodejs.org/api/http.html#http_class_http_incomingmessage) (chỉ server) |
| `res`      | [HTTP response object](https://nodejs.org/api/http.html#http_class_http_serverresponse) (chỉ server) |
| `err`      | Đối tượng lỗi nếu có bất kỳ lỗi nào được gặp phải trong quá trình rendering                          |

## Caveats

- `getInitialProps` chỉ có thể được sử dụng trong các tệp cấp cao nhất của `pages/`, và không phải trong các component lồng nhau. Để có data fetching lồng nhau ở cấp độ component, hãy xem xét khám phá [App Router](/docs/app/getting-started/fetching-data).
- Bất kể route của bạn là static hay dynamic, bất kỳ dữ liệu nào được trả về từ `getInitialProps` dưới dạng `props` sẽ có thể được kiểm tra ở phía client trong HTML ban đầu. Điều này là để cho phép trang được [hydrated](https://react.dev/reference/react-dom/hydrate) một cách chính xác. Đảm bảo rằng bạn không truyền bất kỳ thông tin nhạy cảm nào không nên có sẵn trên client trong `props`.
