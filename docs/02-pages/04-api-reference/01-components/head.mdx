title: Head

---

Chúng tôi cung cấp một component tích hợp sẵn để thêm các phần tử vào `head` của trang:

```jsx
import Head from 'next/head'

function IndexPage() {
  return (
    <div>
      <Head>
        <title>My page title</title>
      </Head>
      <p>Hello world!</p>
    </div>
  )
}

export default IndexPage
```

## Tránh các thẻ trùng lặp

Để tránh các thẻ trùng lặp trong `head` của bạn, bạn có thể sử dụng thuộc tính `key`, điều này sẽ đảm bảo thẻ chỉ được render một lần, như trong ví dụ sau:

```jsx
import Head from 'next/head'

function IndexPage() {
  return (
    <div>
      <Head>
        <title>My page title</title>
        <meta property="og:title" content="My page title" key="title" />
      </Head>
      <Head>
        <meta property="og:title" content="My new title" key="title" />
      </Head>
      <p>Hello world!</p>
    </div>
  )
}

export default IndexPage
```

Trong trường hợp này chỉ có `<meta property="og:title" />` thứ hai được render. Các thẻ `meta` với thuộc tính `key` trùng lặp được tự động xử lý.

> **Thông tin hữu ích**: Các thẻ `<title>` và `<base>` được Next.js tự động kiểm tra trùng lặp, vì vậy việc sử dụng key không cần thiết cho các thẻ này.

> Nội dung của `head` bị xóa khi unmount component, vì vậy hãy đảm bảo mỗi trang định nghĩa hoàn toàn những gì nó cần trong `head`, mà không đưa ra giả định về những gì các trang khác đã thêm vào.

## Sử dụng lồng tối thiểu

`title`, `meta` hoặc bất kỳ phần tử nào khác (ví dụ: `script`) cần được chứa dưới dạng con **trực tiếp** của phần tử `Head`,
hoặc được bọc vào tối đa một cấp `<React.Fragment>` hoặc mảng—nếu không các thẻ sẽ không được chọn đúng cách trên các điều hướng phía client.

## Sử dụng `next/script` cho scripts

Chúng tôi khuyên bạn nên sử dụng [`next/script`](/docs/pages/guides/scripts) trong component của bạn thay vì tạo `<script>` thủ công trong `next/head`.

## Không có thẻ `html` hoặc `body`

Bạn **không thể** sử dụng `<Head>` để đặt các thuộc tính trên thẻ `<html>` hoặc `<body>`. Điều này sẽ dẫn đến lỗi `next-head-count is missing`. `next/head` chỉ có thể xử lý các thẻ bên trong thẻ HTML `<head>`.
