nav_title: Phiên bản 10
description: Nâng cấp ứng dụng Next.js của bạn từ Phiên bản 9 lên Phiên bản 10.
---

Không có thay đổi đột phá (breaking changes) nào giữa phiên bản 9 và 10.

Để nâng cấp lên phiên bản 10, hãy chạy lệnh sau:

```bash filename="Terminal"
npm i next@10
```

```bash filename="Terminal"
yarn add next@10
```

```bash filename="Terminal"
pnpm up next@10
```

```bash filename="Terminal"
bun add next@10
```

> **Thông tin hữu ích:** Nếu bạn đang sử dụng TypeScript, hãy đảm bảo bạn cũng nâng cấp `@types/react` và `@types/react-dom` lên các phiên bản tương ứng của chúng.
