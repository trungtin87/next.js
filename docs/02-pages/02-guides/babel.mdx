Next.js bao gồm preset `next/babel` vào ứng dụng của bạn, bao gồm mọi thứ cần thiết để biên dịch các ứng dụng React và mã phía server. Nhưng nếu bạn muốn mở rộng các cấu hình Babel mặc định, điều đó cũng có thể.

## Thêm Presets và Plugins

Để bắt đầu, bạn chỉ cần định nghĩa tệp `.babelrc` (hoặc `babel.config.js`) trong thư mục gốc của dự án của bạn. Nếu tệp như vậy được tìm thấy, nó sẽ được coi là _nguồn sự thật_, và do đó nó cần định nghĩa những gì Next.js cần, đó là preset `next/babel`.

Đây là một ví dụ về tệp `.babelrc`:

```json filename=".babelrc"
{
  "presets": ["next/babel"],
  "plugins": []
}
```

Bạn có thể [xem tệp này](https://github.com/vercel/next.js/blob/canary/packages/next/src/build/babel/preset.ts) để tìm hiểu về các preset được bao gồm bởi `next/babel`.

Để thêm presets/plugins **mà không cấu hình chúng**, bạn có thể làm theo cách này:

```json filename=".babelrc"
{
  "presets": ["next/babel"],
  "plugins": ["@babel/plugin-proposal-do-expressions"]
}
```

## Tùy chỉnh Presets và Plugins

Để thêm presets/plugins **với cấu hình tùy chỉnh**, hãy làm điều đó trên preset `next/babel` như sau:

```json filename=".babelrc"
{
  "presets": [
    [
      "next/babel",
      {
        "preset-env": {},
        "transform-runtime": {},
        "styled-jsx": {},
        "class-properties": {}
      }
    ]
  ],
  "plugins": []
}
```

Để tìm hiểu thêm về các tùy chọn có sẵn cho mỗi cấu hình, hãy truy cập trang web [tài liệu](https://babeljs.io/docs/) của babel.

> **Thông tin hữu ích**:
>
> - Next.js sử dụng [phiên bản Node.js **hiện tại**](https://github.com/nodejs/release#release-schedule) cho các biên dịch phía server.
> - Tùy chọn `modules` trên `"preset-env"` nên được giữ là `false`, nếu không webpack code splitting sẽ bị tắt.
