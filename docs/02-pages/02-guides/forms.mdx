Biểu mẫu cho phép bạn tạo và cập nhật dữ liệu trong các ứng dụng web. Next.js cung cấp một cách mạnh mẽ để xử lý các thay đổi dữ liệu bằng cách sử dụng **Tuyến API**. Hướng dẫn này sẽ hướng dẫn bạn cách xử lý việc gửi biểu mẫu trên máy chủ.

## Biểu mẫu máy chủ

Để xử lý việc gửi biểu mẫu trên máy chủ, hãy tạo một điểm cuối API để thay đổi dữ liệu một cách an toàn.

```ts filename="pages/api/submit.ts" switcher
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const data = req.body
  const id = await createItem(data)
  res.status(200).json({ id })
}
```

```js filename="pages/api/submit.js" switcher
export default function handler(req, res) {
  const data = req.body
  // gọi cơ sở dữ liệu của bạn, v.v.
  // const id = await createItem(data)
  // ...
  res.status(200).json({ data })
}
```

Sau đó, gọi Tuyến API từ máy khách với một trình xử lý sự kiện:

```tsx filename="pages/index.tsx" switcher
import { FormEvent } from 'react'

export default function Page() {
  async function onSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault()

    const formData = new FormData(event.currentTarget)
    const response = await fetch('/api/submit', {
      method: 'POST',
      body: formData,
    })

    // Xử lý phản hồi nếu cần
    const data = await response.json()
    // ...
  }

  return (
    <form onSubmit={onSubmit}>
      <input type="text" name="name" />
      <button type="submit">Gửi</button>
    </form>
  )
}
```

> **Cần biết:**
>
> - Các Tuyến API [không chỉ định tiêu đề CORS](https://developer.mozilla.org/docs/Web/HTTP/CORS), có nghĩa là chúng chỉ cùng một nguồn gốc theo mặc định.
> - Vì các Tuyến API chạy trên máy chủ, chúng tôi có thể sử dụng các giá trị nhạy cảm (như khóa API) thông qua [Biến môi trường](/docs/pages/guides/environment-variables) mà không để lộ chúng cho máy khách. Điều này rất quan trọng đối với tính bảo mật của ứng dụng của bạn.

## Xác thực biểu mẫu

Chúng tôi khuyên bạn nên sử dụng xác thực HTML như `required` và `type="email"` để xác thực biểu mẫu phía máy khách cơ bản.

Để xác thực phía máy chủ nâng cao hơn, bạn có thể sử dụng một thư viện xác thực lược đồ như [zod](https://zod.dev/) để xác thực các trường biểu mẫu trước khi thay đổi dữ liệu:

```ts filename="pages/api/submit.ts" switcher
import type { NextApiRequest, NextApiResponse } from 'next'
import { z } from 'zod'

const schema = z.object({
  // ...
})

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const parsed = schema.parse(req.body)
  // ...
}
```

```js filename="pages/api/submit.js" switcher
import { z } from 'zod'

const schema = z.object({
  // ...
})

export default async function handler(req, res) {
  const parsed = schema.parse(req.body)
  // ...
}
```

### Xử lý lỗi

Bạn có thể sử dụng trạng thái React để hiển thị thông báo lỗi khi gửi biểu mẫu không thành công:

```tsx filename="pages/index.tsx" switcher
import React, { useState, FormEvent } from 'react'

export default function Page() {
  const [isLoading, setIsLoading] = useState<boolean>(false)
  const [error, setError] = useState<string | null>(null)

  async function onSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault()
    setIsLoading(true)
    setError(null) // Xóa các lỗi trước đó khi một yêu cầu mới bắt đầu

    try {
      const formData = new FormData(event.currentTarget)
      const response = await fetch('/api/submit', {
        method: 'POST',
        body: formData,
      })

      if (!response.ok) {
        throw new Error('Không thể gửi dữ liệu. Vui lòng thử lại.')
      }

      // Xử lý phản hồi nếu cần
      const data = await response.json()
      // ...
    } catch (error) {
      // Ghi lại thông báo lỗi để hiển thị cho người dùng
      setError(error.message)
      console.error(error)
    } finally {
      setIsLoading(false)
    }
  }

  return (
    <div>
      {error && <div style={{ color: 'red' }}>{error}</div>}
      <form onSubmit={onSubmit}>
        <input type="text" name="name" />
        <button type="submit" disabled={isLoading}>
          {isLoading ? 'Đang tải...' : 'Gửi'}
        </button>
      </form>
    </div>
  )
}
```

## Hiển thị trạng thái tải

Bạn có thể sử dụng trạng thái React để hiển thị trạng thái tải khi biểu mẫu đang được gửi trên máy chủ:

```tsx filename="pages/index.tsx" switcher

  const [isLoading, setIsLoading] = useState<boolean>(false)

    event.preventDefault()

    try {
      const formData = new FormData(event.currentTarget)
      const response = await fetch('/api/submit', {
        method: 'POST',
        body: formData,
      })

      // Xử lý phản hồi nếu cần
      const data = await response.json()
      // ...
    } catch (error) {
      // Xử lý lỗi nếu cần
      console.error(error)
    } finally {
      setIsLoading(false) // Đặt trạng thái tải thành false khi yêu cầu hoàn tất
    }
  }

  return (
    <form onSubmit={onSubmit}>
      <input type="text" name="name" />
      <button type="submit" disabled={isLoading}>
        {isLoading ? 'Đang tải...' : 'Gửi'}

  )
}
```

### Chuyển hướng

Nếu bạn muốn chuyển hướng người dùng đến một tuyến đường khác sau khi thay đổi, bạn có thể [`chuyển hướng`](/docs/pages/building-your-application/routing/api-routes#response-helpers) đến bất kỳ URL tuyệt đối hoặc tương đối nào:

```ts filename="pages/api/submit.ts" switcher
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const id = await addPost()
  res.redirect(307, `/post/${id}`)
}
```

