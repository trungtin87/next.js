## Hành vi mặc định

Next.js biên dịch CSS cho [hỗ trợ CSS tích hợp sẵn](/docs/app/getting-started/css) của nó bằng PostCSS.

Ngay từ đầu, không cần cấu hình, Next.js biên dịch CSS với các transformations sau:

- [Autoprefixer](https://github.com/postcss/autoprefixer) tự động thêm vendor prefixes vào CSS rules (back to IE11).
- [Cross-browser Flexbox bugs](https://github.com/philipwalton/flexbugs) được sửa để hoạt động như [the spec](https://www.w3.org/TR/css-flexbox-1/).
- Các tính năng CSS mới được tự động biên dịch để tương thích với Internet Explorer 11:
  - [`all` Property](https://developer.mozilla.org/docs/Web/CSS/all)
  - [Break Properties](https://developer.mozilla.org/docs/Web/CSS/break-after)
  - [`font-variant` Property](https://developer.mozilla.org/docs/Web/CSS/font-variant)
  - [Gap Properties](https://developer.mozilla.org/docs/Web/CSS/gap)
  - [Media Query Ranges](https://developer.mozilla.org/docs/Web/CSS/Media_Queries/Using_media_queries#Syntax_improvements_in_Level_4)

Theo mặc định, [CSS Grid](https://www.w3.org/TR/css-grid-1/) và [Custom Properties](https://developer.mozilla.org/docs/Web/CSS/var) (CSS variables) **không được biên dịch** để hỗ trợ IE11.

Để biên dịch [CSS Grid Layout](https://developer.mozilla.org/docs/Web/CSS/grid) cho IE11, bạn có thể đặt comment sau ở đầu tệp CSS của bạn:

```css
/* autoprefixer grid: autoplace */
```

Bạn cũng có thể enable hỗ trợ IE11 cho [CSS Grid Layout](https://developer.mozilla.org/docs/Web/CSS/grid)
trong toàn bộ dự án của bạn bằng cách cấu hình autoprefixer với cấu hình được hiển thị bên dưới (collapsed).
Xem [\"Customizing Plugins\"](#customizing-plugins) bên dưới để biết thêm thông tin.

<details>
  <summary>Click để xem cấu hình enable CSS Grid Layout</summary>

```json filename="postcss.config.json"
{
  "plugins": [
    "postcss-flexbugs-fixes",
    [
      "postcss-preset-env",
      {
        "autoprefixer": {
          "flexbox": "no-2009",
          "grid": "autoplace"
        },
        "stage": 3,
        "features": {
          "custom-properties": false
        }
      }
    ]
  ]
}
```

</details>

CSS variables không được biên dịch vì [không thể làm điều đó một cách an toàn](https://github.com/MadLittleMods/postcss-css-variables#caveats).
Nếu bạn phải sử dụng variables, hãy xem xét sử dụng một cái gì đó như [Sass variables](https://sass-lang.com/documentation/variables) được biên dịch bởi [Sass](https://sass-lang.com/).

## Tùy chỉnh Target Browsers

Next.js cho phép bạn cấu hình target browsers (cho [Autoprefixer](https://github.com/postcss/autoprefixer) và compiled css features) thông qua [Browserslist](https://github.com/browserslist/browserslist).

Để tùy chỉnh browserslist, hãy tạo một key `browserslist` trong `package.json` của bạn như sau:

```json filename="package.json"
{
  "browserslist": [">0.3%", "not dead", "not op_mini all"]
}
```

Bạn có thể sử dụng công cụ [browsersl.ist](https://browsersl.ist/?q=%3E0.3%25%2C+not+ie+11%2C+not+dead%2C+not+op_mini+all) để visualize browsers bạn đang targeting.

## CSS Modules

Không cần cấu hình để hỗ trợ CSS Modules. Để enable CSS Modules cho một tệp, hãy đổi tên tệp thành có extension `.module.css`.

Bạn có thể tìm hiểu thêm về [hỗ trợ CSS Module của Next.js tại đây](/docs/app/getting-started/css).

## Tùy chỉnh Plugins

> **Cảnh báo**: Khi bạn định nghĩa một tệp cấu hình PostCSS tùy chỉnh, Next.js **hoàn toàn disable** [hành vi mặc định](#default-behavior).
> Hãy đảm bảo cấu hình thủ công tất cả các tính năng bạn cần được biên dịch, bao gồm [Autoprefixer](https://github.com/postcss/autoprefixer).
> Bạn cũng cần cài đặt thủ công bất kỳ plugins nào được bao gồm trong cấu hình tùy chỉnh của bạn, tức là `npm install postcss-flexbugs-fixes postcss-preset-env`.

Để tùy chỉnh cấu hình PostCSS, hãy tạo một tệp `postcss.config.json` trong root của dự án của bạn.

Đây là cấu hình mặc định được sử dụng bởi Next.js:

```json filename="postcss.config.json"
{
  "plugins": [
    "postcss-flexbugs-fixes",
    [
      "postcss-preset-env",
      {
        "autoprefixer": {
          "flexbox": "no-2009"
        },
        "stage": 3,
        "features": {
          "custom-properties": false
        }
      }
    ]
  ]
}
```

> **Nên biết**: Next.js cũng cho phép tệp được đặt tên là `.postcssrc.json`, hoặc, được đọc từ key `postcss` trong `package.json`.

Cũng có thể cấu hình PostCSS với một tệp `postcss.config.js`, hữu ích khi bạn muốn conditionally include plugins dựa trên environment:

```js filename="postcss.config.js"
module.exports = {
  plugins:
    process.env.NODE_ENV === 'production'
      ? [
          'postcss-flexbugs-fixes',
          [
            'postcss-preset-env',
            {
              autoprefixer: {
                flexbox: 'no-2009',
              },
              stage: 3,
              features: {
                'custom-properties': false,
              },
            },
          ],
        ]
      : [
          // No transformations in development
        ],
}
```

> **Nên biết**: Next.js cũng cho phép tệp được đặt tên là `.postcssrc.js`.

**Không sử dụng `require()`** để import PostCSS Plugins. Plugins phải được cung cấp dưới dạng strings.

> **Nên biết**: Nếu `postcss.config.js` của bạn cần hỗ trợ các công cụ non-Next.js khác trong cùng dự án, bạn phải sử dụng định dạng object-based có thể tương tác thay thế:
>
> ```js
> module.exports = {
>   plugins: {
>     'postcss-flexbugs-fixes': {},
>     'postcss-preset-env': {
>       autoprefixer: {
>         flexbox: 'no-2009',
>       },
>       stage: 3,
>       features: {
>         'custom-properties': false,
>       },
>     },
>   },
> }
> ```
