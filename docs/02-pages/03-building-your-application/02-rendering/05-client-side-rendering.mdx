Trong Client-Side Rendering (CSR) với React, trình duyệt tải xuống một trang HTML tối thiểu và JavaScript cần thiết cho trang. JavaScript sau đó được sử dụng để cập nhật DOM và render trang. Khi ứng dụng được tải lần đầu tiên, người dùng có thể nhận thấy một chút delay trước khi họ có thể thấy toàn bộ trang, điều này là do trang chưa được render đầy đủ cho đến khi tất cả JavaScript được tải xuống, parse và thực thi.

Sau khi trang đã được tải lần đầu tiên, việc điều hướng đến các trang khác trên cùng một website thường nhanh hơn, vì chỉ cần fetch dữ liệu cần thiết, và JavaScript có thể render lại các phần của trang mà không yêu cầu refresh trang đầy đủ.

Trong Next.js, có hai cách bạn có thể triển khai client-side rendering:

1. Sử dụng hook `useEffect()` của React bên trong các trang của bạn thay vì các phương thức server-side rendering ([`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props) và [`getServerSideProps`](/docs/pages/building-your-application/data-fetching/get-server-side-props)).
2. Sử dụng một thư viện data fetching như [SWR](https://swr.vercel.app/) hoặc [TanStack Query](https://tanstack.com/query/latest/) để fetch dữ liệu trên client (được khuyến nghị).

Đây là một ví dụ về việc sử dụng `useEffect()` bên trong một trang Next.js:

```jsx filename="pages/index.js"
import React, { useState, useEffect } from 'react'

export function Page() {
  const [data, setData] = useState(null)

  useEffect(() => {
    const fetchData = async () => {
      const response = await fetch('https://api.example.com/data')
      if (!response.ok) {
        throw new Error(`HTTP error! status: ${response.status}`)
      }
      const result = await response.json()
      setData(result)
    }

    fetchData().catch((e) => {
      // handle the error as needed
      console.error('An error occurred while fetching the data: ', e)
    })
  }, [])

  return <p>{data ? `Your data: ${data}` : 'Loading...'}</p>
}
```

Trong ví dụ trên, component bắt đầu bằng cách render `Loading...`. Sau đó, một khi dữ liệu được fetch, nó render lại và hiển thị dữ liệu.

Mặc dù việc fetch dữ liệu trong một `useEffect` là một pattern bạn có thể thấy trong các React Applications cũ hơn, chúng tôi khuyến nghị sử dụng một thư viện data-fetching để có hiệu suất tốt hơn, caching, optimistic updates và nhiều hơn nữa. Đây là một ví dụ tối thiểu sử dụng [SWR](https://swr.vercel.app/) để fetch dữ liệu trên client:

```jsx filename="pages/index.js"
import useSWR from 'swr'

export function Page() {
  const { data, error, isLoading } = useSWR(
    'https://api.example.com/data',
    fetcher
  )

  if (error) return <p>Failed to load.</p>
  if (isLoading) return <p>Loading...</p>

  return <p>Your Data: {data}</p>
}
```

> **Nên biết**:
>
> Hãy nhớ rằng CSR có thể ảnh hưởng đến SEO. Một số search engine crawlers có thể không thực thi JavaScript và do đó chỉ thấy trạng thái empty hoặc loading ban đầu của ứng dụng của bạn. Nó cũng có thể dẫn đến các vấn đề về hiệu suất cho người dùng có kết nối internet hoặc thiết bị chậm hơn, vì họ cần đợi tất cả JavaScript tải và chạy trước khi họ có thể thấy toàn bộ trang. Next.js thúc đẩy một cách tiếp cận hybrid cho phép bạn sử dụng kết hợp [server-side rendering](/docs/pages/building-your-application/rendering/server-side-rendering), [static site generation](/docs/pages/building-your-application/rendering/static-site-generation) và client-side rendering, **tùy thuộc vào nhu cầu của mỗi trang** trong ứng dụng của bạn. Trong App Router, bạn cũng có thể sử dụng [Loading UI với Suspense](/docs/app/api-reference/file-conventions/loading) để hiển thị một loading indicator trong khi trang đang được render.
