---
title: Server-side Rendering (SSR)
description: Sử dụng Server-side Rendering để render các trang trên mỗi yêu cầu.
---

> Còn được gọi là "SSR" hoặc "Dynamic Rendering".

Nếu một trang sử dụng **Server-side Rendering**, HTML của trang được tạo trên **mỗi yêu cầu**.

Để sử dụng Server-side Rendering cho một trang, bạn cần `export` một hàm `async` có tên `getServerSideProps`. Hàm này sẽ được gọi bởi server trên mỗi yêu cầu.

Ví dụ, giả sử trang của bạn cần pre-render dữ liệu được cập nhật thường xuyên (được lấy từ API bên ngoài). Bạn có thể viết `getServerSideProps` để lấy dữ liệu này và truyền nó đến `Page` như bên dưới:

```jsx
export default function Page({ data }) {
  // Render data...
}

// Điều này được gọi trên mỗi yêu cầu
export async function getServerSideProps() {
  // Lấy dữ liệu từ API bên ngoài
  const res = await fetch(`https://.../data`)
  const data = await res.json()

  // Truyền dữ liệu đến trang thông qua props
  return { props: { data } }
}
```

Như bạn có thể thấy, `getServerSideProps` tương tự như `getStaticProps`, nhưng sự khác biệt là `getServerSideProps` được chạy trên mỗi yêu cầu thay vì tại thời điểm build.

Để tìm hiểu thêm về cách `getServerSideProps` hoạt động, hãy xem [tài liệu Data Fetching](/docs/pages/building-your-application/data-fetching/get-server-side-props) của chúng tôi.
