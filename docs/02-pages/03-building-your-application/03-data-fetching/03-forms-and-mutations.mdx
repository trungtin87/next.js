Forms cho phép bạn tạo và cập nhật dữ liệu trong các ứng dụng web. Next.js cung cấp một cách mạnh mẽ để xử lý form submissions và data mutations bằng cách sử dụng **API Routes**.

> **Nên biết:**
>
> - Chúng tôi sẽ sớm khuyến nghị [incrementally adopting](/docs/app/guides/migrating/app-router-migration) App Router và sử dụng [Server Actions](/docs/app/getting-started/updating-data) để xử lý form submissions và data mutations. Server Actions cho phép bạn định nghĩa các hàm server bất đồng bộ có thể được gọi trực tiếp từ các component của bạn, mà không cần tạo API Route thủ công.
> - API Routes [không chỉ định CORS headers](https://developer.mozilla.org/docs/Web/HTTP/CORS), nghĩa là chúng chỉ là same-origin theo mặc định.
> - Vì API Routes chạy trên server, chúng ta có thể sử dụng các giá trị nhạy cảm (như API keys) thông qua [Environment Variables](/docs/pages/guides/environment-variables) mà không expose chúng cho client. Điều này rất quan trọng cho bảo mật của ứng dụng của bạn.

## Ví dụ

### Redirecting

Nếu bạn muốn redirect người dùng đến một route khác sau một mutation, bạn có thể [`redirect`](/docs/pages/building-your-application/routing/api-routes#response-helpers) đến bất kỳ URL tuyệt đối hoặc tương đối nào:

```ts filename="pages/api/submit.ts" switcher
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const id = await addPost()
  res.redirect(307, `/post/${id}`)
}
```

```js filename="pages/api/submit.js" switcher
export default async function handler(req, res) {
  const id = await addPost()
  res.redirect(307, `/post/${id}`)
}
```

### Setting cookies

Bạn có thể set cookies bên trong một API Route bằng cách sử dụng phương thức `setHeader` trên response:

```ts filename="pages/api/cookie.ts" switcher
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  res.setHeader('Set-Cookie', 'username=lee; Path=/; HttpOnly')
  res.status(200).send('Cookie has been set.')
}
```

```js filename="pages/api/cookie.js" switcher
export default async function handler(req, res) {
  res.setHeader('Set-Cookie', 'username=lee; Path=/; HttpOnly')
  res.status(200).send('Cookie has been set.')
}
```

### Reading cookies

Bạn có thể đọc cookies bên trong một API Route bằng cách sử dụng request helper [`cookies`](/docs/pages/building-your-application/routing/api-routes#request-helpers):

```ts filename="pages/api/cookie.ts" switcher
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const auth = req.cookies.authorization
  // ...
}
```

```js filename="pages/api/cookie.js" switcher
export default async function handler(req, res) {
  const auth = req.cookies.authorization
  // ...
}
```

### Deleting cookies

Bạn có thể xóa cookies bên trong một API Route bằng cách sử dụng phương thức `setHeader` trên response:

```ts filename="pages/api/cookie.ts" switcher
import type { NextApiRequest, NextApiResponse } from 'next'

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse
) {
  res.setHeader('Set-Cookie', 'username=; Path=/; HttpOnly; Max-Age=0')
  res.status(200).send('Cookie has been deleted.')
}
```

```js filename="pages/api/cookie.js" switcher
export default async function handler(req, res) {
  res.setHeader('Set-Cookie', 'username=; Path=/; HttpOnly; Max-Age=0')
  res.status(200).send('Cookie has been deleted.')
}
```
