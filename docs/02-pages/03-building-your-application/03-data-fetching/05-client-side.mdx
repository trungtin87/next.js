Client-side data fetching hữu ích khi trang của bạn không yêu cầu SEO indexing, khi bạn không cần pre-render dữ liệu của mình, hoặc khi nội dung của các trang của bạn cần cập nhật thường xuyên. Không giống như các API server-side rendering, bạn có thể sử dụng client-side data fetching ở cấp độ component.

Nếu được thực hiện ở cấp độ trang, dữ liệu được lấy tại runtime, và nội dung của trang được cập nhật khi dữ liệu thay đổi. Khi được sử dụng ở cấp độ component, dữ liệu được lấy tại thời điểm component mount, và nội dung của component được cập nhật khi dữ liệu thay đổi.

Điều quan trọng cần lưu ý là sử dụng client-side data fetching có thể ảnh hưởng đến hiệu suất của ứng dụng của bạn và tốc độ tải của các trang của bạn. Điều này là do data fetching được thực hiện tại thời điểm component hoặc trang mount, và dữ liệu không được cache.

## Client-side data fetching với useEffect

Ví dụ sau đây cho thấy cách bạn có thể lấy dữ liệu ở phía client bằng cách sử dụng hook useEffect.

```jsx
import { useState, useEffect } from 'react'

function Profile() {
  const [data, setData] = useState(null)
  const [isLoading, setLoading] = useState(true)

  useEffect(() => {
    fetch('/api/profile-data')
      .then((res) => res.json())
      .then((data) => {
        setData(data)
        setLoading(false)
      })
  }, [])

  if (isLoading) return <p>Loading...</p>
  if (!data) return <p>No profile data</p>

  return (
    <div>
      <h1>{data.name}</h1>
      <p>{data.bio}</p>
    </div>
  )
}
```

## Client-side data fetching với SWR

Nhóm đằng sau Next.js đã tạo một thư viện React Hook để lấy dữ liệu có tên [**SWR**](https://swr.vercel.app/). Nó **được khuyến nghị cao** nếu bạn đang lấy dữ liệu ở phía client. Nó xử lý caching, revalidation, focus tracking, refetching theo khoảng thời gian, và nhiều hơn nữa.

Sử dụng cùng ví dụ như trên, giờ đây chúng ta có thể sử dụng SWR để lấy dữ liệu profile. SWR sẽ tự động cache dữ liệu cho chúng ta và sẽ revalidate dữ liệu nếu nó trở nên cũ.

Để biết thêm thông tin về việc sử dụng SWR, hãy xem [tài liệu SWR](https://swr.vercel.app/docs/getting-started).

```jsx
import useSWR from 'swr'

const fetcher = (...args) => fetch(...args).then((res) => res.json())

function Profile() {
  const { data, error } = useSWR('/api/profile-data', fetcher)

  if (error) return <div>Failed to load</div>
  if (!data) return <div>Loading...</div>

  return (
    <div>
      <h1>{data.name}</h1>
      <p>{data.bio}</p>
    </div>
  )
}
```
