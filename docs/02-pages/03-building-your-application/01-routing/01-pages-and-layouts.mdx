Pages Router có một router dựa trên hệ thống tệp được xây dựng trên khái niệm về các trang (pages).

Khi một tệp được thêm vào thư mục `pages`, nó tự động có sẵn dưới dạng một route.

Trong Next.js, một **page** là một [React Component](https://react.dev/learn/your-first-component) được export từ một tệp `.js`, `.jsx`, `.ts`, hoặc `.tsx` trong thư mục `pages`. Mỗi page được liên kết với một route dựa trên tên tệp của nó.

**Ví dụ**: Nếu bạn tạo `pages/about.js` export một React component như bên dưới, nó sẽ có thể truy cập được tại `/about`.

```jsx
export default function About() {
  return <div>About</div>
}
```

## Index routes

Router sẽ tự động định tuyến các tệp có tên `index` đến thư mục gốc của thư mục đó.

- `pages/index.js` → `/`
- `pages/blog/index.js` → `/blog`

## Nested routes

Router hỗ trợ các tệp lồng nhau. Nếu bạn tạo một cấu trúc thư mục lồng nhau, các tệp sẽ tự động được định tuyến theo cùng một cách.

- `pages/blog/first-post.js` → `/blog/first-post`
- `pages/dashboard/settings/username.js` → `/dashboard/settings/username`

## Pages với Dynamic Routes

Next.js hỗ trợ các trang với dynamic routes. Ví dụ, nếu bạn tạo một tệp gọi là `pages/posts/[id].js`, thì nó sẽ có thể truy cập được tại `posts/1`, `posts/2`, v.v.

> Để tìm hiểu thêm về dynamic routing, hãy xem [tài liệu Dynamic Routing](/docs/pages/building-your-application/routing/dynamic-routes).

## Layout Pattern

Mô hình React cho phép chúng ta giải cấu trúc một [page](/docs/pages/building-your-application/routing/pages-and-layouts) thành một loạt các components. Nhiều components trong số này thường được tái sử dụng giữa các trang. Ví dụ, bạn có thể có cùng một thanh điều hướng và footer trên mọi trang.

```jsx filename="components/layout.js"
import Navbar from './navbar'
import Footer from './footer'

export default function Layout({ children }) {
  return (
    <>
      <Navbar />
      <main>{children}</main>
      <Footer />
    </>
  )
}
```

## Ví dụ

### Single Shared Layout với Custom App

Nếu bạn chỉ có một layout cho toàn bộ ứng dụng của mình, bạn có thể tạo một [Custom App](/docs/pages/building-your-application/routing/custom-app) và bọc ứng dụng của bạn với layout đó. Vì component `<Layout />` được tái sử dụng khi thay đổi trang, state của component sẽ được giữ nguyên (ví dụ: giá trị input).

```jsx filename="pages/_app.js"
import Layout from '../components/layout'

export default function MyApp({ Component, pageProps }) {
  return (
    <Layout>
      <Component {...pageProps} />
    </Layout>
  )
}
```

### Per-Page Layouts

Nếu bạn cần nhiều layouts, bạn có thể thêm một thuộc tính `getLayout` vào page của mình, cho phép bạn trả về một React component cho layout. Điều này cho phép bạn định nghĩa layout trên cơ sở _từng trang_ (per-page basis). Vì chúng ta đang trả về một hàm, chúng ta có thể có các layouts lồng nhau phức tạp nếu muốn.

```jsx filename="pages/index.js"

import Layout from '../components/layout'
import NestedLayout from '../components/nested-layout'

export default function Page() {
  return (
    /** Your content */
  )
}

Page.getLayout = function getLayout(page) {
  return (
    <Layout>
      <NestedLayout>{page}</NestedLayout>
    </Layout>
  )
}
```

```jsx filename="pages/_app.js"
export default function MyApp({ Component, pageProps }) {
  // Use the layout defined at the page level, if available
  const getLayout = Component.getLayout ?? ((page) => page)

  return getLayout(<Component {...pageProps} />)
}
```

Khi điều hướng giữa các trang, chúng ta muốn _duy trì_ (persist) page state (giá trị input, vị trí cuộn, v.v.) cho trải nghiệm Single-Page Application (SPA).

Mô hình layout này cho phép duy trì state vì cây React component được duy trì giữa các chuyển đổi trang. Với cây component, React có thể hiểu những phần tử nào đã thay đổi để bảo toàn state.

> **Nên biết**: Quá trình này được gọi là [reconciliation](https://react.dev/learn/preserving-and-resetting-state), đó là cách React hiểu những phần tử nào đã thay đổi.

### Với TypeScript

Khi sử dụng TypeScript, trước tiên bạn phải tạo một type mới cho các pages của mình bao gồm một hàm `getLayout`. Sau đó, bạn phải tạo một type mới cho `AppProps` của mình ghi đè thuộc tính `Component` để sử dụng type đã tạo trước đó.

```tsx filename="pages/index.tsx" switcher
import type { ReactElement } from 'react'
import Layout from '../components/layout'
import NestedLayout from '../components/nested-layout'
import type { NextPageWithLayout } from './_app'

const Page: NextPageWithLayout = () => {
  return <p>hello world</p>
}

Page.getLayout = function getLayout(page: ReactElement) {
  return (
    <Layout>
      <NestedLayout>{page}</NestedLayout>
    </Layout>
  )
}

export default Page
```

```jsx filename="pages/index.js" switcher
import Layout from '../components/layout'
import NestedLayout from '../components/nested-layout'

const Page = () => {
  return <p>hello world</p>
}

Page.getLayout = function getLayout(page) {
  return (
    <Layout>
      <NestedLayout>{page}</NestedLayout>
    </Layout>
  )
}

export default Page
```

```tsx filename="pages/_app.tsx" switcher
import type { ReactElement, ReactNode } from 'react'
import type { NextPage } from 'next'
import type { AppProps } from 'next/app'

export type NextPageWithLayout<P = {}, IP = P> = NextPage<P, IP> & {
  getLayout?: (page: ReactElement) => ReactNode
}

type AppPropsWithLayout = AppProps & {
  Component: NextPageWithLayout
}

export default function MyApp({ Component, pageProps }: AppPropsWithLayout) {
  // Use the layout defined at the page level, if available
  const getLayout = Component.getLayout ?? ((page) => page)

  return getLayout(<Component {...pageProps} />)
}
```

```jsx filename="pages/_app.js" switcher
export default function MyApp({ Component, pageProps }) {
  // Use the layout defined at the page level, if available
  const getLayout = Component.getLayout ?? ((page) => page)

  return getLayout(<Component {...pageProps} />)
}
```

### Data Fetching

Bên trong layout của bạn, bạn có thể fetch data phía client sử dụng `useEffect` hoặc một thư viện như [SWR](https://swr.vercel.app/). Vì tệp này không phải là một [Page](/docs/pages/building-your-application/routing/pages-and-layouts), bạn không thể sử dụng `getStaticProps` hoặc `getServerSideProps` hiện tại.

```jsx filename="components/layout.js"
import useSWR from 'swr'
import Navbar from './navbar'
import Footer from './footer'

export default function Layout({ children }) {
  const { data, error } = useSWR('/api/navigation', fetcher)

  if (error) return <div>Failed to load</div>
  if (!data) return <div>Loading...</div>

  return (
    <>
      <Navbar links={data.links} />
      <main>{children}</main>
      <Footer />
    </>
  )
}
```
