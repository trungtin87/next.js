Next.js sử dụng thành phần `App` để khởi tạo các trang. Bạn có thể ghi đè nó và kiểm soát việc khởi tạo trang và:

- Tạo một bố cục được chia sẻ giữa các lần thay đổi trang
- Chèn thêm dữ liệu vào các trang
- [Thêm CSS toàn cục](/docs/app/getting-started/css)

## Cách sử dụng

Để ghi đè `App` mặc định, hãy tạo tệp `pages/_app` như bên dưới:

```tsx filename="pages/_app.tsx" switcher
import type { AppProps } from 'next/app'

export default function MyApp({ Component, pageProps }: AppProps) {
  return <Component {...pageProps} />
}
```

```jsx filename="pages/_app.jsx" switcher
export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

Prop `Component` là `page` đang hoạt động, vì vậy bất cứ khi nào bạn điều hướng giữa các tuyến, `Component` sẽ thay đổi thành `page` mới. Do đó, bất kỳ prop nào bạn gửi đến `Component` sẽ được `page` nhận.

`pageProps` là một đối tượng với các prop ban đầu đã được tải sẵn cho trang của bạn bằng một trong các [phương thức tìm nạp dữ liệu](/docs/pages/building-your-application/data-fetching) của chúng tôi, nếu không thì nó là một đối tượng trống.

> **Cần biết**:
>
> - Nếu ứng dụng của bạn đang chạy và bạn đã thêm một `App` tùy chỉnh, bạn sẽ cần khởi động lại máy chủ phát triển. Chỉ bắt buộc nếu `pages/_app.js` không tồn tại trước đó.
> - `App` không hỗ trợ các [phương thức tìm nạp dữ liệu](/docs/pages/building-your-application/data-fetching) của Next.js như [`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props) hoặc [`getServerSideProps`](/docs/pages/building-your-application/data-fetching/get-server-side-props).

## `getInitialProps` với `App`

Sử dụng [`getInitialProps`](/docs/pages/api-reference/functions/get-initial-props) trong `App` sẽ vô hiệu hóa [Tối ưu hóa tĩnh tự động](/docs/pages/building-your-application/rendering/automatic-static-optimization) cho các trang không có [`getStaticProps`](/docs/pages/building-your-application/data-fetching/get-static-props).

**Chúng tôi không khuyến khích sử dụng mẫu này.** Thay vào đó, hãy xem xét [áp dụng dần dần](/docs/app/guides/migrating/app-router-migration) App Router, cho phép bạn tìm nạp dữ liệu cho các trang và bố cục dễ dàng hơn.

```tsx filename="pages/_app.tsx" switcher
import App, { AppContext, AppInitialProps, AppProps } from 'next/app'

type AppOwnProps = { example: string }

export default function MyApp({
  Component,
  pageProps,
  example,
}: AppProps & AppOwnProps) {
  return (
    <>
      <p>Data: {example}</p>
      <Component {...pageProps} />
    </>
  )
}

MyApp.getInitialProps = async (
  context: AppContext
): Promise<AppOwnProps & AppInitialProps> => {
  const ctx = await App.getInitialProps(context)

  return { ...ctx, example: 'data' }
}
```

```jsx filename="pages/_app.jsx" switcher
import App from 'next/app'

export default function MyApp({ Component, pageProps, example }) {
  return (
    <>
      <p>Data: {example}</p>
      <Component {...pageProps} />
    </>
  )
}

MyApp.getInitialProps = async (context) => {
  const ctx = await App.getInitialProps(context)

  return { ...ctx, example: 'data' }
}
```
