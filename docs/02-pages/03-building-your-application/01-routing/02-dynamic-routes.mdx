Khi bạn không biết trước tên phân đoạn chính xác và muốn tạo tuyến đường từ dữ liệu động, bạn có thể sử dụng Phân đoạn động được điền vào tại thời điểm yêu cầu hoặc [kết xuất trước](/docs/pages/building-your-application/data-fetching/get-static-paths) tại thời điểm xây dựng.

## Quy ước

Một Phân đoạn động có thể được tạo bằng cách bao bọc tên tệp hoặc thư mục trong dấu ngoặc vuông: `[segmentName]`. Ví dụ: `[id]` hoặc `[slug]`.

Các phân đoạn động có thể được truy cập từ [`useRouter`](/docs/pages/api-reference/functions/use-router).

## Ví dụ

Ví dụ, một blog có thể bao gồm tuyến đường sau `pages/blog/[slug].js` trong đó `[slug]` là Phân đoạn động cho các bài đăng trên blog.

```jsx
import { useRouter } from 'next/router'

export default function Page() {
  const router = useRouter()
  return <p>Bài đăng: {router.query.slug}</p>
}
```

| Tuyến đường            | URL ví dụ | `params`        |
| ---------------------- | --------- | --------------- |
| `pages/blog/[slug].js` | `/blog/a` | `{ slug: 'a' }` |
| `pages/blog/[slug].js` | `/blog/b` | `{ slug: 'b' }` |
| `pages/blog/[slug].js` | `/blog/c` | `{ slug: 'c' }` |

## Phân đoạn Catch-all

Các phân đoạn động có thể được mở rộng để **bắt tất cả** các phân đoạn tiếp theo bằng cách thêm dấu ba chấm vào trong dấu ngoặc `[...segmentName]`.

Ví dụ: `pages/shop/[...slug].js` sẽ khớp với `/shop/clothes`, nhưng cũng khớp với `/shop/clothes/tops`, `/shop/clothes/tops/t-shirts`, v.v.

| Tuyến đường               | URL ví dụ     | `params`                    |
| ------------------------- | ------------- | --------------------------- |
| `pages/shop/[...slug].js` | `/shop/a`     | `{ slug: ['a'] }`           |
| `pages/shop/[...slug].js` | `/shop/a/b`   | `{ slug: ['a', 'b'] }`      |
| `pages/shop/[...slug].js` | `/shop/a/b/c` | `{ slug: ['a', 'b', 'c'] }` |

## Phân đoạn Catch-all tùy chọn

Các phân đoạn Catch-all có thể được đặt thành **tùy chọn** bằng cách bao gồm tham số trong dấu ngoặc vuông kép: `[[...segmentName]]`.

Ví dụ: `pages/shop/[[...slug]].js` cũng sẽ khớp với `/shop`, ngoài `/shop/clothes`, `/shop/clothes/tops`, `/shop/clothes/tops/t-shirts`.

Sự khác biệt giữa các phân đoạn **catch-all** và **catch-all tùy chọn** là với tùy chọn, tuyến đường không có tham số cũng được khớp (`/shop` trong ví dụ trên).

| Tuyến đường                 | URL ví dụ     | `params`                    |
| --------------------------- | ------------- | --------------------------- |
| `pages/shop/[[...slug]].js` | `/shop`       | `{ slug: undefined }`       |
| `pages/shop/[[...slug]].js` | `/shop/a`     | `{ slug: ['a'] }`           |
| `pages/shop/[[...slug]].js` | `/shop/a/b`   | `{ slug: ['a', 'b'] }`      |
| `pages/shop/[[...slug]].js` | `/shop/a/b/c` | `{ slug: ['a', 'b', 'c'] }` |
