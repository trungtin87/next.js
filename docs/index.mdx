Chào mừng đến với tài liệu Next.js!

## Next.js là gì?

Next.js là một React framework để xây dựng các ứng dụng web full-stack. Bạn sử dụng React Components để xây dựng giao diện người dùng, và Next.js cho các tính năng và tối ưu hóa bổ sung.

Nó cũng tự động cấu hình các công cụ cấp thấp hơn như bundlers và compilers. Bạn có thể tập trung vào việc xây dựng sản phẩm của mình và ship nhanh chóng.

Cho dù bạn là một nhà phát triển cá nhân hay là một phần của nhóm lớn hơn, Next.js có thể giúp bạn xây dựng các ứng dụng React tương tác, động và nhanh.

## Cách sử dụng tài liệu

Tài liệu được tổ chức thành 3 phần:

- [Getting Started](/docs/app/getting-started): Các hướng dẫn từng bước để giúp bạn tạo một ứng dụng mới và tìm hiểu các tính năng cốt lõi của Next.js.
- [Guides](/docs/app/guides): Các hướng dẫn về các trường hợp sử dụng cụ thể, chọn những gì liên quan đến bạn.

Sử dụng sidebar để điều hướng qua các phần, hoặc tìm kiếm (`Ctrl+K` hoặc `Cmd+K`) để nhanh chóng tìm một trang.

## App Router và Pages Router

Next.js có hai router khác nhau:

- **App Router**: Router mới hơn hỗ trợ các tính năng React mới như Server Components.
- **Pages Router**: Router ban đầu, vẫn được hỗ trợ và đang được cải thiện.

Ở đầu sidebar, bạn sẽ thấy một menu dropdown cho phép bạn chuyển đổi giữa tài liệu [App Router](/docs/app) và [Pages Router](/docs/pages).

### Xử lý phiên bản React

App Router và Pages Router xử lý các phiên bản React khác nhau:

- **App Router**: Sử dụng [React canary releases](https://react.dev/blog/2023/05/03/react-canaries) được tích hợp sẵn, bao gồm tất cả các thay đổi React 19 ổn định, cũng như các tính năng mới hơn đang được xác thực trong các framework, trước khi có bản phát hành React mới.

- **Pages Router**: Sử dụng phiên bản React được cài đặt trong `package.json` của dự án của bạn.

Cách tiếp cận này đảm bảo các tính năng React mới hoạt động đáng tin cậy trong App Router trong khi duy trì khả năng tương thích ngược cho các ứng dụng Pages Router hiện có.

## Kiến thức tiên quyết

Tài liệu của chúng tôi giả định một số kiến thức về phát triển web. Trước khi bắt đầu, sẽ hữu ích nếu bạn thoải mái với:

- HTML
- CSS
- JavaScript
- React

Nếu bạn mới làm quen với React hoặc cần ôn lại, chúng tôi khuyên bạn nên bắt đầu với [khóa học React Foundations](/learn/react-foundations) của chúng tôi, và [khóa học Next.js Foundations](/learn/dashboard-app) giúp bạn xây dựng một ứng dụng khi bạn học.

## Khả năng tiếp cận

Để có trải nghiệm tốt nhất khi sử dụng trình đọc màn hình, chúng tôi khuyên bạn nên sử dụng Firefox và NVDA, hoặc Safari và VoiceOver.
