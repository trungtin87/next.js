Next.js cho phép bạn cấu hình routing và render nội dung để hỗ trợ nhiều ngôn ngữ. Việc làm cho trang web của bạn thích ứng với các locale khác nhau bao gồm nội dung được dịch (localization) và các route được quốc tế hóa (internationalized routes).

## Thuật ngữ

- **Locale:** Một định danh cho một tập hợp các tùy chọn ngôn ngữ và định dạng. Điều này thường bao gồm ngôn ngữ ưa thích của người dùng và có thể là khu vực địa lý của họ.
  - `en-US`: Tiếng Anh được nói tại Hoa Kỳ
  - `nl-NL`: Tiếng Hà Lan được nói tại Hà Lan
  - `nl`: Tiếng Hà Lan, không có khu vực cụ thể

## Tổng quan về Routing

Khuyến nghị sử dụng tùy chọn ngôn ngữ của người dùng trong trình duyệt để chọn locale nào sẽ sử dụng. Việc thay đổi ngôn ngữ ưa thích của bạn sẽ sửa đổi header `Accept-Language` gửi đến ứng dụng của bạn.

Ví dụ, sử dụng các thư viện sau, bạn có thể xem xét một `Request` đến để xác định locale nào sẽ được chọn, dựa trên `Headers`, các locale bạn dự định hỗ trợ, và locale mặc định.

```js filename="proxy.js"
import { match } from '@formatjs/intl-localematcher'
import Negotiator from 'negotiator'

let headers = { 'accept-language': 'en-US,en;q=0.5' }
let languages = new Negotiator({ headers }).languages()
let locales = ['en-US', 'nl-NL', 'nl']
let defaultLocale = 'en-US'

match(languages, locales, defaultLocale) // -> 'en-US'
```

Routing có thể được quốc tế hóa bằng sub-path (`/fr/products`) hoặc domain (`my-site.fr/products`). Với thông tin này, giờ đây bạn có thể chuyển hướng người dùng dựa trên locale bên trong [Middleware](/docs/app/api-reference/file-conventions/middleware).

```js filename="middleware.js"
import { NextResponse } from "next/server";

let locales = ['en-US', 'nl-NL', 'nl']

// Lấy locale ưa thích, tương tự như trên hoặc sử dụng thư viện
function getLocale(request) { ... }

export function middleware(request) {
  // Kiểm tra xem có locale nào được hỗ trợ trong pathname hay không
  const { pathname } = request.nextUrl
  const pathnameHasLocale = locales.some(
    (locale) => pathname.startsWith(`/${locale}/`) || pathname === `/${locale}`
  )

  if (pathnameHasLocale) return

  // Chuyển hướng nếu không có locale
  const locale = getLocale(request)
  request.nextUrl.pathname = `/${locale}${pathname}`
  // v.d. request đến là /products
  // URL mới bây giờ là /en-US/products
  return NextResponse.redirect(request.nextUrl)
}

export const config = {
  matcher: [
    // Bỏ qua tất cả các đường dẫn nội bộ (_next)
    '/((?!_next).*)',
    // Tùy chọn: chỉ chạy trên root (/) URL
    // '/'
  ],
}
```

Cuối cùng, đảm bảo tất cả các tệp đặc biệt bên trong `app/` được lồng dưới `app/[lang]`. Điều này cho phép router của Next.js xử lý động các locale khác nhau trong route, và chuyển tham số `lang` đến mọi layout và page. Ví dụ:

```tsx filename="app/[lang]/page.tsx" switcher
// Bây giờ bạn có quyền truy cập vào locale hiện tại
// v.d. /en-US/products -> `lang` là "en-US"
export default async function Page({
  params,
}: {
  params: Promise<{ lang: string }>
}) {
  const { lang } = await params
  return ...
}
```

```jsx filename="app/[lang]/page.js" switcher
// Bây giờ bạn có quyền truy cập vào locale hiện tại
// v.d. /en-US/products -> `lang` là "en-US"
export default async function Page({ params }) {
  const { lang } = await params
  return ...
}
```

Root layout cũng có thể được lồng trong thư mục mới (v.d. `app/[lang]/layout.js`).

## Localization

Việc thay đổi nội dung hiển thị dựa trên locale ưa thích của người dùng, hay localization, không phải là điều gì đó đặc thù của Next.js. Các mẫu được mô tả dưới đây sẽ hoạt động tương tự với bất kỳ ứng dụng web nào.

Giả sử chúng ta muốn hỗ trợ cả nội dung tiếng Anh và tiếng Hà Lan trong ứng dụng của mình. Chúng ta có thể duy trì hai "từ điển" khác nhau, là các đối tượng cung cấp ánh xạ từ một key nào đó đến một chuỗi đã được bản địa hóa. Ví dụ:

```json filename="dictionaries/en.json"
{
  "products": {
    "cart": "Add to Cart"
  }
}
```

```json filename="dictionaries/nl.json"
{
  "products": {
    "cart": "Toevoegen aan Winkelwagen"
  }
}
```

Sau đó, chúng ta có thể tạo một hàm `getDictionary` để tải các bản dịch cho locale được yêu cầu:

```ts filename="app/[lang]/dictionaries.ts" switcher
import 'server-only'

const dictionaries = {
  en: () => import('./dictionaries/en.json').then((module) => module.default),
  nl: () => import('./dictionaries/nl.json').then((module) => module.default),
}

export const getDictionary = async (locale: 'en' | 'nl') =>
  dictionaries[locale]()
```

```js filename="app/[lang]/dictionaries.js" switcher
import 'server-only'

const dictionaries = {
  en: () => import('./dictionaries/en.json').then((module) => module.default),
  nl: () => import('./dictionaries/nl.json').then((module) => module.default),
}

export const getDictionary = async (locale) => dictionaries[locale]()
```

Với ngôn ngữ được chọn hiện tại, chúng ta có thể fetch từ điển bên trong một layout hoặc page.

```tsx filename="app/[lang]/page.tsx" switcher
import { getDictionary } from './dictionaries'

export default async function Page({
  params,
}: {
  params: Promise<{ lang: 'en' | 'nl' }>
}) {
  const { lang } = await params
  const dict = await getDictionary(lang) // en
  return <button>{dict.products.cart}</button> // Add to Cart
}
```

```jsx filename="app/[lang]/page.js" switcher
import { getDictionary } from './dictionaries'

export default async function Page({ params }) {
  const { lang } = await params
  const dict = await getDictionary(lang) // en
  return <button>{dict.products.cart}</button> // Add to Cart
}
```

Bởi vì tất cả các layout và page trong thư mục `app/` mặc định là [Server Components](/docs/app/getting-started/server-and-client-components), chúng ta không cần phải lo lắng về kích thước của các tệp dịch ảnh hưởng đến kích thước gói JavaScript phía máy khách của chúng ta. Mã này sẽ **chỉ chạy trên server**, và chỉ có HTML kết quả được gửi đến trình duyệt.

## Static Rendering

Để tạo các route tĩnh cho một tập hợp các locale nhất định, chúng ta có thể sử dụng `generateStaticParams` với bất kỳ page hoặc layout nào. Điều này có thể là toàn cục, ví dụ, trong root layout:

```tsx filename="app/[lang]/layout.tsx" switcher
export async function generateStaticParams() {
  return [{ lang: 'en-US' }, { lang: 'de' }]
}

export default async function RootLayout({
  children,
  params,
}: Readonly<{
  children: React.ReactNode
  params: Promise<{ lang: 'en-US' | 'de' }>
}>) {
  return (
    <html lang={(await params).lang}>
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/[lang]/layout.js" switcher
export async function generateStaticParams() {
  return [{ lang: 'en-US' }, { lang: 'de' }]
}

export default async function RootLayout({ children, params }) {
  return (
    <html lang={(await params).lang}>
      <body>{children}</body>
    </html>
  )
}
```
