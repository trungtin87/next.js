React Server Actions là [Server Functions](https://react.dev/reference/rsc/server-functions) thực thi trên máy chủ. Chúng có thể được gọi trong Server và Client Components để xử lý việc gửi biểu mẫu. Hướng dẫn này sẽ chỉ cho bạn cách tạo biểu mẫu trong Next.js với Server Actions.

## Cách nó hoạt động

React mở rộng phần tử HTML [`<form>`](https://developer.mozilla.org/docs/Web/HTML/Element/form) để cho phép Server Actions được gọi với thuộc tính [`action`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/form#action).

Khi được sử dụng trong một biểu mẫu, hàm tự động nhận đối tượng [`FormData`](https://developer.mozilla.org/docs/Web/API/FormData/FormData). Sau đó, bạn có thể trích xuất dữ liệu bằng cách sử dụng các phương thức [`FormData` gốc](https://developer.mozilla.org/en-US/docs/Web/API/FormData#instance_methods):

```tsx filename="app/invoices/page.tsx" switcher
export default function Page() {
  async function createInvoice(formData: FormData) {
    'use server'

    const rawFormData = {
      customerId: formData.get('customerId'),
      amount: formData.get('amount'),
      status: formData.get('status'),
    }

    // thay đổi dữ liệu
    // xác thực lại bộ nhớ cache
  }

  return <form action={createInvoice}>...</form>
}
```

```jsx filename="app/invoices/page.js" switcher
export default function Page() {
  async function createInvoice(formData) {
    'use server'

    const rawFormData = {
      customerId: formData.get('customerId'),
      amount: formData.get('amount'),
      status: formData.get('status'),
    }

    // thay đổi dữ liệu
    // xác thực lại bộ nhớ cache
  }

  return <form action={createInvoice}>...</form>
}
```

> **Cần biết:** Khi làm việc với các biểu mẫu có nhiều trường, hãy sử dụng [`Object.fromEntries()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/fromEntries) của JavaScript. Ví dụ: `const rawFormData = Object.fromEntries(formData)`. Lưu ý rằng đối tượng này sẽ chứa các thuộc tính bổ sung có tiền tố `$ACTION_`.

## Truyền thêm đối số

Ngoài các trường biểu mẫu, bạn có thể truyền thêm các đối số cho Server Function bằng phương thức [`bind`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Function/bind) của JavaScript. Ví dụ, để truyền đối số `userId` cho Server Function `updateUser`:

```tsx filename="app/client-component.tsx" highlight={6} switcher
'use client'

import { updateUser } from './actions'

export function UserProfile({ userId }: { userId: string }) {
  const updateUserWithId = updateUser.bind(null, userId)

  return (
    <form action={updateUserWithId}>
      <input type="text" name="name" />
      <button type="submit">Update User Name</button>
    </form>
  )
}
```

```jsx filename="app/client-component.js" highlight={6} switcher
'use client'

import { updateUser } from './actions'

export function UserProfile({ userId }) {
  const updateUserWithId = updateUser.bind(null, userId)

  return (
    <form action={updateUserWithId}>
      <input type="text" name="name" />
      <button type="submit">Update User Name</button>
    </form>
  )
}
```

Server Function sẽ nhận `userId` như một đối số bổ sung:

```ts filename="app/actions.ts" switcher
'use server'

export async function updateUser(userId: string, formData: FormData) {}
```

```js filename="app/actions.js" switcher
'use server'

export async function updateUser(userId, formData) {}
```

> **Cần biết**:
>
> - Một giải pháp thay thế là truyền các đối số dưới dạng các trường input ẩn trong biểu mẫu (ví dụ: `<input type="hidden" name="userId" value={userId} />`). Tuy nhiên, giá trị sẽ là một phần của HTML được render và sẽ không được mã hóa.
> - `bind` hoạt động trong cả Server và Client Components và hỗ trợ cải tiến lũy tiến (progressive enhancement).

## Xác thực biểu mẫu

Biểu mẫu có thể được xác thực trên máy khách hoặc máy chủ.

- Đối với **xác thực phía máy khách**, bạn có thể sử dụng các thuộc tính HTML như `required` và `type="email"` để xác thực cơ bản.
- Đối với **xác thực phía máy chủ**, bạn có thể sử dụng một thư viện như [zod](https://zod.dev/) để xác thực các trường biểu mẫu. Ví dụ:

```tsx filename="app/actions.ts" switcher
'use server'

import { z } from 'zod'

const schema = z.object({
  email: z.string({
    invalid_type_error: 'Invalid Email',
  }),
})

export default async function createUser(formData: FormData) {
  const validatedFields = schema.safeParse({
    email: formData.get('email'),
  })

  // Trả về sớm nếu dữ liệu biểu mẫu không hợp lệ
  if (!validatedFields.success) {
    return {
      errors: validatedFields.error.flatten().fieldErrors,
    }
  }

  // Thay đổi dữ liệu
}
```

```jsx filename="app/actions.js" switcher
'use server'

import { z } from 'zod'

const schema = z.object({
  email: z.string({
    invalid_type_error: 'Invalid Email',
  }),
})

export default async function createsUser(formData) {
  const validatedFields = schema.safeParse({
    email: formData.get('email'),
  })

  // Trả về sớm nếu dữ liệu biểu mẫu không hợp lệ
  if (!validatedFields.success) {
    return {
      errors: validatedFields.error.flatten().fieldErrors,
    }
  }

  // Thay đổi dữ liệu
}
```

## Lỗi xác thực

Để hiển thị lỗi xác thực hoặc thông báo, hãy biến component định nghĩa `<form>` thành Client Component và sử dụng React [`useActionState`](https://react.dev/reference/react/useActionState).

Khi sử dụng `useActionState`, chữ ký Server function sẽ thay đổi để nhận tham số `prevState` hoặc `initialState` mới làm đối số đầu tiên của nó.

```tsx filename="app/actions.ts" highlight={4} switcher
'use server'

import { z } from 'zod'

export async function createUser(initialState: any, formData: FormData) {
  const validatedFields = schema.safeParse({
    email: formData.get('email'),
  })
  // ...
}
```

```jsx filename="app/actions.ts" highlight={4} switcher
'use server'

import { z } from 'zod'

// ...

export async function createUser(initialState, formData) {
  const validatedFields = schema.safeParse({
    email: formData.get('email'),
  })
  // ...
}
```

Sau đó, bạn có thể render thông báo lỗi có điều kiện dựa trên đối tượng `state`.

```tsx filename="app/ui/signup.tsx" highlight={11,18-20} switcher
'use client'

import { useActionState } from 'react'
import { createUser } from '@/app/actions'

const initialState = {
  message: '',
}

export function Signup() {
  const [state, formAction, pending] = useActionState(createUser, initialState)

  return (
    <form action={formAction}>
      <label htmlFor="email">Email</label>
      <input type="text" id="email" name="email" required />
      {/* ... */}
      <p aria-live="polite">{state?.message}</p>
      <button disabled={pending}>Sign up</button>
    </form>
  )
}
```


## Trạng thái chờ (Pending states)

Hook [`useActionState`](https://react.dev/reference/react/useActionState) hiển thị một boolean `pending` có thể được sử dụng để hiển thị chỉ báo đang tải hoặc vô hiệu hóa nút gửi trong khi hành động đang được thực thi.

```tsx filename="app/ui/signup.tsx" highlight={7,12} switcher
'use client'

import { useActionState } from 'react'
import { createUser } from '@/app/actions'

export function Signup() {
  const [state, formAction, pending] = useActionState(createUser, initialState)

  return (
    <form action={formAction}>
      {/* Các phần tử biểu mẫu khác */}
      <button disabled={pending}>Sign up</button>
    </form>
  )
}
```

```jsx filename="app/ui/signup.js" highlight={7,12} switcher
'use client'

import { useActionState } from 'react'
import { createUser } from '@/app/actions'

export function Signup() {
  const [state, formAction, pending] = useActionState(createUser, initialState)

  return (
    <form action={formAction}>
      {/* Các phần tử biểu mẫu khác */}
      <button disabled={pending}>Sign up</button>
    </form>
  )
}
```

Ngoài ra, bạn có thể sử dụng hook [`useFormStatus`](https://react.dev/reference/react-dom/hooks/useFormStatus) để hiển thị chỉ báo đang tải trong khi hành động đang được thực thi. Khi sử dụng hook này, bạn sẽ cần tạo một component riêng biệt để render chỉ báo đang tải. Ví dụ, để vô hiệu hóa nút khi hành động đang chờ xử lý:

```tsx filename="app/ui/button.tsx" highlight={6} switcher
'use client'

import { useFormStatus } from 'react-dom'

export function SubmitButton() {
  const { pending } = useFormStatus()

  return (
    <button disabled={pending} type="submit">
      Sign Up
    </button>
  )
}
```

```jsx filename="app/ui/button.js" highlight={6} switcher
'use client'

import { useFormStatus } from 'react-dom'

export function SubmitButton() {
  const { pending } = useFormStatus()

  return (
    <button disabled={pending} type="submit">
      Sign Up
    </button>
  )
}
```

Sau đó, bạn có thể lồng component `SubmitButton` bên trong biểu mẫu:

```tsx filename="app/ui/signup.tsx" switcher

import { createUser } from '@/app/actions'

export function Signup() {
  return (
    <form action={createUser}>
      {/* Các phần tử biểu mẫu khác */}

    </form>

}
```


> **Cần biết:** Trong React 19, `useFormStatus` bao gồm các khóa bổ sung trên đối tượng trả về, như data, method, và action. Nếu bạn không sử dụng React 19, chỉ có khóa `pending` là có sẵn.

## Cập nhật lạc quan (Optimistic updates)

Bạn có thể sử dụng hook React [`useOptimistic`](https://react.dev/reference/react/useOptimistic) để cập nhật giao diện người dùng một cách lạc quan trước khi Server Function kết thúc thực thi, thay vì chờ phản hồi:

```tsx filename="app/page.tsx" switcher
'use client'

import { useOptimistic } from 'react'
import { send } from './actions'

type Message = {
  message: string
}

export function Thread({ messages }: { messages: Message[] }) {
  const [optimisticMessages, addOptimisticMessage] = useOptimistic<
    Message[],
    string
  >(messages, (state, newMessage) => [...state, { message: newMessage }])

  const formAction = async (formData: FormData) => {
    const message = formData.get('message') as string
    addOptimisticMessage(message)
    await send(message)
  }

  return (
    <div>
      {optimisticMessages.map((m, i) => (
        <div key={i}>{m.message}</div>
      ))}
      <form action={formAction}>
        <input type="text" name="message" />
        <button type="submit">Send</button>
      </form>
    </div>
  )
}
```

```jsx filename="app/page.js" switcher

}
```

## Các phần tử biểu mẫu lồng nhau

Bạn có thể gọi Server Actions trong các phần tử lồng bên trong `<form>` như `<button>`, `<input type="submit">`, và `<input type="image">`. Các phần tử này chấp nhận prop `formAction` hoặc trình xử lý sự kiện.

Điều này hữu ích trong các trường hợp bạn muốn gọi nhiều Server Actions trong một biểu mẫu. Ví dụ, bạn có thể tạo một phần tử `<button>` cụ thể để lưu bản nháp bài đăng ngoài việc xuất bản nó. Xem [tài liệu React `<form>`](https://react.dev/reference/react-dom/components/form#handling-multiple-submission-types) để biết thêm thông tin.

## Gửi biểu mẫu theo chương trình

Bạn có thể kích hoạt gửi biểu mẫu theo chương trình bằng phương thức [`requestSubmit()`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLFormElement/requestSubmit). Ví dụ, khi người dùng gửi biểu mẫu bằng phím tắt `⌘` + `Enter`, bạn có thể lắng nghe sự kiện `onKeyDown`:

```tsx filename="app/entry.tsx" switcher
'use client'

export function Entry() {
  const handleKeyDown = (e: React.KeyboardEvent<HTMLTextAreaElement>) => {
    if (
      (e.ctrlKey || e.metaKey) &&
      (e.key === 'Enter' || e.key === 'NumpadEnter')
    ) {
      e.preventDefault()
      e.currentTarget.form?.requestSubmit()
    }
  }

  return (
    <div>
      <textarea name="entry" rows={20} required onKeyDown={handleKeyDown} />
    </div>
  )
}
```
