nav_title: JSON-LD
description: Tìm hiểu cách thêm JSON-LD vào ứng dụng Next.js của bạn để mô tả nội dung của bạn cho các công cụ tìm kiếm và AI.
---

[JSON-LD](https://json-ld.org/) là một định dạng cho dữ liệu có cấu trúc có thể được sử dụng bởi các công cụ tìm kiếm và AI để giúp chúng hiểu cấu trúc của trang ngoài nội dung thuần túy. Ví dụ, bạn có thể sử dụng nó để mô tả một người, một sự kiện, một tổ chức, một bộ phim, một cuốn sách, một công thức nấu ăn, và nhiều loại thực thể khác.

Khuyến nghị hiện tại của chúng tôi cho JSON-LD là render dữ liệu có cấu trúc dưới dạng thẻ `<script>` trong các component `layout.js` hoặc `page.js` của bạn.

Đoạn mã sau sử dụng `JSON.stringify`, không làm sạch các chuỗi độc hại được sử dụng trong XSS injection. Để ngăn chặn loại lỗ hổng này, bạn có thể làm sạch các thẻ `HTML` khỏi payload `JSON-LD`, ví dụ, bằng cách thay thế ký tự, `<`, bằng unicode tương đương của nó, `\\u003c`.

Xem lại cách tiếp cận được khuyến nghị của tổ chức bạn để làm sạch các chuỗi có khả năng nguy hiểm, hoặc sử dụng các lựa chọn thay thế được cộng đồng duy trì cho `JSON.stringify` như, [serialize-javascript](https://www.npmjs.com/package/serialize-javascript).

```tsx filename="app/products/[id]/page.tsx" switcher
export default async function Page({ params }) {
  const { id } = await params
  const product = await getProduct(id)

  const jsonLd = {
    '@context': 'https://schema.org',
    '@type': 'Product',
    name: product.name,
    image: product.image,
    description: product.description,
  }

  return (
    <section>
      {/* Add JSON-LD to your page */}
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{
          __html: JSON.stringify(jsonLd).replace(/</g, '\\u003c'),
        }}
      />
      {/* ... */}
    </section>
  )
}
```

Bạn có thể xác thực và kiểm tra dữ liệu có cấu trúc của mình bằng [Rich Results Test](https://search.google.com/test/rich-results) cho Google hoặc [Schema Markup Validator](https://validator.schema.org/) chung.

Bạn có thể gõ JSON-LD của mình bằng TypeScript bằng cách sử dụng các package cộng đồng như [`schema-dts`](https://www.npmjs.com/package/schema-dts):

```tsx
import { Product, WithContext } from 'schema-dts'

const jsonLd: WithContext<Product> = {
  '@context': 'https://schema.org',
  '@type': 'Product',
  name: 'Next.js Sticker',
  image: 'https://nextjs.org/imgs/sticker.png',
  description: 'Dynamic at the speed of static.',
}
```
