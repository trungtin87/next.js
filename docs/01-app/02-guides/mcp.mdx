[Model Context Protocol (MCP)](https://modelcontextprotocol.io) là một tiêu chuẩn mở cho phép các AI agents và coding assistants tương tác với các ứng dụng của bạn thông qua một giao diện được tiêu chuẩn hóa.

Next.js cung cấp hai MCP servers, chúng tôi khuyên bạn nên sử dụng cả hai cùng nhau để có trải nghiệm agent tốt nhất:

### 1. Next.js MCP Server (Tích hợp sẵn)

**Có sẵn trong Next.js 16 trở lên**

Next.js MCP server để lộ các thành phần bên trong ứng dụng của bạn, cho phép agents:

- Truy cập trạng thái ứng dụng thời gian thực và thông tin runtime
- Truy vấn metadata của trang, routes, và chi tiết rendering
- Lấy lỗi build, lỗi runtime, và logs phát triển
- Kiểm tra Server Actions và phân cấp component

Server này chạy bên trong Next.js dev server của bạn và cung cấp quyền truy cập trực tiếp vào trạng thái nội bộ của ứng dụng.

### 2. Next DevTools MCP (Gói bên ngoài)

[`next-devtools-mcp`](https://www.npmjs.com/package/next-devtools-mcp) là một gói riêng biệt cung cấp các công cụ phát triển cấp cao và hướng dẫn:

- **Next.js Knowledge Base**: Truy vấn tài liệu Next.js toàn diện và các thực hành tốt nhất
- **Công cụ Di chuyển và Nâng cấp**: Các trình trợ giúp tự động để nâng cấp lên Next.js 16 với codemods
- **Hướng dẫn Cache Components**: Hỗ trợ thiết lập và cấu hình cho Cache Components
- **Kiểm thử Trình duyệt**: Tích hợp [Playwright MCP](https://github.com/microsoft/playwright-mcp) để xác minh các trang trong trình duyệt

Ngoài ra, `next-devtools-mcp` có thể tự động khám phá và giao tiếp trực tiếp với các Next.js dev servers đang chạy để truy cập các công cụ MCP của chúng (`get_errors`, `get_logs`, `get_page_metadata`, v.v.).

Cùng nhau, hai MCP servers này cung cấp cho agents cả các thành phần bên trong ứng dụng cấp thấp và hướng dẫn phát triển cấp cao.

## Bắt đầu

Next.js MCP server tích hợp sẵn được bật theo mặc định trong quá trình phát triển trong Next.js 16 hoặc cao hơn.

### Cấu hình Next DevTools MCP

Để sử dụng Next DevTools MCP, thêm [`next-devtools-mcp`](https://www.npmjs.com/package/next-devtools-mcp) vào tệp `.mcp.json` tại thư mục gốc của dự án của bạn

```json filename=".mcp.json"
{
  "mcpServers": {
    "next-devtools": {
      "command": "npx",
      "args": ["-y", "next-devtools-mcp@latest"]
    }
  }
}
```

Để biết thêm các chức năng devtools và tùy chọn cấu hình, hãy xem [kho lưu trữ next-devtools-mcp](https://github.com/vercel/next-devtools-mcp).

## Sử dụng với agents

Các Coding Agents tương thích với MCP có thể tự động khám phá và kết nối với Next.js development server của bạn. Điều này cung cấp cho agents ngữ cảnh phong phú về dự án của bạn.

### Lợi ích cho phát triển được hỗ trợ bởi agent

Agents có thể:

- **Đưa ra các đề xuất nhận biết ngữ cảnh**: Đề xuất đúng nơi để thêm các tính năng mới dựa trên cấu trúc hiện có của bạn
- **Truy vấn trạng thái ứng dụng trực tiếp**: Kiểm tra cấu hình hiện tại, routes, và middleware trong quá trình phát triển
- **Hiểu bố cục trang app router của bạn**: Biết chính xác trang và layout nào được render trong trang
- **Cung cấp các triển khai chính xác**: Tạo mã tuân theo các mẫu và quy ước của dự án của bạn

## Quy trình làm việc phát triển

1. Khởi động Next.js development server của bạn:

```bash filename="Terminal"
npm run dev
```

2. Kết nối Coding Agent của bạn với Next.js instance đang chạy

3. Mở ứng dụng của bạn trong trình duyệt để xem trang.

4. Truy vấn agent của bạn để biết thông tin chi tiết và chẩn đoán (xem các ví dụ bên dưới)

### Các công cụ Next.js MCP có sẵn

Experimental Next.js MCP server cung cấp các công cụ sau:

- **`get_errors`**: Lấy lỗi build hiện tại, lỗi runtime, và lỗi type từ dev server của bạn
- **`get_logs`**: Truy cập logs của development server và console output
- **`get_page_metadata`**: Lấy metadata về các trang cụ thể bao gồm routes, components, và thông tin rendering
- **`get_project_metadata`**: Lấy cấu trúc dự án, cấu hình, và metadata tổng thể
- **`get_server_action_by_id`**: Tra cứu Server Actions theo ID của chúng để gỡ lỗi và kiểm tra

## Ví dụ

### Phát hiện và chẩn đoán lỗi

Agent có thể truy vấn ứng dụng Next.js đang chạy của bạn để biết thông tin lỗi thời gian thực:

```bash
User: "What errors are currently in my application?"
```

Hành động của Agent:

- Gọi công cụ `get_errors` được cung cấp bởi Next.js MCP server
- Lấy lỗi build hiện tại, lỗi runtime, và lỗi type từ dev server
- Phân tích các lỗi và cung cấp các bản sửa lỗi có thể thực hiện

### Nâng cấp và các thực hành tốt nhất

Bạn cũng có thể yêu cầu trợ giúp với các khái niệm Next.js và di chuyển:

```bash
User: "Help me upgrade my Next.js app to version 16"
```

Agent sẽ sử dụng next-devtools-mcp để phân tích phiên bản hiện tại của bạn, hướng dẫn bạn qua các di chuyển tự động với codemods, và cung cấp hướng dẫn từng bước để xử lý các thay đổi đột phá như async Request APIs, dynamic route segments, và route handler return types.

Bạn cũng có thể hỏi các câu hỏi khái niệm:

```bash
User: "When should I use 'use client' in App Router?"
```

Agent sẽ truy vấn Next.js knowledge base thông qua next-devtools-mcp và cung cấp các giải thích được hỗ trợ bởi tài liệu với các ví dụ từ codebase của bạn.

## Khắc phục sự cố

### MCP server không kết nối

- Đảm bảo bạn đang sử dụng Next.js v16 hoặc cao hơn
- Khởi động development server của bạn: `npm run dev`
- Khởi động lại development server của bạn
- Kiểm tra xem MCP client của bạn có được cấu hình với đường dẫn chính xác không
- Thêm MCP server vào cài đặt của agent của bạn
