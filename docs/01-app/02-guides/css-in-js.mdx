## Cấu hình CSS-in-JS trong `app`

Cấu hình CSS-in-JS là một quy trình chọn tham gia gồm ba bước bao gồm:

1. Một **style registry** để thu thập tất cả các quy tắc CSS trong một lần render.
2. Hook `useServerInsertedHTML` mới để chèn các quy tắc trước bất kỳ nội dung nào có thể sử dụng chúng.
3. Một Client Component bao bọc ứng dụng của bạn với style registry trong quá trình render phía máy chủ ban đầu.

### `styled-jsx`

Sử dụng `styled-jsx` trong Client Components yêu cầu sử dụng `v5.1.0`. Đầu tiên, tạo một registry mới:

```tsx filename="app/registry.tsx" switcher
'use client'

import React, { useState } from 'react'
import { useServerInsertedHTML } from 'next/navigation'
import { StyleRegistry, createStyleRegistry } from 'styled-jsx'

export default function StyledJsxRegistry({
  children,
}: {
  children: React.ReactNode
}) {
  // Chỉ tạo stylesheet một lần với lazy initial state
  // x-ref: https://reactjs.org/docs/hooks-reference.html#lazy-initial-state
  const [jsxStyleRegistry] = useState(() => createStyleRegistry())

  useServerInsertedHTML(() => {
    const styles = jsxStyleRegistry.styles()
    jsxStyleRegistry.flush()
    return <>{styles}</>
  })

  return <StyleRegistry registry={jsxStyleRegistry}>{children}</StyleRegistry>
}
```

### Styled Components

Dưới đây là ví dụ về cách cấu hình `styled-components@6` hoặc mới hơn:

Đầu tiên, bật styled-components trong `next.config.js`.

```js filename="next.config.js"
module.exports = {
  compiler: {
    styledComponents: true,
  },
}
```

Sau đó, sử dụng API `styled-components` để tạo một component registry toàn cục để thu thập tất cả các quy tắc kiểu CSS được tạo trong quá trình render, và một hàm để trả về các quy tắc đó. Sau đó sử dụng hook `useServerInsertedHTML` để chèn các kiểu đã thu thập trong registry vào thẻ HTML `<head>` trong root layout.

```tsx filename="lib/registry.tsx" switcher
'use client'

import React, { useState } from 'react'
import { useServerInsertedHTML } from 'next/navigation'
import { ServerStyleSheet, StyleSheetManager } from 'styled-components'

export default function StyledComponentsRegistry({
  children,
}: {
  children: React.ReactNode
}) {
  // Chỉ tạo stylesheet một lần với lazy initial state
  // x-ref: https://reactjs.org/docs/hooks-reference.html#lazy-initial-state
  const [styledComponentsStyleSheet] = useState(() => new ServerStyleSheet())

  useServerInsertedHTML(() => {
    const styles = styledComponentsStyleSheet.getStyleElement()
    styledComponentsStyleSheet.instance.clearTag()
    return <>{styles}</>
  })

  if (typeof window !== 'undefined') return <>{children}</>

  return (
    <StyleSheetManager sheet={styledComponentsStyleSheet.instance}>
      {children}
    </StyleSheetManager>
  )
}
```


> **Cần biết**:
>
> - Trong quá trình render phía máy chủ, các kiểu sẽ được trích xuất vào một registry toàn cục và được đẩy vào `<head>` của HTML của bạn. Điều này đảm bảo các quy tắc kiểu được đặt trước bất kỳ nội dung nào có thể sử dụng chúng. Trong tương lai, chúng tôi có thể sử dụng một tính năng React sắp tới để xác định nơi chèn các kiểu.
> - Trong quá trình streaming, các kiểu từ mỗi chunk sẽ được thu thập và thêm vào các kiểu hiện có. Sau khi quá trình hydration phía máy khách hoàn tất, `styled-components` sẽ tiếp quản như bình thường và chèn thêm bất kỳ kiểu động nào khác.
> - Chúng tôi đặc biệt sử dụng một Client Component ở cấp cao nhất của cây cho style registry vì cách này hiệu quả hơn để trích xuất các quy tắc CSS. Nó tránh việc tạo lại các kiểu trong các lần render phía máy chủ tiếp theo và ngăn chúng được gửi trong payload của Server Component.
> - Đối với các trường hợp sử dụng nâng cao, nơi bạn cần định cấu hình các thuộc tính riêng lẻ của quá trình biên dịch styled-components, bạn có thể đọc [tài liệu tham khảo API styled-components của Next.js](/docs/architecture/nextjs-compiler#styled-components) để tìm hiểu thêm.

Có thể sử dụng bất kỳ giải pháp CSS-in-JS hiện có nào. Giải pháp đơn giản nhất là inline styles:

```jsx
function HiThere() {
  return <p style={{ color: 'red' }}>hi there</p>
}

export default HiThere
```

Chúng tôi đóng gói [styled-jsx](https://github.com/vercel/styled-jsx) để cung cấp hỗ trợ cho CSS phạm vi cô lập (isolated scoped CSS).
Mục đích là hỗ trợ "shadow CSS" tương tự như Web Components, nhưng đáng tiếc là [không hỗ trợ render phía máy chủ và chỉ có JS](https://github.com/w3c/webcomponents/issues/71).

Xem các ví dụ trên cho các giải pháp CSS-in-JS phổ biến khác (như Styled Components).

Một component sử dụng `styled-jsx` trông như thế này:

```jsx
function HelloWorld() {
  return (
    <div>
      Hello world
      <p>scoped!</p>
      <style jsx>{`
        p {
          color: blue;
        }
        div {
          background: red;
        }
        @media (max-width: 600px) {
          div {
            background: blue;
          }
        }
      `}</style>
      <style global jsx>{`
        body {
          background: black;
        }
      `}</style>
    </div>
  )
}

export default HelloWorld
```

Vui lòng xem [tài liệu styled-jsx](https://github.com/vercel/styled-jsx) để biết thêm ví dụ.

### Vô hiệu hóa JavaScript

Có, nếu bạn vô hiệu hóa JavaScript, CSS vẫn sẽ được tải trong bản build production (`next start`). Trong quá trình phát triển, chúng tôi yêu cầu bật JavaScript để cung cấp trải nghiệm nhà phát triển tốt nhất với [Fast Refresh](https://nextjs.org/blog/next-9-4#fast-refresh).
