Việc đóng gói (bundling) các package bên ngoài có thể cải thiện đáng kể hiệu suất của ứng dụng của bạn. <AppOnly>Theo mặc định, các package được import bên trong Server Components và Route Handlers được tự động đóng gói bởi Next.js. Trang này sẽ hướng dẫn bạn cách phân tích và tối ưu hóa hơn nữa việc đóng gói package.</AppOnly> <PagesOnly>Theo mặc định, các package được import vào ứng dụng của bạn không được đóng gói. Điều này có thể ảnh hưởng đến hiệu suất hoặc có thể không hoạt động nếu các package bên ngoài không được đóng gói trước, ví dụ, nếu được import từ một monorepo hoặc `node_modules`. Trang này sẽ hướng dẫn bạn cách phân tích và cấu hình việc đóng gói package.</PagesOnly>

## Phân tích JavaScript bundles

[`@next/bundle-analyzer`](https://www.npmjs.com/package/@next/bundle-analyzer) là một plugin cho Next.js giúp bạn quản lý kích thước của các bundle ứng dụng của mình. Nó tạo ra một báo cáo trực quan về kích thước của mỗi package và các dependencies của chúng. Bạn có thể sử dụng thông tin này để loại bỏ các dependencies lớn, chia nhỏ, hoặc [lazy-load](/docs/app/guides/lazy-loading) mã của bạn.

### Cài đặt

Cài đặt plugin bằng cách chạy lệnh sau:

```bash
npm i @next/bundle-analyzer
# hoặc
yarn add @next/bundle-analyzer
# hoặc
pnpm add @next/bundle-analyzer
```

Sau đó, thêm các cài đặt của bundle analyzer vào `next.config.js` của bạn.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {}

const withBundleAnalyzer = require('@next/bundle-analyzer')({
  enabled: process.env.ANALYZE === 'true',
})

module.exports = withBundleAnalyzer(nextConfig)
```

### Tạo báo cáo

Chạy lệnh sau để phân tích các bundles của bạn:

```bash
ANALYZE=true npm run build
# hoặc
ANALYZE=true yarn build
# hoặc
ANALYZE=true pnpm build
```

Báo cáo sẽ mở ba tab mới trong trình duyệt của bạn, bạn có thể kiểm tra chúng. Việc đánh giá định kỳ các bundles của ứng dụng có thể giúp bạn duy trì hiệu suất ứng dụng theo thời gian.

## Tối ưu hóa import package

Một số package, chẳng hạn như thư viện icon, có thể export hàng trăm module, điều này có thể gây ra các vấn đề về hiệu suất trong quá trình phát triển và production.

Bạn có thể tối ưu hóa cách các package này được import bằng cách thêm tùy chọn [`optimizePackageImports`](/docs/app/api-reference/config/next-config-js/optimizePackageImports) vào `next.config.js` của bạn. Tùy chọn này sẽ chỉ tải các module bạn _thực sự_ sử dụng, trong khi vẫn mang lại cho bạn sự tiện lợi khi viết các câu lệnh import với nhiều named exports.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    optimizePackageImports: ['icon-library'],
  },
}

module.exports = nextConfig
```

Next.js cũng tự động tối ưu hóa một số thư viện, do đó chúng không cần phải được đưa vào danh sách optimizePackageImports. Xem [danh sách đầy đủ](/docs/app/api-reference/config/next-config-js/optimizePackageImports).

## Đóng gói các package cụ thể

Để đóng gói các package cụ thể, bạn có thể sử dụng tùy chọn [`transpilePackages`](/docs/app/api-reference/config/next-config-js/transpilePackages) trong `next.config.js` của bạn. Tùy chọn này hữu ích để đóng gói các package bên ngoài chưa được đóng gói trước, ví dụ, trong một monorepo hoặc được import từ `node_modules`.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  transpilePackages: ['package-name'],
}

module.exports = nextConfig
```

## Đóng gói tất cả các package

Để tự động đóng gói tất cả các package (hành vi mặc định trong App Router), bạn có thể sử dụng tùy chọn [`bundlePagesRouterDependencies`](/docs/pages/api-reference/config/next-config-js/bundlePagesRouterDependencies) trong `next.config.js` của bạn.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  bundlePagesRouterDependencies: true,
}

module.exports = nextConfig
```

## Loại trừ các package cụ thể khỏi việc đóng gói

Nếu bạn đã bật tùy chọn [`bundlePagesRouterDependencies`](/docs/pages/api-reference/config/next-config-js/bundlePagesRouterDependencies), bạn có thể loại trừ các package cụ thể khỏi việc tự động đóng gói bằng cách sử dụng tùy chọn [`serverExternalPackages`](/docs/pages/api-reference/config/next-config-js/serverExternalPackages) trong `next.config.js` của bạn:

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  // Tự động đóng gói các package bên ngoài trong Pages Router:
  bundlePagesRouterDependencies: true,
  // Loại trừ các package cụ thể khỏi việc đóng gói cho cả App và Pages Router:
  serverExternalPackages: ['package-name'],
}

module.exports = nextConfig
```

## Loại trừ các package cụ thể khỏi việc đóng gói

Vì các package được import bên trong Server Components và Route Handlers được tự động đóng gói bởi Next.js, bạn có thể loại trừ các package cụ thể khỏi việc đóng gói bằng cách sử dụng tùy chọn [`serverExternalPackages`](/docs/app/api-reference/config/next-config-js/serverExternalPackages) trong `next.config.js` của bạn.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  serverExternalPackages: ['package-name'],
}

module.exports = nextConfig
```

Next.js bao gồm một danh sách các package phổ biến hiện đang làm việc về khả năng tương thích và tự động được loại trừ (opt-ed out). Xem [danh sách đầy đủ](/docs/app/api-reference/config/next-config-js/serverExternalPackages).

</AppOnly>
