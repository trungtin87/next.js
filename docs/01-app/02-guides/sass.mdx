Next.js có hỗ trợ tích hợp sẵn để tích hợp với Sass sau khi package được cài đặt bằng cả hai extension `.scss` và `.sass`. Bạn có thể sử dụng Sass cấp component thông qua CSS Modules và extension `.module.scss` hoặc `.module.sass`.

Đầu tiên, cài đặt [`sass`](https://github.com/sass/sass):

```bash filename="Terminal"
npm install --save-dev sass
```

> **Nên biết**:
>
> Sass hỗ trợ [hai cú pháp khác nhau](https://sass-lang.com/documentation/syntax), mỗi cú pháp có extension riêng của nó.
> Extension `.scss` yêu cầu bạn sử dụng [SCSS syntax](https://sass-lang.com/documentation/syntax#scss),
> trong khi extension `.sass` yêu cầu bạn sử dụng [Indented Syntax ("Sass")](https://sass-lang.com/documentation/syntax#the-indented-syntax).
>
> Nếu bạn không chắc chắn nên chọn cái nào, hãy bắt đầu với extension `.scss` là một superset của CSS, và không yêu cầu bạn học
> Indented Syntax ("Sass").

### Tùy chỉnh Sass Options

Nếu bạn muốn cấu hình các tùy chọn Sass của mình, hãy sử dụng `sassOptions` trong `next.config`.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */

const nextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

module.exports = nextConfig
```

#### Implementation

Bạn có thể sử dụng thuộc tính `implementation` để chỉ định triển khai Sass để sử dụng. Theo mặc định, Next.js sử dụng package [`sass`](https://www.npmjs.com/package/sass).

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  sassOptions: {
    implementation: 'sass-embedded',
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */

const nextConfig = {
  sassOptions: {
    implementation: 'sass-embedded',
  },
}

module.exports = nextConfig
```

### Sass Variables

Next.js hỗ trợ các biến Sass được export từ các tệp CSS Module.

Ví dụ, sử dụng biến Sass `primaryColor` được export:

```scss filename="app/variables.module.scss"
$primary-color: #64ff00;

:export {
  primaryColor: $primary-color;
}
```

<AppOnly>

```jsx filename="app/page.js"
// maps to root `/` URL

import variables from './variables.module.scss'

export default function Page() {
  return <h1 style={{ color: variables.primaryColor }}>Hello, Next.js!</h1>
}
```

</AppOnly>

<PagesOnly>

```jsx filename="pages/_app.js"
import variables from '../styles/variables.module.scss'

export default function MyApp({ Component, pageProps }) {
  return (
    <Layout color={variables.primaryColor}>
      <Component {...pageProps} />
    </Layout>
  )
}
```

</PagesOnly>
