### Layout Scripts

Để tải một script của bên thứ ba cho nhiều routes, import `next/script` và bao gồm script trực tiếp trong layout component của bạn:

```tsx filename="app/dashboard/layout.tsx" switcher
import Script from 'next/script'

export default function DashboardLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <>
      <section>{children}</section>
      <Script src="https://example.com/script.js" />
    </>
  )
}
```

```jsx filename="app/dashboard/layout.js" switcher
import Script from 'next/script'

export default function DashboardLayout({ children }) {
  return (
    <>
      <section>{children}</section>
      <Script src="https://example.com/script.js" />
    </>
  )
}
```

Script của bên thứ ba được fetch khi folder route (v.d. `dashboard/page.js`) hoặc bất kỳ nested route nào (v.d. `dashboard/settings/page.js`) được người dùng truy cập. Next.js sẽ đảm bảo script sẽ **chỉ tải một lần**, ngay cả khi người dùng điều hướng giữa nhiều routes trong cùng một layout.

</AppOnly>

### Application Scripts

<AppOnly>

Để tải một script của bên thứ ba cho tất cả các routes, import `next/script` và bao gồm script trực tiếp trong root layout của bạn:

```tsx filename="app/layout.tsx" switcher
import Script from 'next/script'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
      <Script src="https://example.com/script.js" />
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import Script from 'next/script'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
      <Script src="https://example.com/script.js" />
    </html>
  )
}
```

</AppOnly>

<PagesOnly>

Để tải một script của bên thứ ba cho tất cả các routes, import `next/script` và bao gồm script trực tiếp trong `_app` tùy chỉnh của bạn:

```jsx filename="pages/_app.js"
import Script from 'next/script'

export default function MyApp({ Component, pageProps }) {
  return (
    <>
      <Component {...pageProps} />
      <Script src="https://example.com/script.js" />
    </>
  )
}
```

</PagesOnly>

Script này sẽ tải và thực thi khi _bất kỳ_ route nào trong ứng dụng của bạn được truy cập. Next.js sẽ đảm bảo script sẽ **chỉ tải một lần**, ngay cả khi người dùng điều hướng giữa nhiều trang.

> **Khuyến nghị**: Chúng tôi khuyến nghị chỉ bao gồm các scripts của bên thứ ba trong các trang hoặc layouts cụ thể để giảm thiểu bất kỳ tác động không cần thiết nào đến hiệu suất.

### Strategy

Mặc dù hành vi mặc định của `next/script` cho phép bạn tải các scripts của bên thứ ba trong bất kỳ trang hoặc layout nào, bạn có thể tinh chỉnh hành vi tải của nó bằng cách sử dụng thuộc tính `strategy`:

- `beforeInteractive`: Tải script trước bất kỳ mã Next.js nào và trước khi bất kỳ page hydration nào xảy ra.
- `afterInteractive`: (**mặc định**) Tải script sớm nhưng sau khi một số hydration trên trang xảy ra.
- `lazyOnload`: Tải script sau trong thời gian rảnh của trình duyệt.
- `worker`: (thử nghiệm) Tải script trong một web worker.

Tham khảo tài liệu API reference [`next/script`](/docs/app/api-reference/components/script#strategy) để tìm hiểu thêm về từng strategy và các trường hợp sử dụng của chúng.

### Offloading Scripts To A Web Worker (thử nghiệm)

> **Cảnh báo:** Strategy `worker` chưa ổn định và chưa hoạt động với App Router. Sử dụng thận trọng.

Các scripts sử dụng strategy `worker` được offload và thực thi trong một web worker với [Partytown](https://partytown.builder.io/). Điều này có thể cải thiện hiệu suất của trang web của bạn bằng cách dành luồng chính cho phần còn lại của mã ứng dụng của bạn.

Strategy này vẫn đang thử nghiệm và chỉ có thể được sử dụng nếu cờ `nextScriptWorkers` được bật trong `next.config.js`:

```js filename="next.config.js"
module.exports = {
  experimental: {
    nextScriptWorkers: true,
  },
}
```

Sau đó, chạy `next` (thường là `npm run dev` hoặc `yarn dev`) và Next.js sẽ hướng dẫn bạn qua việc cài đặt các packages cần thiết để hoàn tất thiết lập:

```bash filename="Terminal"
npm run dev
```

Bạn sẽ thấy các hướng dẫn như thế này: Vui lòng cài đặt Partytown bằng cách chạy `npm install @builder.io/partytown`

Khi thiết lập hoàn tất, định nghĩa `strategy="worker"` sẽ tự động khởi tạo Partytown trong ứng dụng của bạn và offload script vào một web worker.

```tsx filename="pages/home.tsx" switcher
import Script from 'next/script'

export default function Home() {
  return (
    <>
      <Script src="https://example.com/script.js" strategy="worker" />
    </>
  )
}
```

```jsx filename="pages/home.js" switcher
import Script from 'next/script'

export default function Home() {
  return (
    <>
      <Script src="https://example.com/script.js" strategy="worker" />
    </>
  )
}
```

Có một số đánh đổi cần được xem xét khi tải một script của bên thứ ba trong một web worker. Vui lòng xem tài liệu [tradeoffs](https://partytown.builder.io/trade-offs) của Partytown để biết thêm thông tin.

#### Sử dụng cấu hình Partytown tùy chỉnh

Mặc dù strategy `worker` không yêu cầu bất kỳ cấu hình bổ sung nào để hoạt động, Partytown hỗ trợ việc sử dụng một đối tượng config để sửa đổi một số cài đặt của nó, bao gồm bật chế độ `debug` và chuyển tiếp các sự kiện và triggers.

Nếu bạn muốn thêm các tùy chọn cấu hình bổ sung, bạn có thể bao gồm nó trong component `<Head />` được sử dụng trong [custom `_document.js`](/docs/pages/building-your-application/routing/custom-document):

```jsx filename="_pages/document.jsx"
import { Html, Head, Main, NextScript } from 'next/document'

export default function Document() {
  return (
    <Html>
      <Head>
        <script
          data-partytown-config
          dangerouslySetInnerHTML={{
            __html: `
              partytown = {
                lib: "/_next/static/~partytown/",
                debug: true
              };
            `,
          }}
        />
      </Head>
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  )
}
```

Để sửa đổi cấu hình của Partytown, các điều kiện sau phải được đáp ứng:

1. Thuộc tính `data-partytown-config` phải được sử dụng để ghi đè cấu hình mặc định được sử dụng bởi Next.js
2. Trừ khi bạn quyết định lưu các tệp thư viện của Partytown trong một thư mục riêng biệt, thuộc tính và giá trị `lib: "/_next/static/~partytown/"` phải được bao gồm trong đối tượng cấu hình để cho Partytown biết Next.js lưu trữ các tệp tĩnh cần thiết ở đâu.

> **Lưu ý**: Nếu bạn đang sử dụng [asset prefix](/docs/pages/api-reference/config/next-config-js/assetPrefix) và muốn sửa đổi cấu hình mặc định của Partytown, bạn phải bao gồm nó như một phần của đường dẫn `lib`.

Hãy xem [các tùy chọn cấu hình](https://partytown.builder.io/configuration) của Partytown để xem danh sách đầy đủ các thuộc tính khác có thể được thêm vào.

</PagesOnly>

### Inline Scripts

Inline scripts, hoặc các scripts không được tải từ một tệp bên ngoài, cũng được hỗ trợ bởi component Script. Chúng có thể được viết bằng cách đặt JavaScript trong dấu ngoặc nhọn:

```jsx
<Script id="show-banner">
  {`document.getElementById('banner').classList.remove('hidden')`}
</Script>
```

Hoặc bằng cách sử dụng thuộc tính `dangerouslySetInnerHTML`:

```jsx
<Script
  id="show-banner"
  dangerouslySetInnerHTML={{
    __html: `document.getElementById('banner').classList.remove('hidden')`,
  }}
/>
```

> **Cảnh báo**: Một thuộc tính `id` phải được gán cho các inline scripts để Next.js theo dõi và tối ưu hóa script.

### Thực thi Mã bổ sung

Các event handlers có thể được sử dụng với component Script để thực thi mã bổ sung sau khi một sự kiện nhất định xảy ra:

- `onLoad`: Thực thi mã sau khi script đã tải xong.
- `onReady`: Thực thi mã sau khi script đã tải xong và mỗi khi component được mount.
- `onError`: Thực thi mã nếu script không tải được.

<AppOnly>

Các handlers này sẽ chỉ hoạt động khi `next/script` được import và sử dụng bên trong một [Client Component](/docs/app/getting-started/server-and-client-components) nơi `"use client"` được định nghĩa là dòng mã đầu tiên:

```tsx filename="app/page.tsx" switcher
'use client'

import Script from 'next/script'

export default function Page() {
  return (
    <>
      <Script
        src="https://example.com/script.js"
        onLoad={() => {
          console.log('Script has loaded')
        }}
      />
    </>
  )
}
```

```jsx filename="app/page.js" switcher
'use client'

import Script from 'next/script'

export default function Page() {

```

### Các Thuộc tính Bổ sung

Có nhiều thuộc tính DOM có thể được gán cho một phần tử `<script>` mà không được sử dụng bởi component Script, như [`nonce`](https://developer.mozilla.org/docs/Web/HTML/Global_attributes/nonce) hoặc [custom data attributes](https://developer.mozilla.org/docs/Web/HTML/Global_attributes/data-*). Bao gồm bất kỳ thuộc tính bổ sung nào sẽ tự động chuyển tiếp nó đến phần tử `<script>` cuối cùng, được tối ưu hóa được bao gồm trong HTML.

<AppOnly>

```tsx filename="app/page.tsx" switcher
import Script from 'next/script'

export default function Page() {
  return (
    <>
      <Script
        src="https://example.com/script.js"
        id="example-script"
        nonce="XUENAJFW"
        data-test="script"
      />
    </>
  )
}
```

```jsx filename="app/page.js" switcher
import Script from 'next/script'

export default function Page() {
```
