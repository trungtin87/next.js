Playwright là một testing framework cho phép bạn tự động hóa Chromium, Firefox và WebKit với một API duy nhất. Bạn có thể sử dụng nó để viết **End-to-End (E2E)** testing. Hướng dẫn này sẽ chỉ cho bạn cách thiết lập Playwright với Next.js và viết các tests đầu tiên của bạn.

## Quickstart

Cách nhanh nhất để bắt đầu là sử dụng `create-next-app` với [ví dụ with-playwright](https://github.com/vercel/next.js/tree/canary/examples/with-playwright). Điều này sẽ tạo một dự án Next.js hoàn chỉnh với Playwright đã được cấu hình.

```bash filename="Terminal"
npx create-next-app@latest --example with-playwright with-playwright-app
```

## Thiết lập thủ công

Để cài đặt Playwright, hãy chạy lệnh sau:

```bash filename="Terminal"
npm init playwright
# hoặc
yarn create playwright
# hoặc
pnpm create playwright
```

Điều này sẽ đưa bạn qua một loạt các prompts để thiết lập và cấu hình Playwright cho dự án của bạn, bao gồm thêm một tệp `playwright.config.ts`. Vui lòng tham khảo [hướng dẫn cài đặt Playwright](https://playwright.dev/docs/intro#installation) để biết hướng dẫn từng bước.

## Tạo Playwright E2E test đầu tiên của bạn

Tạo hai trang Next.js mới:

<AppOnly>

```tsx filename="app/page.tsx"
import Link from 'next/link'

export default function Page() {
  return (
    <div>
      <h1>Home</h1>
      <Link href="/about">About</Link>
    </div>
  )
}
```

```tsx filename="app/about/page.tsx"
import Link from 'next/link'

export default function Page() {
  return (
    <div>
      <h1>About</h1>
      <Link href="/">Home</Link>
    </div>
  )
}
```

</AppOnly>

<PagesOnly>

```tsx filename="pages/index.ts"
import Link from 'next/link'

export default function Home() {
  return (
    <div>
      <h1>Home</h1>
      <Link href="/about">About</Link>
    </div>
  )
}
```

```tsx filename="pages/about.ts"
import Link from 'next/link'

export default function About() {
  return (
    <div>
      <h1>About</h1>
      <Link href="/">Home</Link>
    </div>
  )
}
```

</PagesOnly>

Sau đó, thêm một test để xác minh rằng navigation của bạn hoạt động chính xác:

```ts filename="tests/example.spec.ts"
import { test, expect } from '@playwright/test'

test('should navigate to the about page', async ({ page }) => {
  // Start from the index page (the baseURL is set via the webServer in the playwright.config.ts)
  await page.goto('http://localhost:3000/')
  // Find an element with the text 'About' and click on it
  await page.click('text=About')
  // The new URL should be "/about" (baseURL is used there)
  await expect(page).toHaveURL('http://localhost:3000/about')
  // The new page should contain an h1 with "About"
  await expect(page.locator('h1')).toContainText('About')
})
```

> **Nên biết**: Bạn có thể sử dụng `page.goto("/")` thay vì `page.goto("http://localhost:3000/")`, nếu bạn thêm [`"baseURL": "http://localhost:3000"`](https://playwright.dev/docs/api/class-testoptions#test-options-base-url) vào [tệp cấu hình](https://playwright.dev/docs/test-configuration) `playwright.config.ts`.

### Chạy Playwright tests của bạn

Playwright sẽ mô phỏng một người dùng điều hướng ứng dụng của bạn bằng ba trình duyệt: Chromium, Firefox và Webkit, điều này yêu cầu Next.js server của bạn đang chạy. Chúng tôi khuyến nghị chạy các tests của bạn đối với production code của bạn để mô phỏng chặt chẽ hơn cách ứng dụng của bạn sẽ hoạt động.

Chạy `npm run build` và `npm run start`, sau đó chạy `npx playwright test` trong một cửa sổ terminal khác để chạy các Playwright tests.

> **Nên biết**: Ngoài ra, bạn có thể sử dụng tính năng [`webServer`](https://playwright.dev/docs/test-webserver/) để cho phép Playwright khởi động development server và đợi cho đến khi nó hoàn toàn có sẵn.

### Chạy Playwright trên Continuous Integration (CI)

Playwright theo mặc định sẽ chạy các tests của bạn trong [headless mode](https://playwright.dev/docs/ci#running-headed). Để cài đặt tất cả các Playwright dependencies, hãy chạy `npx playwright install-deps`.
