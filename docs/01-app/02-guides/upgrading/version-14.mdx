## Nâng cấp từ 13 lên 14

Để cập nhật lên Next.js phiên bản 14, hãy chạy lệnh sau bằng trình quản lý gói ưa thích của bạn:

```bash filename="Terminal"
npm i next@next-14 react@18 react-dom@18 && npm i eslint-config-next@next-14 -D
```

```bash filename="Terminal"
yarn add next@next-14 react@18 react-dom@18 && yarn add eslint-config-next@next-14 -D
```

```bash filename="Terminal"
pnpm i next@next-14 react@18 react-dom@18 && pnpm i eslint-config-next@next-14 -D
```

```bash filename="Terminal"
bun add next@next-14 react@18 react-dom@18 && bun add eslint-config-next@next-14 -D
```

> **Thông tin hữu ích:** Nếu bạn đang sử dụng TypeScript, hãy đảm bảo bạn cũng nâng cấp `@types/react` và `@types/react-dom` lên các phiên bản mới nhất của chúng.

### Tóm tắt v14

- Phiên bản Node.js tối thiểu đã được nâng từ 16.14 lên 18.17, vì 16.x đã hết vòng đời.
- Lệnh `next export` đã bị xóa để ủng hộ cấu hình `output: 'export'`. Vui lòng xem [tài liệu](https://nextjs.org/docs/app/guides/static-exports) để biết thêm thông tin.
- Import `next/server` cho `ImageResponse` đã được đổi tên thành `next/og`. Một [codemod có sẵn](/docs/app/guides/upgrading/codemods#next-og-import) để đổi tên import của bạn một cách an toàn và tự động.
- Gói `@next/font` đã bị xóa hoàn toàn để ủng hộ `next/font` tích hợp sẵn. Một [codemod có sẵn](/docs/app/guides/upgrading/codemods#built-in-next-font) để đổi tên import của bạn một cách an toàn và tự động.
- Target WASM cho `next-swc` đã bị xóa.
