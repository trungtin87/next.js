[Lazy loading](https://developer.mozilla.org/docs/Web/Performance/Lazy_loading) trong Next.js giúp cải thiện hiệu suất tải ban đầu của ứng dụng bằng cách giảm lượng JavaScript cần thiết để render một route.

<AppOnly>

Nó cho phép bạn trì hoãn việc tải các **Client Components** và các thư viện đã import, và chỉ bao gồm chúng trong client bundle khi chúng cần thiết. Ví dụ, bạn có thể muốn trì hoãn việc tải một modal cho đến khi người dùng nhấp để mở nó.

Có hai cách bạn có thể triển khai lazy loading trong Next.js:

1. Sử dụng [Dynamic Imports](#nextdynamic) với `next/dynamic`
2. Sử dụng [`React.lazy()`](https://react.dev/reference/react/lazy) với [Suspense](https://react.dev/reference/react/Suspense)

Theo mặc định, Server Components được tự động [code split](https://developer.mozilla.org/docs/Glossary/Code_splitting), và bạn có thể sử dụng [streaming](/docs/app/api-reference/file-conventions/loading) để gửi dần các phần của UI từ server đến client. Lazy loading áp dụng cho Client Components.

## `next/dynamic`

`next/dynamic` là sự kết hợp của [`React.lazy()`](https://react.dev/reference/react/lazy) và [Suspense](https://react.dev/reference/react/Suspense). Nó hoạt động giống nhau trong các thư mục `app` và `pages` để cho phép di chuyển dần dần.

## Ví dụ

### Import Client Components

```jsx filename="app/page.js"
'use client'

import { useState } from 'react'
import dynamic from 'next/dynamic'

// Client Components:
const ComponentA = dynamic(() => import('../components/A'))
const ComponentB = dynamic(() => import('../components/B'))
const ComponentC = dynamic(() => import('../components/C'), { ssr: false })

export default function ClientComponentExample() {
  const [showMore, setShowMore] = useState(false)

  return (
    <div>
      {/* Tải ngay lập tức, nhưng trong một client bundle riêng biệt */}
      <ComponentA />

      {/* Tải theo yêu cầu, chỉ khi điều kiện được đáp ứng */}
      {showMore && <ComponentB />}
      <button onClick={() => setShowMore(!showMore)}>Toggle</button>

      {/* Chỉ tải ở phía client */}
      <ComponentC />
    </div>
  )
}
```

> **Lưu ý:** Khi một Server Component import động một Client Component, việc tự động [code splitting](https://developer.mozilla.org/docs/Glossary/Code_splitting) hiện **không** được hỗ trợ.

### Bỏ qua SSR

Khi sử dụng `React.lazy()` và Suspense, Client Components sẽ được [prerendered](https://github.com/reactwg/server-components/discussions/4) (SSR) theo mặc định.

> **Lưu ý:** Tùy chọn `ssr: false` sẽ chỉ hoạt động cho Client Components, hãy di chuyển nó vào Client Components để đảm bảo client code-splitting hoạt động bình thường.

Nếu bạn muốn vô hiệu hóa pre-rendering cho một Client Component, bạn có thể sử dụng tùy chọn `ssr` được đặt thành `false`:

```jsx
const ComponentC = dynamic(() => import('../components/C'), { ssr: false })
```

### Import Server Components

Nếu bạn import động một Server Component, chỉ các Client Components là con của Server Component đó mới được lazy-load - không phải bản thân Server Component.
Nó cũng sẽ giúp preload các tài sản tĩnh như CSS khi bạn đang sử dụng nó trong Server Components.

```jsx filename="app/page.js"
import dynamic from 'next/dynamic'

// Server Component:
const ServerComponent = dynamic(() => import('../components/ServerComponent'))

export default function ServerComponentExample() {
  return (
    <div>
      <ServerComponent />
    </div>
  )
}
```

> **Lưu ý:** Tùy chọn `ssr: false` không được hỗ trợ trong Server Components. Bạn sẽ thấy lỗi nếu cố gắng sử dụng nó trong Server Components.
> `ssr: false` không được phép với `next/dynamic` trong Server Components. Vui lòng di chuyển nó vào một Client Component.

### Tải Thư viện Bên ngoài

Các thư viện bên ngoài có thể được tải theo yêu cầu bằng cách sử dụng hàm [`import()`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Operators/import). Ví dụ này sử dụng thư viện bên ngoài `fuse.js` để tìm kiếm mờ (fuzzy search). Module chỉ được tải trên client sau khi người dùng nhập vào ô tìm kiếm.

```jsx filename="app/page.js"
'use client'

import { useState } from 'react'

const names = ['Tim', 'Joe', 'Bel', 'Lee']

export default function Page() {
  const [results, setResults] = useState()

  return (
    <div>
      <input
        type="text"
        placeholder="Search"
        onChange={async (e) => {
          const { value } = e.currentTarget
          // Tải động fuse.js
          const Fuse = (await import('fuse.js')).default
          const fuse = new Fuse(names)

          setResults(fuse.search(value))
        }}
      />
      <pre>Results: {JSON.stringify(results, null, 2)}</pre>
    </div>
  )
}
```

### Thêm một component loading tùy chỉnh

```jsx filename="app/page.js"
'use client'

import dynamic from 'next/dynamic'

const WithCustomLoading = dynamic(
  () => import('../components/WithCustomLoading'),
  {
    loading: () => <p>Loading...</p>,
  }
)

export default function Page() {
  return (
    <div>
      {/* Component loading sẽ được render trong khi <WithCustomLoading/> đang tải */}
      <WithCustomLoading />
    </div>
  )
}
```

### Import Named Exports

Để import động một named export, bạn có thể trả về nó từ Promise được trả về bởi hàm [`import()`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Operators/import):

```jsx filename="components/hello.js"
'use client'

export function Hello() {
  return <p>Hello!</p>
}
```

```jsx filename="app/page.js"
import dynamic from 'next/dynamic'

const ClientComponent = dynamic(() =>
  import('../components/hello').then((mod) => mod.Hello)
)
```

## `next/dynamic`

`next/dynamic` là sự kết hợp của [`React.lazy()`](https://react.dev/reference/react/lazy) và [Suspense](https://react.dev/reference/react/Suspense). Nó hoạt động giống nhau trong các thư mục `app` và `pages` để cho phép di chuyển dần dần.

Trong ví dụ dưới đây, bằng cách sử dụng `next/dynamic`, component header sẽ không được bao gồm trong gói JavaScript ban đầu của trang. Trang sẽ render Suspense `fallback` trước, tiếp theo là component `Header` khi ranh giới `Suspense` được giải quyết.

```jsx
import dynamic from 'next/dynamic'

const DynamicHeader = dynamic(() => import('../components/header'), {
  loading: () => <p>Loading...</p>,
})

export default function Home() {
  return <DynamicHeader />
}
```

> **Cần biết**: Trong `import('path/to/component')`, đường dẫn phải được viết rõ ràng. Nó không thể là một template string hay một biến. Hơn nữa, `import()` phải nằm bên trong lệnh gọi `dynamic()` để Next.js có thể khớp các webpack bundles / module ids với lệnh gọi `dynamic()` cụ thể và preload chúng trước khi render. `dynamic()` không thể được sử dụng bên trong quá trình render React vì nó cần được đánh dấu ở cấp cao nhất của module để preload hoạt động, tương tự như `React.lazy`.

## Ví dụ

### Với named exports

Để import động một named export, bạn có thể trả về nó từ [Promise](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Promise) được trả về bởi [`import()`](https://github.com/tc39/proposal-dynamic-import#example):

```jsx filename="components/hello.js"
export function Hello() {
  return <p>Hello!</p>
}

// pages/index.js
import dynamic from 'next/dynamic'

const DynamicComponent = dynamic(() =>
  import('../components/hello').then((mod) => mod.Hello)
)
```

### Với no SSR

Để tải động một component ở phía client, bạn có thể sử dụng tùy chọn `ssr` để vô hiệu hóa server-rendering. Điều này hữu ích nếu một dependency bên ngoài hoặc component dựa vào các API của trình duyệt như `window`.

```jsx
'use client'

import dynamic from 'next/dynamic'

const DynamicHeader = dynamic(() => import('../components/header'), {
  ssr: false,
})
```

### Với thư viện bên ngoài

Ví dụ này sử dụng thư viện bên ngoài `fuse.js` để tìm kiếm mờ (fuzzy search). Module chỉ được tải trong trình duyệt sau khi người dùng nhập vào ô tìm kiếm.

```jsx
import { useState } from 'react'

const names = ['Tim', 'Joe', 'Bel', 'Lee']

export default function Page() {
  const [results, setResults] = useState()

  return (
    <div>
      <input
        type="text"
        placeholder="Search"
        onChange={async (e) => {
          const { value } = e.currentTarget
          // Tải động fuse.js
          const Fuse = (await import('fuse.js')).default
          const fuse = new Fuse(names)

          setResults(fuse.search(value))
        }}
      />
      <pre>Results: {JSON.stringify(results, null, 2)}</pre>
    </div>
  )
}
```
