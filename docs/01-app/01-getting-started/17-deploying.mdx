## Node.js server

Next.js có thể được triển khai lên bất kỳ provider nào hỗ trợ Node.js. Đảm bảo `package.json` của bạn có các scripts `"build"` và `"start"`:

```json filename="package.json"
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start"
  }
}
```

Sau đó, chạy `npm run build` để build ứng dụng của bạn và `npm run start` để khởi động Node.js server. Server này hỗ trợ tất cả các tính năng Next.js. Nếu cần, bạn cũng có thể eject sang một [custom server](/docs/app/guides/custom-server).

Các triển khai Node.js hỗ trợ tất cả các tính năng Next.js. Tìm hiểu cách [cấu hình chúng](/docs/app/guides/self-hosting) cho infrastructure của bạn.

## Docker

Next.js có thể được triển khai lên bất kỳ provider nào hỗ trợ [Docker](https://www.docker.com/) containers. Điều này bao gồm các container orchestrators như Kubernetes hoặc một cloud provider chạy Docker.

Các triển khai Docker hỗ trợ tất cả các tính năng Next.js. Tìm hiểu cách [cấu hình chúng](/docs/app/guides/self-hosting) cho infrastructure của bạn.

> **Lưu ý cho development:** Trong khi Docker rất tốt cho các triển khai production, hãy xem xét sử dụng local development (`npm run dev`) thay vì Docker trong quá trình development trên Mac và Windows để có hiệu suất tốt hơn. [Tìm hiểu thêm về tối ưu hóa local development](/docs/app/guides/local-development).

## Static export

Next.js cho phép bắt đầu như một static site hoặc [Single-Page Application (SPA)](/docs/app/guides/single-page-applications), sau đó tùy chọn nâng cấp để sử dụng các tính năng yêu cầu server.

Vì Next.js hỗ trợ [static exports](/docs/app/guides/static-exports), nó có thể được triển khai và host trên bất kỳ web server nào có thể phục vụ các static assets HTML/CSS/JS. Điều này bao gồm các công cụ như AWS S3, Nginx, hoặc Apache.

Chạy như một [static export](/docs/app/guides/static-exports) **không** hỗ trợ các tính năng Next.js yêu cầu server. [Tìm hiểu thêm](/docs/app/guides/static-exports#unsupported-features).

## Adapters

Next.js có thể được điều chỉnh để chạy trên các nền tảng khác nhau để hỗ trợ khả năng infrastructure của chúng.

Tham khảo tài liệu của từng provider để biết thông tin về các tính năng Next.js được hỗ trợ:

- [AWS Amplify Hosting](https://docs.amplify.aws/nextjs/start/quickstart/nextjs-app-router-client-components)
- [Cloudflare](https://developers.cloudflare.com/workers/frameworks/framework-guides/nextjs)
- [Deno Deploy](https://docs.deno.com/examples/next_tutorial)
- [Netlify](https://docs.netlify.com/frameworks/next-js/overview/#next-js-support-on-netlify)
- [Vercel](https://vercel.com/docs/frameworks/nextjs)

> **Lưu ý:** Chúng tôi đang làm việc trên một [Deployment Adapters API](https://github.com/vercel/next.js/discussions/77740) cho tất cả các nền tảng để áp dụng. Sau khi hoàn thành, chúng tôi sẽ thêm tài liệu về cách viết adapters của riêng bạn.
