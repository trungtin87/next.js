Bạn có thể cập nhật dữ liệu trong Next.js bằng cách sử dụng [Server Functions](https://react.dev/reference/rsc/server-functions) của React. Trang này sẽ hướng dẫn bạn cách [tạo](#creating-server-functions) và [gọi](#invoking-server-functions) Server Functions.

## Server Functions là gì?

Một **Server Function** là một hàm bất đồng bộ (asynchronous function) chạy trên server. Chúng có thể được gọi từ client thông qua một network request, đó là lý do tại sao chúng phải là bất đồng bộ.

Trong ngữ cảnh `action` hoặc mutation, chúng còn được gọi là **Server Actions**.

Theo quy ước, một Server Action là một async function được sử dụng với [`startTransition`](https://react.dev/reference/react/startTransition). Điều này xảy ra tự động khi function được:

- Truyền vào một `<form>` sử dụng prop `action`.
- Truyền vào một `<button>` sử dụng prop `formAction`.

Trong Next.js, Server Actions tích hợp với kiến trúc [caching](/docs/app/guides/caching) của framework. Khi một action được gọi, Next.js có thể trả về cả UI đã cập nhật và dữ liệu mới trong một server roundtrip duy nhất.

Đằng sau hậu trường, actions sử dụng phương thức `POST`, và chỉ phương thức HTTP này mới có thể gọi chúng.

## Tạo Server Functions

Một Server Function có thể được định nghĩa bằng cách sử dụng directive [`use server`](https://react.dev/reference/rsc/use-server). Bạn có thể đặt directive ở đầu một hàm **bất đồng bộ** để đánh dấu hàm đó là một Server Function, hoặc ở đầu một file riêng biệt để đánh dấu tất cả các exports của file đó.

```ts filename="app/lib/actions.ts" switcher
export async function createPost(formData: FormData) {
  'use server'
  const title = formData.get('title')
  const content = formData.get('content')

  // Update data
  // Revalidate cache
}

export async function deletePost(formData: FormData) {
  'use server'
  const id = formData.get('id')

  // Update data
  // Revalidate cache
}
```

```js filename="app/lib/actions.js" switcher

  'use server'
  const title = formData.get('title')

}

  'use server'

  // Revalidate cache
}
```

### Server Components

Server Functions có thể được nội tuyến (inlined) trong Server Components bằng cách thêm directive `"use server"` vào đầu thân hàm:

```tsx filename="app/page.tsx" switcher
export default function Page() {
  // Server Action
  async function createPost(formData: FormData) {
    'use server'
    // ...
  }

  return <></>
}
```

```jsx filename="app/page.js" switcher
export default function Page() {
  // Server Action
  async function createPost(formData: FormData) {
    'use server'
    // ...
  }

  return <></>
}
```

> **Lưu ý:** Server Components hỗ trợ progressive enhancement theo mặc định, nghĩa là các forms gọi Server Actions sẽ được submit ngay cả khi JavaScript chưa tải xong hoặc bị vô hiệu hóa.

### Client Components

Không thể định nghĩa Server Functions trong Client Components. Tuy nhiên, bạn có thể gọi chúng trong Client Components bằng cách import chúng từ một file có directive `"use server"` ở đầu file đó:

```ts filename="app/actions.ts" switcher
'use server'

export async function createPost() {}
```

```js filename="app/actions.js" switcher
'use server'

export async function createPost() {}
```

```tsx filename="app/ui/button.tsx" switcher
'use client'

import { createPost } from '@/app/actions'

export function Button() {
  return <button formAction={createPost}>Create</button>
}
```

```jsx filename="app/ui/button.js" switcher
'use client'

import { createPost } from '@/app/actions'

export function Button() {
  return <button formAction={createPost}>Create</button>
}
```

> **Lưu ý:** Trong Client Components, các forms gọi Server Actions sẽ xếp hàng các submissions nếu JavaScript chưa được tải, và sẽ được ưu tiên khi hydration. Sau khi hydration, trình duyệt không refresh khi form submission.

### Truyền actions như props

Bạn cũng có thể truyền một action cho một Client Component như một prop:

```jsx
<ClientComponent updateItemAction={updateItem} />
```

```tsx filename="app/client-component.tsx" switcher
'use client'

export default function ClientComponent({
  updateItemAction,
}: {
  updateItemAction: (formData: FormData) => void
}) {
  return <form action={updateItemAction}>{/* ... */}</form>
}
```

```jsx filename="app/client-component.js" switcher
'use client'

export default function ClientComponent({ updateItemAction }) {
  return <form action={updateItemAction}>{/* ... */}</form>
}
```

## Gọi Server Functions

Có hai cách chính bạn có thể gọi một Server Function:

1. [Forms](#forms) trong Server và Client Components
2. [Event Handlers](#event-handlers) và [useEffect](#useeffect) trong Client Components

> **Lưu ý:** Server Functions được thiết kế cho server-side mutations. Client hiện tại gửi và chờ chúng từng cái một. Đây là một chi tiết triển khai và có thể thay đổi. Nếu bạn cần parallel data fetching, sử dụng [data fetching](/docs/app/getting-started/fetching-data#server-components) trong Server Components, hoặc thực hiện công việc song song bên trong một Server Function hoặc [Route Handler](/docs/app/guides/backend-for-frontend#manipulating-data) duy nhất.

### Forms

React mở rộng phần tử HTML [`<form>`](https://react.dev/reference/react-dom/components/form) để cho phép Server Function được gọi với prop `action` của HTML.

Khi được gọi trong một form, hàm tự động nhận đối tượng [`FormData`](https://developer.mozilla.org/docs/Web/API/FormData/FormData). Bạn có thể trích xuất dữ liệu bằng cách sử dụng các [phương thức `FormData`](https://developer.mozilla.org/en-US/docs/Web/API/FormData#instance_methods) native:

```tsx filename="app/ui/form.tsx" switcher
import { createPost } from '@/app/actions'

export function Form() {
  return (
    <form action={createPost}>
      <input type="text" name="title" />
      <input type="text" name="content" />
      <button type="submit">Create</button>

}
```

### Event Handlers

Bạn có thể gọi một Server Function trong một Client Component bằng cách sử dụng event handlers như `onClick`.

```tsx filename="app/like-button.tsx" switcher
'use client'

import { incrementLike } from './actions'
import { useState } from 'react'

export default function LikeButton({ initialLikes }: { initialLikes: number }) {
  const [likes, setLikes] = useState(initialLikes)

  return (
    <>
      <p>Total Likes: {likes}</p>
      <button
        onClick={async () => {
          const updatedLikes = await incrementLike()
          setLikes(updatedLikes)
        }}
      >
        Like
      </button>
    </>
  )
}
```

```jsx filename="app/like-button.js" switcher

import { incrementLike } from './actions'
```

## Ví dụ

### Hiển thị pending state

Trong khi thực thi một Server Function, bạn có thể hiển thị một loading indicator với hook [`useActionState`](https://react.dev/reference/react/useActionState) của React. Hook này trả về một boolean `pending`:

```tsx filename="app/ui/button.tsx" switcher
'use client'

import { useActionState, startTransition } from 'react'
import { createPost } from '@/app/actions'
import { LoadingSpinner } from '@/app/ui/loading-spinner'

export function Button() {
  const [state, action, pending] = useActionState(createPost, false)

  return (
    <button onClick={() => startTransition(action)}>
      {pending ? <LoadingSpinner /> : 'Create Post'}
    </button>
  )
}
```

```jsx filename="app/ui/button.js" switcher
'use client'

import { useActionState, startTransition } from 'react'
import { createPost } from '@/app/actions'
import { LoadingSpinner } from '@/app/ui/loading-spinner'

export function Button() {
  const [state, action, pending] = useActionState(createPost, false)

  return (
    <button onClick={() => startTransition(action)}>
      {pending ? <LoadingSpinner /> : 'Create Post'}
    </button>
  )
}
```

### Revalidating

Sau khi thực hiện một bản cập nhật, bạn có thể revalidate Next.js cache và hiển thị dữ liệu đã cập nhật bằng cách gọi [`revalidatePath`](/docs/app/api-reference/functions/revalidatePath) hoặc [`revalidateTag`](/docs/app/api-reference/functions/revalidateTag) bên trong Server Function:

```ts filename="app/lib/actions.ts" switcher
import { revalidatePath } from 'next/cache'

export async function createPost(formData: FormData) {
  'use server'
  // Update data
  // ...

  revalidatePath('/posts')
}
```

```js filename="app/actions.js" switcher
import { revalidatePath } from 'next/cache'

export async function createPost(formData) {
  'use server'
  // Update data
  // ...
  revalidatePath('/posts')
}
```

### Redirecting

Bạn có thể muốn chuyển hướng người dùng đến một trang khác sau khi thực hiện một bản cập nhật. Bạn có thể làm điều này bằng cách gọi [`redirect`](/docs/app/api-reference/functions/redirect) bên trong Server Function.

```ts filename="app/lib/actions.ts" switcher
'use server'

import { revalidatePath } from 'next/cache'
import { redirect } from 'next/navigation'

export async function createPost(formData: FormData) {
  // Update data
  // ...

  revalidatePath('/posts')
  redirect('/posts')
}
```

```js filename="app/actions.js" switcher
'use server'

import { revalidatePath } from 'next/cache'
import { redirect } from 'next/navigation'

export async function createPost(formData) {
  // Update data
  // ...

  revalidatePath('/posts')
  redirect('/posts')
}
```

Việc gọi `redirect` [throws](/docs/app/api-reference/functions/redirect#behavior) một ngoại lệ control-flow được framework xử lý. Bất kỳ mã nào sau đó sẽ không thực thi. Nếu bạn cần dữ liệu mới, hãy gọi [`revalidatePath`](/docs/app/api-reference/functions/revalidatePath) hoặc [`revalidateTag`](/docs/app/api-reference/functions/revalidateTag) trước đó.

### Cookies

Bạn có thể `get`, `set`, và `delete` cookies bên trong một Server Action bằng cách sử dụng API [`cookies`](/docs/app/api-reference/functions/cookies).

Khi bạn [set hoặc delete](/docs/app/api-reference/functions/cookies#understanding-cookie-behavior-in-server-actions) một cookie trong một Server Action, Next.js re-renders trang hiện tại và các layouts của nó trên server để **UI phản ánh giá trị cookie mới**.

> **Lưu ý:** Bản cập nhật server áp dụng cho cây React hiện tại, re-rendering, mounting, hoặc unmounting components, khi cần thiết. Client state được giữ nguyên cho các components được re-rendered, và effects chạy lại nếu dependencies của chúng thay đổi.

```ts filename="app/actions.ts" switcher
'use server'

import { cookies } from 'next/headers'

export async function exampleAction() {
  const cookieStore = await cookies()

  // Get cookie
  cookieStore.get('name')?.value

  // Set cookie
  cookieStore.set('name', 'Delba')

  // Delete cookie
  cookieStore.delete('name')
}
```

```js filename="app/actions.js" switcher
'use server'

import { cookies } from 'next/headers'

export async function exampleAction() {
  // Get cookie
  const cookieStore = await cookies()

  // Get cookie
  cookieStore.get('name')?.value

  // Set cookie
  cookieStore.set('name', 'Delba')

  // Delete cookie
  cookieStore.delete('name')
}
```

### useEffect

Bạn có thể sử dụng hook [`useEffect`](https://react.dev/reference/react/useEffect) của React để gọi một Server Action khi component mounts hoặc một dependency thay đổi. Điều này hữu ích cho các mutations phụ thuộc vào các sự kiện toàn cầu hoặc cần được kích hoạt tự động. Ví dụ, `onKeyDown` cho các phím tắt ứng dụng, một intersection observer hook cho cuộn vô hạn, hoặc khi component mounts để cập nhật số lượt xem:

```tsx filename="app/view-count.tsx" switcher
'use client'

import { incrementViews } from './actions'
import { useState, useEffect, useTransition } from 'react'

export default function ViewCount({ initialViews }: { initialViews: number }) {
  const [views, setViews] = useState(initialViews)
  const [isPending, startTransition] = useTransition()

  useEffect(() => {
    startTransition(async () => {
      const updatedViews = await incrementViews()
      setViews(updatedViews)
    })
  }, [])

  // You can use `isPending` to give users feedback
  return <p>Total Views: {views}</p>
}
```

