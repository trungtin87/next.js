Chào mừng bạn đến với tài liệu Next.js!

Phần **Bắt đầu** này sẽ giúp bạn tạo ứng dụng Next.js đầu tiên của mình và tìm hiểu các tính năng cốt lõi mà bạn sẽ sử dụng trong mọi dự án.

## Kiến thức tiên quyết

Tài liệu của chúng tôi giả định bạn đã quen thuộc với phát triển web. Trước khi bắt đầu, sẽ rất hữu ích nếu bạn cảm thấy thoải mái với:

- HTML
- CSS
- JavaScript
- React

Nếu bạn mới làm quen với React hoặc cần ôn lại kiến thức, chúng tôi khuyên bạn nên bắt đầu với [khóa học React Foundations](/learn/react-foundations) của chúng tôi, và [khóa học Next.js Foundations](/learn/dashboard-app) giúp bạn xây dựng một ứng dụng trong khi học.
