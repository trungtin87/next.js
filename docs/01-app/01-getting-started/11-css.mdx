## Tailwind CSS

[Tailwind CSS](https://tailwindcss.com/) là một utility-first CSS framework cung cấp các utility classes cấp thấp để xây dựng các thiết kế tùy chỉnh.

<AppOnly>

Cài đặt Tailwind CSS:

```bash package="pnpm"
pnpm add -D tailwindcss @tailwindcss/postcss
```

```bash package="npm"
npm install -D tailwindcss @tailwindcss/postcss
```

```bash package="yarn"
yarn add -D tailwindcss @tailwindcss/postcss
```

```bash package="bun"
bun add -D tailwindcss @tailwindcss/postcss
```

Thêm PostCSS plugin vào file `postcss.config.mjs` của bạn:

```js filename="postcss.config.mjs"
export default {
  plugins: {
    '@tailwindcss/postcss': {},
  },
}
```

Import Tailwind trong file global CSS của bạn:

```css filename="app/globals.css"
@import 'tailwindcss';
```

Import file CSS trong root layout của bạn:

```tsx filename="app/layout.tsx" switcher
import './globals.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import './globals.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

Bây giờ bạn có thể bắt đầu sử dụng các utility classes của Tailwind trong ứng dụng của bạn:

```tsx filename="app/page.tsx" switcher
export default function Page() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <h1 className="text-4xl font-bold">Welcome to Next.js!</h1>
    </main>
  )
}
```

```jsx filename="app/page.js" switcher

  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <h1 className="text-4xl font-bold">Welcome to Next.js!</h1>
    </main>
  )
}
```

## CSS Modules

CSS Modules giới hạn phạm vi CSS cục bộ bằng cách tạo ra các tên class duy nhất. Điều này cho phép bạn sử dụng cùng một tên class trong các file khác nhau mà không lo về xung đột đặt tên.

<AppOnly>

Để bắt đầu sử dụng CSS Modules, tạo một file mới với phần mở rộng `.module.css` và import nó vào bất kỳ component nào bên trong thư mục `app`:

```css filename="app/blog/blog.module.css"
.blog {
  padding: 24px;
}
```

```tsx filename="app/blog/page.tsx" switcher
import styles from './blog.module.css'

export default function Page() {
  return <main className={styles.blog}></main>
}
```

```jsx filename="app/blog/page.js" switcher
import styles from './blog.module.css'

export default function Layout() {
  return <main className={styles.blog}></main>
}
```

</AppOnly>

<PagesOnly>

Để bắt đầu sử dụng CSS Modules, tạo một file mới với phần mở rộng `.module.css` và import nó vào bất kỳ component nào bên trong thư mục `pages`:

```css filename="/styles/blog.module.css"
.blog {

}
```

```jsx filename="pages/blog/index.js" switcher
  return <main className={styles.blog}></main>
}
```

</PagesOnly>

## Global CSS

Bạn có thể sử dụng global CSS để áp dụng styles trên toàn bộ ứng dụng của bạn.

<AppOnly>

Tạo một file `app/global.css` và import nó trong root layout để áp dụng styles cho **mọi route** trong ứng dụng của bạn:

```css filename="app/global.css"
body {
  padding: 20px 20px 60px;
  max-width: 680px;
  margin: 0 auto;
}
```

```tsx filename="app/layout.tsx" switcher
// These styles apply to every route in the application
import './global.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
// These styles apply to every route in the application
import './global.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

> **Lưu ý:** Global styles có thể được import vào bất kỳ layout, page, hoặc component nào bên trong thư mục `app`. Tuy nhiên, vì Next.js sử dụng hỗ trợ tích hợp sẵn của React cho stylesheets để tích hợp với Suspense, điều này hiện tại không loại bỏ stylesheets khi bạn điều hướng giữa các routes, điều này có thể dẫn đến xung đột. Chúng tôi khuyên bạn nên sử dụng global styles cho CSS _thực sự_ global (như base styles của Tailwind), [Tailwind CSS](#tailwind-css) cho component styling, và [CSS Modules](#css-modules) cho custom scoped CSS khi cần thiết.

</AppOnly>

<PagesOnly>

Import stylesheet trong file `pages/_app.js` để áp dụng styles cho **mọi route** trong ứng dụng của bạn:

```tsx filename="pages/_app.js"
import '@/styles/global.css'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

Do tính chất toàn cầu của stylesheets, và để tránh xung đột, bạn nên import chúng bên trong [`pages/_app.js`](/docs/pages/building-your-application/routing/custom-app).

</PagesOnly>

## External stylesheets

<AppOnly>

Stylesheets được publish bởi các packages bên ngoài có thể được import ở bất kỳ đâu trong thư mục `app`, bao gồm cả các colocated components:

```tsx filename="app/layout.tsx" switcher
import 'bootstrap/dist/css/bootstrap.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body className="container">{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import 'bootstrap/dist/css/bootstrap.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body className="container">{children}</body>
    </html>
  )
}
```

> **Lưu ý:** Trong React 19, `<link rel="stylesheet" href="..." />` cũng có thể được sử dụng. Xem [tài liệu React `link`](https://react.dev/reference/react-dom/components/link) để biết thêm thông tin.

</AppOnly>

<PagesOnly>

Next.js cho phép bạn import CSS files từ một JavaScript file. Điều này là có thể vì Next.js mở rộng khái niệm [`import`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Statements/import) vượt ra ngoài JavaScript.

### Import styles từ `node_modules`

Kể từ Next.js **9.5.4**, việc import một CSS file từ `node_modules` được cho phép ở bất kỳ đâu trong ứng dụng của bạn.

Đối với global stylesheets, như `bootstrap` hoặc `nprogress`, bạn nên import file bên trong `pages/_app.js`. Ví dụ:

```jsx filename="pages/_app.js"
import 'bootstrap/dist/css/bootstrap.css'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

Để import CSS được yêu cầu bởi một third-party component, bạn có thể làm như vậy trong component của bạn. Ví dụ:

```jsx filename="components/example-dialog.js"
import { useState } from 'react'
import { Dialog } from '@reach/dialog'
import VisuallyHidden from '@reach/visually-hidden'
import '@reach/dialog/styles.css'

function ExampleDialog(props) {
  const [showDialog, setShowDialog] = useState(false)
  const open = () => setShowDialog(true)
  const close = () => setShowDialog(false)

  return (
    <div>
      <button onClick={open}>Open Dialog</button>
      <Dialog isOpen={showDialog} onDismiss={close}>
        <button className="close-button" onClick={close}>
          <VisuallyHidden>Close</VisuallyHidden>
          <span aria-hidden>×</span>
        </button>
        <p>Hello there. I am a dialog</p>
      </Dialog>
    </div>
  )
}
```

</PagesOnly>

## Ordering và Merging

Next.js tối ưu hóa CSS trong quá trình production builds bằng cách tự động chunking (gộp) stylesheets. **Thứ tự của CSS** phụ thuộc vào **thứ tự bạn import styles trong code của bạn**.

Ví dụ, `base-button.module.css` sẽ được sắp xếp trước `page.module.css` vì `<BaseButton>` được import trước `page.module.css`:

```tsx filename="page.tsx" switcher
import { BaseButton } from './base-button'
import styles from './page.module.css'

export default function Page() {
  return <BaseButton className={styles.primary} />
}
```

```jsx filename="page.js" switcher
import { BaseButton } from './base-button'
import styles from './page.module.css'

export default function Page() {
  return <BaseButton className={styles.primary} />
}
```

```tsx filename="base-button.tsx" switcher
import styles from './base-button.module.css'

export function BaseButton() {
  return <button className={styles.primary} />
}
```

```jsx filename="base-button.js" switcher
import styles from './base-button.module.css'

export function BaseButton() {
  return <button className={styles.primary} />
}
```

### Khuyến nghị

Để giữ thứ tự CSS có thể dự đoán được:

- Cố gắng chứa các CSS imports trong một JavaScript hoặc TypeScript entry file duy nhất
- Import global styles và Tailwind stylesheets ở root của ứng dụng của bạn.
- **Sử dụng Tailwind CSS** cho hầu hết các nhu cầu styling vì nó bao gồm các design patterns phổ biến với utility classes.
- Sử dụng CSS Modules cho component-specific styles khi Tailwind utilities không đủ.
- Sử dụng một quy ước đặt tên nhất quán cho các CSS modules của bạn. Ví dụ, sử dụng `<name>.module.css` thay vì `<name>.tsx`.
- Extract shared styles vào các shared components để tránh duplicate imports.
- Tắt linters hoặc formatters tự động sắp xếp imports như [`sort-imports`](https://eslint.org/docs/latest/rules/sort-imports) của ESLint.
- Bạn có thể sử dụng option [`cssChunking`](/docs/app/api-reference/config/next-config-js/cssChunking) trong `next.config.js` để kiểm soát cách CSS được chunked.

## Development vs Production

- Trong development (`next dev`), CSS updates áp dụng ngay lập tức với [Fast Refresh](/docs/architecture/fast-refresh).
- Trong production (`next build`), tất cả CSS files được tự động nối lại thành **nhiều file `.css` đã được minified và code-split**, đảm bảo lượng CSS tối thiểu được load cho một route.
- CSS vẫn load khi JavaScript bị tắt trong production, nhưng JavaScript được yêu cầu trong development cho Fast Refresh.
- Thứ tự CSS có thể hoạt động khác nhau trong development, luôn đảm bảo kiểm tra build (`next build`) để xác minh thứ tự CSS cuối cùng.
