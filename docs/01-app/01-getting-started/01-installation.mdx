Tạo một ứng dụng Next.js mới và chạy nó trên máy local.

## Bắt đầu nhanh

1. Tạo một ứng dụng Next.js mới có tên `my-app`
2. `cd my-app` và khởi động dev server.
3. Truy cập `http://localhost:3000`.

```bash package="pnpm"
pnpm create next-app@latest my-app --yes
cd my-app
pnpm dev
```

```bash package="npm"
npx create-next-app@latest my-app --yes
cd my-app
npm run dev
```

```bash package="yarn"
yarn create next-app@latest my-app --yes
cd my-app
yarn dev
```

```bash package="bun"
bun create next-app@latest my-app --yes
cd my-app
bun dev
```

- `--yes` bỏ qua các prompts bằng cách sử dụng preferences đã lưu hoặc mặc định. Thiết lập mặc định kích hoạt TypeScript, Tailwind, App Router, và Turbopack, với import alias `@/*`.

</AppOnly>

## Yêu cầu hệ thống

Trước khi bắt đầu, hãy đảm bảo hệ thống của bạn đáp ứng các yêu cầu sau:

- [Node.js 20.9](https://nodejs.org/) hoặc mới hơn.
- macOS, Windows (bao gồm WSL), hoặc Linux.

## Tạo với CLI

Cách nhanh nhất để tạo một ứng dụng Next.js mới là sử dụng [`create-next-app`](/docs/app/api-reference/cli/create-next-app), công cụ này sẽ thiết lập mọi thứ tự động cho bạn. Để tạo một dự án, chạy:

```bash filename="Terminal"
npx create-next-app@latest
```

Khi cài đặt, bạn sẽ thấy các prompts sau:

```txt filename="Terminal"
What is your project named? my-app
Would you like to use the recommended Next.js defaults?
    Yes, use recommended defaults - TypeScript, ESLint, Tailwind CSS, App Router, Turbopack
    No, reuse previous settings
    No, customize settings - Choose your own preferences
```

Nếu bạn chọn `customize settings`, bạn sẽ thấy các prompts sau:

```txt filename="Terminal"
Would you like to use TypeScript? No / Yes
Which linter would you like to use? ESLint / Biome / None
Would you like to use React Compiler? No / Yes
Would you like to use Tailwind CSS? No / Yes
Would you like your code inside a `src/` directory? No / Yes
Would you like to use App Router? (recommended) No / Yes
Would you like to use Turbopack? (recommended) No / Yes
Would you like to customize the import alias (`@/*` by default)? No / Yes
What import alias would you like configured? @/*
```

Sau khi hoàn tất các prompts, [`create-next-app`](/docs/app/api-reference/cli/create-next-app) sẽ tạo một thư mục với tên dự án của bạn và cài đặt các dependencies cần thiết.

## Cài đặt thủ công

Để tạo một ứng dụng Next.js mới theo cách thủ công, hãy cài đặt các packages cần thiết:

```bash package="pnpm"
pnpm i next@latest react@latest react-dom@latest
```

```bash package="npm"
npm i next@latest react@latest react-dom@latest
```

```bash package="yarn"
yarn add next@latest react@latest react-dom@latest
```

```bash package="bun"
bun add next@latest react@latest react-dom@latest
```

> **Lưu ý**: App Router sử dụng [React canary releases](https://react.dev/blog/2023/05/03/react-canaries) tích hợp sẵn, bao gồm tất cả các thay đổi ổn định của React 19, cũng như các tính năng mới hơn đang được xác thực trong các frameworks. Pages Router sử dụng phiên bản React mà bạn cài đặt trong `package.json`.

Sau đó, thêm các scripts sau vào file `package.json` của bạn:

```json filename="package.json"
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "eslint",
    "lint:fix": "eslint --fix"
  }
}
```

Các scripts này đại diện cho các giai đoạn khác nhau khi phát triển một ứng dụng:

- `next dev`: Khởi động development server sử dụng Turbopack (bundler mặc định).
- `next build`: Build ứng dụng cho production.
- `next start`: Khởi động production server.
- `eslint`: Chạy ESLint.

Turbopack hiện là bundler mặc định. Để sử dụng Webpack, chạy `next dev --webpack` hoặc `next build --webpack`. Xem [tài liệu Turbopack](/docs/app/api-reference/turbopack) để biết chi tiết cấu hình.

### Tạo thư mục `app`

Next.js sử dụng file-system routing (định tuyến dựa trên hệ thống file), có nghĩa là các routes trong ứng dụng của bạn được xác định bởi cách bạn cấu trúc các files.

Tạo một thư mục `app`. Sau đó, bên trong `app`, tạo một file `layout.tsx`. File này là [root layout](/docs/app/api-reference/file-conventions/layout#root-layout). Nó là bắt buộc và phải chứa các thẻ `<html>` và `<body>`.

```tsx filename="app/layout.tsx" switcher
export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

Tạo một trang chủ `app/page.tsx` với một số nội dung ban đầu:

```tsx filename="app/page.tsx" switcher
export default function Page() {
  return <h1>Hello, Next.js!</h1>
}
```

```jsx filename="app/page.js" switcher
export default function Page() {
  return <h1>Hello, Next.js!</h1>
}
```

Cả `layout.tsx` và `page.tsx` sẽ được render khi người dùng truy cập root của ứng dụng (`/`).

### Tạo thư mục `pages`

Next.js sử dụng file-system routing (định tuyến dựa trên hệ thống file), có nghĩa là các routes trong ứng dụng của bạn được xác định bởi cách bạn cấu trúc các files.

Tạo một thư mục `pages` ở root của dự án. Sau đó, thêm một file `index.tsx` bên trong thư mục `pages`. Đây sẽ là trang chủ của bạn (`/`):

```tsx filename="pages/index.tsx" switcher
export default function Page() {
  return <h1>Hello, Next.js!</h1>
}
```

```jsx filename="pages/index.js" switcher
export default function Page() {
  return <h1>Hello, Next.js!</h1>
}
```

Tiếp theo, thêm một file `_app.tsx` bên trong `pages/` để định nghĩa global layout. Tìm hiểu thêm về [custom App file](/docs/pages/building-your-application/routing/custom-app).

```tsx filename="pages/_app.tsx" switcher
import type { AppProps } from 'next/app'

export default function App({ Component, pageProps }: AppProps) {
  return <Component {...pageProps} />
}
```

```jsx filename="pages/_app.js" switcher
export default function App({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

Cuối cùng, thêm một file `_document.tsx` bên trong `pages/` để kiểm soát response ban đầu từ server. Tìm hiểu thêm về [custom Document file](/docs/pages/building-your-application/routing/custom-document).

```tsx filename="pages/_document.tsx" switcher
import { Html, Head, Main, NextScript } from 'next/document'

export default function Document() {
  return (
    <Html>
      <Head />
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  )
}
```

```jsx filename="pages/_document.js" switcher
import { Html, Head, Main, NextScript } from 'next/document'

export default function Document() {
  return (
    <Html>
      <Head />
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  )
}
```

</PagesOnly>

### Tạo thư mục `public` (tùy chọn)

Tạo một thư mục [`public`](/docs/app/api-reference/file-conventions/public-folder) ở root của dự án để lưu trữ các static assets như images, fonts, v.v. Các files bên trong `public` sau đó có thể được tham chiếu bởi code của bạn bắt đầu từ base URL (`/`).

Bạn có thể tham chiếu các assets này bằng cách sử dụng root path (`/`). Ví dụ, `public/profile.png` có thể được tham chiếu là `/profile.png`:

```tsx filename="app/page.tsx" highlight={4} switcher
import Image from 'next/image'

export default function Page() {
  return <Image src="/profile.png" alt="Profile" width={100} height={100} />
}
```

```jsx filename="app/page.js" highlight={4} switcher
import Image from 'next/image'

export default function Page() {
  return <Image src="/profile.png" alt="Profile" width={100} height={100} />
}
```

## Thiết lập linting

Next.js hỗ trợ linting với ESLint hoặc Biome. Chọn một linter và chạy nó trực tiếp qua `package.json` scripts.

- Sử dụng **ESLint** (quy tắc toàn diện):

```json filename="package.json"
{
  "scripts": {
    "lint": "eslint",
    "lint:fix": "eslint --fix"
  }
}
```

- Hoặc sử dụng **Biome** (linter + formatter nhanh):

```json filename="package.json"
{
  "scripts": {
    "lint": "biome check",
    "format": "biome format --write"
  }
}
```

Nếu dự án của bạn trước đây sử dụng `next lint`, hãy di chuyển các scripts của bạn sang ESLint CLI với codemod:

```bash filename="Terminal"
npx @next/codemod@canary next-lint-to-eslint-cli .
```

Nếu bạn sử dụng ESLint, hãy tạo một cấu hình rõ ràng (khuyến nghị `eslint.config.mjs`). ESLint hỗ trợ cả [định dạng cũ `.eslintrc.*` và định dạng mới `eslint.config.mjs`](https://eslint.org/docs/latest/use/configure/configuration-files#configuring-eslint). Xem [tài liệu tham khảo ESLint API](/docs/app/api-reference/config/eslint#with-core-web-vitals) để biết thiết lập được khuyến nghị.

> **Lưu ý**: Bắt đầu từ Next.js 16, `next build` không còn tự động chạy linter nữa. Thay vào đó, bạn có thể chạy linter thông qua NPM scripts.

Xem trang [ESLint Plugin](/docs/app/api-reference/config/eslint) để biết thêm thông tin.

## Thiết lập Absolute Imports và Module Path Aliases

Next.js có hỗ trợ tích hợp sẵn cho các tùy chọn `"paths"` và `"baseUrl"` của các files `tsconfig.json` và `jsconfig.json`.

Các tùy chọn này cho phép bạn alias các thư mục dự án thành absolute paths, giúp việc import modules dễ dàng và sạch sẽ hơn. Ví dụ:

```jsx
// Trước
import { Button } from '../../../components/button'

// Sau
import { Button } from '@/components/button'
```

Để cấu hình absolute imports, thêm tùy chọn cấu hình `baseUrl` vào file `tsconfig.json` hoặc `jsconfig.json` của bạn. Ví dụ:

```json filename="tsconfig.json or jsconfig.json"
{
  "compilerOptions": {
    "baseUrl": "src/"
  }
}
```

Ngoài việc cấu hình `baseUrl` path, bạn có thể sử dụng tùy chọn `"paths"` để `"alias"` module paths.

Ví dụ, cấu hình sau ánh xạ `@/components/*` thành `components/*`:

```json filename="tsconfig.json or jsconfig.json"
{
  "compilerOptions": {
    "baseUrl": "src/",
    "paths": {
      "@/styles/*": ["styles/*"],
      "@/components/*": ["components/*"]
    }
  }
}
```

Mỗi `"paths"` đều tương đối với vị trí `baseUrl`.
