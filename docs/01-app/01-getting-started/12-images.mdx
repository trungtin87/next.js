Component [`<Image>`](/docs/app/api-reference/components/image) của Next.js mở rộng phần tử HTML `<img>` để cung cấp:

- **Tối ưu hóa kích thước:** Tự động phục vụ hình ảnh có kích thước chính xác cho mỗi thiết bị, sử dụng các định dạng hình ảnh hiện đại như WebP.
- **Ổn định trực quan:** Tự động ngăn [layout shift](https://web.dev/articles/cls) khi hình ảnh đang tải.
- **Tải trang nhanh hơn:** Chỉ tải hình ảnh khi chúng xuất hiện trong viewport bằng cách sử dụng lazy loading gốc của trình duyệt, với các placeholder blur-up tùy chọn.
- **Linh hoạt tài sản:** Thay đổi kích thước hình ảnh theo yêu cầu, ngay cả hình ảnh được lưu trữ trên các server từ xa.

Để bắt đầu sử dụng `<Image>`, import nó từ `next/image` và render trong component của bạn.

```tsx filename="app/page.tsx" switcher
import Image from 'next/image'

export default function Page() {
  return <Image src="" alt="" />
}
```

```jsx filename="app/page.js" switcher
import Image from 'next/image'

export default function Page() {
  return <Image src="" alt="" />
}
```

Thuộc tính `src` có thể là hình ảnh [local](#local-images) hoặc [remote](#remote-images).

## Hình ảnh local

Bạn có thể lưu trữ các file tĩnh, như hình ảnh và fonts, trong thư mục [`public`](/docs/app/api-reference/file-conventions/public-folder) ở thư mục gốc. Các file bên trong `public` sau đó có thể được tham chiếu bởi code của bạn bắt đầu từ base URL (`/`).

<Image
  alt="Folder structure showing app and public folders"
  srcLight="/docs/light/public-folder.png"
  srcDark="/docs/dark/public-folder.png"
  width="1600"
  height="282"
/>

```tsx filename="app/page.tsx" switcher
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
```

```jsx filename="app/page.js" switcher
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
```

Nếu hình ảnh được import tĩnh, Next.js sẽ tự động xác định [`width`](/docs/app/api-reference/components/image#width-and-height) và [`height`](/docs/app/api-reference/components/image#width-and-height) bên trong. Các giá trị này được sử dụng để xác định tỷ lệ hình ảnh và ngăn [Cumulative Layout Shift](https://web.dev/articles/cls) trong khi hình ảnh của bạn đang tải.

```tsx filename="app/page.tsx" switcher
import Image from 'next/image'
import ProfileImage from './profile.png'

export default function Page() {
  return (
    <Image
      src={ProfileImage}
      alt="Picture of the author"
      // width={500} automatically provided
      // height={500} automatically provided
      // blurDataURL="data:..." automatically provided
      // placeholder="blur" // Optional blur-up while loading
    />
  )
}
```

```jsx filename="app/page.js" switcher
import Image from 'next/image'
import ProfileImage from './profile.png'

export default function Page() {
  return (
    <Image
      src={ProfileImage}
      alt="Picture of the author"
      // width={500} automatically provided
      // height={500} automatically provided
      // blurDataURL="data:..." automatically provided
      // placeholder="blur" // Optional blur-up while loading
    />
  )
}
```

## Hình ảnh remote

Để sử dụng hình ảnh remote, bạn có thể cung cấp một URL string cho thuộc tính `src`.

```tsx filename="app/page.tsx" switcher
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="https://s3.amazonaws.com/my-bucket/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
```

```jsx filename="app/page.js" switcher
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="https://s3.amazonaws.com/my-bucket/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
```

Vì Next.js không có quyền truy cập vào các file remote trong quá trình build, bạn sẽ cần cung cấp các props [`width`](/docs/app/api-reference/components/image#width-and-height), [`height`](/docs/app/api-reference/components/image#width-and-height) và tùy chọn [`blurDataURL`](/docs/app/api-reference/components/image#blurdataurl) theo cách thủ công. `width` và `height` được sử dụng để suy ra tỷ lệ chính xác của hình ảnh và tránh layout shift khi hình ảnh đang tải. Ngoài ra, bạn có thể sử dụng [`fill` property](/docs/app/api-reference/components/image#fill) để làm cho hình ảnh lấp đầy kích thước của phần tử cha.

Để cho phép an toàn hình ảnh từ các server từ xa, bạn cần định nghĩa danh sách các URL patterns được hỗ trợ trong [`next.config.js`](/docs/app/api-reference/config/next-config-js). Hãy cụ thể nhất có thể để ngăn chặn việc sử dụng độc hại. Ví dụ, cấu hình sau chỉ cho phép hình ảnh từ một AWS S3 bucket cụ thể:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const config: NextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 's3.amazonaws.com',
        port: '',
        pathname: '/my-bucket/**',
        search: '',
      },
    ],
  },
}

export default config
```

```js filename="next.config.js" switcher
module.exports = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 's3.amazonaws.com',
        port: '',
        pathname: '/my-bucket/**',
        search: '',
      },
    ],
  },
}
```
