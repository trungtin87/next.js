## Route Handlers

Route Handlers cho phép bạn tạo custom request handlers cho một route cụ thể bằng cách sử dụng Web [Request](https://developer.mozilla.org/docs/Web/API/Request) và [Response](https://developer.mozilla.org/docs/Web/API/Response) APIs.

  alt="Route.js Special File"

> **Lưu ý**: Route Handlers chỉ khả dụng bên trong thư mục `app`. Chúng tương đương với [API Routes](/docs/pages/building-your-application/routing/api-routes) bên trong thư mục `pages`, có nghĩa là bạn **không** cần sử dụng API Routes và Route Handlers cùng lúc.

### Quy ước

Route Handlers được định nghĩa trong file [`route.js|ts`](/docs/app/api-reference/file-conventions/route) bên trong thư mục `app`:

```ts filename="app/api/route.ts" switcher
export async function GET(request: Request) {}
```

```js filename="app/api/route.js" switcher
export async function GET(request) {}
```

Route Handlers có thể được lồng ở bất kỳ đâu bên trong thư mục `app`, tương tự như `page.js` và `layout.js`. Nhưng **không thể** có file `route.js` ở cùng mức route segment với `page.js`.

### Các phương thức HTTP được hỗ trợ

Các [phương thức HTTP](https://developer.mozilla.org/docs/Web/HTTP/Methods) sau được hỗ trợ: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, và `OPTIONS`. Nếu một phương thức không được hỗ trợ được gọi, Next.js sẽ trả về response `405 Method Not Allowed`.

### API `NextRequest` và `NextResponse` mở rộng

Ngoài việc hỗ trợ [Request](https://developer.mozilla.org/docs/Web/API/Request) và [Response](https://developer.mozilla.org/docs/Web/API/Response) APIs gốc, Next.js mở rộng chúng với [`NextRequest`](/docs/app/api-reference/functions/next-request) và [`NextResponse`](/docs/app/api-reference/functions/next-response) để cung cấp các helpers tiện lợi cho các use cases nâng cao.

### Caching

Route Handlers không được cached theo mặc định. Tuy nhiên, bạn có thể chọn caching cho các phương thức `GET`. Các phương thức HTTP được hỗ trợ khác **không** được cached. Để cache một phương thức `GET`, sử dụng [route config option](/docs/app/api-reference/file-conventions/route-segment-config#dynamic) như `export const dynamic = 'force-static'` trong file Route Handler của bạn.

```ts filename="app/items/route.ts" switcher
export const dynamic = 'force-static'

export async function GET() {
  const res = await fetch('https://data.mongodb-api.com/...', {
    headers: {
      'Content-Type': 'application/json',
      'API-Key': process.env.DATA_API_KEY,
    },
  })
  const data = await res.json()

  return Response.json({ data })
}
```

```js filename="app/items/route.js" switcher
export const dynamic = 'force-static'

export async function GET() {
  const res = await fetch('https://data.mongodb-api.com/...', {
    headers: {
      'Content-Type': 'application/json',
      'API-Key': process.env.DATA_API_KEY,
    },
  })
  const data = await res.json()

  return Response.json({ data })
}
```

> **Lưu ý**: Các phương thức HTTP được hỗ trợ khác **không** được cached, ngay cả khi chúng được đặt cùng với phương thức `GET` được cached trong cùng file.

### Route Handlers đặc biệt

Các Route Handlers đặc biệt như [`sitemap.ts`](/docs/app/api-reference/file-conventions/metadata/sitemap), [`opengraph-image.tsx`](/docs/app/api-reference/file-conventions/metadata/opengraph-image), và [`icon.tsx`](/docs/app/api-reference/file-conventions/metadata/app-icons), và các [metadata files](/docs/app/api-reference/file-conventions/metadata) khác vẫn static theo mặc định trừ khi chúng sử dụng Dynamic APIs hoặc dynamic config options.

### Route Resolution

Bạn có thể coi `route` là routing primitive ở mức thấp nhất.

- Chúng **không** tham gia vào layouts hoặc client-side navigations như `page`.
- **Không thể** có file `route.js` ở cùng route với `page.js`.

| Page                 | Route              | Kết quả                      |
| -------------------- | ------------------ | ---------------------------- |
| `app/page.js`        | `app/route.js`     | <Cross size={18} /> Conflict |
| `app/page.js`        | `app/api/route.js` | <Check size={18} /> Valid    |
| `app/[user]/page.js` | `app/api/route.js` | <Check size={18} /> Valid    |

Mỗi file `route.js` hoặc `page.js` sẽ xử lý tất cả các HTTP verbs cho route đó.

```ts filename="app/page.ts" switcher
export default function Page() {
  return <h1>Hello, Next.js!</h1>
}

// Conflict
// `app/route.ts`
export async function POST(request: Request) {}
```

```js filename="app/page.js" switcher
export default function Page() {
  return <h1>Hello, Next.js!</h1>
}

// Conflict
// `app/route.js`
export async function POST(request) {}
```

Đọc thêm về cách Route Handlers [bổ sung cho ứng dụng frontend của bạn](/docs/app/guides/backend-for-frontend), hoặc khám phá [Tài liệu tham khảo API](/docs/app/api-reference/file-conventions/route) của Route Handlers.

### Route Context Helper

Trong TypeScript, bạn có thể type tham số `context` cho Route Handlers với helper [`RouteContext`](/docs/app/api-reference/file-conventions/route#route-context-helper) có sẵn toàn cục:

```ts filename="app/users/[id]/route.ts" switcher
import type { NextRequest } from 'next/server'

export async function GET(_req: NextRequest, ctx: RouteContext<'/users/[id]'>) {
  const { id } = await ctx.params
  return Response.json({ id })
}
```

> **Lưu ý**
>
> - Types được generate trong quá trình `next dev`, `next build` hoặc `next typegen`.
