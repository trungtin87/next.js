Route Handlers cho phép bạn tạo các trình xử lý yêu cầu tùy chỉnh cho một tuyến đường (route) nhất định bằng cách sử dụng các API Web [Request](https://developer.mozilla.org/docs/Web/API/Request) và [Response](https://developer.mozilla.org/docs/Web/API/Response).

```ts filename="route.ts" switcher
export async function GET() {
  return Response.json({ message: 'Hello World' })
}
```

```js filename="route.js" switcher
export async function GET() {
  return Response.json({ message: 'Hello World' })
}
```

## Reference

### HTTP Methods

Một tệp **route** cho phép bạn tạo các trình xử lý yêu cầu tùy chỉnh cho một tuyến đường nhất định. Các [phương thức HTTP](https://developer.mozilla.org/docs/Web/HTTP/Methods) sau được hỗ trợ: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `HEAD`, và `OPTIONS`.

```ts filename="route.ts" switcher
export async function GET(request: Request) {}

export async function HEAD(request: Request) {}

export async function POST(request: Request) {}

export async function PUT(request: Request) {}

export async function DELETE(request: Request) {}

export async function PATCH(request: Request) {}

// Nếu `OPTIONS` không được định nghĩa, Next.js sẽ tự động triển khai `OPTIONS` và thiết lập tiêu đề `Allow` thích hợp trong Response tùy thuộc vào các phương thức khác được định nghĩa trong Route Handler.
export async function OPTIONS(request: Request) {}
```

```js filename="route.js" switcher
export async function GET(request) {}

export async function HEAD(request) {}

export async function POST(request) {}

export async function PUT(request) {}

export async function DELETE(request) {}

export async function PATCH(request) {}

// Nếu `OPTIONS` không được định nghĩa, Next.js sẽ tự động triển khai `OPTIONS` và thiết lập tiêu đề `Allow` thích hợp trong Response tùy thuộc vào các phương thức khác được định nghĩa trong Route Handler.
export async function OPTIONS(request) {}
```

### Parameters

#### `request` (tùy chọn)

Đối tượng `request` là một đối tượng [NextRequest](/docs/app/api-reference/functions/next-request), là một phần mở rộng của Web [Request](https://developer.mozilla.org/docs/Web/API/Request) API. `NextRequest` cung cấp cho bạn quyền kiểm soát tốt hơn đối với yêu cầu đến, bao gồm việc truy cập dễ dàng vào `cookies` và một đối tượng URL đã được phân tích cú pháp mở rộng `nextUrl`.

```ts filename="route.ts" switcher
import type { NextRequest } from 'next/server'

export async function GET(request: NextRequest) {
  const url = request.nextUrl
}
```

```js filename="route.js" switcher
export async function GET(request) {
  const url = request.nextUrl
}
```

#### `context` (tùy chọn)

- **`params`**: một promise phân giải thành một đối tượng chứa các [tham số tuyến đường động](/docs/app/api-reference/file-conventions/dynamic-routes) cho tuyến đường hiện tại.

```ts filename="app/dashboard/[team]/route.ts" switcher
export async function GET(
  request: Request,
  { params }: { params: Promise<{ team: string }> }
) {
  const { team } = await params
}
```

```js filename="app/dashboard/[team]/route.js" switcher
export async function GET(request, { params }) {
  const { team } = await params
}
```

| Ví dụ                            | URL            | `params`                           |
| -------------------------------- | -------------- | ---------------------------------- |
| `app/dashboard/[team]/route.js`  | `/dashboard/1` | `Promise<{ team: '1' }>`           |
| `app/shop/[tag]/[item]/route.js` | `/shop/1/2`    | `Promise<{ tag: '1', item: '2' }>` |
| `app/blog/[...slug]/route.js`    | `/blog/1/2`    | `Promise<{ slug: ['1', '2'] }>`    |

### Route Context Helper

Bạn có thể định kiểu (type) cho ngữ cảnh Route Handler bằng cách sử dụng `RouteContext` để nhận `params` được định kiểu mạnh từ một route literal. `RouteContext` là một helper có sẵn trên toàn cục.

```ts filename="app/users/[id]/route.ts"
import type { NextRequest } from 'next/server'

export async function GET(_req: NextRequest, ctx: RouteContext<'/users/[id]'>) {
  const { id } = await ctx.params
  return Response.json({ id })
}
```

> **Cần biết**
>
> - Các kiểu (types) được tạo ra trong quá trình `next dev`, `next build` hoặc `next typegen`.
> - Sau khi tạo kiểu, helper `RouteContext` sẽ có sẵn trên toàn cục. Nó không cần phải được import.

## Examples

### Cookies

Bạn có thể đọc hoặc đặt cookies với [`cookies`](/docs/app/api-reference/functions/cookies) từ `next/headers`.

```ts filename="route.ts" switcher
import { cookies } from 'next/headers'

export async function GET(request: NextRequest) {
  const cookieStore = await cookies()

  const a = cookieStore.get('a')
  const b = cookieStore.set('b', '1')
  const c = cookieStore.delete('c')
}
```

```js filename="route.js" switcher
import { cookies } from 'next/headers'

export async function GET(request) {
  const cookieStore = await cookies()

  const a = cookieStore.get('a')
  const b = cookieStore.set('b', '1')
  const c = cookieStore.delete('c')
}
```

Ngoài ra, bạn có thể trả về một `Response` mới sử dụng tiêu đề [`Set-Cookie`](https://developer.mozilla.org/docs/Web/HTTP/Headers/Set-Cookie).

```ts filename="app/api/route.ts" switcher
import { cookies } from 'next/headers'

export async function GET(request: Request) {
  const cookieStore = await cookies()
  const token = cookieStore.get('token')

  return new Response('Hello, Next.js!', {
    status: 200,
    headers: { 'Set-Cookie': `token=${token.value}` },
  })
}
```

```js filename="app/api/route.js" switcher
import { cookies } from 'next/headers'

export async function GET(request) {
  const cookieStore = await cookies()
  const token = cookieStore.get('token')

  return new Response('Hello, Next.js!', {
    status: 200,
    headers: { 'Set-Cookie': `token=${token.value}` },
  })
}
```

Bạn cũng có thể sử dụng các Web API cơ bản để đọc cookies từ yêu cầu ([`NextRequest`](/docs/app/api-reference/functions/next-request)):

```ts filename="app/api/route.ts" switcher
import { type NextRequest } from 'next/server'

export async function GET(request: NextRequest) {
  const token = request.cookies.get('token')
}
```

```js filename="app/api/route.js" switcher

  const token = request.cookies.get('token')
}
```

### Headers

Bạn có thể đọc headers với [`headers`](/docs/app/api-reference/functions/headers) từ `next/headers`.

```ts filename="route.ts" switcher
import { headers } from 'next/headers'
import type { NextRequest } from 'next/server'

export async function GET(request: NextRequest) {
  const headersList = await headers()
  const referer = headersList.get('referer')
}
```

```js filename="route.js" switcher
import { headers } from 'next/headers'

export async function GET(request) {
  const headersList = await headers()
  const referer = headersList.get('referer')
}
```

Instance `headers` này là chỉ đọc (read-only). Để đặt headers, bạn cần trả về một `Response` mới với các `headers` mới.

```ts filename="app/api/route.ts" switcher
import { headers } from 'next/headers'

export async function GET(request: Request) {
  const headersList = await headers()
  const referer = headersList.get('referer')

  return new Response('Hello, Next.js!', {
    status: 200,
    headers: { referer: referer },
  })
}
```

```js filename="app/api/route.js" switcher
import { headers } from 'next/headers'

export async function GET(request) {
  const headersList = await headers()
  const referer = headersList.get('referer')

  return new Response('Hello, Next.js!', {
    status: 200,
    headers: { referer: referer },
  })
}
```

Bạn cũng có thể sử dụng các Web API cơ bản để đọc headers từ yêu cầu ([`NextRequest`](/docs/app/api-reference/functions/next-request)):

```ts filename="app/api/route.ts" switcher
import { type NextRequest } from 'next/server'

export async function GET(request: NextRequest) {
  const requestHeaders = new Headers(request.headers)
}
```

```js filename="app/api/route.js" switcher
export async function GET(request) {
  const requestHeaders = new Headers(request.headers)
}
```

### Revalidating Cached Data

Bạn có thể [xác thực lại dữ liệu đã lưu trong bộ nhớ cache](/docs/app/guides/incremental-static-regeneration) bằng cách sử dụng tùy chọn cấu hình phân đoạn tuyến đường `revalidate`.

### Dynamic Route Segments

Route Handlers có thể sử dụng [Dynamic Segments](/docs/app/api-reference/file-conventions/dynamic-routes) để tạo các trình xử lý yêu cầu từ dữ liệu động.

```ts filename="app/items/[slug]/route.ts" switcher
export async function GET(
  request: Request,
  { params }: { params: Promise<{ slug: string }> }
) {
  const { slug } = await params // 'a', 'b', hoặc 'c'
}
```

```js filename="app/items/[slug]/route.js" switcher
export async function GET(request, { params }) {
  const { slug } = await params // 'a', 'b', hoặc 'c'
}
```

| Route                       | URL Ví dụ  | `params`                 |
| --------------------------- | ---------- | ------------------------ |
| `app/items/[slug]/route.js` | `/items/a` | `Promise<{ slug: 'a' }>` |
| `app/items/[slug]/route.js` | `/items/b` | `Promise<{ slug: 'b' }>` |
| `app/items/[slug]/route.js` | `/items/c` | `Promise<{ slug: 'c' }>` |

### URL Query Parameters

Đối tượng request được truyền đến Route Handler là một instance `NextRequest`, bao gồm [một số phương thức tiện lợi bổ sung](/docs/app/api-reference/functions/next-request#nexturl), chẳng hạn như các phương thức để xử lý tham số truy vấn dễ dàng hơn.

```ts filename="app/api/search/route.ts" switcher
import { type NextRequest } from 'next/server'

export function GET(request: NextRequest) {
  const searchParams = request.nextUrl.searchParams
  const query = searchParams.get('query')
  // query là "hello" cho /api/search?query=hello
}
```

```js filename="app/api/search/route.js" switcher
export function GET(request) {
  const searchParams = request.nextUrl.searchParams
  const query = searchParams.get('query')
  // query là "hello" cho /api/search?query=hello
}
```

### Streaming

Streaming thường được sử dụng kết hợp với các Mô hình Ngôn ngữ Lớn (LLMs), chẳng hạn như OpenAI, cho nội dung do AI tạo ra. Tìm hiểu thêm về [AI SDK](https://sdk.vercel.ai/docs/introduction).

```ts filename="app/api/chat/route.ts" switcher
import { openai } from '@ai-sdk/openai'
import { StreamingTextResponse, streamText } from 'ai'

export async function POST(req: Request) {
  const { messages } = await req.json()
  const result = await streamText({
    model: openai('gpt-4-turbo'),
    messages,
  })

  return new StreamingTextResponse(result.toAIStream())
}
```

```js filename="app/api/chat/route.js" switcher
import { openai } from '@ai-sdk/openai'
import { StreamingTextResponse, streamText } from 'ai'

export async function POST(req) {
  const { messages } = await req.json()
  const result = await streamText({
    model: openai('gpt-4-turbo'),
    messages,
  })

  return new StreamingTextResponse(result.toAIStream())
}
```

Các sự trừu tượng hóa này sử dụng Web API để tạo luồng. Bạn cũng có thể sử dụng trực tiếp các Web API cơ bản.

```ts filename="app/api/route.ts" switcher
// https://developer.mozilla.org/docs/Web/API/ReadableStream#convert_async_iterator_to_stream
function iteratorToStream(iterator: any) {
  return new ReadableStream({
    async pull(controller) {
      const { value, done } = await iterator.next()

      if (done) {
        controller.close()
      } else {
        controller.enqueue(value)
      }
    },
  })
}

function sleep(time: number) {
  return new Promise((resolve) => {
    setTimeout(resolve, time)
  })
}

const encoder = new TextEncoder()

async function* makeIterator() {
  yield encoder.encode('<p>One</p>')
  await sleep(200)
  yield encoder.encode('<p>Two</p>')
  await sleep(200)
  yield encoder.encode('<p>Three</p>')
}

export async function GET() {
  const iterator = makeIterator()
  const stream = iteratorToStream(iterator)

  return new Response(stream)
}
```

### Request Body FormData

Bạn có thể đọc `FormData` bằng hàm `request.formData()`:

```ts filename="app/items/route.ts" switcher
export async function POST(request: Request) {
  const formData = await request.formData()
  const name = formData.get('name')
  const email = formData.get('email')
  return Response.json({ name, email })
}
```

```js filename="app/items/route.js" switcher

  const formData = await request.formData()
  const name = formData.get('name')
  const email = formData.get('email')

```

Vì dữ liệu `formData` đều là chuỗi, bạn có thể muốn sử dụng [`zod-form-data`](https://www.npmjs.com/zod-form-data) để xác thực yêu cầu và lấy dữ liệu ở định dạng bạn muốn (ví dụ: `number`).

### CORS

Bạn có thể đặt tiêu đề CORS cho một Route Handler cụ thể bằng các phương thức Web API tiêu chuẩn:

```ts filename="app/api/route.ts" switcher
export async function GET(request: Request) {
  return new Response('Hello, Next.js!', {
    status: 200,
    headers: {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type, Authorization',
    },
  })
}
```


> **Cần biết**:
>
> - Để thêm tiêu đề CORS cho nhiều Route Handlers, bạn có thể sử dụng [Proxy](/docs/app/api-reference/file-conventions/proxy#cors) hoặc [tệp `next.config.js`](/docs/app/api-reference/config/next-config-js/headers#cors).

### Webhooks

Bạn có thể sử dụng Route Handler để nhận webhooks từ các dịch vụ bên thứ ba:

```ts filename="app/api/route.ts" switcher
export async function POST(request: Request) {
  try {
    const text = await request.text()
    // Xử lý payload của webhook
  } catch (error) {
    return new Response(`Webhook error: ${error.message}`, {
      status: 400,
    })
  }

  return new Response('Success!', {
    status: 200,
  })
}
```

