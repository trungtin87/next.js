Một file **template** tương tự như một [layout](/docs/app/getting-started/layouts-and-pages#creating-a-layout) ở chỗ nó bao bọc một layout hoặc page. Không giống như layouts tồn tại qua các routes và duy trì state, templates được cung cấp một key duy nhất, nghĩa là các children Client Components sẽ reset state của chúng khi điều hướng.

Chúng hữu ích khi bạn cần:

- Đồng bộ lại (Resynchronize) `useEffect` khi điều hướng.
- Reset state của một child Client Components khi điều hướng. Ví dụ, một trường input.
- Để thay đổi hành vi mặc định của framework. Ví dụ, Suspense boundaries bên trong layouts chỉ hiển thị fallback trong lần tải đầu tiên, trong khi templates hiển thị nó trên mỗi lần điều hướng.

## Quy ước

Một template có thể được định nghĩa bằng cách export một default React component từ một file `template.js`. Component nên chấp nhận một prop `children`.

<Image
  alt="template.js special file"
  srcLight="/docs/light/template-special-file.png"
  srcDark="/docs/dark/template-special-file.png"

```tsx filename="app/template.tsx" switcher
export default function Template({ children }: { children: React.ReactNode }) {
  return <div>{children}</div>
}
```

```jsx filename="app/template.js" switcher
export default function Template({ children }) {
  return <div>{children}</div>
}
```

Về mặt lồng nhau (nesting), `template.js` được render giữa một layout và children của nó. Dưới đây là một output đơn giản hóa:

```jsx filename="Output"
<Layout>
  {/* Lưu ý rằng template được cung cấp một key duy nhất. */}
  <Template key={routeParam}>{children}</Template>
</Layout>
```

## Props

### `children` (bắt buộc)

Template chấp nhận một prop `children`.

```jsx filename="Output"
<Layout>
  {/* Lưu ý rằng template tự động được cung cấp một key duy nhất. */}
  <Template key={routeParam}>{children}</Template>
</Layout>
```

## Hành vi

- **Server Components**: Mặc định, templates là Server Components.
- **Với điều hướng**: Templates nhận một key duy nhất cho cấp độ segment của riêng chúng. Chúng remount khi segment đó (bao gồm các dynamic params của nó) thay đổi. Điều hướng bên trong các segments sâu hơn không làm remount các templates cấp cao hơn. Search params không kích hoạt remounts.
- **State reset**: Bất kỳ Client Component nào bên trong template sẽ reset state của nó khi điều hướng.
- **Effect re-run**: Các effects như `useEffect` sẽ đồng bộ lại (re-synchronize) khi component remounts.
- **DOM reset**: Các phần tử DOM bên trong template được tạo lại hoàn toàn.

### Templates trong quá trình điều hướng và remounting

Phần này minh họa cách templates hoạt động trong quá trình điều hướng. Nó chỉ ra, từng bước, templates nào remount trên mỗi thay đổi route và tại sao.

Sử dụng cây dự án này:

```
app
├── about
│   ├── page.tsx
├── blog
│   ├── [slug]
│   │   └── page.tsx
│   ├── page.tsx
│   └── template.tsx
├── layout.tsx
├── page.tsx
└── template.tsx
```

Bắt đầu tại `/`, cây React trông đại khái như thế này.

> Lưu ý: Các giá trị `key` hiển thị trong các ví dụ là minh họa, các giá trị trong ứng dụng của bạn có thể khác.

```jsx filename="Output"
<RootLayout>
  {/* app/template.tsx */}
  <Template key="/">
    <Page />
  </Template>
</RootLayout>
```

Điều hướng đến `/about` (segment đầu tiên thay đổi), root template key thay đổi, nó remounts:

```jsx filename="Output"
<RootLayout>
  {/* app/template.tsx */}
  <Template key="/about">
    <AboutPage />
  </Template>
</RootLayout>
```

Điều hướng đến `/blog` (segment đầu tiên thay đổi), root template key thay đổi, nó remounts và blog-level template mounts:

```jsx filename="Output"
<RootLayout>
  {/* app/template.tsx (root) */}
  <Template key="/blog">
    {/* app/blog/template.tsx */}
    <Template key="/blog">
      <BlogIndexPage />
    </Template>
  </Template>
</RootLayout>
```

Điều hướng trong cùng một segment đầu tiên đến `/blog/first-post` (child segment thay đổi), root template key không thay đổi, nhưng blog-level template key thay đổi, nó remounts:

```jsx filename="Output"
<RootLayout>
  {/* app/template.tsx (root) */}
  <Template key="/blog">
    {/* app/blog/template.tsx */}
    {/* remounts bởi vì child segment ở cấp độ này đã thay đổi */}
    <Template key="/blog/first-post">
      <BlogPostPage slug="first-post" />
    </Template>
  </Template>
</RootLayout>
```

Điều hướng đến `/blog/second-post` (cùng segment đầu tiên, child segment khác), root template key không thay đổi, nhưng blog-level template key thay đổi, nó remounts lần nữa:

```jsx filename="Output"
<RootLayout>
  {/* app/template.tsx (root) */}
  <Template key="/blog">
    {/* app/blog/template.tsx */}
    {/* remounts lần nữa do child segment thay đổi */}
    <Template key="/blog/second-post">
      <BlogPostPage slug="second-post" />
    </Template>
  </Template>
</RootLayout>
```
