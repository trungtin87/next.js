File `page` cho phép bạn định nghĩa UI là **duy nhất** cho một route. Bạn có thể tạo một page bằng cách export mặc định một component từ file:

```tsx filename="app/blog/[slug]/page.tsx" switcher
export default function Page({
  params,
  searchParams,
}: {
  params: Promise<{ slug: string }>
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  return <h1>My Page</h1>
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
export default function Page({ params, searchParams }) {
  return <h1>My Page</h1>
}
```

## Lưu ý

- Các phần mở rộng file `.js`, `.jsx`, hoặc `.tsx` có thể được sử dụng cho `page`.
- Một `page` luôn là **leaf** (lá) của route subtree.
- Một file `page` là bắt buộc để làm cho một route segment **có thể truy cập công khai**.
- Pages là [Server Components](https://react.dev/reference/rsc/server-components) mặc định, nhưng có thể được đặt thành một [Client Component](https://react.dev/reference/rsc/use-client).

## Tham khảo

### Props

#### `params` (tùy chọn)

Một promise resolve thành một object chứa [dynamic route parameters](/docs/app/api-reference/file-conventions/dynamic-routes) từ root segment xuống đến page đó.

```tsx filename="app/shop/[slug]/page.tsx" switcher
export default async function Page({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
}
```

```jsx filename="app/shop/[slug]/page.js" switcher
export default async function Page({ params }) {
  const { slug } = await params
}
```

| Example Route                        | URL         | `params`                                |
| ------------------------------------ | ----------- | --------------------------------------- |
| `app/shop/[slug]/page.js`            | `/shop/1`   | `Promise<{ slug: '1' }>`                |
| `app/shop/[category]/[item]/page.js` | `/shop/1/2` | `Promise<{ category: '1', item: '2' }>` |
| `app/shop/[...slug]/page.js`         | `/shop/1/2` | `Promise<{ slug: ['1', '2'] }>`         |

- Vì prop `params` là một promise, bạn phải sử dụng `async/await` hoặc hàm [`use`](https://react.dev/reference/react/use) của React để truy cập các giá trị.
  - Trong phiên bản 14 và cũ hơn, `params` là một synchronous prop. Để giúp tương thích ngược, bạn vẫn có thể truy cập nó một cách đồng bộ trong Next.js 15, nhưng hành vi này sẽ bị deprecated trong tương lai.

#### `searchParams` (tùy chọn)

Một promise resolve thành một object chứa [search parameters](https://developer.mozilla.org/docs/Learn/Common_questions/What_is_a_URL#parameters) của URL hiện tại. Ví dụ:

```tsx filename="app/shop/page.tsx" switcher
export default async function Page({
  searchParams,
}: {
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const filters = (await searchParams).filters
}
```

```jsx filename="app/shop/page.js" switcher
export default async function Page({ searchParams }) {
  const filters = (await searchParams).filters
}
```

Client Component **pages** cũng có thể truy cập `searchParams` sử dụng hook [`use`](https://react.dev/reference/react/use) của React:

```tsx filename="app/shop/page.tsx" switcher
'use client'
import { use } from 'react'

export default function Page({
  searchParams,
}: {
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const filters = use(searchParams).filters
}
```

```jsx filename="app/page.jsx" switcher
'use client'
import { use } from 'react'

export default function Page({ searchParams }) {
  const filters = use(searchParams).filters
}
```

| Example URL     | `searchParams`                |
| --------------- | ----------------------------- |
| `/shop?a=1`     | `Promise<{ a: '1' }>`         |
| `/shop?a=1&b=2` | `Promise<{ a: '1', b: '2' }>` |
| `/shop?a=1&a=2` | `Promise<{ a: ['1', '2'] }>`  |

- Vì prop `searchParams` là một promise. Bạn phải sử dụng `async/await` hoặc hàm [`use`](https://react.dev/reference/react/use) của React để truy cập các giá trị.
  - Trong phiên bản 14 và cũ hơn, `searchParams` là một synchronous prop. Để giúp tương thích ngược, bạn vẫn có thể truy cập nó một cách đồng bộ trong Next.js 15, nhưng hành vi này sẽ bị deprecated trong tương lai.
- `searchParams` là một **[Dynamic API](/docs/app/guides/caching#dynamic-rendering)** mà các giá trị của nó không thể biết trước. Sử dụng nó sẽ opt page vào **[dynamic rendering](/docs/app/guides/caching#dynamic-rendering)** tại request time.
- `searchParams` là một plain JavaScript object, không phải là một instance `URLSearchParams`.

### Page Props Helper

Bạn có thể type pages với `PageProps` để nhận được `params` và `searchParams` được typed mạnh từ route literal. `PageProps` là một helper có sẵn toàn cục.

```tsx filename="app/blog/[slug]/page.tsx"
export default async function Page(props: PageProps<'/blog/[slug]'>) {
  const { slug } = await props.params
  const query = await props.searchParams
  return <h1>Blog Post: {slug}</h1>
}
```

> **Lưu ý**
>
> - Sử dụng một literal route (ví dụ `'/blog/[slug]'`) cho phép autocomplete và strict keys cho `params`.
> - Static routes resolve `params` thành `{}`.
> - Types được tạo trong quá trình `next dev`, `next build`, hoặc với `next typegen`.
> - Sau khi tạo type, helper `PageProps` có sẵn toàn cục. Nó không cần phải được import.

## Ví dụ

### Hiển thị nội dung dựa trên `params`

Sử dụng [dynamic route segments](/docs/app/api-reference/file-conventions/dynamic-routes), bạn có thể hiển thị hoặc fetch nội dung cụ thể cho page dựa trên prop `params`.

```tsx filename="app/blog/[slug]/page.tsx" switcher
export default async function Page({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
  return <h1>Blog Post: {slug}</h1>
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
export default async function Page({ params }) {
  const { slug } = await params
  return <h1>Blog Post: {slug}</h1>
}
```

### Xử lý filtering với `searchParams`

Bạn có thể sử dụng prop `searchParams` để xử lý filtering, pagination, hoặc sorting dựa trên query string của URL.

```tsx filename="app/shop/page.tsx" switcher
export default async function Page({
  searchParams,
}: {
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const { page = '1', sort = 'asc', query = '' } = await searchParams

  return (
    <div>
      <h1>Product Listing</h1>
      <p>Search query: {query}</p>
      <p>Current page: {page}</p>
      <p>Sort order: {sort}</p>
    </div>
  )
}
```

```jsx filename="app/shop/page.js" switcher
export default async function Page({ searchParams }) {
  const { page = '1', sort = 'asc', query = '' } = await searchParams

  return (
    <div>
      <h1>Product Listing</h1>
      <p>Search query: {query}</p>
      <p>Current page: {page}</p>
      <p>Sort order: {sort}</p>
    </div>
  )
}
```

### Đọc `searchParams` và `params` trong Client Components

Để sử dụng `searchParams` và `params` trong một Client Component (không thể là `async`), bạn có thể sử dụng hàm [`use`](https://react.dev/reference/react/use) của React để đọc promise:

```tsx filename="app/page.tsx" switcher
'use client'

import { use } from 'react'

export default function Page({
  params,
  searchParams,
}: {
  params: Promise<{ slug: string }>
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const { slug } = use(params)
  const { query } = use(searchParams)
}
```

```js filename="app/page.js" switcher
'use client'

import { use } from 'react'

export default function Page({ params, searchParams }) {
  const { slug } = use(params)
  const { query } = use(searchParams)
}
```
