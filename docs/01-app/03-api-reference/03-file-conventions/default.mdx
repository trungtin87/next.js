Tệp `default.js` được sử dụng để render một fallback trong [Parallel Routes](/docs/app/api-reference/file-conventions/parallel-routes) khi Next.js không thể khôi phục trạng thái hoạt động của [slot](/docs/app/api-reference/file-conventions/parallel-routes#slots) sau một lần tải trang đầy đủ.

Trong quá trình [soft navigation](/docs/app/getting-started/linking-and-navigating#client-side-transitions), Next.js theo dõi _trạng thái_ hoạt động (subpage) cho mỗi slot. Tuy nhiên, đối với hard navigations (tải trang đầy đủ), Next.js không thể khôi phục trạng thái hoạt động. Trong trường hợp này, một tệp `default.js` có thể được render cho các subpage không khớp với URL hiện tại.

Xem xét cấu trúc thư mục sau. Slot `@team` có một trang `settings`, nhưng `@analytics` thì không.

Khi điều hướng đến `/settings`, slot `@team` sẽ render trang `settings` trong khi duy trì trang hiện đang hoạt động cho slot `@analytics`.

Khi refresh, Next.js sẽ render một `default.js` cho `@analytics`. Nếu `default.js` không tồn tại, một lỗi sẽ được trả về cho các named slots (`@team`, `@analytics`, v.v.) và yêu cầu bạn định nghĩa một `default.js` để tiếp tục. Nếu bạn muốn giữ hành vi cũ là trả về 404 trong các tình huống này, bạn có thể tạo một `default.js` chứa:

```tsx filename="app/@team/default.js"
import { notFound } from 'next/navigation'

export default function Default() {
  notFound()
}
```

Ngoài ra, vì `children` là một implicit slot, bạn cũng cần tạo một tệp `default.js` để render một fallback cho `children` khi Next.js không thể khôi phục trạng thái hoạt động của trang cha. Nếu bạn không tạo một `default.js` cho slot `children`, nó sẽ trả về một trang 404 cho route.

## Tham khảo

### `params` (tùy chọn)

Một promise resolve thành một đối tượng chứa [dynamic route parameters](/docs/app/api-reference/file-conventions/dynamic-routes) từ root segment xuống các subpage của slot. Ví dụ:

```tsx filename="app/[artist]/@sidebar/default.js" switcher
export default async function Default({
  params,
}: {
  params: Promise<{ artist: string }>
}) {
  const { artist } = await params
}
```

```jsx filename="app/[artist]/@sidebar/default.js" switcher
export default async function Default({ params }) {
  const { artist } = await params
}
```

| Ví dụ                                      | URL          | `params`                                     |
| ------------------------------------------ | ------------ | -------------------------------------------- |
| `app/[artist]/@sidebar/default.js`         | `/zack`      | `Promise<{ artist: 'zack' }>`                |
| `app/[artist]/[album]/@sidebar/default.js` | `/zack/next` | `Promise<{ artist: 'zack', album: 'next' }>` |

- Vì prop `params` là một promise. Bạn phải sử dụng `async/await` hoặc hàm [`use`](https://react.dev/reference/react/use) của React để truy cập các giá trị.
  - Trong phiên bản 14 và trước đó, `params` là một prop đồng bộ. Để giúp tương thích ngược, bạn vẫn có thể truy cập nó một cách đồng bộ trong Next.js 15, nhưng hành vi này sẽ bị deprecated trong tương lai.
