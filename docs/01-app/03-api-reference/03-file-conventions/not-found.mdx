Next.js cung cấp hai quy ước để xử lý các trường hợp không tìm thấy (not found):

- **`not-found.js`**: Được sử dụng khi bạn gọi hàm [`notFound`](/docs/app/api-reference/functions/not-found) trong một route segment.
- **`global-not-found.js`**: Được sử dụng để định nghĩa một trang 404 toàn cục cho các routes không khớp trên toàn bộ ứng dụng của bạn. Điều này được xử lý ở cấp độ routing và không phụ thuộc vào việc render một layout hoặc page.

## `not-found.js`

File **not-found** được sử dụng để render UI khi hàm [`notFound`](/docs/app/api-reference/functions/not-found) được ném ra bên trong một route segment. Cùng với việc phục vụ một custom UI, Next.js sẽ trả về một mã trạng thái HTTP `200` cho các phản hồi được stream, và `404` cho các phản hồi không được stream.

```tsx filename="app/not-found.tsx" switcher
import Link from 'next/link'

export default function NotFound() {
  return (
    <div>
      <h2>Not Found</h2>
      <p>Could not find requested resource</p>
      <Link href="/">Return Home</Link>
    </div>
  )
}
```

```jsx filename="app/blog/not-found.js" switcher
import Link from 'next/link'

export default function NotFound() {
  return (
    <div>
      <h2>Not Found</h2>
      <p>Could not find requested resource</p>
      <Link href="/">Return Home</Link>
    </div>
  )
}
```

## `global-not-found.js` (experimental)

File `global-not-found.js` cho phép bạn định nghĩa một trang 404 cho toàn bộ ứng dụng của bạn. Không giống như `not-found.js`, hoạt động ở cấp độ route, file này được sử dụng khi một URL được yêu cầu không khớp với bất kỳ route nào cả. Next.js **bỏ qua rendering** và trả về trực tiếp trang toàn cục này.

File `global-not-found.js` bỏ qua rendering bình thường của ứng dụng của bạn, điều này có nghĩa là bạn sẽ cần import bất kỳ global styles, fonts, hoặc các dependencies khác mà trang 404 của bạn yêu cầu.

> **Lưu ý**: Một phiên bản nhỏ hơn của global styles của bạn, và một font family đơn giản hơn có thể cải thiện hiệu suất của trang này.

`global-not-found.js` hữu ích khi bạn không thể xây dựng một trang 404 bằng cách sử dụng sự kết hợp của `layout.js` và `not-found.js`. Điều này có thể xảy ra trong hai trường hợp:

- Ứng dụng của bạn có nhiều root layouts (ví dụ `app/(admin)/layout.tsx` và `app/(shop)/layout.tsx`), vì vậy không có layout đơn lẻ nào để tạo thành một global 404 từ đó.
- Root layout của bạn được định nghĩa sử dụng top-level dynamic segments (ví dụ `app/[country]/layout.tsx`), điều này làm cho việc tạo một trang 404 nhất quán trở nên khó khăn hơn.

Để kích hoạt nó, thêm cờ `globalNotFound` trong `next.config.ts`:

```tsx filename="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    globalNotFound: true,
  },
}

export default nextConfig
```

Sau đó, tạo một file ở root của thư mục `app`: `app/global-not-found.js`:

```tsx filename="app/global-not-found.tsx" switcher
// Import global styles và fonts
import './globals.css'
import { Inter } from 'next/font/google'
import type { Metadata } from 'next'

const inter = Inter({ subsets: ['latin'] })

export const metadata: Metadata = {
  title: '404 - Page Not Found',
  description: 'The page you are looking for does not exist.',
}

export default function GlobalNotFound() {
  return (
    <html lang="en" className={inter.className}>
      <body>
        <h1>404 - Page Not Found</h1>
        <p>This page does not exist.</p>
      </body>
    </html>
  )
}
```

## Tham khảo

### Props

Các components `not-found.js` hoặc `global-not-found.js` không chấp nhận bất kỳ props nào.

> **Lưu ý**: Ngoài việc bắt các lỗi `notFound()` dự kiến, các file root `app/not-found.js` và `app/global-not-found.js` xử lý bất kỳ URLs không khớp nào cho toàn bộ ứng dụng của bạn. Điều này có nghĩa là người dùng truy cập một URL không được xử lý bởi ứng dụng của bạn sẽ được hiển thị UI đã export.

## Ví dụ

### Data Fetching

Mặc định, `not-found` là một Server Component. Bạn có thể đánh dấu nó là `async` để fetch và hiển thị dữ liệu:

```tsx filename="app/not-found.tsx" switcher
import Link from 'next/link'
import { headers } from 'next/headers'

export default async function NotFound() {
  const headersList = await headers()
  const domain = headersList.get('host')
  const data = await getSiteData(domain)
  return (
    <div>
      <h2>Not Found: {data.name}</h2>
      <p>Could not find requested resource</p>
      <p>
        View <Link href="/blog">all posts</Link>
      </p>
    </div>
  )
}
```


Nếu bạn cần sử dụng Client Component hooks như `usePathname` để hiển thị nội dung dựa trên path, bạn phải fetch dữ liệu ở phía client thay thế.

### Metadata

Đối với `global-not-found.js`, bạn có thể export một object `metadata` hoặc một hàm [`generateMetadata`](/docs/app/api-reference/functions/generate-metadata) để tùy chỉnh `<title>`, `<meta>`, và các thẻ head khác cho trang 404 của bạn:

> **Lưu ý**: Next.js tự động inject `<meta name="robots" content="noindex" />` cho các trang trả về mã trạng thái 404, bao gồm các trang `global-not-found.js`.

```tsx filename="app/global-not-found.tsx" switcher
import type { Metadata } from 'next'

export const metadata: Metadata = {
  title: 'Not Found',
  description: 'The page you are looking for does not exist.',
}

export default function GlobalNotFound() {
  return (

        <div>
          <h1>Not Found</h1>
          <p>The page you are looking for does not exist.</p>
        </div>
      </body>
    </html>
  )
}
```
