Tệp `instrumentation-client.js|ts` cho phép bạn thêm monitoring, analytics code, và các side-effects khác chạy trước khi ứng dụng của bạn trở nên tương tác. Điều này hữu ích để thiết lập performance tracking, error monitoring, polyfills, hoặc bất kỳ công cụ client-side observability nào khác.

Để sử dụng nó, hãy đặt tệp vào **root** của ứng dụng của bạn hoặc bên trong thư mục `src`.

## Sử dụng

Không giống như [server-side instrumentation](/docs/app/guides/instrumentation), bạn không cần export bất kỳ hàm cụ thể nào. Bạn có thể viết monitoring code của mình trực tiếp trong tệp:

```ts filename="instrumentation-client.ts" switcher
// Set up performance monitoring
performance.mark('app-init')

// Initialize analytics
console.log('Analytics initialized')

// Set up error tracking
window.addEventListener('error', (event) => {
  // Send to your error tracking service
  reportError(event.error)
})
```

**Xử lý lỗi:** Triển khai các khối try-catch xung quanh instrumentation code của bạn để đảm bảo giám sát mạnh mẽ. Điều này ngăn các lỗi theo dõi riêng lẻ ảnh hưởng đến các tính năng instrumentation khác.

## Theo dõi điều hướng Router

Bạn có thể export một hàm `onRouterTransitionStart` để nhận thông báo khi điều hướng bắt đầu:

```ts filename="instrumentation-client.ts" switcher
performance.mark('app-init')

export function onRouterTransitionStart(
  url: string,
  navigationType: 'push' | 'replace' | 'traverse'
) {
  console.log(`Navigation started: ${navigationType} to ${url}`)
  performance.mark(`nav-start-${Date.now()}`)
}
```

```js filename="instrumentation-client.js" switcher
performance.mark('app-init')

export function onRouterTransitionStart(url, navigationType) {
  console.log(`Navigation started: ${navigationType} to ${url}`)
  performance.mark(`nav-start-${Date.now()}`)
}
```

Hàm `onRouterTransitionStart` nhận hai tham số:

- `url: string` - URL đang được điều hướng đến
- `navigationType: 'push' | 'replace' | 'traverse'` - Loại điều hướng

## Cân nhắc về hiệu suất

Giữ cho instrumentation code nhẹ nhàng.

Next.js giám sát thời gian khởi tạo trong quá trình phát triển và sẽ ghi lại cảnh báo nếu nó mất hơn 16ms, điều này có thể ảnh hưởng đến việc tải trang mượt mà.

## Thời gian thực thi

Tệp `instrumentation-client.js` thực thi tại một điểm cụ thể trong vòng đời ứng dụng:

1. **Sau khi** tài liệu HTML được tải
2. **Trước khi** React hydration bắt đầu
3. **Trước khi** tương tác của người dùng có thể thực hiện

Thời gian này làm cho nó trở nên lý tưởng để thiết lập error tracking, analytics, và performance monitoring cần nắm bắt các sự kiện vòng đời ứng dụng sớm.

## Ví dụ

### Error tracking

Khởi tạo error tracking trước khi React bắt đầu và thêm navigation breadcrumbs để có ngữ cảnh gỡ lỗi tốt hơn.

```ts filename="instrumentation-client.ts" switcher
import Monitor from './lib/monitoring'

Monitor.initialize()

export function onRouterTransitionStart(url: string) {
  Monitor.pushEvent({
    message: `Navigation to ${url}`,
    category: 'navigation',
  })
}
```

```js filename="instrumentation-client.js" switcher
import Monitor from './lib/monitoring'

Monitor.initialize()

export function onRouterTransitionStart(url) {
  Monitor.pushEvent({
    message: `Navigation to ${url}`,
    category: 'navigation',
  })
}
```

### Analytics tracking

Khởi tạo analytics và theo dõi các sự kiện điều hướng với metadata chi tiết để phân tích hành vi người dùng.

```ts filename="instrumentation-client.ts" switcher
import { analytics } from './lib/analytics'

analytics.init()

export function onRouterTransitionStart(url: string, navigationType: string) {
  analytics.track('page_navigation', {
    url,
    type: navigationType,
    timestamp: Date.now(),
  })
}
```

### Performance monitoring

Theo dõi Time to Interactive và hiệu suất điều hướng bằng cách sử dụng Performance Observer API và performance marks.

```ts filename="instrumentation-client.ts" switcher
const startTime = performance.now()

const observer = new PerformanceObserver(
  (list: PerformanceObserverEntryList) => {
    for (const entry of list.getEntries()) {
      if (entry instanceof PerformanceNavigationTiming) {
        console.log('Time to Interactive:', entry.loadEventEnd - startTime)
      }
    }
  }
)

observer.observe({ entryTypes: ['navigation'] })

export function onRouterTransitionStart(url: string) {
  performance.mark(`nav-start-${url}`)
}
```

### Polyfills

Tải polyfills trước khi mã ứng dụng chạy. Sử dụng static imports để tải ngay lập tức và dynamic imports để tải có điều kiện dựa trên phát hiện tính năng.

```ts filename="instrumentation-client.ts" switcher
import './lib/polyfills'

if (!window.ResizeObserver) {
  import('./lib/polyfills/resize-observer').then((mod) => {
    window.ResizeObserver = mod.default
  })
}
```
