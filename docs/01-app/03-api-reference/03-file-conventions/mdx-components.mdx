Tệp `mdx-components.js|tsx` là **bắt buộc** để sử dụng [`@next/mdx` với App Router](/docs/app/guides/mdx) và sẽ không hoạt động nếu không có nó. Ngoài ra, bạn có thể sử dụng nó để [tùy chỉnh styles](/docs/app/guides/mdx#using-custom-styles-and-components).

Sử dụng tệp `mdx-components.tsx` (hoặc `.js`) trong thư mục gốc của dự án của bạn để định nghĩa MDX Components. Ví dụ, ở cùng cấp với `pages` hoặc `app`, hoặc bên trong `src` nếu có.

```tsx filename="mdx-components.tsx" switcher
import type { MDXComponents } from 'mdx/types'

const components: MDXComponents = {}

export function useMDXComponents(): MDXComponents {
  return components
}
```

```js filename="mdx-components.js" switcher
const components = {}

export function useMDXComponents() {
  return components
}
```

## Exports

### Hàm `useMDXComponents`

Tệp phải export một hàm duy nhất có tên `useMDXComponents`. Hàm này không chấp nhận bất kỳ đối số nào.

```tsx filename="mdx-components.tsx" switcher
import type { MDXComponents } from 'mdx/types'

const components: MDXComponents = {}

export function useMDXComponents(): MDXComponents {
  return components
}
```

```js filename="mdx-components.js" switcher
const components = {}

export function useMDXComponents() {
  return components
}
```
