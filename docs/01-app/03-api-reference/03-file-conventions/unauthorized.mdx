Tệp **unauthorized** được sử dụng để render UI khi hàm [`unauthorized`](/docs/app/api-reference/functions/unauthorized) được gọi trong quá trình xác thực. Cùng với việc cho phép bạn tùy chỉnh UI, Next.js sẽ trả về mã trạng thái `401`.

```tsx filename="app/unauthorized.tsx" switcher
import Login from '@/app/components/Login'

export default function Unauthorized() {
  return (
    <main>
      <h1>401 - Unauthorized</h1>
      <p>Please log in to access this page.</p>
      <Login />
    </main>
  )
}
```

```jsx filename="app/unauthorized.js" switcher

  return (

}
```

## Tham khảo

### Props

Các component `unauthorized.js` không chấp nhận bất kỳ props nào.

## Ví dụ

### Hiển thị UI đăng nhập cho người dùng chưa xác thực

Bạn có thể sử dụng hàm [`unauthorized`](/docs/app/api-reference/functions/unauthorized) để render tệp `unauthorized.js` với UI đăng nhập.

```tsx filename="app/dashboard/page.tsx" switcher
import { verifySession } from '@/app/lib/dal'
import { unauthorized } from 'next/navigation'

export default async function DashboardPage() {
  const session = await verifySession()

  if (!session) {
    unauthorized()
  }

  return <div>Dashboard</div>
}
```
