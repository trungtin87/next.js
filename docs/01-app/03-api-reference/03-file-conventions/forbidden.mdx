Tệp **forbidden** được sử dụng để render UI khi hàm [`forbidden`](/docs/app/api-reference/functions/forbidden) được gọi trong quá trình xác thực. Cùng với việc cho phép bạn tùy chỉnh UI, Next.js sẽ trả về mã trạng thái `403`.

```tsx filename="app/forbidden.tsx" switcher
import Link from 'next/link'

export default function Forbidden() {
  return (
    <div>
      <h2>Forbidden</h2>
      <p>You are not authorized to access this resource.</p>
      <Link href="/">Return Home</Link>
    </div>
  )
}
```

