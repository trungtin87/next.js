nav_title: Metadata Files

---

Phần này của tài liệu bao gồm **các quy ước Metadata file**. Metadata dựa trên file có thể được định nghĩa bằng cách thêm các tệp metadata đặc biệt vào các đoạn route.

Mỗi quy ước file có thể được định nghĩa bằng cách sử dụng một tệp tĩnh (ví dụ: `opengraph-image.jpg`), hoặc một biến thể động sử dụng mã để tạo tệp (ví dụ: `opengraph-image.js`).

Sau khi một tệp được định nghĩa, Next.js sẽ tự động phục vụ tệp (với hash trong production để caching) và cập nhật các phần tử head liên quan với metadata chính xác, chẳng hạn như URL của tài sản, loại tệp và kích thước hình ảnh.

> **Thông tin hữu ích**:
>
> - Các Route Handler đặc biệt như [`sitemap.ts`](/docs/app/api-reference/file-conventions/metadata/sitemap), [`opengraph-image.tsx`](/docs/app/api-reference/file-conventions/metadata/opengraph-image), và [`icon.tsx`](/docs/app/api-reference/file-conventions/metadata/app-icons), và các [tệp metadata](/docs/app/api-reference/file-conventions/metadata) khác được cache theo mặc định.
> - Nếu sử dụng cùng với [`proxy.ts`](/docs/app/api-reference/file-conventions/proxy), [cấu hình matcher](/docs/app/api-reference/file-conventions/proxy#matcher) để loại trừ các tệp metadata.
