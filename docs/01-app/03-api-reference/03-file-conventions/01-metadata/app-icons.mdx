Các file conventions `favicon`, `icon`, hoặc `apple-icon` cho phép bạn đặt icons cho ứng dụng của mình.

Chúng hữu ích để thêm app icons xuất hiện ở những nơi như tab trình duyệt web, màn hình chính điện thoại và kết quả của công cụ tìm kiếm.

Có hai cách để đặt app icons:

- [Sử dụng image files (.ico, .jpg, .png)](#image-files-ico-jpg-png)
- [Sử dụng code để tạo icon (.js, .ts, .tsx)](#generate-icons-using-code-js-ts-tsx)

## Image files (.ico, .jpg, .png)

Sử dụng một image file để đặt app icon bằng cách đặt một image file `favicon`, `icon`, hoặc `apple-icon` bên trong thư mục `/app` của bạn.
Hình ảnh `favicon` chỉ có thể được đặt ở cấp cao nhất của `app/`.

Next.js sẽ đánh giá file và tự động thêm các thẻ thích hợp vào phần tử `<head>` của ứng dụng của bạn.

| File convention             | Các loại file được hỗ trợ               | Vị trí hợp lệ |
| --------------------------- | --------------------------------------- | ------------- |
| [`favicon`](#favicon)       | `.ico`                                  | `app/`        |
| [`icon`](#icon)             | `.ico`, `.jpg`, `.jpeg`, `.png`, `.svg` | `app/**/*`    |
| [`apple-icon`](#apple-icon) | `.jpg`, `.jpeg`, `.png`                 | `app/**/*`    |

### `favicon`

Thêm một image file `favicon.ico` vào root `/app` route segment.

```html filename="<head> output"
<link rel="icon" href="/favicon.ico" sizes="any" />
```

### `icon`

Thêm một image file `icon.(ico|jpg|jpeg|png|svg)`.

```html filename="<head> output"
<link
  rel="icon"
  href="/icon?<generated>"
  type="image/<generated>"
  sizes="<generated>"
/>
```

### `apple-icon`

Thêm một image file `apple-icon.(jpg|jpeg|png)`.

```html filename="<head> output"
<link
  rel="apple-touch-icon"
  href="/apple-icon?<generated>"
  type="image/<generated>"
  sizes="<generated>"
/>
```

> **Lưu ý**:
>
> - Bạn có thể đặt nhiều icons bằng cách thêm hậu tố số vào tên file. Ví dụ, `icon1.png`, `icon2.png`, v.v. Các file được đánh số sẽ sắp xếp theo thứ tự từ điển.
> - Favicons chỉ có thể được đặt trong root `/app` segment. Nếu bạn cần độ chi tiết cao hơn, bạn có thể sử dụng [`icon`](#icon).
> - Các thẻ `<link>` và thuộc tính thích hợp như `rel`, `href`, `type`, và `sizes` được xác định bởi loại icon và metadata của file được đánh giá.
> - Ví dụ, một file `.png` 32 x 32px sẽ có các thuộc tính `type="image/png"` và `sizes="32x32"`.
> - `sizes="any"` được thêm vào icons khi phần mở rộng là `.svg` hoặc kích thước hình ảnh của file không được xác định. Chi tiết thêm trong [favicon handbook](https://evilmartians.com/chronicles/how-to-favicon-in-2021-six-files-that-fit-most-needs) này.

## Tạo icons sử dụng code (.js, .ts, .tsx)

Ngoài việc sử dụng [literal image files](#image-files-ico-jpg-png), bạn có thể **tạo** icons bằng lập trình sử dụng code.

Tạo một app icon bằng cách tạo một route `icon` hoặc `apple-icon` export mặc định một function.

| File convention | Các loại file được hỗ trợ |
| --------------- | ------------------------- |
| `icon`          | `.js`, `.ts`, `.tsx`      |
| `apple-icon`    | `.js`, `.ts`, `.tsx`      |

Cách dễ nhất để tạo một icon là sử dụng API [`ImageResponse`](/docs/app/api-reference/functions/image-response) từ `next/og`.

```tsx filename="app/icon.tsx" switcher
import { ImageResponse } from 'next/og'

// Image metadata
export const size = {
  width: 32,
  height: 32,
}
export const contentType = 'image/png'

// Image generation
export default function Icon() {
  return new ImageResponse(
    (
      // ImageResponse JSX element
      <div
        style={{
          fontSize: 24,
          background: 'black',
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          color: 'white',
        }}
      >
        A
      </div>
    ),
    // ImageResponse options
    {
      // Để thuận tiện, chúng ta có thể sử dụng lại config metadata size của icon đã export
      // để cũng đặt width và height của ImageResponse.
      ...size,
    }
  )
}
```

```jsx filename="app/icon.js" switcher
import { ImageResponse } from 'next/og'

// Image metadata
export const size = {
  width: 32,
  height: 32,
}
export const contentType = 'image/png'

// Image generation
export default function Icon() {
  return new ImageResponse(
    (
      // ImageResponse JSX element
      <div
        style={{
          fontSize: 24,
          background: 'black',
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          color: 'white',
        }}
      >
        A
      </div>
    ),
    // ImageResponse options
    {
      // Để thuận tiện, chúng ta có thể sử dụng lại config metadata size của icon đã export
      // để cũng đặt width và height của ImageResponse.
      ...size,
    }
  )
}
```

```html filename="<head> output"
<link rel="icon" href="/icon?<generated>" type="image/png" sizes="32x32" />
```

> **Lưu ý**:
>
> - Mặc định, các icons được tạo được [**tối ưu hóa tĩnh**](/docs/app/guides/caching#static-rendering) (được tạo tại build time và cached) trừ khi chúng sử dụng [Dynamic APIs](/docs/app/guides/caching#dynamic-rendering) hoặc uncached data.
> - Bạn có thể tạo nhiều icons trong cùng một file sử dụng [`generateImageMetadata`](/docs/app/api-reference/functions/generate-image-metadata).
> - Bạn không thể tạo một `favicon` icon. Sử dụng [`icon`](#icon) hoặc một file [favicon.ico](#favicon) thay thế.
> - App icons là các Route Handlers đặc biệt được cache mặc định trừ khi chúng sử dụng một tùy chọn [Dynamic API](/docs/app/guides/caching#dynamic-apis) hoặc [dynamic config](/docs/app/guides/caching#segment-config-options).

### Props

Function export mặc định nhận các props sau:

#### `params` (tùy chọn)

Một promise resolve thành một object chứa object [dynamic route parameters](/docs/app/api-reference/file-conventions/dynamic-routes) từ root segment xuống đến segment mà `icon` hoặc `apple-icon` được đặt cùng.

> **Lưu ý**: Nếu bạn sử dụng [`generateImageMetadata`](/docs/app/api-reference/functions/generate-image-metadata), function cũng sẽ nhận một prop `id` là một promise resolving thành giá trị `id` từ một trong các items được trả về bởi `generateImageMetadata`.

```tsx filename="app/shop/[slug]/icon.tsx" switcher
export default async function Icon({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
  // ...
}
```

```jsx filename="app/shop/[slug]/icon.js" switcher
export default async function Icon({ params }) {
  const { slug } = await params
  // ...
}
```

| Route                           | URL         | `params`                           |
| ------------------------------- | ----------- | ---------------------------------- |
| `app/shop/icon.js`              | `/shop`     | `undefined`                        |
| `app/shop/[slug]/icon.js`       | `/shop/1`   | `Promise<{ slug: '1' }>`           |
| `app/shop/[tag]/[item]/icon.js` | `/shop/1/2` | `Promise<{ tag: '1', item: '2' }>` |

### Returns

Function export mặc định nên trả về một `Blob` | `ArrayBuffer` | `TypedArray` | `DataView` | `ReadableStream` | `Response`.

> **Lưu ý**: `ImageResponse` thỏa mãn return type này.

### Config exports

Bạn có thể tùy chọn cấu hình metadata của icon bằng cách export các biến `size` và `contentType` từ route `icon` hoặc `apple-icon`.

| Option                        | Type                                                                                                            |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------- |
| [`size`](#size)               | `{ width: number; height: number }`                                                                             |
| [`contentType`](#contenttype) | `string` - [image MIME type](https://developer.mozilla.org/docs/Web/HTTP/Basics_of_HTTP/MIME_types#image_types) |

#### `size`

```tsx filename="icon.tsx | apple-icon.tsx" switcher
export const size = { width: 32, height: 32 }

export default function Icon() {}
```

```jsx filename="icon.js | apple-icon.js" switcher
export const size = { width: 32, height: 32 }

export default function Icon() {}
```

```html filename="<head> output"
<link rel="icon" sizes="32x32" />
```

#### `contentType`

```tsx filename="icon.tsx | apple-icon.tsx" switcher
export const contentType = 'image/png'

export default function Icon() {}
```

```jsx filename="icon.js | apple-icon.js" switcher
export const contentType = 'image/png'

export default function Icon() {}
```

```html filename="<head> output"
<link rel="icon" type="image/png" />
```

#### Route Segment Config

`icon` và `apple-icon` là các [Route Handlers](/docs/app/api-reference/file-conventions/route) chuyên biệt có thể sử dụng các tùy chọn [route segment configuration](/docs/app/api-reference/file-conventions/route-segment-config) giống như Pages và Layouts.
