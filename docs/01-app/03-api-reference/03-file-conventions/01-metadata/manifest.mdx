Thêm hoặc tạo tệp `manifest.(json|webmanifest)` khớp với [Web Manifest Specification](https://developer.mozilla.org/docs/Web/Manifest) trong **thư mục gốc** của thư mục `app` để cung cấp thông tin về ứng dụng web của bạn cho trình duyệt.

## Tệp Manifest tĩnh

```json filename="app/manifest.json | app/manifest.webmanifest"
{
  "name": "My Next.js Application",
  "short_name": "Next.js App",
  "description": "An application built with Next.js",
  "start_url": "/"
  // ...
}
```

## Tạo tệp Manifest

Thêm tệp `manifest.js` hoặc `manifest.ts` trả về một [`Manifest` object](#manifest-object).

> Thông tin hữu ích: `manifest.js` là Route Handlers đặc biệt được cache theo mặc định trừ khi nó sử dụng [Dynamic API](/docs/app/guides/caching#dynamic-apis) hoặc tùy chọn [dynamic config](/docs/app/guides/caching#segment-config-options).

```ts filename="app/manifest.ts" switcher
import type { MetadataRoute } from 'next'

export default function manifest(): MetadataRoute.Manifest {
  return {
    name: 'Next.js App',
    short_name: 'Next.js App',
    description: 'Next.js App',
    start_url: '/',
    display: 'standalone',
    background_color: '#fff',
    theme_color: '#fff',
    icons: [
      {
        src: '/favicon.ico',
        sizes: 'any',
        type: 'image/x-icon',
      },
    ],
  }
}
```

```js filename="app/manifest.js" switcher
export default function manifest() {
  return {
    name: 'Next.js App',

```

### Manifest Object

Đối tượng manifest chứa một danh sách rộng rãi các tùy chọn có thể được cập nhật do các tiêu chuẩn web mới. Để biết thông tin về tất cả các tùy chọn hiện tại, hãy tham khảo kiểu `MetadataRoute.Manifest` trong trình soạn thảo mã của bạn nếu sử dụng [TypeScript](/docs/app/api-reference/config/typescript#ide-plugin) hoặc xem tài liệu [MDN](https://developer.mozilla.org/docs/Web/Manifest).
