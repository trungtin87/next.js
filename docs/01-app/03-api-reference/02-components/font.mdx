[`next/font`](/docs/app/api-reference/components/font) tự động tối ưu hóa fonts của bạn (bao gồm custom fonts) và loại bỏ các external network requests để cải thiện quyền riêng tư và hiệu suất.

Nó bao gồm **built-in automatic self-hosting** cho bất kỳ font file nào. Điều này có nghĩa là bạn có thể tối ưu load web fonts mà không có [layout shift](https://web.dev/articles/cls).

Bạn cũng có thể dễ dàng sử dụng tất cả [Google Fonts](https://fonts.google.com/). CSS và font files được download tại build time và self-hosted với phần còn lại của static assets của bạn. **Không có requests nào được gửi đến Google bởi trình duyệt.**

<AppOnly>

```tsx filename="app/layout.tsx" switcher
import { Inter } from 'next/font/google'

// Nếu loading variable font, bạn không cần chỉ định font weight
const inter = Inter({
  subsets: ['latin'],
  display: 'swap',
})

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" className={inter.className}>
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import { Inter } from 'next/font/google'

// Nếu loading variable font, bạn không cần chỉ định font weight
const inter = Inter({

  display: 'swap',
})

export default function RootLayout({ children }) {
  return (
    <html lang="en" className={inter.className}>
      <body>{children}</body>
    </html>
  )
}
```

</AppOnly>

### `src`

Path của font file dưới dạng string hoặc array of objects (với type `Array<{path: string, weight?: string, style?: string}>`) tương đối với thư mục nơi font loader function được gọi.

Được sử dụng trong `next/font/local`

- Bắt buộc

Ví dụ:

- `src:'./fonts/my-font.woff2'` trong đó `my-font.woff2` được đặt trong thư mục có tên `fonts` bên trong thư mục `app`
- `src:[{path: './inter/Inter-Thin.ttf', weight: '100',},{path: './inter/Inter-Regular.ttf',weight: '400',},{path: './inter/Inter-Bold-Italic.ttf', weight: '700',style: 'italic',},]`
- nếu font loader function được gọi trong `app/page.tsx` sử dụng `src:'../styles/fonts/my-font.ttf'`, thì `my-font.ttf` được đặt trong `styles/fonts` ở root của project

### `weight`

Font [`weight`](https://fonts.google.com/knowledge/glossary/weight) với các khả năng sau:

- Một string với các giá trị có thể của weights có sẵn cho font cụ thể hoặc một range of values nếu đó là [variable](https://fonts.google.com/variablefonts) font
- Một array of weight values nếu font không phải là [variable google font](https://fonts.google.com/variablefonts). Nó áp dụng cho `next/font/google` only.

Được sử dụng trong `next/font/google` và `next/font/local`

- Bắt buộc nếu font được sử dụng **không phải** là [variable](https://fonts.google.com/variablefonts)

Ví dụ:

- `weight: '400'`: Một string cho single weight value - đối với font [`Inter`](https://fonts.google.com/specimen/Inter?query=inter), các giá trị có thể là `'100'`, `'200'`, `'300'`, `'400'`, `'500'`, `'600'`, `'700'`, `'800'`, `'900'` hoặc `'variable'` trong đó `'variable'` là mặc định)
- `weight: '100 900'`: Một string cho range giữa `100` và `900` cho variable font
- `weight: ['100','400','900']`: Một array of 3 giá trị có thể cho non variable font

### `style`

Font [`style`](https://developer.mozilla.org/docs/Web/CSS/font-style) với các khả năng sau:

- Một string [value](https://developer.mozilla.org/docs/Web/CSS/font-style#values) với giá trị mặc định là `'normal'`
- Một array of style values nếu font không phải là [variable google font](https://fonts.google.com/variablefonts). Nó áp dụng cho `next/font/google` only.

Được sử dụng trong `next/font/google` và `next/font/local`

- Tùy chọn

Ví dụ:

- `style: 'italic'`: Một string - nó có thể là `normal` hoặc `italic` cho `next/font/google`
- `style: 'oblique'`: Một string - nó có thể nhận bất kỳ giá trị nào cho `next/font/local` nhưng được mong đợi đến từ [standard font styles](https://developer.mozilla.org/docs/Web/CSS/font-style)
- `style: ['italic','normal']`: Một array of 2 values cho `next/font/google` - các giá trị từ `normal` và `italic`

### `subsets`

Font [`subsets`](https://fonts.google.com/knowledge/glossary/subsetting) được định nghĩa bởi một array of string values với tên của mỗi subset bạn muốn được [preloaded](/docs/app/api-reference/components/font#specifying-a-subset). Fonts được chỉ định thông qua `subsets` sẽ có link preload tag được inject vào head khi tùy chọn [`preload`](#preload) là true, đó là mặc định.

Được sử dụng trong `next/font/google`

- Tùy chọn

Ví dụ:

- `subsets: ['latin']`: Một array với subset `latin`

Bạn có thể tìm danh sách tất cả subsets trên trang Google Fonts cho font của bạn.

### `axes`

Một số variable fonts có thêm `axes` có thể được bao gồm. Mặc định, chỉ font weight được bao gồm để giữ kích thước file nhỏ. Các giá trị có thể của `axes` phụ thuộc vào font cụ thể.

Được sử dụng trong `next/font/google`

- Tùy chọn

Ví dụ:

- `axes: ['slnt']`: Một array với value `slnt` cho `Inter` variable font có `slnt` như additional `axes` như được hiển thị [ở đây](https://fonts.google.com/variablefonts?vfquery=inter#font-families). Bạn có thể tìm các giá trị `axes` có thể cho font của mình bằng cách sử dụng filter trên [Google variable fonts page](https://fonts.google.com/variablefonts#font-families) và tìm kiếm axes khác ngoài `wght`

### `display`

Font [`display`](https://developer.mozilla.org/docs/Web/CSS/@font-face/font-display) với các string [values](https://developer.mozilla.org/docs/Web/CSS/@font-face/font-display#values) có thể là `'auto'`, `'block'`, `'swap'`, `'fallback'` hoặc `'optional'` với giá trị mặc định là `'swap'`.

Được sử dụng trong `next/font/google` và `next/font/local`

- Tùy chọn

Ví dụ:

- `display: 'optional'`: Một string được gán cho giá trị `optional`

### `preload`

Một boolean value chỉ định xem font có nên được [preloaded](/docs/app/api-reference/components/font#preloading) hay không. Mặc định là `true`.

Được sử dụng trong `next/font/google` và `next/font/local`

- Tùy chọn

Ví dụ:

- `preload: false`

### `fallback`

Fallback font để sử dụng nếu font không thể được load. Một array of strings của fallback fonts không có mặc định.

- Tùy chọn

Được sử dụng trong `next/font/google` và `next/font/local`

Ví dụ:

- `fallback: ['system-ui', 'arial']`: Một array đặt fallback fonts thành `system-ui` hoặc `arial`

### `adjustFontFallback`

- Đối với `next/font/google`: Một boolean value đặt xem một automatic fallback font có nên được sử dụng để giảm [Cumulative Layout Shift](https://web.dev/cls/) hay không. Mặc định là `true`.
- Đối với `next/font/local`: Một string hoặc boolean `false` value đặt xem một automatic fallback font có nên được sử dụng để giảm [Cumulative Layout Shift](https://web.dev/cls/) hay không. Các giá trị có thể là `'Arial'`, `'Times New Roman'` hoặc `false`. Mặc định là `'Arial'`.

Được sử dụng trong `next/font/google` và `next/font/local`

- Tùy chọn

Ví dụ:

- `adjustFontFallback: false`: cho `next/font/google`
- `adjustFontFallback: 'Times New Roman'`: cho `next/font/local`

### `variable`

Một string value để định nghĩa CSS variable name sẽ được sử dụng nếu style được áp dụng với [CSS variable method](#css-variables).

Được sử dụng trong `next/font/google` và `next/font/local`

- Tùy chọn

Ví dụ:

- `variable: '--my-font'`: CSS variable `--my-font` được khai báo

### `declarations`

Một array of font face [descriptor](https://developer.mozilla.org/docs/Web/CSS/@font-face#descriptors) key-value pairs định nghĩa `@font-face` được tạo thêm.

Được sử dụng trong `next/font/local`

- Tùy chọn

Ví dụ:

- `declarations: [{ prop: 'ascent-override', value: '90%' }]`

### Áp dụng font trong `<head>`

Bạn cũng có thể sử dụng font mà không có wrapper và `className` bằng cách inject nó vào `<head>` như sau:

```jsx filename="pages/_app.js"
import { Inter } from 'next/font/google'

const inter = Inter({ subsets: ['latin'] })

export default function MyApp({ Component, pageProps }) {
  return (
    <>
      <style jsx global>{`
        html {
          font-family: ${inter.style.fontFamily};
        }
      `}</style>
      <Component {...pageProps} />
    </>
  )
}
```

## Sử dụng nhiều Fonts

Bạn có thể import và sử dụng nhiều fonts trong ứng dụng của mình. Có hai cách tiếp cận bạn có thể thực hiện.

Cách tiếp cận đầu tiên là tạo một utility function export một font, import nó, và áp dụng `className` của nó khi cần. Điều này đảm bảo font chỉ được preload khi nó được render:

```ts filename="app/fonts.ts" switcher
import { Inter, Roboto_Mono } from 'next/font/google'
```

```tsx filename="app/layout.tsx" switcher
import { Inter, Roboto_Mono } from 'next/font/google'
import styles from './global.css'

const inter = Inter({
  subsets: ['latin'],
  variable: '--font-inter',
  display: 'swap',
})

const roboto_mono = Roboto_Mono({
  subsets: ['latin'],
  variable: '--font-roboto-mono',
  display: 'swap',
})

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" className={`${inter.variable} ${roboto_mono.variable}`}>
      <body>
        <h1>My App</h1>
        <div>{children}</div>
      </body>
    </html>
  )
}
```

### Local Fonts

Import `next/font/local` và chỉ định `src` của local font file của bạn. Chúng tôi khuyến nghị sử dụng [variable fonts](https://fonts.google.com/variablefonts) để có hiệu suất và tính linh hoạt tốt nhất.

<AppOnly>

```tsx filename="app/layout.tsx" switcher
import localFont from 'next/font/local'

// Font files có thể được colocated bên trong `app`
const myFont = localFont({
  src: './my-font.woff2',
  display: 'swap',
})
```

### Với Tailwind CSS

`next/font` tích hợp liền mạch với [Tailwind CSS](https://tailwindcss.com/) sử dụng [CSS variables](/docs/app/api-reference/components/font#css-variables).

Trong ví dụ bên dưới, chúng tôi sử dụng fonts `Inter` và `Roboto_Mono` từ `next/font/google` (bạn có thể sử dụng bất kỳ Google Font hoặc Local Font nào). Sử dụng tùy chọn `variable` để định nghĩa CSS variable name, chẳng hạn như `inter` và `roboto_mono` cho các fonts này tương ứng. Sau đó, áp dụng `inter.variable` và `roboto_mono.variable` để bao gồm CSS variables trong HTML document của bạn.

> **Lưu ý**: Bạn có thể thêm các variables này vào thẻ `<html>` hoặc `<body>`, tùy thuộc vào sở thích, nhu cầu styling hoặc yêu cầu dự án của bạn.

### Áp dụng Styles

Bạn có thể áp dụng font styles theo ba cách:

- [`className`](#classname)
- [`style`](#style-1)
- [CSS Variables](#css-variables)

#### `className`

Trả về một read-only CSS `className` cho font đã load để được truyền cho một HTML element.

```tsx
<p className={inter.className}>Hello, Next.js!</p>
```

#### `style`

Trả về một read-only CSS `style` object cho font đã load để được truyền cho một HTML element, bao gồm `style.fontFamily` để truy cập font family name và fallback fonts.

```tsx
<p style={inter.style}>Hello World</p>
```

#### CSS Variables

Nếu bạn muốn đặt styles của mình trong external style sheet và chỉ định các tùy chọn bổ sung ở đó, hãy sử dụng CSS variable method.

Ngoài việc import font, cũng import CSS file nơi CSS variable được định nghĩa và đặt variable option của font loader object như sau:

```tsx filename="app/page.tsx" switcher
import { Inter } from 'next/font/google'
import styles from '../styles/component.module.css'

const inter = Inter({
  variable: '--font-inter',
})
```

```jsx filename="app/page.js" switcher
import { Inter } from 'next/font/google'
import styles from '../styles/component.module.css'

const inter = Inter({
  variable: '--font-inter',
})
```

Để sử dụng font, đặt `className` của parent container của text bạn muốn style thành giá trị `variable` của font loader và `className` của text thành property `styles` từ external CSS file.

```tsx filename="app/page.tsx" switcher
<main className={inter.variable}>
  <p className={styles.text}>Hello World</p>
</main>
```

```jsx filename="app/page.js" switcher
<main className={inter.variable}>
  <p className={styles.text}>Hello World</p>
</main>
```

Định nghĩa `text` selector class trong CSS file `component.module.css` như sau:

```css filename="styles/component.module.css"
.text {
  font-family: var(--font-inter);
  font-weight: 200;
  font-style: italic;
}
```

Trong ví dụ trên, text `Hello World` được styled bằng font `Inter` và generated font fallback với `font-weight: 200` và `font-style: italic`.

### Sử dụng font definitions file

Mỗi lần bạn gọi `localFont` hoặc Google font function, font đó sẽ được hosted như một instance trong ứng dụng của bạn. Do đó, nếu bạn cần sử dụng cùng một font ở nhiều nơi, bạn nên load nó ở một nơi và import related font object nơi bạn cần nó. Điều này được thực hiện bằng cách sử dụng font definitions file.

Ví dụ, tạo file `fonts.ts` trong thư mục `styles` ở root của app directory của bạn.

Sau đó, chỉ định font definitions của bạn như sau:

```ts filename="styles/fonts.ts" switcher
import { Inter, Lora, Source_Sans_3 } from 'next/font/google'
import localFont from 'next/font/local'

// định nghĩa variable fonts của bạn
const inter = Inter()
const lora = Lora()
// định nghĩa 2 weights của non-variable font
const sourceCodePro400 = Source_Sans_3({ weight: '400' })
const sourceCodePro700 = Source_Sans_3({ weight: '700' })
// định nghĩa custom local font nơi GreatVibes-Regular.ttf được lưu trong thư mục styles
const greatVibes = localFont({ src: './GreatVibes-Regular.ttf' })

export { inter, lora, sourceCodePro400, sourceCodePro700, greatVibes }
```

```js filename="styles/fonts.js" switcher
import { Inter, Lora, Source_Sans_3 } from 'next/font/google'
import localFont from 'next/font/local'

// định nghĩa variable fonts của bạn
const inter = Inter()
const lora = Lora()
// định nghĩa 2 weights của non-variable font
const sourceCodePro400 = Source_Sans_3({ weight: '400' })
const sourceCodePro700 = Source_Sans_3({ weight: '700' })
// định nghĩa custom local font nơi GreatVibes-Regular.ttf được lưu trong thư mục styles
const greatVibes = localFont({ src: './GreatVibes-Regular.ttf' })

export { inter, lora, sourceCodePro400, sourceCodePro700, greatVibes }
```

Bây giờ bạn có thể sử dụng các definitions này trong code của mình như sau:

```tsx filename="app/page.tsx" switcher
import { inter, lora, sourceCodePro700, greatVibes } from '../styles/fonts'

export default function Page() {
  return (
    <div>
      <p className={inter.className}>Hello world using Inter font</p>
      <p style={lora.style}>Hello world using Lora font</p>
      <p className={sourceCodePro700.className}>
        Hello world using Source_Sans_3 font with weight 700
      </p>
      <p className={greatVibes.className}>My title in Great Vibes font</p>
    </div>
  )
}
```


Để dễ dàng truy cập font definitions trong code của bạn, bạn có thể định nghĩa path alias trong files `tsconfig.json` hoặc `jsconfig.json` của bạn như sau:

```json filename="tsconfig.json"
{
  "compilerOptions": {
    "paths": {
      "@/fonts": ["./styles/fonts"]
```


### Preloading

<AppOnly>

Khi một font function được gọi trên một page của site của bạn, nó không có sẵn globally và được preload trên tất cả routes. Thay vào đó, font chỉ được preload trên các related routes dựa trên type of file nơi nó được sử dụng:

- Nếu đó là một [unique page](/docs/app/api-reference/file-conventions/page), nó được preload trên unique route cho page đó.
- Nếu đó là một [layout](/docs/app/api-reference/file-conventions/layout), nó được preload trên tất cả các routes được wrapped bởi layout.
- Nếu đó là [root layout](/docs/app/api-reference/file-conventions/layout#root-layout), nó được preload trên tất cả routes.

</AppOnly>

<PagesOnly>

Khi một font function được gọi trên một page của site của bạn, nó không có sẵn globally và được preload trên tất cả routes. Thay vào đó, font chỉ được preload trên related route/s dựa trên type of file nơi nó được sử dụng:

- nếu đó là một [unique page](/docs/pages/building-your-application/routing/pages-and-layouts), nó được preload trên unique route cho page đó
- nếu đó là trong [custom App](/docs/pages/building-your-application/routing/custom-app), nó được preload trên tất cả các routes của site dưới `/pages`

</PagesOnly>
