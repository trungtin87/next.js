`create-next-app` CLI cho phép bạn tạo một ứng dụng Next.js mới bằng cách sử dụng template mặc định hoặc một [ví dụ](https://github.com/vercel/next.js/tree/canary/examples) từ một kho lưu trữ GitHub công khai. Đây là cách dễ nhất để bắt đầu với Next.js.

Sử dụng cơ bản:

```bash filename="Terminal"
npx create-next-app@latest [project-name] [options]
```

## Tham khảo

Các tùy chọn sau đây có sẵn:

| Tùy chọn                                  | Mô tả                                                                   |
| ----------------------------------------- | ----------------------------------------------------------------------- |
| `-h` hoặc `--help`                        | Hiển thị tất cả các tùy chọn có sẵn                                     |
| `-v` hoặc `--version`                     | Xuất số phiên bản                                                       |
| `--no-*`                                  | Phủ định các tùy chọn mặc định. Ví dụ: `--no-ts`                        |
| `--ts` hoặc `--typescript`                | Khởi tạo như một dự án TypeScript (mặc định)                            |
| `--js` hoặc `--javascript`                | Khởi tạo như một dự án JavaScript                                       |
| `--tailwind`                              | Khởi tạo với cấu hình Tailwind CSS (mặc định)                           |
| `--react-compiler`                        | Khởi tạo với React Compiler được bật                                    |
| `--eslint`                                | Khởi tạo với cấu hình ESLint                                            |
| `--biome`                                 | Khởi tạo với cấu hình Biome                                             |
| `--no-linter`                             | Bỏ qua cấu hình linter                                                  |
| `--app`                                   | Khởi tạo như một dự án App Router                                       |
| `--api`                                   | Khởi tạo một dự án chỉ với route handlers                               |
| `--src-dir`                               | Khởi tạo bên trong thư mục `src/`                                       |
| `--turbopack`                             | Buộc bật Turbopack trong package.json được tạo (được bật theo mặc định) |
| `--webpack`                               | Buộc bật Webpack trong package.json được tạo                            |
| `--import-alias <alias-to-configure>`     | Chỉ định import alias để sử dụng (mặc định "@/\*")                      |
| `--empty`                                 | Khởi tạo một dự án trống                                                |
| `--use-npm`                               | Chỉ định rõ ràng cho CLI để bootstrap ứng dụng bằng npm                 |
| `--use-pnpm`                              | Chỉ định rõ ràng cho CLI để bootstrap ứng dụng bằng pnpm                |
| `--use-yarn`                              | Chỉ định rõ ràng cho CLI để bootstrap ứng dụng bằng Yarn                |
| `--use-bun`                               | Chỉ định rõ ràng cho CLI để bootstrap ứng dụng bằng Bun                 |
| `-e` hoặc `--example [name] [github-url]` | Một ví dụ để bootstrap ứng dụng với                                     |
| `--example-path <path-to-example>`        | Chỉ định đường dẫn đến ví dụ một cách riêng biệt                        |
| `--reset-preferences`                     | Chỉ định rõ ràng cho CLI để reset bất kỳ tùy chọn nào đã lưu            |
| `--skip-install`                          | Chỉ định rõ ràng cho CLI để bỏ qua cài đặt các gói                      |
| `--disable-git`                           | Chỉ định rõ ràng cho CLI để vô hiệu hóa khởi tạo git                    |
| `--yes`                                   | Sử dụng các tùy chọn trước đó hoặc mặc định cho tất cả các tùy chọn     |

## Ví dụ

### Với template mặc định

Để tạo một ứng dụng mới sử dụng template mặc định, chạy lệnh sau trong terminal của bạn:

```bash filename="Terminal"
npx create-next-app@latest
```

Khi cài đặt, bạn sẽ thấy các lời nhắc sau:

```txt filename="Terminal"
What is your project named? my-app
Would you like to use the recommended Next.js defaults?
    Yes, use recommended defaults - TypeScript, ESLint, Tailwind CSS, App Router, Turbopack
    No, reuse previous settings
    No, customize settings - Choose your own preferences
```

Nếu bạn chọn `customize settings`, bạn sẽ thấy các lời nhắc sau:

```txt filename="Terminal"
Would you like to use TypeScript? No / Yes
Which linter would you like to use? ESLint / Biome / None
Would you like to use React Compiler? No / Yes
Would you like to use Tailwind CSS? No / Yes
Would you like your code inside a `src/` directory? No / Yes
Would you like to use App Router? (recommended) No / Yes
Would you like to use Turbopack? (recommended) No / Yes
Would you like to customize the import alias (`@/*` by default)? No / Yes
What import alias would you like configured? @/*
```

Sau các lời nhắc, `create-next-app` sẽ tạo một thư mục với tên dự án của bạn và cài đặt các dependencies cần thiết.

### Tùy chọn Linter

**ESLint**: Linter JavaScript truyền thống và phổ biến nhất. Bao gồm các quy tắc cụ thể của Next.js từ `@next/eslint-plugin-next`.

**Biome**: Một linter và formatter hiện đại, nhanh chóng kết hợp chức năng của ESLint và Prettier. Bao gồm hỗ trợ domain Next.js và React tích hợp để có hiệu suất tối ưu.

**None**: Bỏ qua cấu hình linter hoàn toàn. Bạn luôn có thể thêm một linter sau này.

Khi bạn đã trả lời các lời nhắc, một dự án mới sẽ được tạo với cấu hình bạn đã chọn.

### Với một ví dụ Next.js chính thức

Để tạo một ứng dụng mới sử dụng một ví dụ Next.js chính thức, sử dụng cờ `--example`. Ví dụ:

```bash filename="Terminal"
npx create-next-app@latest --example [example-name] [your-project-name]
```

Bạn có thể xem danh sách tất cả các ví dụ có sẵn cùng với hướng dẫn thiết lập trong [kho lưu trữ Next.js](https://github.com/vercel/next.js/tree/canary/examples).

### Với bất kỳ ví dụ GitHub công khai nào

Để tạo một ứng dụng mới sử dụng bất kỳ ví dụ GitHub công khai nào, sử dụng tùy chọn `--example` với URL của repo GitHub. Ví dụ:

```bash filename="Terminal"
npx create-next-app@latest --example "https://github.com/.../" [your-project-name]
```
