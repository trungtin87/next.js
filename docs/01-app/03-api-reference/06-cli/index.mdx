Next.js đi kèm với **hai** công cụ Giao diện dòng lệnh (CLI):

- **`create-next-app`**: Nhanh chóng tạo một ứng dụng Next.js mới bằng cách sử dụng mẫu mặc định hoặc một [ví dụ](https://github.com/vercel/next.js/tree/canary/examples) từ kho lưu trữ GitHub công khai.
- **`next`**: Chạy máy chủ phát triển Next.js, build ứng dụng của bạn, và hơn thế nữa.
