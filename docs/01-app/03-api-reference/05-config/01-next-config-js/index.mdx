Next.js có thể được cấu hình thông qua tệp `next.config.js` trong thư mục gốc của dự án của bạn (ví dụ, bởi `package.json`) với một default export.

```js filename="next.config.js"
// @ts-check

/** @type {import('next').NextConfig} */
const nextConfig = {
  /* config options here */
}

module.exports = nextConfig
```

## ECMAScript Modules

`next.config.js` là một module Node.js thông thường, không phải là tệp JSON. Nó được sử dụng bởi Next.js server và các giai đoạn build, và nó không được bao gồm trong browser build.

Nếu bạn cần [ECMAScript modules](https://nodejs.org/api/esm.html), bạn có thể sử dụng `next.config.mjs`:

```js filename="next.config.mjs"
// @ts-check

/**
 * @type {import('next').NextConfig}
 */
const nextConfig = {
  /* config options here */
}

export default nextConfig
```

> **Nên biết**: `next.config` với các phần mở rộng `.cjs`, `.cts`, hoặc `.mts` hiện **không** được hỗ trợ.

## Cấu hình như một Hàm

Bạn cũng có thể sử dụng một hàm:

```js filename="next.config.mjs"
// @ts-check

export default (phase, { defaultConfig }) => {
  /**
   * @type {import('next').NextConfig}
   */
  const nextConfig = {
    /* config options here */
  }
  return nextConfig
}
```

### Cấu hình Async

Kể từ Next.js 12.1.0, bạn có thể sử dụng một hàm async:

```js filename="next.config.js"
// @ts-check

module.exports = async (phase, { defaultConfig }) => {
  /**
   * @type {import('next').NextConfig}
   */
  const nextConfig = {
    /* config options here */
  }
  return nextConfig
}
```

### Phase

`phase` là ngữ cảnh hiện tại mà cấu hình được tải. Bạn có thể xem [các phase có sẵn](https://github.com/vercel/next.js/blob/5e6b008b561caf2710ab7be63320a3d549474a5b/packages/next/shared/lib/constants.ts#L19-L23). Các phase có thể được import từ `next/constants`:

```js filename="next.config.js"
// @ts-check

const { PHASE_DEVELOPMENT_SERVER } = require('next/constants')

module.exports = (phase, { defaultConfig }) => {
  if (phase === PHASE_DEVELOPMENT_SERVER) {
    return {
      /* development only config options here */
    }
  }

  return {
    /* config options for all phases except development here */
  }
}
```

## TypeScript

Nếu bạn đang sử dụng TypeScript trong dự án của mình, bạn có thể sử dụng `next.config.ts` để sử dụng TypeScript trong cấu hình của bạn:

```ts filename="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  /* config options here */
}

export default nextConfig
```

Các dòng được chú thích là nơi bạn có thể đặt các cấu hình được phép bởi `next.config.js`, được [định nghĩa trong tệp này](https://github.com/vercel/next.js/blob/canary/packages/next/src/server/config-shared.ts).

Tuy nhiên, không có cấu hình nào là bắt buộc, và không cần thiết phải hiểu mỗi cấu hình làm gì. Thay vào đó, hãy tìm kiếm các tính năng bạn cần kích hoạt hoặc sửa đổi trong phần này và chúng sẽ chỉ cho bạn những việc cần làm.

> Tránh sử dụng các tính năng JavaScript mới không có sẵn trong phiên bản Node.js mục tiêu của bạn. `next.config.js` sẽ không được phân tích cú pháp bởi Webpack hoặc Babel.

## Unit Testing (thử nghiệm)

Bắt đầu từ Next.js 15.1, gói `next/experimental/testing/server` chứa các tiện ích để giúp unit test các tệp `next.config.js`.

Hàm `unstable_getResponseFromNextConfig` chạy các hàm [`headers`](/docs/app/api-reference/config/next-config-js/headers), [`redirects`](/docs/app/api-reference/config/next-config-js/redirects), và [`rewrites`](/docs/app/api-reference/config/next-config-js/rewrites) từ `next.config.js` với thông tin request được cung cấp và trả về `NextResponse` với kết quả của việc định tuyến.

> Phản hồi từ `unstable_getResponseFromNextConfig` chỉ xem xét các trường `next.config.js` và không xem xét proxy hoặc filesystem routes, vì vậy kết quả trong production có thể khác với unit test.

```js
import {
  getRedirectUrl,
  unstable_getResponseFromNextConfig,
} from 'next/experimental/testing/server'

const response = await unstable_getResponseFromNextConfig({
  url: 'https://nextjs.org/test',
  nextConfig: {
    async redirects() {
      return [{ source: '/test', destination: '/test2', permanent: false }]
    },
  },
})
expect(response.status).toEqual(307)
expect(getRedirectUrl(response)).toEqual('https://nextjs.org/test2')
```
