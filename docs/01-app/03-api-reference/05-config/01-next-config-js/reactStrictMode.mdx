> **Thông tin hữu ích**: Kể từ Next.js 13.5.1, Strict Mode là `true` theo mặc định với `app` router, vì vậy cấu hình trên chỉ cần thiết cho `pages`. Bạn vẫn có thể vô hiệu hóa Strict Mode bằng cách đặt `reactStrictMode: false`.

> **Đề xuất**: Chúng tôi đặc biệt khuyên bạn nên kích hoạt Strict Mode trong ứng dụng Next.js của mình để chuẩn bị tốt hơn cho ứng dụng của bạn cho tương lai của React.

[Strict Mode](https://react.dev/reference/react/StrictMode) của React là một tính năng chỉ dành cho chế độ phát triển để làm nổi bật các vấn đề tiềm ẩn trong ứng dụng. Nó giúp xác định các lifecycle không an toàn, việc sử dụng API cũ và một số tính năng khác.

Runtime của Next.js tuân thủ Strict Mode. Để chọn tham gia Strict Mode, hãy cấu hình tùy chọn sau trong `next.config.js` của bạn:

```js filename="next.config.js"
module.exports = {
  reactStrictMode: true,
}
```

Nếu bạn hoặc nhóm của bạn chưa sẵn sàng sử dụng Strict Mode trong toàn bộ ứng dụng, không sao cả! Bạn có thể di chuyển dần dần từng trang một bằng cách sử dụng `<React.StrictMode>`.
