Sử dụng tùy chọn `crossOrigin` để thêm [thuộc tính `crossOrigin`](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/crossorigin) vào tất cả các thẻ `<script>` được tạo bởi <AppOnly>component [`next/script`](/docs/app/guides/scripts)</AppOnly> <PagesOnly>các component [`next/script`](/docs/pages/guides/scripts) và [`next/head`](/docs/pages/api-reference/components/head)</PagesOnly>, và xác định cách xử lý các yêu cầu cross-origin.

```js filename="next.config.js"
module.exports = {
  crossOrigin: 'anonymous',
}
```

## Tùy chọn

- `'anonymous'`: Thêm thuộc tính [`crossOrigin="anonymous"`](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/crossorigin#anonymous).
- `'use-credentials'`: Thêm [`crossOrigin="use-credentials"`](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/crossorigin#use-credentials).
