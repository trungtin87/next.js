## Cách sử dụng

Turbopack FileSystem Cache cho phép Turbopack giảm công việc qua các lệnh `next dev` hoặc `next build`. Khi được kích hoạt, Turbopack sẽ lưu và khôi phục dữ liệu vào thư mục `.next` giữa các lần build, điều này có thể tăng tốc đáng kể các lần build và phiên dev tiếp theo.

> **Thông tin hữu ích:** Tính năng FileSystem Cache là Beta và vẫn đang được phát triển. Người dùng áp dụng nên mong đợi một số vấn đề về tính ổn định. Chúng tôi khuyên bạn nên áp dụng nó cho quá trình phát triển trước.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    // Kích hoạt filesystem caching cho `next dev`
    turbopackFileSystemCacheForDev: true,
    // Kích hoạt filesystem caching cho `next build`
    turbopackFileSystemCacheForBuild: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    // Kích hoạt filesystem caching cho `next dev`
    turbopackFileSystemCacheForDev: true,
    // Kích hoạt filesystem caching cho `next build`
    turbopackFileSystemCacheForBuild: true,
  },
}

module.exports = nextConfig
```

## Thay đổi phiên bản

| Phiên bản | Thay đổi                                                                       |
| --------- | ------------------------------------------------------------------------------ |
| `v16.0.0` | Phát hành Beta với các cờ riêng biệt cho build và dev                          |
| `v15.5.0` | Persistent caching được phát hành như thử nghiệm trên các bản phát hành canary |
