Next.js có thể tự động transpile và đóng gói các dependencies từ các gói cục bộ (như monorepos) hoặc từ các dependencies bên ngoài (`node_modules`). Điều này thay thế cho gói `next-transpile-modules`.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  transpilePackages: ['package-name'],
}

module.exports = nextConfig
```

## Lịch sử phiên bản

| Phiên bản | Thay đổi                           |
| --------- | ---------------------------------- |
| `v13.0.0` | `transpilePackages` được thêm vào. |
