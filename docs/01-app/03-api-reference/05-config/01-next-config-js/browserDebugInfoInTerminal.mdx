Tùy chọn `experimental.browserDebugInfoInTerminal` chuyển tiếp đầu ra console và lỗi runtime có nguồn gốc từ trình duyệt đến terminal của dev server.

Tùy chọn này bị vô hiệu hóa theo mặc định. Khi được kích hoạt, nó chỉ hoạt động trong chế độ development.

## Cách sử dụng

Kích hoạt chuyển tiếp:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    browserDebugInfoInTerminal: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    browserDebugInfoInTerminal: true,
  },
}

module.exports = nextConfig
```

### Giới hạn Serialization

Các đối tượng/mảng lồng nhau sâu được cắt ngắn bằng cách sử dụng **các giá trị mặc định hợp lý**. Bạn có thể điều chỉnh các giới hạn này:

- **depthLimit**: (tùy chọn) Giới hạn độ sâu stringification cho các đối tượng/mảng lồng nhau. Mặc định: 5
- **edgeLimit**: (tùy chọn) Số lượng thuộc tính hoặc phần tử tối đa để bao gồm cho mỗi đối tượng hoặc mảng. Mặc định: 100

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    browserDebugInfoInTerminal: {
      depthLimit: 5,
      edgeLimit: 100,
    },
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    browserDebugInfoInTerminal: {
      depthLimit: 5,
      edgeLimit: 100,
    },
  },
}

module.exports = nextConfig
```

### Vị trí Source

Các vị trí source được bao gồm theo mặc định khi tính năng này được kích hoạt.

```tsx filename="app/page.tsx" highlight={8}
'use client'

export default function Home() {
  return (
    <button
      type="button"
      onClick={() => {
        console.log('Hello World')
      }}
    >
      Click me
    </button>
  )
}
```

Nhấp vào nút sẽ in thông báo này vào terminal.

```bash filename="Terminal"
[browser] Hello World (app/page.tsx:8:17)
```

Để ẩn chúng, hãy đặt `showSourceLocation: false`.

- **showSourceLocation**: Bao gồm thông tin vị trí source khi có sẵn.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    browserDebugInfoInTerminal: {
      showSourceLocation: false,
    },
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    browserDebugInfoInTerminal: {
      showSourceLocation: false,
    },
  },
}

module.exports = nextConfig
```
