Một số tính năng thường được yêu cầu có sẵn dưới dạng plugins:

- [@next/mdx](https://github.com/vercel/next.js/tree/canary/packages/next-mdx)
- [@next/bundle-analyzer](https://github.com/vercel/next.js/tree/canary/packages/next-bundle-analyzer)

Để mở rộng việc sử dụng `webpack` của chúng tôi, bạn có thể định nghĩa một hàm mở rộng cấu hình của nó bên trong `next.config.js`, như sau:

```js filename="next.config.js"
module.exports = {
  webpack: (
    config,
    { buildId, dev, isServer, defaultLoaders, nextRuntime, webpack }
  ) => {
    // Quan trọng: trả về config đã sửa đổi
    return config
  },
}
```

> Hàm `webpack` được thực thi ba lần, hai lần cho server (nodejs / edge runtime) và một lần cho client. Điều này cho phép bạn phân biệt giữa cấu hình client và server bằng cách sử dụng thuộc tính `isServer`.

Đối số thứ hai cho hàm `webpack` là một object với các thuộc tính sau:

- `buildId`: `String` - Build id, được sử dụng làm định danh duy nhất giữa các bản build.
- `dev`: `Boolean` - Chỉ ra liệu quá trình biên dịch có được thực hiện trong development hay không.
- `isServer`: `Boolean` - Là `true` cho biên dịch phía server, và `false` cho biên dịch phía client.
- `nextRuntime`: `String | undefined` - Runtime đích cho biên dịch phía server; hoặc `"edge"` hoặc `"nodejs"`, nó là `undefined` cho biên dịch phía client.
- `defaultLoaders`: `Object` - Các loaders mặc định được sử dụng nội bộ bởi Next.js:
  - `babel`: `Object` - Cấu hình `babel-loader` mặc định.

Ví dụ sử dụng `defaultLoaders.babel`:

```js
// Example config for adding a loader that depends on babel-loader
// This source was taken from the @next/mdx plugin source:
// https://github.com/vercel/next.js/tree/canary/packages/next-mdx
module.exports = {
  webpack: (config, options) => {
    config.module.rules.push({
      test: /\.mdx/,
      use: [
        options.defaultLoaders.babel,
        {
          loader: '@mdx-js/loader',
          options: pluginOptions.options,
        },
      ],
    })

    return config
  },
}
```

#### `nextRuntime`

Lưu ý rằng `isServer` là `true` khi `nextRuntime` là `"edge"` hoặc `"nodejs"`, `nextRuntime` `"edge"` hiện chỉ dành cho proxy và Server Components trong edge runtime.
