Các tùy chọn để cấu hình hành vi Server Actions trong ứng dụng Next.js của bạn.

## `allowedOrigins`

Danh sách các miền nguồn gốc (origin) an toàn bổ sung mà từ đó Server Actions có thể được gọi. Next.js so sánh nguồn gốc của yêu cầu Server Action với miền host, đảm bảo chúng khớp để ngăn chặn các cuộc tấn công CSRF. Nếu không được cung cấp, chỉ cùng nguồn gốc được cho phép.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */

module.exports = {
  experimental: {
    serverActions: {
      allowedOrigins: ['my-proxy.com', '*.my-proxy.com'],
    },
  },
}
```

## `bodySizeLimit`

Theo mặc định, kích thước tối đa của request body được gửi đến Server Action là 1MB, để ngăn chặn việc tiêu thụ quá nhiều tài nguyên server trong việc phân tích lượng lớn dữ liệu, cũng như các cuộc tấn công DDoS tiềm ẩn.

Tuy nhiên, bạn có thể cấu hình giới hạn này bằng cách sử dụng tùy chọn `serverActions.bodySizeLimit`. Nó có thể nhận số byte hoặc bất kỳ định dạng chuỗi nào được hỗ trợ bởi bytes, ví dụ `1000`, `'500kb'` hoặc `'3mb'`.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */

module.exports = {
  experimental: {
    serverActions: {
      bodySizeLimit: '2mb',
    },
  },
}
```

## Kích hoạt Server Actions (v13)

Server Actions đã trở thành tính năng ổn định trong Next.js 14, và được kích hoạt theo mặc định. Tuy nhiên, nếu bạn đang sử dụng phiên bản Next.js cũ hơn, bạn có thể kích hoạt chúng bằng cách đặt `experimental.serverActions` thành `true`.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const config = {
  experimental: {
    serverActions: true,
  },
}

module.exports = config
```
