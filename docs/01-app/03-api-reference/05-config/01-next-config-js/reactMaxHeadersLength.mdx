---
title: reactMaxHeadersLength
description: Độ dài tối đa của các header được phát ra bởi React và thêm vào phản hồi.
---

Trong quá trình render tĩnh, React có thể phát ra các header có thể được thêm vào phản hồi. Những header này có thể được sử dụng để cải thiện hiệu suất bằng cách cho phép trình duyệt tải trước các tài nguyên như fonts, scripts, và stylesheets. Giá trị mặc định là `6000`, nhưng bạn có thể ghi đè giá trị này bằng cách cấu hình tùy chọn `reactMaxHeadersLength` trong `next.config.js`:

```js filename="next.config.js"
module.exports = {
  reactMaxHeadersLength: 1000,
}
```

> **Thông tin hữu ích**: Tùy chọn này chỉ có sẵn trong App Router.

Tùy thuộc vào loại proxy giữa trình duyệt và server, các header có thể bị cắt bớt. Ví dụ, nếu bạn đang sử dụng reverse proxy không hỗ trợ header dài, bạn nên đặt giá trị thấp hơn để đảm bảo rằng các header không bị cắt bớt.
