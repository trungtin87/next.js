Theo mặc định Next.js sẽ thêm header `x-powered-by`. Để chọn không tham gia (opt-out), hãy mở `next.config.js` và vô hiệu hóa cấu hình `poweredByHeader`:

```js filename="next.config.js"
module.exports = {
  poweredByHeader: false,
}
```
