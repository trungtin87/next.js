---
title: cacheComponents
description: Tìm hiểu cách kích hoạt cờ cacheComponents trong Next.js.
---

Cờ `cacheComponents` là một tính năng trong Next.js khiến các hoạt động data fetching trong App Router bị loại trừ khỏi pre-render trừ khi chúng được cache một cách rõ ràng. Điều này có thể hữu ích để tối ưu hóa hiệu suất của dynamic data fetching trong Server Components.

Nó hữu ích nếu ứng dụng của bạn yêu cầu data fetching mới trong runtime thay vì phục vụ từ cache được pre-render.

Nó được kỳ vọng sử dụng cùng với [`use cache`](/docs/app/api-reference/directives/use-cache) để data fetching của bạn xảy ra tại runtime theo mặc định trừ khi bạn định nghĩa các phần cụ thể của ứng dụng của bạn được cache với `use cache` ở cấp độ trang, hàm hoặc component.

## Cách sử dụng

Để kích hoạt cờ `cacheComponents`, hãy đặt nó thành `true` trong tệp `next.config.ts` của bạn:

```ts filename="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,
}

export default nextConfig
```

Khi `cacheComponents` được kích hoạt, bạn có thể sử dụng các hàm và cấu hình cache sau:

- [Chỉ thị `use cache`](/docs/app/api-reference/directives/use-cache)
- [Hàm `cacheLife`](/docs/app/api-reference/config/next-config-js/cacheLife) với `use cache`
- [Hàm `cacheTag`](/docs/app/api-reference/functions/cacheTag)

## Lưu ý

- Trong khi `cacheComponents` có thể tối ưu hóa hiệu suất bằng cách đảm bảo data fetching mới trong runtime, nó cũng có thể gây ra độ trễ bổ sung so với việc phục vụ nội dung được pre-render.

## Lịch sử phiên bản

| Phiên bản | Thay đổi                                                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 16.0.0    | `cacheComponents` được giới thiệu. Cờ này kiểm soát các cờ `ppr`, `useCache`, và `dynamicIO` như một cấu hình thống nhất duy nhất. |
