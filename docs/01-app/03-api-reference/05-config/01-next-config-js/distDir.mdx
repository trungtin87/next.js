Bạn có thể chỉ định tên để sử dụng cho thư mục build tùy chỉnh thay vì `.next`.

Mở `next.config.js` và thêm cấu hình `distDir`:

```js filename="next.config.js"
module.exports = {
  distDir: 'build',
}
```

Bây giờ nếu bạn chạy `next build` Next.js sẽ sử dụng `build` thay vì thư mục mặc định `.next`.

> `distDir` **không nên** rời khỏi thư mục dự án của bạn. Ví dụ, `../build` là một thư mục **không hợp lệ**.
