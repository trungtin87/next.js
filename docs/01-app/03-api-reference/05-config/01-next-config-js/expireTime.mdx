Bạn có thể chỉ định thời gian hết hạn `stale-while-revalidate` tùy chỉnh để các CDN sử dụng trong header `Cache-Control` cho các trang được kích hoạt ISR.

Mở `next.config.js` và thêm cấu hình `expireTime`:

```js filename="next.config.js"
module.exports = {
  // một giờ tính bằng giây
  expireTime: 3600,
}
```

Bây giờ khi gửi header `Cache-Control`, thời gian hết hạn sẽ được tính toán dựa trên khoảng thời gian revalidate cụ thể.

Ví dụ, nếu bạn có revalidate là 15 phút trên một đường dẫn và thời gian hết hạn là một giờ, header `Cache-Control` được tạo sẽ là `s-maxage=900, stale-while-revalidate=2700` để nó có thể ở trạng thái stale trong 15 phút ít hơn thời gian hết hạn đã cấu hình.
