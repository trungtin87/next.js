---
title: typedRoutes
description: Kích hoạt hỗ trợ cho các liên kết được định kiểu tĩnh (statically typed links).
---

> **Lưu ý**: Tùy chọn này đã được đánh dấu là ổn định, vì vậy bạn nên sử dụng `typedRoutes` thay vì `experimental.typedRoutes`.

Hỗ trợ cho [các liên kết được định kiểu tĩnh](/docs/app/api-reference/config/typescript#statically-typed-links). Tính năng này yêu cầu sử dụng TypeScript trong dự án của bạn.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  typedRoutes: true,
}

module.exports = nextConfig
```
