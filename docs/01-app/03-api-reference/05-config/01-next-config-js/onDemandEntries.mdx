Next.js cung cấp một số tùy chọn cho phép bạn kiểm soát cách server sẽ hủy bỏ hoặc giữ trong bộ nhớ các trang đã build trong quá trình phát triển.

Để thay đổi các giá trị mặc định, hãy mở `next.config.js` và thêm cấu hình `onDemandEntries`:

```js filename="next.config.js"
module.exports = {
  onDemandEntries: {
    // khoảng thời gian (tính bằng ms) mà server sẽ giữ các trang trong bộ đệm
    maxInactiveAge: 25 * 1000,
    // số lượng trang nên được giữ đồng thời mà không bị hủy bỏ
    pagesBufferLength: 2,
  },
}
```
