Để thêm biến môi trường vào bundle JavaScript, hãy mở `next.config.js` và thêm cấu hình `env`:

```js filename="next.config.js"
module.exports = {
  env: {
    customKey: 'my-value',
  },
}
```

Bây giờ bạn có thể truy cập `process.env.customKey` trong mã của bạn. Ví dụ:

```jsx
function Page() {
  return <h1>The value of customKey is: {process.env.customKey}</h1>
}

export default Page
```

Next.js sẽ thay thế `process.env.customKey` bằng `'my-value'` tại thời điểm build. Cố gắng destructure các biến `process.env` sẽ không hoạt động do bản chất của webpack [DefinePlugin](https://webpack.js.org/plugins/define-plugin/).

Ví dụ, dòng sau:

```jsx
return <h1>The value of customKey is: {process.env.customKey}</h1>
```

Sẽ trở thành:

```jsx
return <h1>The value of customKey is: {'my-value'}</h1>
```
