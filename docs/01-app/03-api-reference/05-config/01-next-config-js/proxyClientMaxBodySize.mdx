title: proxyClientMaxBodySize
description: Cấu hình kích thước request body tối đa khi sử dụng proxy.
version: experimental
---

Khi proxy được sử dụng, Next.js sẽ tự động clone request body và buffer nó trong bộ nhớ để cho phép đọc nhiều lần - cả trong proxy và route handler cơ bản. Để ngăn chặn việc sử dụng bộ nhớ quá mức, tùy chọn cấu hình này đặt giới hạn kích thước cho buffered body.

Theo mặc định, kích thước body tối đa là **10MB**. Nếu một request body vượt quá giới hạn này, body sẽ chỉ được buffer cho đến giới hạn đó, và một cảnh báo sẽ được ghi lại (log) cho biết route nào đã vượt quá giới hạn.

## Tùy chọn

### Định dạng String (khuyên dùng)

Chỉ định kích thước bằng định dạng chuỗi dễ đọc:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    proxyClientMaxBodySize: '1mb',
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    proxyClientMaxBodySize: '1mb',
  },
}

module.exports = nextConfig
```

Các đơn vị được hỗ trợ: `b`, `kb`, `mb`, `gb`

### Định dạng Number

Ngoài ra, chỉ định kích thước bằng bytes dưới dạng số:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    proxyClientMaxBodySize: 1048576, // 1MB tính bằng bytes
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    proxyClientMaxBodySize: 1048576, // 1MB tính bằng bytes
  },
}

module.exports = nextConfig
```

## Hành vi

Khi một request body vượt quá giới hạn đã cấu hình:

1. Next.js sẽ chỉ buffer N bytes đầu tiên (lên đến giới hạn)
2. Một cảnh báo sẽ được ghi vào console cho biết route đã vượt quá giới hạn
3. Request sẽ tiếp tục xử lý bình thường, nhưng chỉ một phần body sẽ có sẵn
4. Request sẽ **không** thất bại hoặc trả về lỗi cho client

Nếu ứng dụng của bạn cần xử lý toàn bộ request body, bạn nên:

- Tăng giới hạn `proxyClientMaxBodySize`
- Xử lý phần body bị thiếu một cách khéo léo trong logic ứng dụng của bạn

## Ví dụ

```ts filename="proxy.ts"
import { NextRequest, NextResponse } from 'next/server'

export async function proxy(request: NextRequest) {
  // Next.js tự động buffer body với giới hạn kích thước đã cấu hình
  // Bạn có thể đọc body trong proxy...
  const body = await request.text()

  // Nếu body vượt quá giới hạn, chỉ dữ liệu một phần sẽ có sẵn
  console.log('Body size:', body.length)

  return NextResponse.next()
}
```

```ts filename="app/api/upload/route.ts"
import { NextRequest, NextResponse } from 'next/server'

export async function POST(request: NextRequest) {
  // ...và body vẫn có sẵn trong route handler của bạn
  const body = await request.text()

  console.log('Body in route handler:', body.length)

  return NextResponse.json({ received: body.length })
}
```

## Cần biết

- Cài đặt này chỉ áp dụng khi proxy được sử dụng trong ứng dụng của bạn
- Giới hạn mặc định 10MB được thiết kế để cân bằng việc sử dụng bộ nhớ và các trường hợp sử dụng điển hình
- Giới hạn áp dụng cho mỗi request, không phải toàn cầu trên tất cả các request đồng thời
- Đối với các ứng dụng xử lý upload file lớn, hãy xem xét tăng giới hạn cho phù hợp
