Next.js bao gồm hỗ trợ cho [React Compiler](https://react.dev/learn/react-compiler/introduction), một công cụ được thiết kế để cải thiện hiệu suất bằng cách tự động tối ưu hóa việc render component. Điều này giảm nhu cầu memoization thủ công bằng `useMemo` và `useCallback`.

Next.js bao gồm một tối ưu hóa hiệu suất tùy chỉnh được viết bằng SWC giúp React Compiler hiệu quả hơn. Thay vì chạy compiler trên mọi tệp, Next.js phân tích dự án của bạn và chỉ áp dụng React Compiler cho các tệp liên quan. Điều này tránh công việc không cần thiết và dẫn đến các bản build nhanh hơn so với việc sử dụng plugin Babel một mình.

## Cách hoạt động

React Compiler chạy thông qua một plugin Babel. Để giữ cho các bản build nhanh, Next.js sử dụng tối ưu hóa SWC tùy chỉnh chỉ áp dụng React Compiler cho các tệp liên quan—như những tệp có JSX hoặc React Hooks.

Điều này tránh biên dịch mọi thứ và giữ chi phí hiệu suất ở mức tối thiểu. Bạn vẫn có thể thấy các bản build chậm hơn một chút so với compiler mặc định dựa trên Rust, nhưng tác động là nhỏ và được bản địa hóa.

Để sử dụng nó, hãy cài đặt `babel-plugin-react-compiler`:

```bash filename="Terminal"
npm install -D babel-plugin-react-compiler
```

Sau đó, thêm tùy chọn `reactCompiler` trong `next.config.js`:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  reactCompiler: true,
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactCompiler: true,
}

module.exports = nextConfig
```

## Annotations

Bạn có thể cấu hình compiler để chạy ở chế độ "opt-in" như sau:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  reactCompiler: {
    compilationMode: 'annotation',
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactCompiler: {
    compilationMode: 'annotation',
  },
}

module.exports = nextConfig
```

Sau đó, bạn có thể chú thích các component hoặc hook cụ thể với chỉ thị `"use memo"` từ React để chọn tham gia:

```ts filename="app/page.tsx" switcher
export default function Page() {
  'use memo'
  // ...
}
```

```js filename="app/page.js" switcher
export default function Page() {
  'use memo'
  // ...
}
```

> **Lưu ý:** Bạn cũng có thể sử dụng chỉ thị `"use no memo"` từ React để có hiệu ứng ngược lại, chọn không tham gia một component hoặc hook.
