title: isolatedDevBuild

version: experimental
---

Tùy chọn thử nghiệm `isolatedDevBuild` tách các đầu ra build development và production vào các thư mục khác nhau. Khi được kích hoạt, development server (`next dev`) ghi đầu ra của nó vào `.next/dev` thay vì `.next`, ngăn chặn xung đột khi chạy `next dev` và `next build` đồng thời.

Điều này đặc biệt hữu ích khi các công cụ tự động (ví dụ: AI agents) chạy `next build` để xác thực các thay đổi trong khi development server của bạn đang chạy, đảm bảo dev server không bị ảnh hưởng bởi các thay đổi được thực hiện bởi quá trình build.

Tính năng này được **kích hoạt theo mặc định** để giữ các đầu ra development và production riêng biệt và ngăn chặn xung đột.

## Cấu hình

Để chọn không tham gia tính năng này, hãy đặt `isolatedDevBuild` thành `false` trong cấu hình của bạn:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    isolatedDevBuild: false, // mặc định là true
  },
}

export default nextConfig
```

```js filename="next.config.mjs" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    isolatedDevBuild: false, // mặc định là true
  },
}

export default nextConfig
```
