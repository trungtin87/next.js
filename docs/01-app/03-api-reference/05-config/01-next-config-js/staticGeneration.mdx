---
title: staticGeneration*
description: Tìm hiểu cách cấu hình Static Generation trong ứng dụng Next.js của bạn.
version: experimental
---

Các tùy chọn `staticGeneration*` cho phép bạn cấu hình quá trình Static Generation cho các trường hợp sử dụng nâng cao.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    staticGenerationRetryCount: 1,
    staticGenerationMaxConcurrency: 8,
    staticGenerationMinPagesPerWorker: 25,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
const nextConfig = {
  experimental: {
    staticGenerationRetryCount: 1,
    staticGenerationMaxConcurrency: 8,
    staticGenerationMinPagesPerWorker: 25,
  },
}

export default nextConfig
```

## Tùy chọn cấu hình

Các tùy chọn sau đây có sẵn:

- `staticGenerationRetryCount`: Số lần thử lại tạo trang thất bại trước khi làm thất bại bản build.
- `staticGenerationMaxConcurrency`: Số lượng trang tối đa được xử lý trên mỗi worker.
- `staticGenerationMinPagesPerWorker`: Số lượng trang tối thiểu được xử lý trước khi khởi động một worker mới.
