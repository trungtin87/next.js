Source Maps được kích hoạt theo mặc định trong quá trình phát triển. Trong các bản build production, chúng bị vô hiệu hóa để ngăn bạn làm lộ mã nguồn của mình trên client, trừ khi bạn chọn tham gia (opt-in) cụ thể với cờ cấu hình.

Next.js cung cấp một cờ cấu hình bạn có thể sử dụng để kích hoạt tạo source map cho trình duyệt trong quá trình build production:

```js filename="next.config.js"
module.exports = {
  productionBrowserSourceMaps: true,
}
```

Khi tùy chọn `productionBrowserSourceMaps` được kích hoạt, các source map sẽ được xuất ra trong cùng thư mục với các tệp JavaScript. Next.js sẽ tự động phục vụ các tệp này khi được yêu cầu.

- Thêm source maps có thể làm tăng thời gian `next build`
- Tăng mức sử dụng bộ nhớ trong quá trình `next build`
