---
title: mdxRs
description: Sử dụng trình biên dịch Rust mới để biên dịch các tệp MDX trong App Router.
version: experimental.
---

Để sử dụng thử nghiệm với `@next/mdx`. Biên dịch các tệp MDX bằng trình biên dịch Rust mới.

```js filename="next.config.js"
const withMDX = require('@next/mdx')()

/** @type {import('next').NextConfig} */
const nextConfig = {
  pageExtensions: ['ts', 'tsx', 'mdx'],
  experimental: {
    mdxRs: true,
  },
}

module.exports = withMDX(nextConfig)
```
