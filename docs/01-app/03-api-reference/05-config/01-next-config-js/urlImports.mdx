URL imports là một tính năng thử nghiệm cho phép bạn import các module trực tiếp từ các server bên ngoài (thay vì từ ổ đĩa cục bộ).

> **Cảnh báo**: Chỉ sử dụng các domain mà bạn tin tưởng để tải xuống và thực thi trên máy của bạn. Vui lòng thận trọng và cẩn thận cho đến khi tính năng này được đánh dấu là ổn định.

Để tham gia, hãy thêm các tiền tố URL được phép vào trong `next.config.js`:

```js filename="next.config.js"
module.exports = {
  experimental: {
    urlImports: ['https://example.com/assets/', 'https://cdn.skypack.dev'],
  },
}
```

Sau đó, bạn có thể import các module trực tiếp từ các URL:

```js
import { a, b, c } from 'https://example.com/assets/some/module.js'
```

URL Imports có thể được sử dụng ở mọi nơi mà các package imports thông thường có thể được sử dụng.

## Security Model

Tính năng này được thiết kế với **bảo mật là ưu tiên hàng đầu**. Để bắt đầu, chúng tôi đã thêm một cờ thử nghiệm buộc bạn phải cho phép rõ ràng các domain mà bạn chấp nhận URL imports từ đó. Chúng tôi đang làm việc để đưa điều này đi xa hơn bằng cách giới hạn URL imports chỉ thực thi trong browser sandbox bằng cách sử dụng [Edge Runtime](/docs/app/api-reference/edge).

## Lockfile

Khi sử dụng URL imports, Next.js sẽ tạo một thư mục `next.lock` chứa một lockfile và các assets đã được lấy.
Thư mục này **phải được commit vào Git**, không được bỏ qua bởi `.gitignore`.

- Khi chạy `next dev`, Next.js sẽ tải xuống và thêm tất cả các URL Imports mới được phát hiện vào lockfile của bạn.
- Khi chạy `next build`, Next.js sẽ chỉ sử dụng lockfile để build ứng dụng cho production.

Thông thường, không cần các network requests và bất kỳ lockfile lỗi thời nào sẽ khiến build thất bại.
Một ngoại lệ là các tài nguyên phản hồi với `Cache-Control: no-cache`.
Các tài nguyên này sẽ có một entry `no-cache` trong lockfile và sẽ luôn được lấy từ network trên mỗi build.

## Examples

### Skypack

```js
import confetti from 'https://cdn.skypack.dev/canvas-confetti'
import { useEffect } from 'react'

export default () => {
  useEffect(() => {
    confetti()
  })
  return <p>Hello</p>
}
```

### Static Image Imports

```js
import Image from 'next/image'
import logo from 'https://example.com/assets/logo.png'

export default () => (
  <div>
    <Image src={logo} placeholder="blur" />
  </div>
)
```

### URLs in CSS

```css
.className {
  background: url('https://example.com/assets/hero.jpg');
}
```

### Asset Imports

```js
const logo = new URL('https://example.com/assets/file.txt', import.meta.url)

console.log(logo.pathname)

// prints "/_next/static/media/file.a9727b5d.txt"
```
