Next.js sẽ tạo [etags](https://en.wikipedia.org/wiki/HTTP_ETag) cho mọi trang theo mặc định. Bạn có thể muốn vô hiệu hóa việc tạo etag cho các trang HTML tùy thuộc vào chiến lược cache của bạn.

Mở `next.config.js` và vô hiệu hóa tùy chọn `generateEtags`:

```js filename="next.config.js"
module.exports = {
  generateEtags: false,
}
```
