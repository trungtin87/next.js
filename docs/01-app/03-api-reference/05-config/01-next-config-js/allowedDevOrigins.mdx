Next.js không tự động chặn các yêu cầu cross-origin trong quá trình phát triển, nhưng sẽ chặn theo mặc định trong phiên bản chính tiếp theo của Next.js để ngăn chặn việc yêu cầu trái phép các tài sản/endpoint nội bộ có sẵn trong chế độ phát triển.

Để cấu hình ứng dụng Next.js cho phép các yêu cầu từ các nguồn gốc khác ngoài hostname mà server được khởi tạo (`localhost` theo mặc định), bạn có thể sử dụng tùy chọn cấu hình `allowedDevOrigins`.

`allowedDevOrigins` cho phép bạn đặt các nguồn gốc bổ sung có thể được sử dụng trong chế độ phát triển. Ví dụ, để sử dụng `local-origin.dev` thay vì chỉ `localhost`, hãy mở `next.config.js` và thêm cấu hình `allowedDevOrigins`:

```js filename="next.config.js"
module.exports = {
  allowedDevOrigins: ['local-origin.dev', '*.local-origin.dev'],
}
```
