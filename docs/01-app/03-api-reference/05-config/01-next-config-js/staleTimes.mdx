`staleTimes` là một tính năng thử nghiệm cho phép caching các đoạn trang trong [client-side router cache](/docs/app/guides/caching#client-side-router-cache).

Bạn có thể kích hoạt tính năng thử nghiệm này và cung cấp thời gian revalidation tùy chỉnh bằng cách đặt cờ thử nghiệm `staleTimes`:

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    staleTimes: {
      dynamic: 30,
      static: 180,
    },
  },
}

module.exports = nextConfig
```

Các thuộc tính `static` và `dynamic` tương ứng với khoảng thời gian (tính bằng giây) dựa trên các loại [link prefetching](/docs/app/api-reference/components/link#prefetch) khác nhau.

- Thuộc tính `dynamic` được sử dụng khi trang không được tạo tĩnh cũng như không được prefetch đầy đủ (ví dụ: với `prefetch={true}`).
  - Mặc định: 0 giây (không được cache)
- Thuộc tính `static` được sử dụng cho các trang được tạo tĩnh, hoặc khi prop `prefetch` trên `Link` được đặt thành `true`, hoặc khi gọi [`router.prefetch`](/docs/app/guides/caching#routerprefetch).
  - Mặc định: 5 phút

> **Thông tin hữu ích**:
>
> - [Loading boundaries](/docs/app/api-reference/file-conventions/loading) được coi là có thể tái sử dụng cho khoảng thời gian `static` được định nghĩa trong cấu hình này.
> - Điều này không ảnh hưởng đến [partial rendering](/docs/app/getting-started/linking-and-navigating#client-side-transitions), **có nghĩa là các layout được chia sẻ sẽ không tự động được refetch trên mỗi điều hướng, chỉ có đoạn trang thay đổi.**
> - Điều này không thay đổi hành vi [back/forward caching](/docs/app/guides/caching#client-side-router-cache) để ngăn chặn layout shift và để ngăn mất vị trí cuộn của trình duyệt.

Bạn có thể tìm hiểu thêm về Client Router Cache [tại đây](/docs/app/guides/caching#client-side-router-cache).

### Lịch sử phiên bản

| Phiên bản | Thay đổi                                                     |
| --------- | ------------------------------------------------------------ |
| `v15.0.0` | Mặc định `dynamic` `staleTimes` đã thay đổi từ 30s thành 0s. |
| `v14.2.0` | `staleTimes` thử nghiệm được giới thiệu.                     |
