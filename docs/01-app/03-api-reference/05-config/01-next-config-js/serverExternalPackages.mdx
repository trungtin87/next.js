---

Các dependencies được sử dụng bên trong [Server Components](/docs/app/getting-started/server-and-client-components) và [Route Handlers](/docs/app/api-reference/file-conventions/route) sẽ tự động được đóng gói bởi Next.js.

Nếu một dependency đang sử dụng các tính năng cụ thể của Node.js, bạn có thể chọn không tham gia các dependencies cụ thể khỏi việc đóng gói Server Components và sử dụng `require` gốc của Node.js.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  serverExternalPackages: ['@acme/ui'],
}

module.exports = nextConfig
```
