`viewTransition` là một cờ thử nghiệm kích hoạt [View Transitions API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API) mới trong React. API này cho phép bạn tận dụng View Transitions browser API gốc để tạo các chuyển đổi liền mạch giữa các trạng thái UI.

Để kích hoạt tính năng này, bạn cần đặt thuộc tính `viewTransition` thành `true` trong tệp `next.config.js` của bạn.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    viewTransition: true,
  },
}

module.exports = nextConfig
```

> Thông báo quan trọng: Component `<ViewTransition>` đã có sẵn trong kênh phát hành Canary của React.
> `experimental.viewTransition` chỉ cần thiết để kích hoạt tích hợp sâu hơn với các tính năng Next.js, ví dụ: tự động
> [thêm Transition types](https://react.dev/reference/react/addTransitionType) cho các điều hướng. Các loại transition cụ thể của Next.js chưa được triển khai.

## Cách sử dụng

Bạn có thể import [Component `<ViewTransition>`](https://react.dev/reference/react/ViewTransition) từ React trong ứng dụng của mình:

```jsx
import { ViewTransition } from 'react'
```

### Demo trực tiếp

Xem [Next.js View Transition Demo](https://view-transition-example.vercel.app) của chúng tôi để thấy tính năng này hoạt động.

Khi API này phát triển, chúng tôi sẽ cập nhật tài liệu và chia sẻ thêm ví dụ. Tuy nhiên, hiện tại, chúng tôi đặc biệt khuyên bạn không nên sử dụng tính năng này trong production.
