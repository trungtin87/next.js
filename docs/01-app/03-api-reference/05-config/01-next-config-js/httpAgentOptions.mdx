Trong các phiên bản Node.js trước 18, Next.js tự động polyfill `fetch()` với [undici](/docs/architecture/supported-browsers#polyfills) và kích hoạt [HTTP Keep-Alive](https://developer.mozilla.org/docs/Web/HTTP/Headers/Keep-Alive) theo mặc định.

Để vô hiệu hóa HTTP Keep-Alive cho tất cả các cuộc gọi `fetch()` ở phía server, hãy mở `next.config.js` và thêm cấu hình `httpAgentOptions`:

```js filename="next.config.js"
module.exports = {
  httpAgentOptions: {
    keepAlive: false,
  },
}
```
