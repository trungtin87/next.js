Next.js tạo ra một ID trong quá trình `next build` để xác định phiên bản nào của ứng dụng của bạn đang được phục vụ. Cùng một bản build nên được sử dụng và khởi động nhiều container.

Nếu bạn đang build lại cho từng giai đoạn của môi trường của mình, bạn sẽ cần tạo một build ID nhất quán để sử dụng giữa các container. Sử dụng lệnh `generateBuildId` trong `next.config.js`:

```jsx filename="next.config.js"
module.exports = {
  generateBuildId: async () => {
    // Điều này có thể là bất cứ thứ gì, sử dụng git hash mới nhất
    return process.env.GIT_HASH
  },
}
```
