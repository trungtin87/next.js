## Thiết lập CDN

Để thiết lập một [CDN](https://en.wikipedia.org/wiki/Content_delivery_network), bạn có thể thiết lập một asset prefix và cấu hình origin của CDN để resolve đến domain mà Next.js được host.

Mở `next.config.mjs` và thêm cấu hình `assetPrefix` dựa trên [phase](/docs/app/api-reference/config/next-config-js#async-configuration):

```js filename="next.config.mjs"
// @ts-check
import { PHASE_DEVELOPMENT_SERVER } from 'next/constants'

export default (phase) => {
  const isDev = phase === PHASE_DEVELOPMENT_SERVER
  /**
   * @type {import('next').NextConfig}
   */
  const nextConfig = {
    assetPrefix: isDev ? undefined : 'https://cdn.mydomain.com',
  }
  return nextConfig
}
```

Next.js sẽ tự động sử dụng asset prefix của bạn cho các tệp JavaScript và CSS mà nó tải từ đường dẫn `/_next/` (thư mục `.next/static/`). Ví dụ, với cấu hình trên, yêu cầu sau cho một JS chunk:

```
/_next/static/chunks/4b9b41aaa062cbbfeff4add70f256968c51ece5d.4d708494b3aed70c04f0.js
```

Sẽ thay vào đó trở thành:

```
https://cdn.mydomain.com/_next/static/chunks/4b9b41aaa062cbbfeff4add70f256968c51ece5d.4d708494b3aed70c04f0.js
```

Cấu hình chính xác để tải các tệp của bạn lên một CDN nhất định sẽ phụ thuộc vào CDN bạn chọn. Thư mục duy nhất bạn cần host trên CDN của bạn là nội dung của `.next/static/`, nên được tải lên dưới dạng `_next/static/` như yêu cầu URL ở trên chỉ ra. **Không tải lên phần còn lại của thư mục `.next/` của bạn**, vì bạn không nên expose server code và cấu hình khác cho public.

Trong khi `assetPrefix` bao gồm các yêu cầu đến `_next/static`, nó không ảnh hưởng đến các đường dẫn sau:

<AppOnly>

- Các tệp trong thư mục [public](/docs/app/api-reference/file-conventions/public-folder); nếu bạn muốn phục vụ các assets đó qua CDN, bạn sẽ phải tự giới thiệu prefix

</AppOnly>

<PagesOnly>

- Các tệp trong thư mục [public](/docs/pages/api-reference/file-conventions/public-folder); nếu bạn muốn phục vụ các assets đó qua CDN, bạn sẽ phải tự giới thiệu prefix
- Các yêu cầu `/_next/data/` cho các trang `getServerSideProps`. Các yêu cầu này sẽ luôn được thực hiện đối với domain chính vì chúng không phải là static.
- Các yêu cầu `/_next/data/` cho các trang `getStaticProps`. Các yêu cầu này sẽ luôn được thực hiện đối với domain chính để hỗ trợ [Incremental Static Generation](/docs/pages/guides/incremental-static-regeneration), ngay cả khi bạn không sử dụng nó (để nhất quán).

</PagesOnly>
