Tùy chọn cấu hình `authInterrupts` cho phép bạn sử dụng các API [`forbidden`](/docs/app/api-reference/functions/forbidden) và [`unauthorized`](/docs/app/api-reference/functions/unauthorized) trong ứng dụng của bạn. Mặc dù các chức năng này là thử nghiệm, bạn phải kích hoạt tùy chọn `authInterrupts` trong tệp `next.config.js` của mình để sử dụng chúng:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    authInterrupts: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
module.exports = {
  experimental: {
    authInterrupts: true,
  },
}
```
