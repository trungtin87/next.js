Để triển khai ứng dụng Next.js dưới một sub-path của một miền, bạn có thể sử dụng tùy chọn cấu hình `basePath`.

`basePath` cho phép bạn đặt tiền tố đường dẫn cho ứng dụng. Ví dụ, để sử dụng `/docs` thay vì `''` (một chuỗi rỗng, mặc định), hãy mở `next.config.js` và thêm cấu hình `basePath`:

```js filename="next.config.js"
module.exports = {
  basePath: '/docs',
}
```

> **Thông tin hữu ích**: Giá trị này phải được đặt tại thời điểm build và không thể thay đổi mà không build lại vì giá trị được nhúng vào các bundle phía client.

### Links

Khi liên kết đến các trang khác bằng `next/link` và `next/router`, `basePath` sẽ được tự động áp dụng.

Ví dụ, sử dụng `/about` sẽ tự động trở thành `/docs/about` khi `basePath` được đặt thành `/docs`.

```js
export default function HomePage() {
  return (
    <>
      <Link href="/about">About Page</Link>
    </>
  )
}
```

Output html:

```html
<a href="/docs/about">About Page</a>
```

Điều này đảm bảo rằng bạn không phải thay đổi tất cả các link trong ứng dụng của mình khi thay đổi giá trị `basePath`.

### Images

<AppOnly>

Khi sử dụng component [`next/image`](/docs/app/api-reference/components/image), bạn sẽ cần thêm `basePath` vào trước `src`.

</AppOnly>

<PagesOnly>

Khi sử dụng component [`next/image`](/docs/pages/api-reference/components/image), bạn sẽ cần thêm `basePath` vào trước `src`.

</PagesOnly>

Ví dụ, sử dụng `/docs/me.png` sẽ phục vụ hình ảnh của bạn đúng cách khi `basePath` được đặt thành `/docs`.

```jsx
import Image from 'next/image'

function Home() {
  return (
    <>
      <h1>My Homepage</h1>
      <Image
        src="/docs/me.png"
        alt="Picture of the author"
        width={500}
        height={500}
      />
      <p>Welcome to my homepage!</p>
    </>
  )
}

export default Home
```
