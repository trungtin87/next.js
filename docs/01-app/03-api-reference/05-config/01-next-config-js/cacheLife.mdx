Tùy chọn `cacheLife` cho phép bạn định nghĩa **các profile cache tùy chỉnh** khi sử dụng hàm [`cacheLife`](/docs/app/api-reference/functions/cacheLife) bên trong các component hoặc hàm, và trong phạm vi của [chỉ thị `use cache`](/docs/app/api-reference/directives/use-cache).

## Cách sử dụng

Để định nghĩa một profile, hãy kích hoạt [cờ `cacheComponents`](/docs/app/api-reference/config/next-config-js/cacheComponents) và thêm profile cache trong đối tượng `cacheLife` trong tệp `next.config.js`. Ví dụ, một profile `blog`:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,
  cacheLife: {
    blog: {
      stale: 3600, // 1 giờ
      revalidate: 900, // 15 phút
      expire: 86400, // 1 ngày
    },
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
module.exports = {
  cacheComponents: true,
  cacheLife: {
    blog: {
      stale: 3600, // 1 giờ
      revalidate: 900, // 15 phút
      expire: 86400, // 1 ngày
    },
  },
}
```

Bây giờ bạn có thể sử dụng cấu hình `blog` tùy chỉnh này trong component hoặc hàm của bạn như sau:

```tsx filename="app/actions.ts" highlight={4,5} switcher
import { cacheLife } from 'next/cache'

export async function getCachedData() {
  'use cache'
  cacheLife('blog')
  const data = await fetch('/api/data')
  return data
}
```

```jsx filename="app/actions.js" highlight={4,5} switcher
import { cacheLife } from 'next/cache'

export async function getCachedData() {
  'use cache'
  cacheLife('blog')
  const data = await fetch('/api/data')
  return data
}
```

## Tham khảo

Đối tượng cấu hình có các giá trị khóa với định dạng sau:

| **Thuộc tính** | **Giá trị** | **Mô tả**                                                                                             | **Yêu cầu**                          |
| -------------- | ----------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------ |
| `stale`        | `number`    | Thời gian client nên cache một giá trị mà không kiểm tra server.                                      | Tùy chọn                             |
| `revalidate`   | `number`    | Tần suất mà cache nên làm mới trên server; các giá trị cũ có thể được phục vụ trong khi revalidating. | Tùy chọn                             |
| `expire`       | `number`    | Thời gian tối đa mà một giá trị có thể vẫn cũ trước khi chuyển sang dynamic.                          | Tùy chọn - Phải dài hơn `revalidate` |
