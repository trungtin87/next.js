## Tùy chọn

### Fetching

Bạn có thể cấu hình mức độ logging và liệu URL đầy đủ có được ghi vào console hay không khi chạy Next.js trong chế độ phát triển.

Hiện tại, `logging` chỉ áp dụng cho data fetching sử dụng API `fetch`. Nó chưa áp dụng cho các log khác bên trong Next.js.

```js filename="next.config.js"
module.exports = {
  logging: {
    fetches: {
      fullUrl: true,
    },
  },
}
```

Bất kỳ yêu cầu `fetch` nào được khôi phục từ [Server Components HMR cache](/docs/app/api-reference/config/next-config-js/serverComponentsHmrCache) đều không được ghi theo mặc định. Tuy nhiên, điều này có thể được kích hoạt bằng cách đặt `logging.fetches.hmrRefreshes` thành `true`.

```js filename="next.config.js"
module.exports = {
  logging: {
    fetches: {
      hmrRefreshes: true,
    },
  },
}
```

### Incoming Requests

Theo mặc định, tất cả các yêu cầu đến sẽ được ghi vào console trong quá trình phát triển. Bạn có thể sử dụng tùy chọn `incomingRequests` để quyết định yêu cầu nào cần bỏ qua.
Vì điều này chỉ được ghi trong quá trình phát triển, tùy chọn này không ảnh hưởng đến các bản build production.

```js filename="next.config.js"
module.exports = {
  logging: {
    incomingRequests: {
      ignore: [/\\api\\/v1\\/health/],
    },
  },
}
```

Hoặc bạn có thể vô hiệu hóa logging yêu cầu đến bằng cách đặt `incomingRequests` thành `false`.

```js filename="next.config.js"
module.exports = {
  logging: {
    incomingRequests: false,
  },
}
```

### Vô hiệu hóa Logging

Ngoài ra, bạn có thể vô hiệu hóa logging phát triển bằng cách đặt `logging` thành `false`.

```js filename="next.config.js"
module.exports = {
  logging: false,
}
```
