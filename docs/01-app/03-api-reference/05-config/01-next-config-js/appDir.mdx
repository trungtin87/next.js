> **Thông tin hữu ích**: Tùy chọn này **không còn** cần thiết kể từ Next.js 13.4. App Router hiện đã ổn định.

App Router ([thư mục `app`](/docs/app)) kích hoạt hỗ trợ cho [layouts](/docs/app/api-reference/file-conventions/layout), [Server Components](/docs/app/getting-started/server-and-client-components), [streaming](/docs/app/api-reference/file-conventions/loading), và [colocated data fetching](/docs/app/getting-started/fetching-data).

Sử dụng thư mục `app` sẽ tự động kích hoạt [React Strict Mode](https://react.dev/reference/react/StrictMode). Tìm hiểu cách [áp dụng dần dần `app`](/docs/app/guides/migrating/app-router-migration#migrating-from-pages-to-app).
