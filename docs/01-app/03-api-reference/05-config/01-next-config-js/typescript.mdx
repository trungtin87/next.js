Next.js sẽ làm thất bại **bản build production** (`next build`) của bạn khi có lỗi TypeScript trong dự án của bạn.

Nếu bạn muốn Next.js tạo mã production một cách nguy hiểm ngay cả khi ứng dụng của bạn có lỗi, bạn có thể vô hiệu hóa bước kiểm tra kiểu tích hợp sẵn.

Nếu bị vô hiệu hóa, hãy đảm bảo bạn đang chạy kiểm tra kiểu như một phần của quy trình build hoặc deploy của mình, nếu không điều này có thể rất nguy hiểm.

Mở `next.config.js` và kích hoạt tùy chọn `ignoreBuildErrors` trong cấu hình `typescript`:

```js filename="next.config.js"
module.exports = {
  typescript: {
    // !! CẢNH BÁO !!
    // Nguy hiểm cho phép các bản build production hoàn thành thành công ngay cả khi
    // dự án của bạn có lỗi kiểu.
    // !! CẢNH BÁO !!
    ignoreBuildErrors: true,
  },
}
```
