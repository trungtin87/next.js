title: useLightningcss
description: Kích hoạt hỗ trợ thử nghiệm cho Lightning CSS.

---

Hỗ trợ thử nghiệm để sử dụng [Lightning CSS](https://lightningcss.dev) với webpack. Lightning CSS là một bộ chuyển đổi và minifier CSS nhanh, được viết bằng Rust.

Nếu tùy chọn này không được đặt, Next.js trên webpack sử dụng [PostCSS](https://postcss.org/) với [`postcss-preset-env`](https://www.npmjs.com/package/postcss-preset-env) theo mặc định.

Turbopack sử dụng Lightning CSS theo mặc định kể từ Next 14.2. Tùy chọn cấu hình này không có hiệu lực trên Turbopack. Turbopack luôn sử dụng Lightning CSS.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    useLightningcss: false, // mặc định, bị bỏ qua trên Turbopack
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    useLightningcss: true, // vô hiệu hóa PostCSS trên webpack
  },
}

module.exports = nextConfig
```

## Lịch sử phiên bản

| Phiên bản | Thay đổi                                                                                                                                                                                               |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `15.1.0`  | Hỗ trợ cho `useSwcCss` đã bị xóa khỏi Turbopack.                                                                                                                                                       |
| `14.2.0`  | Bộ xử lý CSS mặc định của Turbopack đã được thay đổi từ `@swc/css` sang Lightning CSS. `useLightningcss` bị bỏ qua trên Turbopack, và tùy chọn legacy `experimental.turbo.useSwcCss` đã được thêm vào. |
