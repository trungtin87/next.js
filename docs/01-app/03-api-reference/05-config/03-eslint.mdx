Next.js cung cấp một plugin ESLint, [`@next/eslint-plugin-next`](https://www.npmjs.com/package/@next/eslint-plugin-next), đã được đóng gói trong cấu hình cơ sở giúp có thể bắt các vấn đề phổ biến trong ứng dụng Next.js.

## Cài đặt ESLint

Làm cho linting hoạt động nhanh chóng với ESLint CLI (flat config):

1. Cài đặt ESLint và cấu hình Next.js:

   ```bash package="pnpm"
   pnpm add -D eslint eslint-config-next
   ```

   ```bash package="npm"
   npm i -D eslint eslint-config-next
   ```

   ```bash package="yarn"
   yarn add --dev eslint eslint-config-next
   ```

   ```bash package="bun"
   bun add -d eslint eslint-config-next
   ```

2. Tạo `eslint.config.mjs` với cấu hình Next.js:

   ```js filename="eslint.config.mjs"
   import { defineConfig, globalIgnores } from 'eslint/config'
   import nextVitals from 'eslint-config-next/core-web-vitals'

   const eslintConfig = defineConfig([
     ...nextVitals,
     // Ghi đè các ignores mặc định của eslint-config-next.
     globalIgnores([
       // Ignores mặc định của eslint-config-next:
       '.next/**',
       'out/**',
       'build/**',
       'next-env.d.ts',
     ]),
   ])

   export default eslintConfig
   ```

3. Chạy ESLint:

   ```bash package="pnpm"
   pnpm exec eslint .
   ```

   ```bash package="npm"
   npx eslint .
   ```

   ```bash package="yarn"
   yarn eslint .
   ```

   ```bash package="bun"
   bunx eslint .
   ```

## Tham khảo

Các bộ quy tắc được đề xuất từ các plugin ESLint sau đều được sử dụng trong `eslint-config-next`:

- [`eslint-plugin-react`](https://www.npmjs.com/package/eslint-plugin-react)
- [`eslint-plugin-react-hooks`](https://www.npmjs.com/package/eslint-plugin-react-hooks)
- [`@next/eslint-plugin-next`](https://www.npmjs.com/package/@next/eslint-plugin-next)

## Ví dụ

### Chỉ định thư mục gốc trong monorepo

Nếu bạn đang sử dụng `@next/eslint-plugin-next` trong một dự án nơi Next.js không được cài đặt trong thư mục gốc của bạn (chẳng hạn như monorepo), bạn có thể cho `@next/eslint-plugin-next` biết nơi tìm ứng dụng Next.js của bạn bằng cách sử dụng thuộc tính `settings` trong `eslint.config.mjs` của bạn:

```js filename="eslint.config.mjs"
import { defineConfig } from 'eslint/config'
import eslintNextPlugin from '@next/eslint-plugin-next'

const eslintConfig = defineConfig([
  {
    plugins: {
      next: eslintNextPlugin,
    },
    settings: {
      next: {
        rootDir: 'packages/my-app/',
      },
    },
    files: [
      // ...files
    ],
    ignores: [
      // ...ignores
    ],
  },
])

export default eslintConfig
```

`rootDir` có thể là một đường dẫn (tương đối hoặc tuyệt đối), một glob (tức là `"packages/*/"`), hoặc một mảng các đường dẫn và/hoặc globs.

### Vô hiệu hóa quy tắc

Nếu bạn muốn sửa đổi hoặc vô hiệu hóa bất kỳ quy tắc nào được cung cấp bởi các plugin được hỗ trợ (`react`, `react-hooks`, `next`), bạn có thể thay đổi trực tiếp chúng bằng cách sử dụng thuộc tính `rules` trong `eslint.config.mjs` của bạn:

```js filename="eslint.config.mjs"
import { defineConfig, globalIgnores } from 'eslint/config'
import nextVitals from 'eslint-config-next/core-web-vitals'

const eslintConfig = defineConfig([
  ...nextVitals,
  {
    rules: {
      'react/no-unescaped-entities': 'off',
      '@next/next/no-page-custom-font': 'off',
    },
  },
  // Ghi đè các ignores mặc định của eslint-config-next.
  globalIgnores([
    // Ignores mặc định của eslint-config-next:
    '.next/**',
    'out/**',
    'build/**',
    'next-env.d.ts',
  ]),
])

export default eslintConfig
```

### Với Core Web Vitals

Bật bộ quy tắc `next/core-web-vitals` bằng cách mở rộng nó trong cấu hình ESLint của bạn.

```js filename="eslint.config.mjs"
import { defineConfig, globalIgnores } from 'eslint/config'
import nextVitals from 'eslint-config-next/core-web-vitals'

const eslintConfig = defineConfig([
  ...nextVitals,
  // Ghi đè các ignores mặc định của eslint-config-next.
  globalIgnores([
    // Ignores mặc định của eslint-config-next:
    '.next/**',
    'out/**',
    'build/**',
    'next-env.d.ts',
  ]),
])

export default eslintConfig
```

`next/core-web-vitals` cập nhật `@next/eslint-plugin-next` để báo lỗi trên một số quy tắc là cảnh báo theo mặc định nếu chúng ảnh hưởng đến [Core Web Vitals](https://web.dev/vitals/).

> Điểm nhập `next/core-web-vitals` được tự động bao gồm cho các ứng dụng mới được xây dựng với [Create Next App](/docs/app/api-reference/cli/create-next-app).

### Với TypeScript

Ngoài các quy tắc ESLint của Next.js, `create-next-app --typescript` cũng sẽ thêm các quy tắc lint dành riêng cho TypeScript với `next/typescript` vào cấu hình của bạn:

```js filename="eslint.config.mjs"
import { defineConfig, globalIgnores } from 'eslint/config'
import nextVitals from 'eslint-config-next/core-web-vitals'
import nextTs from 'eslint-config-next/typescript'

const eslintConfig = defineConfig([
  ...nextVitals,
  ...nextTs,
  // Ghi đè các ignores mặc định của eslint-config-next.
  globalIgnores([
    // Ignores mặc định của eslint-config-next:
    '.next/**',
    'out/**',
    'build/**',
    'next-env.d.ts',
  ]),
])

export default eslintConfig
```

Các quy tắc đó dựa trên [`plugin:@typescript-eslint/recommended`](https://typescript-eslint.io/linting/configs#recommended).
Xem [typescript-eslint > Configs](https://typescript-eslint.io/linting/configs) để biết thêm chi tiết.

### Với Prettier

ESLint cũng chứa các quy tắc định dạng mã, có thể xung đột với thiết lập [Prettier](https://prettier.io/) hiện có của bạn. Chúng tôi khuyên bạn nên bao gồm [eslint-config-prettier](https://github.com/prettier/eslint-config-prettier) trong cấu hình ESLint của bạn để làm cho ESLint và Prettier hoạt động cùng nhau.

Đầu tiên, cài đặt phụ thuộc:

```bash package="pnpm"
pnpm add -D eslint-config-prettier
```

```bash package="npm"
npm i -D eslint-config-prettier
```

```bash package="yarn"
yarn add --dev eslint-config-prettier
```

```bash package="bun"
bun add -d eslint-config-prettier
```

Sau đó, thêm `prettier` vào cấu hình ESLint hiện có của bạn:

```js filename="eslint.config.mjs"
import { defineConfig, globalIgnores } from 'eslint/config'
import nextVitals from 'eslint-config-next/core-web-vitals'
import prettier from 'eslint-config-prettier/flat'

const eslintConfig = defineConfig([
  ...nextVitals,
  prettier,
  // Ghi đè các ignores mặc định của eslint-config-next.
  globalIgnores([
    // Ignores mặc định của eslint-config-next:
    '.next/**',
    'out/**',
    'build/**',
    'next-env.d.ts',
  ]),
])

export default eslintConfig
```

### Chạy lint trên các tệp đã staged

Nếu bạn muốn sử dụng ESLint với [lint-staged](https://github.com/okonet/lint-staged) để chạy linter trên các tệp git đã staged, hãy thêm phần sau vào tệp `.lintstagedrc.js` trong thư mục gốc của dự án của bạn:

```js filename=".lintstagedrc.js"
const path = require('path')

const buildEslintCommand = (filenames) =>
  `eslint --fix ${filenames
    .map((f) => `"${path.relative(process.cwd(), f)}"`)
    .join(' ')}`

module.exports = {
  '*.{js,jsx,ts,tsx}': [buildEslintCommand],
}
```

### Di chuyển cấu hình hiện có

Nếu bạn đã cấu hình ESLint trong ứng dụng của mình, chúng tôi khuyên bạn nên mở rộng trực tiếp từ plugin này thay vì bao gồm `eslint-config-next` trừ khi một vài điều kiện được đáp ứng.

#### Bộ quy tắc plugin được đề xuất

Nếu các điều kiện sau là đúng:

- Bạn đã cài đặt một hoặc nhiều plugin sau (riêng biệt hoặc thông qua một cấu hình khác như `airbnb` hoặc `react-app`):
  - `react`
  - `react-hooks`
  - `jsx-a11y`
  - `import`
- Bạn đã xác định `parserOptions` cụ thể khác với cách Babel được cấu hình trong Next.js (điều này không được khuyến nghị trừ khi bạn đã [tùy chỉnh cấu hình Babel của mình](/docs/pages/guides/babel))
- Bạn đã cài đặt `eslint-plugin-import` với Node.js và/hoặc TypeScript [resolvers](https://github.com/benmosher/eslint-plugin-import#resolvers) được xác định để xử lý imports

Sau đó, chúng tôi khuyên bạn nên xóa các cài đặt này nếu bạn thích cách các thuộc tính này đã được cấu hình trong [`eslint-config-next`](https://github.com/vercel/next.js/blob/canary/packages/eslint-config-next/index.js) hoặc mở rộng trực tiếp từ plugin Next.js ESLint thay thế:

```js
module.exports = {
  extends: [
    //...
    'plugin:@next/next/recommended',
  ],
}
```

Plugin có thể được cài đặt bình thường trong dự án của bạn:

```bash package="pnpm"
pnpm add -D @next/eslint-plugin-next
```

```bash package="npm"
npm i -D @next/eslint-plugin-next
```

```bash package="yarn"
yarn add --dev @next/eslint-plugin-next
```

```bash package="bun"
bun add -d @next/eslint-plugin-next
```

Điều này giúp loại bỏ nguy cơ xung đột hoặc lỗi có thể xảy ra do việc import cùng một plugin hoặc parser qua nhiều cấu hình.

#### Cấu hình bổ sung

Nếu bạn đã sử dụng một cấu hình ESLint riêng biệt và muốn bao gồm `eslint-config-next`, hãy đảm bảo rằng nó được mở rộng cuối cùng sau các cấu hình khác. Ví dụ:

```js filename="eslint.config.mjs"
import { defineConfig, globalIgnores } from 'eslint/config'
import nextPlugin from '@next/eslint-plugin-next'

const eslintConfig = defineConfig([
  nextPlugin.configs['core-web-vitals'],
  // Danh sách các mẫu bỏ qua.
  globalIgnores([]),
])

export default eslintConfig
```

Cấu hình `next` đã xử lý việc thiết lập các giá trị mặc định cho các thuộc tính `parser`, `plugins` và `settings`. Không cần phải khai báo lại thủ công bất kỳ thuộc tính nào trong số này trừ khi bạn cần một cấu hình khác cho trường hợp sử dụng của mình.

Nếu bạn bao gồm bất kỳ cấu hình có thể chia sẻ nào khác, **bạn sẽ cần đảm bảo rằng các thuộc tính này không bị ghi đè hoặc sửa đổi**. Nếu không, chúng tôi khuyên bạn nên xóa bất kỳ cấu hình nào chia sẻ hành vi với cấu hình `next` hoặc mở rộng trực tiếp từ plugin Next.js ESLint như đã đề cập ở trên.
