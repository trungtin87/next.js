Next.js có hai server runtimes mà bạn có thể sử dụng trong ứng dụng của mình:

- **Node.js Runtime** (mặc định), có quyền truy cập vào tất cả các API Node.js và được sử dụng để render ứng dụng của bạn.
- **Edge Runtime** chứa một [tập hợp các API](#reference) hạn chế hơn, được sử dụng trong [Proxy](/docs/app/api-reference/file-conventions/proxy).

## Những lưu ý

- Edge Runtime không hỗ trợ tất cả các API Node.js. Một số gói có thể không hoạt động như mong đợi.
- Edge Runtime không hỗ trợ Incremental Static Regeneration (ISR).
- Cả hai runtimes đều có thể hỗ trợ [streaming](/docs/app/api-reference/file-conventions/loading) tùy thuộc vào bộ điều hợp triển khai (deployment adapter) của bạn.

### Các API không được hỗ trợ

Edge Runtime có một số hạn chế bao gồm:

- Các API Node.js gốc **không được hỗ trợ**. Ví dụ, bạn không thể đọc hoặc ghi vào hệ thống tệp.
- `node_modules` _có thể_ được sử dụng, miễn là chúng triển khai ES Modules và không sử dụng các API Node.js gốc.
- Gọi `require` trực tiếp là **không được phép**. Sử dụng ES Modules thay thế.

Các tính năng ngôn ngữ JavaScript sau bị tắt, và **sẽ không hoạt động:**

| [`WebAssembly.compile`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/WebAssembly/compile)         | Biên dịch một mô-đun WebAssembly từ nguồn bộ đệm             |
| [`WebAssembly.instantiate`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/WebAssembly/instantiate) | Biên dịch và khởi tạo một mô-đun WebAssembly từ nguồn bộ đệm |

Trong một số trường hợp hiếm hoi, mã của bạn có thể chứa (hoặc nhập) một số câu lệnh đánh giá mã động mà _không thể truy cập được khi chạy_ và không thể bị loại bỏ bởi treeshaking.
Bạn có thể nới lỏng kiểm tra để cho phép các tệp cụ thể với cấu hình Proxy của mình:

```javascript filename="proxy.ts"
export const config = {
  unstable_allowDynamic: [
    // cho phép một tệp duy nhất
    '/lib/utilities.js',
    // sử dụng glob để cho phép bất kỳ thứ gì trong mô-đun bên thứ 3 function-bind
    '**/node_modules/function-bind/**',
  ],
}
```

`unstable_allowDynamic` là một [glob](https://github.com/micromatch/micromatch#matching-features), hoặc một mảng các globs, bỏ qua đánh giá mã động cho các tệp cụ thể. Các globs là tương đối với thư mục gốc ứng dụng của bạn.

Hãy cảnh báo rằng nếu các câu lệnh này được thực thi trên Edge, _chúng sẽ ném ra lỗi và gây ra lỗi runtime_.
