Chỉ thị `'use client'` khai báo một entry point cho các component sẽ được render ở **phía client** và nên được sử dụng khi tạo các giao diện người dùng tương tác (UI) yêu cầu khả năng JavaScript phía client, chẳng hạn như quản lý state, xử lý sự kiện và truy cập vào các browser APIs. Đây là một tính năng của React.

> **Nên biết:**
>
> Bạn không cần thêm chỉ thị `'use client'` vào mọi tệp chứa Client Components. Bạn chỉ cần thêm nó vào các tệp có các component bạn muốn render trực tiếp trong Server Components. Chỉ thị `'use client'` định nghĩa [boundary](https://nextjs.org/docs/app/building-your-application/rendering#network-boundary) client-server, và các component được export từ tệp như vậy phục vụ như các entry points cho client.

## Cách sử dụng

Để khai báo một entry point cho Client Components, hãy thêm chỉ thị `'use client'` **ở đầu tệp**, trước bất kỳ imports nào:

```tsx filename="app/components/counter.tsx" highlight={1} switcher
'use client'

import { useState } from 'react'

export default function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  )
}
```

```jsx filename="app/components/counter.js" highlight={1} switcher
'use client'

import { useState } from 'react'

export default function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  )
}
```

Khi sử dụng chỉ thị `'use client'`, các props của Client Components phải là [serializable](https://react.dev/reference/rsc/use-client#serializable-types). Điều này có nghĩa là các props cần ở định dạng mà React có thể serialize khi gửi dữ liệu từ server đến client.

```tsx filename="app/components/counter.tsx" highlight={4} switcher
'use client'

export default function Counter({
  onClick /* ❌ Function không serializable */,
}) {
  return (
    <div>
      <button onClick={onClick}>Increment</button>
    </div>
  )
}
```

```jsx filename="app/components/counter.js" highlight={4} switcher
'use client'

export default function Counter({
  onClick /* ❌ Function không serializable */,
}) {
  return (
    <div>
      <button onClick={onClick}>Increment</button>
    </div>
  )
}
```

## Lồng Client Components trong Server Components

Kết hợp Server và Client Components cho phép bạn xây dựng các ứng dụng vừa hiệu suất vừa tương tác:

1. **Server Components**: Sử dụng cho nội dung tĩnh, data fetching và các phần tử thân thiện với SEO.
2. **Client Components**: Sử dụng cho các phần tử tương tác yêu cầu state, effects hoặc browser APIs.
3. **Component composition**: Lồng Client Components trong Server Components khi cần thiết để tách biệt rõ ràng logic server và client.

Trong ví dụ sau:

- `Header` là một Server Component xử lý nội dung tĩnh.
- `Counter` là một Client Component cho phép tương tác trong trang.

```tsx filename="app/page.tsx" highlight={2,8} switcher
import Header from './header'
import Counter from './counter' // This is a Client Component

export default function Page() {
  return (
    <div>
      <Header />
      <Counter />
    </div>
  )
}
```

```jsx filename="app/page.js" highlight={2,8} switcher
import Header from './header'
import Counter from './counter' // This is a Client Component

export default function Page() {
  return (
    <div>
      <Header />
      <Counter />
    </div>
  )
}
```
