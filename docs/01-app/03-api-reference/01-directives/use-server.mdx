Chỉ thị `use server` chỉ định một hàm hoặc file sẽ được thực thi ở **phía server**. Nó có thể được sử dụng ở đầu file để chỉ ra rằng tất cả các hàm trong file đều chạy phía server, hoặc inline ở đầu một hàm để đánh dấu hàm đó là một [Server Function](https://19.react.dev/reference/rsc/server-functions). Đây là một tính năng của React.

## Sử dụng `use server` ở đầu file

Ví dụ sau đây cho thấy một file có chỉ thị `use server` ở đầu. Tất cả các hàm trong file sẽ được thực thi trên server.

```tsx filename="app/actions.ts" highlight={1} switcher
'use server'
import { db } from '@/lib/db' // Database client của bạn

export async function createUser(data: { name: string; email: string }) {
  const user = await db.user.create({ data })
  return user
}
```

```jsx filename="app/actions.js" highlight={1} switcher
'use server'
import { db } from '@/lib/db' // Database client của bạn

export async function createUser(data) {
  const user = await db.user.create({ data })
  return user
}
```

### Sử dụng Server Functions trong Client Component

Để sử dụng Server Functions trong Client Components, bạn cần tạo Server Functions trong một file riêng biệt sử dụng chỉ thị `use server` ở đầu file. Các Server Functions này sau đó có thể được import vào Client và Server Components và thực thi.

Giả sử bạn có một Server Function `fetchUsers` trong `actions.ts`:

```tsx filename="app/actions.ts" highlight={1} switcher
'use server'
import { db } from '@/lib/db' // Database client của bạn

export async function fetchUsers() {
  const users = await db.user.findMany()
  return users
}
```

```jsx filename="app/actions.js" highlight={1} switcher
'use server'
import { db } from '@/lib/db' // Database client của bạn

export async function fetchUsers() {
  const users = await db.user.findMany()
  return users
}
```

Sau đó bạn có thể import Server Function `fetchUsers` vào một Client Component và thực thi nó ở phía client.

```tsx filename="app/components/my-button.tsx" highlight={1,2,8} switcher
'use client'
import { fetchUsers } from '../actions'

export default function MyButton() {
  return <button onClick={() => fetchUsers()}>Lấy Danh Sách Users</button>
}
```

```jsx filename="app/components/my-button.js" highlight={1,2,8} switcher
'use client'
import { fetchUsers } from '../actions'

export default function MyButton() {
  return <button onClick={() => fetchUsers()}>Lấy Danh Sách Users</button>
}
```

## Sử dụng `use server` inline

Trong ví dụ sau, `use server` được sử dụng inline ở đầu một hàm để đánh dấu nó là một [Server Function](https://19.react.dev/reference/rsc/server-functions):

```tsx filename="app/posts/[id]/page.tsx" switcher highlight={8}
import { EditPost } from './edit-post'
import { revalidatePath } from 'next/cache'

export default async function PostPage({ params }: { params: { id: string } }) {
  const post = await getPost(params.id)

  async function updatePost(formData: FormData) {
    'use server'
    await savePost(params.id, formData)
    revalidatePath(`/posts/${params.id}`)
  }

  return <EditPost updatePostAction={updatePost} post={post} />
}
```

```jsx filename="app/posts/[id]/page.js" switcher highlight={8}
import { EditPost } from './edit-post'
import { revalidatePath } from 'next/cache'

export default async function PostPage({ params }) {
  const post = await getPost(params.id)

  async function updatePost(formData) {
    'use server'
    await savePost(params.id, formData)
    revalidatePath(`/posts/${params.id}`)
  }

  return <EditPost updatePostAction={updatePost} post={post} />
}
```

## Các vấn đề bảo mật cần lưu ý

Khi sử dụng chỉ thị `use server`, điều quan trọng là phải đảm bảo rằng tất cả logic phía server đều an toàn và dữ liệu nhạy cảm được bảo vệ.

### Xác thực và phân quyền

Luôn xác thực và phân quyền người dùng trước khi thực hiện các thao tác nhạy cảm phía server.

```tsx filename="app/actions.ts" highlight={1,7,8,9,10} switcher
'use server'

import { db } from '@/lib/db' // Database client của bạn
import { authenticate } from '@/lib/auth' // Thư viện xác thực của bạn

export async function createUser(
  data: { name: string; email: string },
  token: string
) {
  const user = authenticate(token)
  if (!user) {
    throw new Error('Unauthorized')
  }
  const newUser = await db.user.create({ data })
  return newUser
}
```

```jsx filename="app/actions.js" highlight={1,7,8,9,10} switcher
'use server'

import { db } from '@/lib/db' // Database client của bạn
import { authenticate } from '@/lib/auth' // Thư viện xác thực của bạn

export async function createUser(data, token) {
  const user = authenticate(token)
  if (!user) {
    throw new Error('Unauthorized')
  }
  const newUser = await db.user.create({ data })
  return newUser
}
```
