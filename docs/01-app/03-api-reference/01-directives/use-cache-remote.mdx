Chỉ thị `'use cache: remote'` kích hoạt caching của **dữ liệu được chia sẻ** trong các ngữ cảnh động mà [`use cache`](/docs/app/api-reference/directives/use-cache) thông thường sẽ không hoạt động, ví dụ sau khi gọi [`await connection()`](/docs/app/api-reference/functions/connection), [`await cookies()`](/docs/app/api-reference/functions/cookies) hoặc [`await headers()`](/docs/app/api-reference/functions/headers).

> **Lưu ý:**
>
> - Kết quả được lưu trữ trong các cache handlers phía server và được chia sẻ giữa tất cả người dùng.
> - Đối với **dữ liệu dành riêng cho người dùng** phụ thuộc vào [`await cookies()`](/docs/app/api-reference/functions/cookies) hoặc [`await headers()`](/docs/app/api-reference/functions/headers), hãy sử dụng [`'use cache: private'`](/docs/app/api-reference/directives/use-cache-private) thay thế.

## Cách sử dụng

Để sử dụng `'use cache: remote'`, kích hoạt cờ [`cacheComponents`](/docs/app/api-reference/config/next-config-js/cacheComponents) trong file `next.config.ts` của bạn:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  cacheComponents: true,
}

export default nextConfig
```

Sau đó thêm `'use cache: remote'` vào hàm của bạn cần cache dữ liệu trong ngữ cảnh động.

### Ví dụ cơ bản

Cache giá sản phẩm cần được lấy tại thời điểm request nhưng có thể được chia sẻ giữa tất cả người dùng. Sử dụng [`cacheLife`](/docs/app/api-reference/functions/cacheLife#custom-cache-profiles) để đặt thời gian tồn tại cache của giá.

```tsx filename="app/product/[id]/page.tsx" switcher
import { Suspense } from 'react'
import { connection } from 'next/server'
import { cacheTag, cacheLife } from 'next/cache'

export default async function ProductPage({
  params,
}: {
  params: Promise<{ id: string }>
}) {
  const { id } = await params

  return (
    <div>
      <ProductDetails id={id} />
      <Suspense fallback={<div>Đang tải giá...</div>}>
        <ProductPrice productId={id} />
      </Suspense>
    </div>
  )
}

function ProductDetails({ id }: { id: string }) {
  return <div>Sản phẩm: {id}</div>
}

async function ProductPrice({ productId }: { productId: string }) {
  // Gọi connection() làm cho component này động, ngăn
  // nó được bao gồm trong static shell. Điều này đảm bảo giá
  // luôn được lấy tại thời điểm request.
  await connection()

  // Bây giờ chúng ta có thể cache giá trong remote cache handler.
  // 'use cache' thông thường sẽ KHÔNG hoạt động ở đây vì chúng ta đang trong ngữ cảnh động.
  const price = await getProductPrice(productId)

  return <div>Giá: ${price}</div>
}

async function getProductPrice(productId: string) {
  'use cache: remote'
  cacheTag(`product-price-${productId}`)
  cacheLife({ expire: 3600 }) // 1 giờ

  // Database query này được cache và chia sẻ giữa tất cả người dùng
  return db.products.getPrice(productId)
}
```

> **Lưu ý:** [`use cache`](/docs/app/api-reference/directives/use-cache) thông thường sẽ không cache bất cứ thứ gì khi được sử dụng trong ngữ cảnh động (sau [`await connection()`](/docs/app/api-reference/functions/connection), [`await cookies()`](/docs/app/api-reference/functions/cookies), [`await headers()`](/docs/app/api-reference/functions/headers), v.v.). Sử dụng `'use cache: remote'` để kích hoạt runtime caching trong các tình huống này.

## Sự khác biệt giữa `use cache: remote` với `use cache` và `use cache: private`

Next.js cung cấp ba chỉ thị caching, mỗi chỉ thị được thiết kế cho các trường hợp sử dụng khác nhau:

| Tính năng                         | `use cache`                              | `'use cache: remote'`                                            | `'use cache: private'`                               |
| --------------------------------- | ---------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------- |
| **Hoạt động trong ngữ cảnh động** | Không (yêu cầu ngữ cảnh tĩnh)            | Có (được thiết kế cho ngữ cảnh động)                             | Có                                                   |
| **Truy cập `await cookies()`**    | Không                                    | Không                                                            | Có                                                   |
| **Truy cập `await headers()`**    | Không                                    | Không                                                            | Có                                                   |
| **Sau `await connection()`**      | Không (sẽ không cache)                   | Không                                                            | Không                                                |
| **Lưu trữ trong cache handler**   | Có (phía server)                         | Có (phía server)                                                 | Không (chỉ phía client)                              |
| **Phạm vi cache**                 | Toàn cục (được chia sẻ)                  | Toàn cục (được chia sẻ)                                          | Theo người dùng (cô lập)                             |
| **Hỗ trợ runtime prefetching**    | N/A (pre-rendered tại build)             | Không                                                            | Có (khi được cấu hình)                               |
| **Trường hợp sử dụng**            | Nội dung tĩnh, được chia sẻ (build-time) | Nội dung động, được chia sẻ trong runtime contexts (per-request) | Nội dung được cá nhân hóa, dành riêng cho người dùng |

> **Lưu ý:** Mặc dù bạn không thể gọi `await cookies()` hoặc `await headers()` bên trong `'use cache: remote'`, bạn có thể đọc các giá trị trước khi gọi một hàm được bao bọc bởi `'use cache: remote'` và các đối số sẽ được bao gồm trong cache key. Lưu ý rằng điều này không được khuyến nghị vì nó sẽ tăng đáng kể kích thước cache và giảm tỷ lệ cache hit.

### Khi nào sử dụng mỗi chỉ thị

Chọn chỉ thị caching phù hợp dựa trên trường hợp sử dụng của bạn:

**Sử dụng [`use cache`](/docs/app/api-reference/directives/use-cache) khi:**

- Nội dung có thể được prerender tại build time
- Nội dung được chia sẻ giữa tất cả người dùng
- Nội dung không phụ thuộc vào dữ liệu cụ thể của request

**Sử dụng `'use cache: remote'` khi:**

- Bạn cần caching trong ngữ cảnh động
- Nội dung được chia sẻ giữa người dùng nhưng phải được render theo từng request (sau `await connection()`)
- Bạn muốn cache các thao tác tốn kém trong server-side cache handler

**Sử dụng [`'use cache: private'`](/docs/app/api-reference/directives/use-cache-private) khi:**

- Nội dung được cá nhân hóa theo người dùng (phụ thuộc vào cookies, headers)
- Bạn cần [runtime prefetching](/docs/app/guides/prefetching) của nội dung dành riêng cho người dùng
- Nội dung không bao giờ được chia sẻ giữa người dùng

## Cách hoạt động

Chỉ thị `'use cache: remote'` kích hoạt runtime caching của dữ liệu được chia sẻ trong các ngữ cảnh động bằng cách lưu trữ kết quả trong các server-side cache handlers thay vì prerender tại build time.

### Phát hiện ngữ cảnh động

Khi Next.js gặp các API nhất định như [`connection()`](/docs/app/api-reference/functions/connection), [`cookies()`](/docs/app/api-reference/functions/cookies), hoặc [`headers()`](/docs/app/api-reference/functions/headers), ngữ cảnh trở thành "động". Trong ngữ cảnh động:

1. **`use cache` thông thường ngừng hoạt động** - nó sẽ không cache bất cứ thứ gì
2. **`'use cache: remote'` tiếp tục hoạt động** - nó được cache bởi remote cache handler.
3. **Kết quả được lưu trữ phía server** trong key-value store được cấu hình cho deployment của bạn
4. **Dữ liệu được cache được chia sẻ giữa các requests** - giảm tải database và origin requests

> **Lưu ý:** Không có `'use cache: remote'`, các hàm trong ngữ cảnh động sẽ thực thi trên mỗi request, có thể tạo ra các bottleneck về hiệu suất. Remote caching loại bỏ vấn đề này bằng cách lưu trữ kết quả trong các server-side cache handlers.

### Hành vi lưu trữ

Remote caches được **lưu trữ bằng cách sử dụng server-side cache handlers**, có thể bao gồm:

- **Distributed key-value stores** (in-memory hoặc persistent storage solutions)
- **File system hoặc in-memory storage** (thường được sử dụng trong development hoặc cho custom deployments)
- **Environment-specific caches** (được cung cấp bởi hosting infrastructure của bạn)
- **Custom hoặc configured cache handlers** (tùy thuộc vào thiết lập ứng dụng của bạn)

Điều này có nghĩa là:

1. Dữ liệu được cache được chia sẻ giữa tất cả người dùng và requests
2. Cache entries tồn tại vượt ra ngoài một phiên làm việc đơn lẻ
3. Cache invalidation hoạt động thông qua [`cacheTag`](/docs/app/api-reference/functions/cacheTag) và [`revalidateTag`](/docs/app/api-reference/functions/revalidateTag)
4. Cache expiration được kiểm soát bởi cấu hình [`cacheLife`](/docs/app/api-reference/functions/cacheLife)

### Ví dụ về ngữ cảnh động

```tsx
async function UserDashboard() {
  // Gọi connection() làm cho ngữ cảnh trở nên động
  await connection()

  // Không có chỉ thị caching nào, điều này chạy trên mỗi request
  const stats = await getStats()

  // Với 'use cache: remote', điều này được cache trong remote handler
  const analytics = await getAnalytics()

  return (
    <div>
      <Stats data={stats} />
      <Analytics data={analytics} />
    </div>
  )
}

async function getAnalytics() {
  'use cache: remote'
  cacheLife({ expire: 300 }) // 5 phút

  // Thao tác tốn kém này được cache và chia sẻ giữa tất cả requests
  return fetchAnalyticsData()
}
```

## Request APIs và remote caches

Mặc dù `'use cache: remote'` về mặt kỹ thuật cho phép truy cập vào dữ liệu cụ thể của request bằng cách gọi các API như [`cookies()`](/docs/app/api-reference/functions/cookies) và [`headers()`](/docs/app/api-reference/functions/headers) trước khi gọi một hàm được bao bọc bởi `'use cache: remote'`, nhưng nói chung không được khuyến nghị sử dụng chúng cùng nhau:

| API | Được phép trong `use cache` | Được phép trong `'use cache: remote'` | Được khuyến nghị |\n| ------------------------------------------------------------------------------------- | ---------------------- | -------------------------------- | ------------------------------------------------------------------------------------------ |
| [`cookies()`](/docs/app/api-reference/functions/cookies) | Không | Không | Sử dụng [`'use cache: private'`](/docs/app/api-reference/directives/use-cache-private) thay thế |
| [`headers()`](/docs/app/api-reference/functions/headers) | Không | Không | Sử dụng [`'use cache: private'`](/docs/app/api-reference/directives/use-cache-private) thay thế |
| [`connection()`](/docs/app/api-reference/functions/connection) | Không | Không | Không - chúng không bao giờ có thể được cache |
| [`searchParams`](/docs/app/api-reference/file-conventions/page#searchparams-optional) | Không | Không | Sử dụng [`'use cache: private'`](/docs/app/api-reference/directives/use-cache-private) thay thế |

> **Quan trọng:** Nếu bạn cần cache dựa trên cookies, headers, hoặc search params, hãy sử dụng [`'use cache: private'`](/docs/app/api-reference/directives/use-cache-private) thay thế. Remote caches được chia sẻ giữa tất cả người dùng, vì vậy caching dữ liệu dành riêng cho người dùng trong chúng có thể dẫn đến kết quả không chính xác được phục vụ cho người dùng khác nhau.

## Quy tắc lồng nhau

Remote caches có các quy tắc lồng nhau cụ thể:

- Remote caches **có thể** được lồng bên trong các remote caches khác (`'use cache: remote'`)
- Remote caches **có thể** được lồng bên trong regular caches (`'use cache'`)
- Remote caches **không thể** được lồng bên trong private caches (`'use cache: private'`)
- Private caches **không thể** được lồng bên trong remote caches

```tsx
// HỢP LỆ: Remote bên trong remote
async function outerRemote() {
  'use cache: remote'
  const result = await innerRemote()
  return result
}

async function innerRemote() {
  'use cache: remote'
  return getData()
}

// HỢP LỆ: Remote bên trong regular cache
async function outerCache() {
  'use cache'
  // Nếu điều này trong ngữ cảnh động, inner remote cache sẽ hoạt động
  const result = await innerRemote()
  return result
}

async function innerRemote() {
  'use cache: remote'
  return getData()
}

// KHÔNG HỢP LỆ: Remote bên trong private
async function outerPrivate() {
  'use cache: private'
  const result = await innerRemote() // Lỗi!
  return result
}

async function innerRemote() {
  'use cache: remote'
  return getData()
}

// KHÔNG HỢP LỆ: Private bên trong remote
async function outerRemote() {
  'use cache: remote'
  const result = await innerPrivate() // Lỗi!
  return result
}

async function innerPrivate() {
  'use cache: private'
  return getData()
}
```

## Ví dụ

Các ví dụ sau đây minh họa các pattern phổ biến để sử dụng `'use cache: remote'`. Để biết chi tiết về các tham số `cacheLife` (`stale`, `revalidate`, `expire`), xem [tài liệu API `cacheLife`](/docs/app/api-reference/functions/cacheLife).

### Database queries theo từng request

Cache các database queries tốn kém được truy cập trong ngữ cảnh động, giảm tải trên database của bạn:

```tsx filename="app/dashboard/page.tsx"
import { connection } from 'next/server'
import { cacheLife, cacheTag } from 'next/cache'

export default async function DashboardPage() {
  // Làm cho ngữ cảnh trở nên động
  await connection()

  const stats = await getGlobalStats()

  return <StatsDisplay stats={stats} />
}

async function getGlobalStats() {
  'use cache: remote'
  cacheTag('global-stats')
  cacheLife({ expire: 60 }) // 1 phút

  // Database query tốn kém này được cache và chia sẻ giữa tất cả người dùng,
  // giảm tải trên database của bạn
  const stats = await db.analytics.aggregate({
    total_users: 'count',
    active_sessions: 'count',
    revenue: 'sum',
  })

  return stats
}
```

### API responses trong streaming contexts

Cache các API responses được lấy trong quá trình streaming hoặc sau các thao tác động:

```tsx filename="app/feed/page.tsx"
import { Suspense } from 'react'
import { connection } from 'next/server'
import { cacheLife, cacheTag } from 'next/cache'

export default async function FeedPage() {
  return (
    <div>
      <Suspense fallback={<Skeleton />}>
        <FeedItems />
      </Suspense>
    </div>
  )
}

async function FeedItems() {
  // Ngữ cảnh động
  await connection()

  const items = await getFeedItems()

  return items.map((item) => <FeedItem key={item.id} item={item} />)
}

async function getFeedItems() {
  'use cache: remote'
  cacheTag('feed-items')
  cacheLife({ expire: 120 }) // 2 phút

  // API call này được cache, giảm requests đến external service của bạn
  const response = await fetch('https://api.example.com/feed')
  return response.json()
}
```

### Dữ liệu được tính toán sau các kiểm tra động

Cache các tính toán tốn kém xảy ra sau các kiểm tra bảo mật hoặc tính năng động:

```tsx filename="app/reports/page.tsx"
import { connection } from 'next/server'
import { cacheLife } from 'next/cache'

export default async function ReportsPage() {
  // Kiểm tra bảo mật động
  await connection()

  const report = await generateReport()

  return <ReportViewer report={report} />
}

async function generateReport() {
  'use cache: remote'
  cacheLife({ expire: 3600 }) // 1 giờ

  // Tính toán tốn kém này được cache và chia sẻ giữa tất cả người dùng được ủy quyền,
  // tránh các tính toán lặp lại
  const data = await db.transactions.findMany()

  return {
    totalRevenue: calculateRevenue(data),
    topProducts: analyzeProducts(data),
    trends: calculateTrends(data),
  }
}
```

### Các chiến lược caching hỗn hợp

Kết hợp static, remote, và private caching để đạt hiệu suất tối ưu:

```tsx filename="app/product/[id]/page.tsx"
import { Suspense } from 'react'
import { connection } from 'next/server'
import { cookies } from 'next/headers'
import { cacheLife, cacheTag } from 'next/cache'

// Dữ liệu sản phẩm tĩnh - prerendered tại build time
async function getProduct(id: string) {
  'use cache'
  cacheTag(`product-${id}`)

  // Điều này được cache tại build time và chia sẻ giữa tất cả người dùng
  return db.products.find({ where: { id } })
}

// Dữ liệu giá được chia sẻ - cached tại runtime trong remote handler
async function getProductPrice(id: string) {
  'use cache: remote'
  cacheTag(`product-price-${id}`)
  cacheLife({ expire: 300 }) // 5 phút

  // Điều này được cache tại runtime và chia sẻ giữa tất cả người dùng
  return db.products.getPrice({ where: { id } })
}

// Đề xuất dành riêng cho người dùng - private cache theo người dùng
async function getRecommendations(productId: string) {
  'use cache: private'
  cacheLife({ expire: 60 }) // 1 phút

  const sessionId = (await cookies()).get('session-id')?.value

  // Điều này được cache theo người dùng và không bao giờ được chia sẻ
  return db.recommendations.findMany({
    where: { productId, sessionId },
  })
}

export default async function ProductPage({ params }) {
  const { id } = await params

  // Dữ liệu sản phẩm tĩnh
  const product = await getProduct(id)

  return (
    <div>
      <ProductDetails product={product} />

      {/* Giá được chia sẻ động */}
      <Suspense fallback={<PriceSkeleton />}>
        <ProductPriceComponent productId={id} />
      </Suspense>

      {/* Đề xuất được cá nhân hóa động */}
      <Suspense fallback={<RecommendationsSkeleton />}>
        <ProductRecommendations productId={id} />
      </Suspense>
    </div>
  )
}

function ProductDetails({ product }) {
  return (
    <div>
      <h1>{product.name}</h1>
      <p>{product.description}</p>
    </div>
  )
}

async function ProductPriceComponent({ productId }) {
  // Làm cho component này trở nên động
  await connection()

  const price = await getProductPrice(productId)
  return <div>Giá: ${price}</div>
}

async function ProductRecommendations({ productId }) {
  const recommendations = await getRecommendations(productId)
  return <RecommendationsList items={recommendations} />
}

function PriceSkeleton() {
```

> **Lưu ý**:
>
> - Remote caches được lưu trữ trong server-side cache handlers và được chia sẻ giữa tất cả người dùng
> - Remote caches hoạt động trong ngữ cảnh động mà [`use cache`](/docs/app/api-reference/directives/use-cache) thông thường sẽ thất bại
> - Sử dụng [`cacheTag()`](/docs/app/api-reference/functions/cacheTag) và [`revalidateTag()`](/docs/app/api-reference/functions/revalidateTag) để invalidate remote caches theo yêu cầu
> - Sử dụng [`cacheLife()`](/docs/app/api-reference/functions/cacheLife) để cấu hình cache expiration
> - Đối với dữ liệu dành riêng cho người dùng, sử dụng [`'use cache: private'`](/docs/app/api-reference/directives/use-cache-private) thay vì `'use cache: remote'`
> - Remote caches giảm tải origin bằng cách lưu trữ dữ liệu được tính toán hoặc lấy về phía server
