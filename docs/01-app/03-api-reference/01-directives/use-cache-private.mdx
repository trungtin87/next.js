Chỉ thị `'use cache: private'` kích hoạt runtime prefetching của nội dung được cá nhân hóa phụ thuộc vào cookies, headers, hoặc search params.

> **Lưu ý:** `'use cache: private'` là một biến thể của [`use cache`](/docs/app/api-reference/directives/use-cache) được thiết kế đặc biệt cho nội dung dành riêng cho người dùng cần có thể prefetch được nhưng không bao giờ được lưu trữ trong server-side cache handlers.

## Cách sử dụng

Để sử dụng `'use cache: private'`, kích hoạt cờ [`cacheComponents`](/docs/app/api-reference/config/next-config-js/cacheComponents) trong file `next.config.ts` của bạn:

```tsx filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  cacheComponents: true,
}

export default nextConfig
```

```jsx filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  cacheComponents: true,
}

export default nextConfig
```

Sau đó thêm `'use cache: private'` vào hàm của bạn cùng với cấu hình `cacheLife` và export `unstable_prefetch` từ page của bạn.

### Ví dụ cơ bản

```tsx filename="app/product/[id]/page.tsx" switcher
import { Suspense } from 'react'
import { cookies } from 'next/headers'
import { cacheLife, cacheTag } from 'next/cache'

// BẮT BUỘC: Kích hoạt runtime prefetching
export const unstable_prefetch = {
  mode: 'runtime',
  samples: [
    { params: { id: '1' }, cookies: [{ name: 'session-id', value: '1' }] },
  ],
}

export default async function ProductPage({
  params,
}: {
  params: Promise<{ id: string }>
}) {
  const { id } = await params

  return (
    <div>
      <ProductDetails id={id} />
      <Suspense fallback={<div>Đang tải đề xuất...</div>}>
        <Recommendations productId={id} />
      </Suspense>
    </div>
  )
}

async function Recommendations({ productId }: { productId: string }) {
  const recommendations = await getRecommendations(productId)

  return (
    <div>
      {recommendations.map((rec) => (
        <ProductCard key={rec.id} product={rec} />
      ))}
    </div>
  )
}

async function getRecommendations(productId: string) {
  'use cache: private'
  cacheTag(`recommendations-${productId}`)
  cacheLife({ stale: 60 }) // Tối thiểu 30 giây yêu cầu cho runtime prefetch

  // Truy cập cookies trong private cache functions
  const sessionId = (await cookies()).get('session-id')?.value || 'guest'

  return getPersonalizedRecommendations(productId, sessionId)
}
```

> **Lưu ý:** Private caches yêu cầu thời gian stale của `cacheLife` ít nhất 30 giây để kích hoạt runtime prefetching. Các giá trị dưới 30 giây được coi là động.

## Sự khác biệt với `use cache`

Trong khi `use cache` thông thường được thiết kế cho nội dung tĩnh, được chia sẻ có thể được cache trên server, `'use cache: private'` được thiết kế đặc biệt cho nội dung động, dành riêng cho người dùng cần:

1. **Được cá nhân hóa** - thay đổi dựa trên cookies, headers, hoặc search params
2. **Có thể prefetch** - có thể được tải trước khi người dùng điều hướng đến trang
3. **Chỉ client** - không bao giờ được lưu trữ vào server-side cache handlers

| Tính năng                         | `use cache`                 | `'use cache: private'`                               |
| --------------------------------- | --------------------------- | ---------------------------------------------------- |
| **Truy cập `await cookies()`**    | Không                       | Có                                                   |
| **Truy cập `await headers()`**    | Không                       | Có                                                   |
| **Truy cập `await searchParams`** | Không                       | Có                                                   |
| **Lưu trữ trong cache handler**   | Có (phía server)            | Không (chỉ phía client)                              |
| **Runtime prefetchable**          | N/A (đã là static)          | Có (khi được cấu hình)                               |
| **Phạm vi cache**                 | Toàn cục (được chia sẻ)     | Theo người dùng (cô lập)                             |
| **Trường hợp sử dụng**            | Nội dung tĩnh, được chia sẻ | Nội dung được cá nhân hóa, dành riêng cho người dùng |

## Cách hoạt động

### Runtime prefetching

Khi người dùng di chuột qua hoặc xem một liên kết đến một trang có `unstable_prefetch = { mode: 'runtime' }`:

1. **Nội dung tĩnh** được prefetch ngay lập tức (layouts, page shell)
2. **Private cache functions** được thực thi với cookies/headers hiện tại của người dùng
3. **Kết quả được lưu trữ** trong Resume Data Cache phía client
4. **Điều hướng là tức thì** - cả nội dung tĩnh và được cá nhân hóa đều đã được tải

> **Lưu ý:** Không có `'use cache: private'`, nội dung được cá nhân hóa không thể được prefetch và phải đợi cho đến sau khi điều hướng hoàn tất. Runtime prefetching loại bỏ độ trễ này bằng cách thực thi các cache functions với ngữ cảnh request hiện tại của người dùng.

### Hành vi lưu trữ

Private caches **không bao giờ được lưu trữ** vào server-side cache handlers (như Redis, Vercel Data Cache, v.v.). Chúng chỉ tồn tại để:

1. Kích hoạt runtime prefetching của nội dung được cá nhân hóa
2. Lưu trữ dữ liệu được prefetch trong client-side cache trong phiên làm việc
3. Phối hợp cache invalidation với tags và stale times

Điều này đảm bảo dữ liệu dành riêng cho người dùng không bao giờ vô tình được chia sẻ giữa người dùng trong khi vẫn kích hoạt điều hướng nhanh, được prefetch.

### Yêu cầu về stale time

> **Lưu ý:** Các hàm có thời gian stale của `cacheLife` nhỏ hơn 30 giây sẽ không được runtime prefetch, ngay cả khi sử dụng `'use cache: private'`. Điều này ngăn prefetching dữ liệu thay đổi nhanh chóng có khả năng đã cũ vào thời điểm điều hướng.

```tsx
// Sẽ được runtime prefetch (stale ≥ 30s)
cacheLife({ stale: 60 })

// Sẽ được runtime prefetch (stale ≥ 30s)
cacheLife({ stale: 30 })

// Sẽ KHÔNG được runtime prefetch (stale < 30s)
cacheLife({ stale: 10 })
```

## Request APIs được phép trong private caches

Các API cụ thể của request sau có thể được sử dụng bên trong các hàm `'use cache: private'`:

| API            | Được phép trong `use cache` | Được phép trong `'use cache: private'` |
| -------------- | --------------------------- | -------------------------------------- |
| `cookies()`    | Không                       | Có                                     |
| `headers()`    | Không                       | Có                                     |
| `searchParams` | Không                       | Có                                     |
| `connection()` | Không                       | Không                                  |

> **Lưu ý:** API [`connection()`](https://nextjs.org/docs/app/api-reference/functions/connection) bị cấm trong cả `use cache` và `'use cache: private'` vì nó cung cấp thông tin cụ thể về connection không thể được cache một cách an toàn.

## Quy tắc lồng nhau

Private caches có các quy tắc lồng nhau cụ thể để ngăn dữ liệu dành riêng cho người dùng rò rỉ vào shared caches:

- Private caches **có thể** được lồng bên trong các private caches khác
- Private caches **không thể** được lồng bên trong public caches (`'use cache'`, `'use cache: remote'`)
- Public caches **có thể** được lồng bên trong private caches

```tsx
// HỢP LỆ: Private bên trong private
async function outerPrivate() {
  'use cache: private'
  const result = await innerPrivate()
  return result
}

async function innerPrivate() {
  'use cache: private'
  return getData()
}

// KHÔNG HỢP LỆ: Private bên trong public
async function outerPublic() {
  'use cache'
  const result = await innerPrivate() // Lỗi!
  return result
}

async function innerPrivate() {
  'use cache: private'
  return getData()
}
```

## Ví dụ

### Đề xuất sản phẩm được cá nhân hóa

Ví dụ này cho thấy cách cache các đề xuất sản phẩm được cá nhân hóa dựa trên session cookie của người dùng. Các đề xuất được prefetch tại runtime khi người dùng di chuột qua các liên kết sản phẩm.

```tsx filename="app/product/[id]/page.tsx"
import { cookies } from 'next/headers'
import { cacheLife, cacheTag } from 'next/cache'

export const unstable_prefetch = {
  mode: 'runtime',
  samples: [
    { params: { id: '1' }, cookies: [{ name: 'user-id', value: 'user-123' }] },
  ],
}

async function getRecommendations(productId: string) {
  'use cache: private'
  cacheTag(`recommendations-${productId}`)
  cacheLife({ stale: 60 })

  const userId = (await cookies()).get('user-id')?.value

  // Lấy đề xuất được cá nhân hóa dựa trên lịch sử duyệt web của người dùng
  const recommendations = await db.recommendations.findMany({
    where: { userId, productId },
  })

  return recommendations
}
```

### Giá dành riêng cho người dùng

Cache thông tin giá thay đổi theo cấp độ người dùng, cho phép điều hướng tức thì đến trang giá với các mức giá được cá nhân hóa đã được tải.

```tsx filename="app/pricing/page.tsx"
import { cookies } from 'next/headers'
import { cacheLife } from 'next/cache'

export const unstable_prefetch = {
  mode: 'runtime',
  samples: [{ cookies: [{ name: 'user-tier', value: 'premium' }] }],
}

async function getPricing() {
  'use cache: private'
  cacheLife({ stale: 300 }) // 5 phút

  const tier = (await cookies()).get('user-tier')?.value || 'free'

  // Trả về giá cụ thể theo cấp độ
  return db.pricing.findMany({ where: { tier } })
}
```

### Nội dung được bản địa hóa dựa trên headers

Phục vụ nội dung được bản địa hóa dựa trên header `Accept-Language` của người dùng, prefetch biến thể ngôn ngữ chính xác trước khi điều hướng.

```tsx filename="app/page.tsx"
import { headers } from 'next/headers'
import { cacheLife, cacheTag } from 'next/cache'

export const unstable_prefetch = {
  mode: 'runtime',
  samples: [{ headers: [{ name: 'accept-language', value: 'en-US' }] }],
}

async function getLocalizedContent() {
  'use cache: private'
  cacheTag('content')
  cacheLife({ stale: 3600 }) // 1 giờ

  const headersList = await headers()
  const locale = headersList.get('accept-language')?.split(',')[0] || 'en-US'

  return db.content.findMany({ where: { locale } })
}
```

### Kết quả tìm kiếm với tùy chọn người dùng

Prefetch kết quả tìm kiếm bao gồm các tùy chọn dành riêng cho người dùng, đảm bảo kết quả tìm kiếm được cá nhân hóa tải ngay lập tức.

```tsx filename="app/search/page.tsx"
import { cookies } from 'next/headers'
import { cacheLife } from 'next/cache'

export const unstable_prefetch = {
  mode: 'runtime',
  samples: [
    {
      searchParams: { q: 'laptop' },
      cookies: [{ name: 'preferences', value: 'compact-view' }],
    },
  ],
}

async function getSearchResults(query: string) {
  'use cache: private'
  cacheLife({ stale: 120 }) // 2 phút

  const preferences = (await cookies()).get('preferences')?.value

  // Áp dụng tùy chọn người dùng vào kết quả tìm kiếm
  return searchWithPreferences(query, preferences)
}
```

> **Lưu ý**:
>
> - Private caches là tạm thời và chỉ tồn tại trong client-side cache trong suốt phiên làm việc
> - Kết quả private cache không bao giờ được ghi vào server-side cache handlers
> - Export `unstable_prefetch` là bắt buộc để runtime prefetching hoạt động
> - Thời gian stale tối thiểu 30 giây là bắt buộc để private caches được prefetch
> - Bạn có thể sử dụng `cacheTag()` và `revalidateTag()` để invalidate private caches
> - Mỗi người dùng nhận được các private cache entries riêng của họ dựa trên cookies/headers của họ
