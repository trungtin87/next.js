Hàm `permanentRedirect` cho phép bạn chuyển hướng người dùng đến một URL khác. `permanentRedirect` có thể được sử dụng trong Server Components, Client Components, [Route Handlers](/docs/app/api-reference/file-conventions/route), và [Server Actions](/docs/app/getting-started/updating-data).

Khi được sử dụng trong ngữ cảnh streaming, điều này sẽ chèn một meta tag để phát ra redirect ở phía client. Khi được sử dụng trong một server action, nó sẽ phục vụ một phản hồi HTTP redirect 303 cho người gọi. Nếu không, nó sẽ phục vụ một phản hồi HTTP redirect 308 (Permanent) cho người gọi.

Nếu một tài nguyên không tồn tại, bạn có thể sử dụng [hàm `notFound`](/docs/app/api-reference/functions/not-found) thay thế.

> **Nên biết**: Nếu bạn muốn trả về một HTTP redirect 307 (Temporary) thay vì 308 (Permanent), bạn có thể sử dụng [hàm `redirect`](/docs/app/api-reference/functions/redirect) thay thế.

## Parameters

Hàm `permanentRedirect` chấp nhận hai tham số:

```js
permanentRedirect(path, type)
```

| Tham số | Kiểu                                                               | Mô tả                                                                  |
| ------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| `path`  | `string`                                                           | URL để chuyển hướng đến. Có thể là đường dẫn tương đối hoặc tuyệt đối. |
| `type`  | `'replace'` (default) hoặc `'push'` (default trong Server Actions) | Loại redirect để thực hiện.                                            |

Theo mặc định, `permanentRedirect` sẽ sử dụng `push` (thêm một entry mới vào browser history stack) trong [Server Actions](/docs/app/getting-started/updating-data) và `replace` (thay thế URL hiện tại trong browser history stack) ở mọi nơi khác. Bạn có thể ghi đè hành vi này bằng cách chỉ định tham số `type`.

Tham số `type` không có hiệu lực khi được sử dụng trong Server Components.

## Returns

`permanentRedirect` không trả về giá trị.

## Example

Gọi hàm `permanentRedirect()` sẽ ném một lỗi `NEXT_REDIRECT` và chấm dứt việc render của route segment mà nó được ném.

```jsx filename="app/team/[id]/page.js"
import { permanentRedirect } from 'next/navigation'

async function fetchTeam(id) {
  const res = await fetch('https://...')
  if (!res.ok) return undefined
  return res.json()
}

export default async function Profile({ params }) {
  const { id } = await params
  const team = await fetchTeam(id)
  if (!team) {
    permanentRedirect('/login')
  }

  // ...
}
```

> **Nên biết**: `permanentRedirect` không yêu cầu bạn sử dụng `return permanentRedirect()` vì nó sử dụng kiểu TypeScript [`never`](https://www.typescriptlang.org/docs/handbook/2/functions.html#never).
