`headers` là một hàm **async** cho phép bạn **đọc** các HTTP incoming request headers từ một [Server Component](/docs/app/getting-started/server-and-client-components).

```tsx filename="app/page.tsx" switcher
import { headers } from 'next/headers'

export default async function Page() {
  const headersList = await headers()
  const userAgent = headersList.get('user-agent')
}
```

```jsx filename="app/page.js" switcher
import { headers } from 'next/headers'

export default async function Page() {
  const headersList = await headers()
  const userAgent = headersList.get('user-agent')
}
```

## Tham khảo

### Parameters

`headers` không nhận bất kỳ parameters nào.

### Returns

`headers` trả về một đối tượng [Web Headers](https://developer.mozilla.org/docs/Web/API/Headers) **read-only**.

- [`Headers.entries()`](https://developer.mozilla.org/docs/Web/API/Headers/entries): Trả về một [`iterator`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Iteration_protocols) cho phép đi qua tất cả các cặp key/value có trong đối tượng này.
- [`Headers.forEach()`](https://developer.mozilla.org/docs/Web/API/Headers/forEach): Thực thi một hàm được cung cấp một lần cho mỗi cặp key/value trong đối tượng `Headers` này.
- [`Headers.get()`](https://developer.mozilla.org/docs/Web/API/Headers/get): Trả về một chuỗi [`String`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/String) của tất cả các giá trị của một header trong một đối tượng `Headers` với một tên cho trước.
- [`Headers.has()`](https://developer.mozilla.org/docs/Web/API/Headers/has): Trả về một boolean cho biết liệu một đối tượng `Headers` có chứa một header nhất định hay không.
- [`Headers.keys()`](https://developer.mozilla.org/docs/Web/API/Headers/keys): Trả về một [`iterator`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Iteration_protocols) cho phép bạn đi qua tất cả các keys của các cặp key/value có trong đối tượng này.
- [`Headers.values()`](https://developer.mozilla.org/docs/Web/API/Headers/values): Trả về một [`iterator`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Iteration_protocols) cho phép bạn đi qua tất cả các values của các cặp key/value có trong đối tượng này.

## Nên biết

- `headers` là một hàm **asynchronous** trả về một promise. Bạn phải sử dụng `async/await` hoặc hàm [`use`](https://react.dev/reference/react/use) của React.
  - Trong phiên bản 14 và trước đó, `headers` là một hàm đồng bộ. Để giúp tương thích ngược, bạn vẫn có thể truy cập nó một cách đồng bộ trong Next.js 15, nhưng hành vi này sẽ bị deprecated trong tương lai.
- Vì `headers` là read-only, bạn không thể `set` hoặc `delete` các outgoing request headers.
- `headers` là một [Dynamic API](/docs/app/guides/caching#dynamic-rendering) có các giá trị trả về không thể biết trước. Sử dụng nó sẽ opt một route vào **[dynamic rendering](/docs/app/guides/caching#dynamic-rendering)**.

## Ví dụ

### Sử dụng Authorization header

```jsx filename="app/page.js"
import { headers } from 'next/headers'

export default async function Page() {
  const authorization = (await headers()).get('authorization')
  const res = await fetch('...', {
    headers: { authorization }, // Forward the authorization header
  })
  const user = await res.json()

  return <h1>{user.name}</h1>
}
```
