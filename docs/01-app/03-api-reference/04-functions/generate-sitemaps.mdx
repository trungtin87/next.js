Bạn có thể sử dụng hàm `generateSitemaps` để tạo nhiều sitemap cho ứng dụng của bạn.

## Returns

`generateSitemaps` trả về một mảng các đối tượng với thuộc tính `id`.

## URLs

Các sitemap được tạo của bạn sẽ có sẵn tại `/.../sitemap/[id].xml`. Ví dụ, `/product/sitemap/1.xml`.

## Example

Ví dụ, để chia một sitemap bằng cách sử dụng `generateSitemaps`, hãy trả về một mảng các đối tượng với sitemap `id`. Sau đó, sử dụng `id` để tạo các sitemap duy nhất.

```ts filename="app/product/sitemap.ts" switcher
import { BASE_URL } from '@/app/lib/constants'

export async function generateSitemaps() {
  // Fetch the total number of products and calculate the number of sitemaps needed
  return [{ id: 0 }, { id: 1 }, { id: 2 }, { id: 3 }]
}

export default async function sitemap({
  id,
}: {
  id: number
}): Promise<MetadataRoute.Sitemap> {
  // Google's limit is 50,000 URLs per sitemap
  const start = id * 50000
  const end = start + 50000
  const products = await getProducts(
    `SELECT id, date FROM products WHERE id BETWEEN ${start} AND ${end}`
  )
  return products.map((product) => ({
    url: `${BASE_URL}/product/${product.id}`,
    lastModified: product.date,
  }))
}
```

## Lịch sử phiên bản

| Phiên bản | Thay đổi                                                                                                                                             |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `v15.0.0` | `generateSitemaps` giờ đây tạo các URL nhất quán giữa development và production                                                                      |
| `v13.3.2` | `generateSitemaps` được giới thiệu. Trong development, bạn có thể xem sitemap được tạo tại `/.../sitemap.xml/[id]`. Ví dụ, `/product/sitemap.xml/1`. |
