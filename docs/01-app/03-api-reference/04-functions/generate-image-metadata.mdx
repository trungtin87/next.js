Bạn có thể sử dụng `generateImageMetadata` để tạo các phiên bản khác nhau của một hình ảnh hoặc trả về nhiều hình ảnh cho một route segment. Điều này hữu ích khi bạn muốn tránh hard-coding các giá trị metadata, chẳng hạn như cho các icons.

## Parameters

Hàm `generateImageMetadata` chấp nhận các parameters sau:

#### `params` (tùy chọn)

Một object chứa object [dynamic route parameters](/docs/app/api-reference/file-conventions/dynamic-routes) từ root segment xuống đến segment mà `generateImageMetadata` được gọi.

```tsx filename="icon.tsx" switcher
export function generateImageMetadata({
  params,
}: {
  params: { slug: string }
}) {
  // ...
}
```

```jsx filename="icon.js" switcher
export function generateImageMetadata({ params }) {
  // ...
}
```

| Route                           | URL         | `params`                  |
| ------------------------------- | ----------- | ------------------------- |
| `app/shop/icon.js`              | `/shop`     | `undefined`               |
| `app/shop/[slug]/icon.js`       | `/shop/1`   | `{ slug: '1' }`           |
| `app/shop/[tag]/[item]/icon.js` | `/shop/1/2` | `{ tag: '1', item: '2' }` |

## Returns

Hàm `generateImageMetadata` nên trả về một `array` các objects chứa metadata của hình ảnh như `alt` và `size`. Ngoài ra, mỗi item **phải** bao gồm một giá trị `id` sẽ được truyền dưới dạng một promise cho các props của hàm tạo hình ảnh.

| Image Metadata Object | Type                                |
| --------------------- | ----------------------------------- |
| `id`                  | `string` (required)                 |
| `alt`                 | `string`                            |
| `size`                | `{ width: number; height: number }` |
| `contentType`         | `string`                            |

```tsx filename="icon.tsx" switcher
import { ImageResponse } from 'next/og'

export function generateImageMetadata() {
  return [
    {
      contentType: 'image/png',
      size: { width: 48, height: 48 },
      id: 'small',
    },
    {
      contentType: 'image/png',
      size: { width: 72, height: 72 },
      id: 'medium',
    },
  ]
}

export default async function Icon({ id }: { id: Promise<string | number> }) {
  const iconId = await id
  return new ImageResponse(
    (
      <div
        style={{
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          fontSize: 88,
          background: '#000',
          color: '#fafafa',
        }}
      >
        Icon {iconId}
      </div>
    )
  )
}
```


## Image generation function props

Khi sử dụng `generateImageMetadata`, hàm tạo hình ảnh export mặc định nhận các props sau:

#### `id`

Một promise resolve thành giá trị `id` từ một trong các items được trả về bởi `generateImageMetadata`. `id` sẽ là một `string` hoặc `number` tùy thuộc vào những gì được trả về từ `generateImageMetadata`.

```tsx filename="icon.tsx" switcher
export default async function Icon({ id }: { id: Promise<string | number> }) {
  const iconId = await id
  // Use iconId to generate the image
}
```

```jsx filename="icon.js" switcher
export default async function Icon({ id }) {
  const iconId = await id
  // Use iconId to generate the image
}
```

#### `params` (tùy chọn)

Một promise resolve thành một object chứa các [dynamic route parameters](/docs/app/api-reference/file-conventions/dynamic-routes) từ root segment xuống đến segment mà hình ảnh được đặt cùng.

```tsx filename="icon.tsx" switcher
export default async function Icon({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
  // Use slug to generate the image
}
```

```jsx filename="icon.js" switcher
export default async function Icon({ params }) {
  const { slug } = await params
  // Use slug to generate the image
}
```

### Ví dụ

#### Sử dụng dữ liệu bên ngoài

Ví dụ này sử dụng object `params` và dữ liệu bên ngoài để tạo nhiều [Open Graph images](/docs/app/api-reference/file-conventions/metadata/opengraph-image) cho một route segment.

```tsx filename="app/products/[id]/opengraph-image.tsx" switcher
import { ImageResponse } from 'next/og'
import { getCaptionForImage, getOGImages } from '@/app/utils/images'

export async function generateImageMetadata({
  params,
}: {
  params: { id: string }
}) {
  const images = await getOGImages(params.id)

  return images.map((image, idx) => ({
    id: idx,
    size: { width: 1200, height: 600 },
    alt: image.text,
    contentType: 'image/png',
  }))
}

export default async function Image({
  params,
  id,
}: {
  params: Promise<{ id: string }>
  id: Promise<number>
}) {
  const productId = (await params).id
  const imageId = await id
  const text = await getCaptionForImage(productId, imageId)

  return new ImageResponse(
    (
      <div
        style={
          {
            // ...
          }
        }
      >
        {text}
      </div>
    )
  )
}
```

```jsx filename="app/products/[id]/opengraph-image.js" switcher

import { getCaptionForImage, getOGImages } from '@/app/utils/images'

export async function generateImageMetadata({ params }) {

      <div

          {
            // ...

        }
      >
        {text}
      </div>
    )
  )
}
```

## Lịch sử phiên bản

| Version   | Changes                                                                                     |
| --------- | ------------------------------------------------------------------------------------------- |
| `v16.0.0` | `id` được truyền cho hàm tạo Image hiện là một promise resolve thành `string` hoặc `number` |
| `v16.0.0` | `params` được truyền cho hàm tạo Image hiện là một promise resolve thành một object         |
| `v13.3.0` | `generateImageMetadata` được giới thiệu.                                                    |
