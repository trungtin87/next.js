---

`useSelectedLayoutSegments` là một **Client Component** hook cho phép bạn đọc các route segments đang hoạt động **bên dưới** Layout mà nó được gọi.

Nó hữu ích cho việc tạo UI trong parent Layouts cần biết về các child segments đang hoạt động như breadcrumbs.

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useSelectedLayoutSegments } from 'next/navigation'

export default function ExampleClientComponent() {
  const segments = useSelectedLayoutSegments()

  return (
    <ul>
      {segments.map((segment, index) => (
        <li key={index}>{segment}</li>
      ))}
    </ul>
  )
}
```

```jsx filename="app/example-client-component.js" switcher
'use client'

import { useSelectedLayoutSegments } from 'next/navigation'

export default function ExampleClientComponent() {
  const segments = useSelectedLayoutSegments()

  return (
    <ul>
      {segments.map((segment, index) => (
        <li key={index}>{segment}</li>
      ))}
    </ul>
  )
}
```

> **Lưu ý**:
>
> - Vì `useSelectedLayoutSegments` là một [Client Component](/docs/app/getting-started/server-and-client-components) hook, và Layouts là [Server Components](/docs/app/getting-started/server-and-client-components) theo mặc định, `useSelectedLayoutSegments` thường được gọi thông qua một Client Component được import vào một Layout.
> - Các segments được trả về bao gồm [Route Groups](/docs/app/api-reference/file-conventions/route-groups), mà bạn có thể không muốn bao gồm trong UI của mình. Bạn có thể sử dụng phương thức mảng [`filter`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/filter) để loại bỏ các mục bắt đầu bằng dấu ngoặc.

## Tham số

```tsx
const segments = useSelectedLayoutSegments(parallelRoutesKey?: string)
```

`useSelectedLayoutSegments` _tùy chọn_ chấp nhận một [`parallelRoutesKey`](/docs/app/api-reference/file-conventions/parallel-routes#with-useselectedlayoutsegments), cho phép bạn đọc route segment đang hoạt động bên trong slot đó.

## Giá trị trả về

`useSelectedLayoutSegments` trả về một mảng các chuỗi chứa các segments đang hoạt động một cấp bên dưới layout mà hook được gọi. Hoặc một mảng rỗng nếu không có segment nào tồn tại.

Ví dụ, với các Layouts và URLs bên dưới, các segments được trả về sẽ là:

| Layout                    | URL đã truy cập       | Segments được trả về        |
| ------------------------- | --------------------- | --------------------------- |
| `app/layout.js`           | `/`                   | `[]`                        |
| `app/layout.js`           | `/dashboard`          | `['dashboard']`             |
| `app/layout.js`           | `/dashboard/settings` | `['dashboard', 'settings']` |
| `app/dashboard/layout.js` | `/dashboard`          | `[]`                        |
| `app/dashboard/layout.js` | `/dashboard/settings` | `['settings']`              |
