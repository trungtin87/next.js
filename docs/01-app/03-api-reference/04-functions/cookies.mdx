`cookies` là một hàm **async** cho phép bạn đọc các HTTP incoming request cookies trong [Server Components](/docs/app/getting-started/server-and-client-components), và đọc/ghi outgoing request cookies trong [Server Actions](/docs/app/getting-started/updating-data) hoặc [Route Handlers](/docs/app/api-reference/file-conventions/route).

```tsx filename="app/page.tsx" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  const theme = cookieStore.get('theme')
  return '...'
}
```

```js filename="app/page.js" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  const theme = cookieStore.get('theme')
  return '...'
}
```

## Tham khảo

### Phương thức

Các phương thức sau có sẵn:

| Phương thức                 | Kiểu trả về      | Mô tả                                                                                 |
| --------------------------- | ---------------- | ------------------------------------------------------------------------------------- |
| `get('name')`               | Object           | Chấp nhận tên cookie và trả về một object với tên và giá trị.                         |
| `getAll()`                  | Mảng các objects | Trả về danh sách tất cả các cookies có tên khớp.                                      |
| `has('name')`               | Boolean          | Chấp nhận tên cookie và trả về một boolean dựa trên việc cookie có tồn tại hay không. |
| `set(name, value, options)` | -                | Chấp nhận tên cookie, giá trị, và các tùy chọn và đặt outgoing request cookie.        |
| `delete(name)`              | -                | Chấp nhận tên cookie và xóa cookie.                                                   |
| `clear()`                   | -                | Xóa tất cả cookies.                                                                   |
| `toString()`                | String           | Trả về biểu diễn chuỗi của các cookies.                                               |

### Tùy chọn

Khi đặt một cookie, các thuộc tính sau từ object `options` được hỗ trợ:

| Tùy chọn      | Kiểu                                   | Mô tả                                                                                               |
| ------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `name`        | String                                 | Chỉ định tên của cookie.                                                                            |
| `value`       | String                                 | Chỉ định giá trị được lưu trữ trong cookie.                                                         |
| `expires`     | Date                                   | Định nghĩa ngày chính xác khi cookie sẽ hết hạn.                                                    |
| `maxAge`      | Number                                 | Đặt tuổi thọ của cookie tính bằng giây.                                                             |
| `domain`      | String                                 | Chỉ định domain nơi cookie có sẵn.                                                                  |
| `path`        | String, mặc định: `'/'`                | Giới hạn phạm vi của cookie trong một path cụ thể trong domain.                                     |
| `secure`      | Boolean                                | Đảm bảo cookie chỉ được gửi qua kết nối HTTPS để tăng cường bảo mật.                                |
| `httpOnly`    | Boolean                                | Hạn chế cookie đối với các HTTP requests, ngăn chặn truy cập client-side.                           |
| `sameSite`    | Boolean, `'lax'`, `'strict'`, `'none'` | Kiểm soát hành vi cross-site request của cookie.                                                    |
| `priority`    | String (`"low"`, `"medium"`, `"high"`) | Chỉ định mức độ ưu tiên của cookie                                                                  |
| `partitioned` | Boolean                                | Chỉ ra liệu cookie có được [phân vùng (partitioned)](https://github.com/privacycg/CHIPS) hay không. |

Tùy chọn duy nhất có giá trị mặc định là `path`.

Để tìm hiểu thêm về các tùy chọn này, xem [tài liệu MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Cookies).

## Lưu ý

- `cookies` là một hàm **bất đồng bộ (asynchronous)** trả về một promise. Bạn phải sử dụng `async/await` hoặc hàm [`use`](https://react.dev/reference/react/use) của React để truy cập cookies.
  - Trong phiên bản 14 và cũ hơn, `cookies` là một hàm đồng bộ. Để giúp tương thích ngược, bạn vẫn có thể truy cập nó đồng bộ trong Next.js 15, nhưng hành vi này sẽ bị deprecated trong tương lai.
- `cookies` là một [Dynamic API](/docs/app/guides/caching#dynamic-rendering) có các giá trị trả về không thể biết trước. Sử dụng nó trong một layout hoặc page sẽ opt một route vào [dynamic rendering](/docs/app/guides/caching#dynamic-rendering).
- Phương thức `.delete` chỉ có thể được gọi:
  - Trong một [Server Action](/docs/app/getting-started/updating-data) hoặc [Route Handler](/docs/app/api-reference/file-conventions/route).
  - Nếu nó thuộc về cùng một domain mà từ đó `.set` được gọi. Đối với wildcard domains, subdomain cụ thể phải khớp chính xác. Ngoài ra, mã phải được thực thi trên cùng một protocol (HTTP hoặc HTTPS) như cookie bạn muốn xóa.
- HTTP không cho phép đặt cookies sau khi streaming bắt đầu, vì vậy bạn phải sử dụng `.set` trong một [Server Action](/docs/app/getting-started/updating-data) hoặc [Route Handler](/docs/app/api-reference/file-conventions/route).

## Hiểu hành vi Cookie trong Server Components

Khi làm việc với cookies trong Server Components, điều quan trọng là phải hiểu rằng cookies về cơ bản là một cơ chế lưu trữ client-side:

- **Đọc cookies** hoạt động trong Server Components vì bạn đang truy cập dữ liệu cookie mà trình duyệt của client gửi đến server trong HTTP request headers.
- **Đặt cookies** không thể được thực hiện trực tiếp trong một Server Component, ngay cả khi sử dụng Route Handler hoặc Server Action. Điều này là do cookies thực sự được lưu trữ bởi trình duyệt, không phải server.

Server chỉ có thể gửi hướng dẫn (thông qua headers `Set-Cookie`) để bảo trình duyệt lưu trữ cookies - việc lưu trữ thực tế diễn ra ở phía client. Đây là lý do tại sao các thao tác cookie sửa đổi state (`.set`, `.delete`, `.clear`) phải được thực hiện trong một Route Handler hoặc Server Action nơi response headers có thể được đặt đúng cách.

## Hiểu hành vi Cookie trong Server Actions

Sau khi bạn đặt hoặc xóa một cookie trong một Server Action, Next.js re-renders trang hiện tại và layouts của nó trên server để UI phản ánh giá trị cookie mới. Xem [hướng dẫn Caching](/docs/app/guides/caching#cookies).

UI không bị unmounted, nhưng các effects phụ thuộc vào dữ liệu đến từ server sẽ chạy lại.

Để refresh dữ liệu đã cache nữa, hãy gọi [`revalidatePath`](/docs/app/api-reference/functions/revalidatePath) hoặc [`revalidateTag`](/docs/app/api-reference/functions/revalidateTag) bên trong action.

## Ví dụ

### Lấy một cookie

Bạn có thể sử dụng phương thức `(await cookies()).get('name')` để lấy một cookie đơn lẻ:

```tsx filename="app/page.tsx" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  const theme = cookieStore.get('theme')
  return '...'
}
```

```jsx filename="app/page.js" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  const theme = cookieStore.get('theme')
  return '...'
}
```

### Lấy tất cả cookies

Bạn có thể sử dụng phương thức `(await cookies()).getAll()` để lấy tất cả cookies có tên khớp. Nếu `name` không được chỉ định, nó trả về tất cả các cookies có sẵn.

```tsx filename="app/page.tsx" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  return cookieStore.getAll().map((cookie) => (
    <div key={cookie.name}>
      <p>Name: {cookie.name}</p>
      <p>Value: {cookie.value}</p>
    </div>
  ))
}
```

```jsx filename="app/page.js" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  return cookieStore.getAll().map((cookie) => (
    <div key={cookie.name}>
      <p>Name: {cookie.name}</p>
      <p>Value: {cookie.value}</p>
    </div>
  ))
}
```

### Đặt một cookie

Bạn có thể sử dụng phương thức `(await cookies()).set(name, value, options)` trong một [Server Action](/docs/app/getting-started/updating-data) hoặc [Route Handler](/docs/app/api-reference/file-conventions/route) để đặt một cookie. [Object `options`](#options) là tùy chọn.

```tsx filename="app/actions.ts" switcher
'use server'

import { cookies } from 'next/headers'

export async function create(data) {
  const cookieStore = await cookies()

  cookieStore.set('name', 'lee')
  // hoặc
  cookieStore.set('name', 'lee', { secure: true })
  // hoặc
  cookieStore.set({
    name: 'name',
    value: 'lee',
    httpOnly: true,
    path: '/',
  })
}
```

```js filename="app/actions.js" switcher
'use server'

import { cookies } from 'next/headers'

export async function create(data) {
  const cookieStore = await cookies()

  cookieStore.set('name', 'lee')
  // hoặc
  cookieStore.set('name', 'lee', { secure: true })
  // hoặc
  cookieStore.set({
    name: 'name',
    value: 'lee',
    httpOnly: true,
    path: '/',
  })
}
```

### Kiểm tra xem một cookie có tồn tại không

Bạn có thể sử dụng phương thức `(await cookies()).has(name)` để kiểm tra xem một cookie có tồn tại không:

```tsx filename="app/page.ts" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  const hasCookie = cookieStore.has('theme')
  return '...'
}
```

```jsx filename="app/page.js" switcher
import { cookies } from 'next/headers'

export default async function Page() {
  const cookieStore = await cookies()
  const hasCookie = cookieStore.has('theme')
  return '...'
}
```

### Xóa cookies

Có ba cách bạn có thể xóa một cookie.

Sử dụng phương thức `delete()`:

```tsx filename="app/actions.ts" switcher
'use server'

import { cookies } from 'next/headers'

export async function delete(data) {
  (await cookies()).delete('name')
}
```

```js filename="app/actions.js" switcher
'use server'

import { cookies } from 'next/headers'

export async function delete(data) {
  (await cookies()).delete('name')
}
```

Đặt một cookie mới với cùng tên và giá trị rỗng:

```tsx filename="app/actions.ts" switcher
'use server'

import { cookies } from 'next/headers'

export async function delete(data) {
  (await cookies()).set('name', '')
}
```

```js filename="app/actions.js" switcher
'use server'

import { cookies } from 'next/headers'

export async function delete(data) {
  (await cookies()).set('name', '')
}
```

Đặt `maxAge` thành 0 sẽ làm hết hạn cookie ngay lập tức. `maxAge` chấp nhận giá trị tính bằng giây.

```tsx filename="app/actions.ts" switcher
'use server'

import { cookies } from 'next/headers'

export async function delete(data) {
  (await cookies()).set('name', 'value', { maxAge: 0 })
}
```

```js filename="app/actions.js" switcher
'use server'

import { cookies } from 'next/headers'

export async function delete(data) {
  (await cookies()).set('name', 'value', { maxAge: 0 })
}
```
