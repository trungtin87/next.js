`draftMode` là một hàm **async** cho phép bạn enable và disable [Draft Mode](/docs/app/guides/draft-mode), cũng như kiểm tra xem Draft Mode có được enable hay không trong một [Server Component](/docs/app/getting-started/server-and-client-components).

```tsx filename="app/page.ts" switcher
import { draftMode } from 'next/headers'

export default async function Page() {
  const { isEnabled } = await draftMode()
}
```

```jsx filename="app/page.js" switcher
import { draftMode } from 'next/headers'

export default async function Page() {
  const { isEnabled } = await draftMode()
}
```

## Tham khảo

Các phương thức và thuộc tính sau đây có sẵn:

| Phương thức | Mô tả                                                                                      |
| ----------- | ------------------------------------------------------------------------------------------ |
| `isEnabled` | Một giá trị boolean cho biết liệu Draft Mode có được enable hay không.                     |
| `enable()`  | Enable Draft Mode trong một Route Handler bằng cách set một cookie (`__prerender_bypass`). |
| `disable()` | Disable Draft Mode trong một Route Handler bằng cách xóa một cookie.                       |

## Nên biết

- `draftMode` là một hàm **asynchronous** trả về một promise. Bạn phải sử dụng `async/await` hoặc hàm [`use`](https://react.dev/reference/react/use) của React.
  - Trong phiên bản 14 và trước đó, `draftMode` là một hàm đồng bộ. Để giúp tương thích ngược, bạn vẫn có thể truy cập nó một cách đồng bộ trong Next.js 15, nhưng hành vi này sẽ bị deprecated trong tương lai.
- Một giá trị bypass cookie mới sẽ được tạo mỗi khi bạn chạy `next build`. Điều này đảm bảo rằng bypass cookie không thể bị đoán.
- Để test Draft Mode locally qua HTTP, trình duyệt của bạn sẽ cần cho phép third-party cookies và local storage access.

## Ví dụ

### Enable Draft Mode

Để enable Draft Mode, hãy tạo một [Route Handler](/docs/app/api-reference/file-conventions/route) mới và gọi phương thức `enable()`:

```tsx filename="app/draft/route.ts" switcher
import { draftMode } from 'next/headers'

export async function GET(request: Request) {
  const draft = await draftMode()
  draft.enable()
  return new Response('Draft mode is enabled')
}
```

```js filename="app/draft/route.js" switcher
import { draftMode } from 'next/headers'

export async function GET(request) {
  const draft = await draftMode()
  draft.enable()
  return new Response('Draft mode is enabled')
}
```

### Disable Draft Mode

Theo mặc định, Draft Mode session kết thúc khi trình duyệt bị đóng.

Để disable Draft Mode thủ công, hãy gọi phương thức `disable()` trong [Route Handler](/docs/app/api-reference/file-conventions/route) của bạn:

```tsx filename="app/draft/route.ts" switcher
import { draftMode } from 'next/headers'

export async function GET(request: Request) {
  const draft = await draftMode()
  draft.disable()
  return new Response('Draft mode is disabled')
}
```

```js filename="app/draft/route.js" switcher
import { draftMode } from 'next/headers'

export async function GET(request) {
  const draft = await draftMode()
  draft.disable()
  return new Response('Draft mode is disabled')
}
```

Sau đó, gửi một request để invoke Route Handler. Nếu gọi route bằng cách sử dụng [component `<Link>`](/docs/app/api-reference/components/link), bạn phải truyền `prefetch={false}` để tránh vô tình xóa cookie khi prefetch.

### Kiểm tra xem Draft Mode có được enable hay không

Bạn có thể kiểm tra xem Draft Mode có được enable hay không trong một Server Component với thuộc tính `isEnabled`:

```tsx filename="app/page.ts" switcher
import { draftMode } from 'next/headers'

export default async function Page() {
  const { isEnabled } = await draftMode()
  return (
    <main>
      <h1>My Blog Post</h1>
      <p>Draft Mode is currently {isEnabled ? 'Enabled' : 'Disabled'}</p>
    </main>
  )
}
```

```jsx filename="app/page.js" switcher
import { draftMode } from 'next/headers'

export default async function Page() {
  const { isEnabled } = await draftMode()
  return (
    <main>
      <h1>My Blog Post</h1>
      <p>Draft Mode is currently {isEnabled ? 'Enabled' : 'Disabled'}</p>
    </main>
  )
}
```
