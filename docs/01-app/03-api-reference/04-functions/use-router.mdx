Hook `useRouter` cho phép bạn thay đổi routes theo chương trình bên trong [Client Components](/docs/app/getting-started/server-and-client-components).

> **Khuyến nghị:** Sử dụng [`<Link>` component](/docs/app/api-reference/components/link) để điều hướng trừ khi bạn có yêu cầu cụ thể cần sử dụng `useRouter`.

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useRouter } from 'next/navigation'

export default function Page() {
  const router = useRouter()

  return (
    <button type="button" onClick={() => router.push('/dashboard')}>
      Dashboard
    </button>
  )
}
```

```jsx filename="app/example-client-component.js" switcher
'use client'

import { useRouter } from 'next/navigation'

export default function Page() {
  const router = useRouter()

  return (
    <button type="button" onClick={() => router.push('/dashboard')}>
      Dashboard
    </button>
  )
}
```

## `useRouter()`

- `router.push(href: string, { scroll: boolean })`: Thực hiện client-side navigation đến route được cung cấp. Thêm một entry mới vào [browser's history stack](https://developer.mozilla.org/docs/Web/API/History_API).
- `router.replace(href: string, { scroll: boolean })`: Thực hiện client-side navigation đến route được cung cấp mà không thêm entry mới vào browser’s history stack.
- `router.refresh()`: Refresh route hiện tại. Tạo một request mới đến server, re-fetching data requests, và re-rendering Server Components. Client sẽ merge updated React Server Component payload mà không làm mất client-side React (ví dụ: `useState`) hoặc browser state (ví dụ: scroll position) không bị ảnh hưởng.
- `router.prefetch(href: string, options?: { onInvalidate?: () => void })`: [Prefetch](/docs/app/getting-started/linking-and-navigating#prefetching) route được cung cấp để chuyển đổi client-side nhanh hơn. Callback tùy chọn `onInvalidate` được gọi khi [prefetched data trở nên cũ](/docs/app/guides/prefetching#extending-or-ejecting-link).
- `router.back()`: Điều hướng quay lại route trước đó trong browser’s history stack.
- `router.forward()`: Điều hướng tới trang tiếp theo trong browser’s history stack.

> **Nên biết**:
>
> - Bạn không được gửi URLs không tin cậy hoặc chưa được sanitize đến `router.push` hoặc `router.replace`, vì điều này có thể mở trang web của bạn cho các lỗ hổng cross-site scripting (XSS). Ví dụ, `javascript:` URLs được gửi đến `router.push` hoặc `router.replace` sẽ được thực thi trong ngữ cảnh trang của bạn.
> - `<Link>` component tự động prefetch routes khi chúng trở nên visible trong viewport.
> - `refresh()` có thể tạo lại cùng một kết quả nếu fetch requests được cache. Các Dynamic APIs khác như `cookies` và `headers` cũng có thể thay đổi response.
> - Callback `onInvalidate` được gọi tối đa một lần cho mỗi prefetch request. Nó báo hiệu khi bạn có thể muốn kích hoạt một prefetch mới cho updated route data.

### Di chuyển từ `next/router`

- Hook `useRouter` nên được import từ `next/navigation` và không phải `next/router` khi sử dụng App Router
- Chuỗi `pathname` đã bị xóa và được thay thế bằng [`usePathname()`](/docs/app/api-reference/functions/use-pathname)
- Object `query` đã bị xóa và được thay thế bằng [`useSearchParams()`](/docs/app/api-reference/functions/use-search-params)
- `router.events` đã được thay thế. [Xem bên dưới.](#router-events)

[Xem hướng dẫn di chuyển đầy đủ](/docs/app/guides/migrating/app-router-migration).

## Ví dụ

### Router events

Bạn có thể lắng nghe các thay đổi trang bằng cách kết hợp các Client Component hooks khác như `usePathname` và `useSearchParams`.

```jsx filename="app/components/navigation-events.js"
'use client'

import { useEffect } from 'react'
import { usePathname, useSearchParams } from 'next/navigation'

export function NavigationEvents() {
  const pathname = usePathname()
  const searchParams = useSearchParams()

  useEffect(() => {
    const url = `${pathname}?${searchParams}`
    console.log(url)
    // You can now use the current URL
    // ...
  }, [pathname, searchParams])

  return '...'
}
```

Có thể được import vào một layout.

```jsx filename="app/layout.js" highlight={2,10-12}
import { Suspense } from 'react'
import { NavigationEvents } from './components/navigation-events'

export default function Layout({ children }) {
  return (
    <html lang="en">
      <body>
        {children}

        <Suspense fallback={null}>
          <NavigationEvents />
        </Suspense>
      </body>
    </html>
  )
}
```

> **Nên biết**: `<NavigationEvents>` được bọc trong một [`Suspense` boundary](/docs/app/api-reference/file-conventions/loading#examples) bởi vì [`useSearchParams()`](/docs/app/api-reference/functions/use-search-params) gây ra client-side rendering lên đến `Suspense` boundary gần nhất trong quá trình [static rendering](/docs/app/guides/caching#static-rendering). [Tìm hiểu thêm](/docs/app/api-reference/functions/use-search-params#behavior).

### Disable scroll to top

Theo mặc định, Next.js sẽ cuộn lên đầu trang khi điều hướng đến một route mới. Bạn có thể disable hành vi này bằng cách truyền `scroll: false` cho `router.push()` hoặc `router.replace()`.

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useRouter } from 'next/navigation'

export default function Page() {
  const router = useRouter()

  return (
    <button
      type="button"
      onClick={() => router.push('/dashboard', { scroll: false })}
    >
      Dashboard
    </button>
  )
}
```

```jsx filename="app/example-client-component.jsx" switcher
'use client'

import { useRouter } from 'next/navigation'

export default function Page() {
  const router = useRouter()

  return (
    <button
      type="button"
      onClick={() => router.push('/dashboard', { scroll: false })}
    >
      Dashboard
    </button>
  )
}
```
