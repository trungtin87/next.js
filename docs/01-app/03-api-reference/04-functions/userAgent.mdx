Helper `userAgent` mở rộng [Web Request API](https://developer.mozilla.org/docs/Web/API/Request) với các thuộc tính và phương thức bổ sung để tương tác với đối tượng user agent từ request.

```ts filename="proxy.ts" switcher
import { NextRequest, NextResponse, userAgent } from 'next/server'

export function proxy(request: NextRequest) {
  const url = request.nextUrl
  const { device } = userAgent(request)

  // device.type có thể là: 'mobile', 'tablet', 'console', 'smarttv',
  // 'wearable', 'embedded', hoặc undefined (cho desktop browsers)
  const viewport = device.type || 'desktop'

  url.searchParams.set('viewport', viewport)
  return NextResponse.rewrite(url)
}
```


## `isBot`

Một boolean chỉ ra liệu request có đến từ một bot đã biết hay không.

## `browser`

Một object chứa thông tin về trình duyệt được sử dụng trong request.

- `name`: Một chuỗi đại diện cho tên của trình duyệt, hoặc `undefined` nếu không thể xác định.
- `version`: Một chuỗi đại diện cho phiên bản của trình duyệt, hoặc `undefined`.

## `device`

Một object chứa thông tin về thiết bị được sử dụng trong request.

- `model`: Một chuỗi đại diện cho model của thiết bị, hoặc `undefined`.
- `type`: Một chuỗi đại diện cho loại thiết bị, chẳng hạn như `console`, `mobile`, `tablet`, `smarttv`, `wearable`, `embedded`, hoặc `undefined`.
- `vendor`: Một chuỗi đại diện cho nhà cung cấp của thiết bị, hoặc `undefined`.

## `engine`

Một object chứa thông tin về engine của trình duyệt.

- `name`: Một chuỗi đại diện cho tên của engine. Các giá trị có thể bao gồm: `Amaya`, `Blink`, `EdgeHTML`, `Flow`, `Gecko`, `Goanna`, `iCab`, `KHTML`, `Links`, `Lynx`, `NetFront`, `NetSurf`, `Presto`, `Tasman`, `Trident`, `w3m`, `WebKit` hoặc `undefined`.
- `version`: Một chuỗi đại diện cho phiên bản của engine, hoặc `undefined`.

## `os`

Một object chứa thông tin về hệ điều hành.

- `name`: Một chuỗi đại diện cho tên của OS, hoặc `undefined`.
- `version`: Một chuỗi đại diện cho phiên bản của OS, hoặc `undefined`.

## `cpu`

Một object chứa thông tin về kiến trúc CPU.

- `architecture`: Một chuỗi đại diện cho kiến trúc của CPU. Các giá trị có thể bao gồm: `68k`, `amd64`, `arm`, `arm64`, `armhf`, `avr`, `ia32`, `ia64`, `irix`, `irix64`, `mips`, `mips64`, `pa-risc`, `ppc`, `sparc`, `sparc64` hoặc `undefined`
