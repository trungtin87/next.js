NextRequest mở rộng [Web Request API](https://developer.mozilla.org/docs/Web/API/Request) với các convenience methods bổ sung.

## `cookies`

Đọc hoặc mutate header [`Set-Cookie`](https://developer.mozilla.org/docs/Web/HTTP/Headers/Set-Cookie) của request.

### `set(name, value)`

Với một name, set một cookie với giá trị đã cho trên request.

```ts
// Given incoming request /home
// Set a cookie to hide the banner
// request will have a `Set-Cookie:show-banner=false;path=/home` header
request.cookies.set('show-banner', 'false')
```

### `get(name)`

Với một cookie name, trả về giá trị của cookie. Nếu cookie không được tìm thấy, `undefined` được trả về. Nếu nhiều cookies được tìm thấy, cái đầu tiên được trả về.

```ts
// Given incoming request /home
// { name: 'show-banner', value: 'false', Path: '/home' }
request.cookies.get('show-banner')
```

### `getAll()`

Với một cookie name, trả về các giá trị của cookie. Nếu không có name nào được cung cấp, trả về tất cả cookies trên request.

```ts
// Given incoming request /home
// [
//   { name: 'experiments', value: 'new-pricing-page', Path: '/home' },
//   { name: 'experiments', value: 'winter-launch', Path: '/home' },
// ]
request.cookies.getAll('experiments')
// Alternatively, get all cookies for the request
request.cookies.getAll()
```

### `delete(name)`

Với một cookie name, xóa cookie khỏi request.

```ts
// Returns true for deleted, false is nothing is deleted
request.cookies.delete('experiments')
```

### `has(name)`

Với một cookie name, trả về `true` nếu cookie tồn tại trên request.

```ts
// Returns true if cookie exists, false if it does not
request.cookies.has('experiments')
```

### `clear()`

Xóa header `Set-Cookie` khỏi request.

```ts
request.cookies.clear()
```

## `nextUrl`

Mở rộng native [`URL`](https://developer.mozilla.org/docs/Web/API/URL) API với các convenience methods bổ sung, bao gồm các thuộc tính cụ thể của Next.js.

```ts
// Given a request to /home, pathname is /home
request.nextUrl.pathname
// Given a request to /home?name=lee, searchParams is { 'name': 'lee' }
request.nextUrl.searchParams
```

Các options sau đây có sẵn:

<PagesOnly>

| Thuộc tính        | Type                      | Mô tả                                                                                                                            |
| ----------------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `basePath`        | `string`                  | [Base path](/docs/pages/api-reference/config/next-config-js/basePath) của URL.                                                   |
| `buildId`         | `string` \| `undefined`   | Build identifier của ứng dụng Next.js. Có thể được [tùy chỉnh](/docs/pages/api-reference/config/next-config-js/generateBuildId). |
| `defaultLocale`   | `string` \| `undefined`   | Default locale cho [internationalization](/docs/pages/guides/internationalization).                                              |
| `domainLocale`    |                           |                                                                                                                                  |
| - `defaultLocale` | `string`                  | Default locale trong một domain.                                                                                                 |
| - `domain`        | `string`                  | Domain liên kết với một locale cụ thể.                                                                                           |
| - `http`          | `boolean` \| `undefined`  | Cho biết domain có đang sử dụng HTTP hay không.                                                                                  |
| `locales`         | `string[]` \| `undefined` | Một mảng các locales có sẵn.                                                                                                     |
| `locale`          | `string` \| `undefined`   | Locale hiện đang hoạt động.                                                                                                      |
| `url`             | `URL`                     | URL object.                                                                                                                      |

</PagesOnly>

<AppOnly>

| Thuộc tính     | Type                    | Mô tả                                                                                                                          |
| -------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `basePath`     | `string`                | [Base path](/docs/app/api-reference/config/next-config-js/basePath) của URL.                                                   |
| `buildId`      | `string` \| `undefined` | Build identifier của ứng dụng Next.js. Có thể được [tùy chỉnh](/docs/app/api-reference/config/next-config-js/generateBuildId). |
| `pathname`     | `string`                | Pathname của URL.                                                                                                              |
| `searchParams` | `Object`                | Search parameters của URL.                                                                                                     |

> **Lưu ý:** Các thuộc tính internationalization từ Pages Router không có sẵn để sử dụng trong App Router. Tìm hiểu thêm về [internationalization với App Router](/docs/app/guides/internationalization).

</AppOnly>
