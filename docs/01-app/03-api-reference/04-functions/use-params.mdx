`useParams` là một hook **Client Component** cho phép bạn đọc [dynamic params](/docs/app/api-reference/file-conventions/dynamic-routes) của route được điền bởi URL hiện tại.

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useParams } from 'next/navigation'

export default function ExampleClientComponent() {
  const params = useParams<{ tag: string; item: string }>()

  // Route -> /shop/[tag]/[item]
  // URL -> /shop/shoes/nike-air-max-97
  // `params` -> { tag: 'shoes', item: 'nike-air-max-97' }
  console.log(params)

  return '...'
}
```

```jsx filename="app/example-client-component.js" switcher
'use client'

import { useParams } from 'next/navigation'

export default function ExampleClientComponent() {
  const params = useParams()

  // Route -> /shop/[tag]/[item]
  // URL -> /shop/shoes/nike-air-max-97
  // `params` -> { tag: 'shoes', item: 'nike-air-max-97' }
  console.log(params)

  return '...'
}
```

## Tham số

```tsx
const params = useParams()
```

`useParams` không nhận bất kỳ tham số nào.

## Giá trị trả về

`useParams` trả về một đối tượng chứa các [dynamic parameters](/docs/app/api-reference/file-conventions/dynamic-routes) được điền của route hiện tại.

- Mỗi thuộc tính trong đối tượng là một đoạn động đang hoạt động.
- Tên thuộc tính là tên của đoạn, và giá trị thuộc tính là những gì đoạn được điền vào.
- Giá trị thuộc tính sẽ là `string` hoặc mảng `string` tùy thuộc vào [loại đoạn động](/docs/app/api-reference/file-conventions/dynamic-routes).
- Nếu route không chứa dynamic parameters, `useParams` trả về một đối tượng rỗng.
- Nếu được sử dụng trong Pages Router, `useParams` sẽ trả về `null` trên lần render đầu tiên và cập nhật với các thuộc tính theo các quy tắc trên sau khi router sẵn sàng.

Ví dụ:

| Route                           | URL         | `useParams()`             |
| ------------------------------- | ----------- | ------------------------- |
| `app/shop/page.js`              | `/shop`     | `{}`                      |
| `app/shop/[slug]/page.js`       | `/shop/1`   | `{ slug: '1' }`           |
| `app/shop/[tag]/[item]/page.js` | `/shop/1/2` | `{ tag: '1', item: '2' }` |
| `app/shop/[...slug]/page.js`    | `/shop/1/2` | `{ slug: ['1', '2'] }`    |
