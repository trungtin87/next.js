`useSelectedLayoutSegment` là một **Client Component** hook cho phép bạn đọc route segment đang hoạt động **một cấp bên dưới** Layout mà nó được gọi.

Nó hữu ích cho UI điều hướng, chẳng hạn như các tab bên trong một parent layout thay đổi kiểu tùy thuộc vào child segment đang hoạt động.

```tsx filename="app/example-client-component.tsx" switcher
'use client'

import { useSelectedLayoutSegment } from 'next/navigation'

export default function ExampleClientComponent() {
  const segment = useSelectedLayoutSegment()

  return <p>Active segment: {segment}</p>
}
```

```jsx filename="app/example-client-component.js" switcher
'use client'

import { useSelectedLayoutSegment } from 'next/navigation'

export default function ExampleClientComponent() {
  const segment = useSelectedLayoutSegment()

  return <p>Active segment: {segment}</p>
}
```

> **Lưu ý**:
>
> - Vì `useSelectedLayoutSegment` là một [Client Component](/docs/app/getting-started/server-and-client-components) hook, và Layouts là [Server Components](/docs/app/getting-started/server-and-client-components) theo mặc định, `useSelectedLayoutSegment` thường được gọi thông qua một Client Component được import vào một Layout.
> - `useSelectedLayoutSegment` chỉ trả về segment một cấp bên dưới. Để trả về tất cả các segments đang hoạt động, xem [`useSelectedLayoutSegments`](/docs/app/api-reference/functions/use-selected-layout-segments)

## Tham số

```tsx
const segment = useSelectedLayoutSegment(parallelRoutesKey?: string)
```

`useSelectedLayoutSegment` _tùy chọn_ chấp nhận một [`parallelRoutesKey`](/docs/app/api-reference/file-conventions/parallel-routes#with-useselectedlayoutsegments), cho phép bạn đọc route segment đang hoạt động bên trong slot đó.

## Giá trị trả về

`useSelectedLayoutSegment` trả về một chuỗi của segment đang hoạt động hoặc `null` nếu không tồn tại.

Ví dụ, với các Layouts và URLs bên dưới, segment được trả về sẽ là:

| Layout                    | URL đã truy cập                | Segment được trả về |
| ------------------------- | ------------------------------ | ------------------- |
| `app/layout.js`           | `/`                            | `null`              |
| `app/layout.js`           | `/dashboard`                   | `'dashboard'`       |
| `app/dashboard/layout.js` | `/dashboard`                   | `null`              |
| `app/dashboard/layout.js` | `/dashboard/settings`          | `'settings'`        |
| `app/dashboard/layout.js` | `/dashboard/analytics`         | `'analytics'`       |
| `app/dashboard/layout.js` | `/dashboard/analytics/monthly` | `'analytics'`       |

## Ví dụ

### Tạo một active link component

Bạn có thể sử dụng `useSelectedLayoutSegment` để tạo một active link component thay đổi kiểu tùy thuộc vào segment đang hoạt động. Ví dụ, một danh sách các bài đăng nổi bật trong thanh bên của một blog:

```tsx filename="app/blog/blog-nav-link.tsx" switcher
'use client'

import Link from 'next/link'
import { useSelectedLayoutSegment } from 'next/navigation'

// Component *client* này sẽ được import vào một blog layout
export default function BlogNavLink({
  slug,
  children,
}: {
  slug: string
  children: React.ReactNode
}) {
  // Điều hướng đến `/blog/hello-world` sẽ trả về 'hello-world'
  // cho layout segment đã chọn
  const segment = useSelectedLayoutSegment()
  const isActive = slug === segment

  return (
    <Link
      href={`/blog/${slug}`}
      // Thay đổi kiểu tùy thuộc vào việc liên kết có đang hoạt động hay không
      style={{ fontWeight: isActive ? 'bold' : 'normal' }}
    >
      {children}
    </Link>
  )
}
```


```tsx filename="app/blog/layout.tsx" switcher
// Import Client Component vào một parent Layout (Server Component)
import { BlogNavLink } from './blog-nav-link'
import getFeaturedPosts from './get-featured-posts'

export default async function Layout({
  children,
}: {
  children: React.ReactNode
}) {
  const featuredPosts = await getFeaturedPosts()
  return (
    <div>
      {featuredPosts.map((post) => (
        <div key={post.id}>
          <BlogNavLink slug={post.slug}>{post.title}</BlogNavLink>
        </div>
      ))}
      <div>{children}</div>
    </div>
  )
}
```
