Hàm `notFound` cho phép bạn render [`tệp not-found`](/docs/app/api-reference/file-conventions/not-found) trong một đoạn route cũng như chèn thẻ `<meta name="robots" content="noindex" />`.

## `notFound()`

Gọi hàm `notFound()` sẽ ném một lỗi `NEXT_HTTP_ERROR_FALLBACK;404` và chấm dứt việc render đoạn route mà nó được ném. Chỉ định một [tệp **not-found**](/docs/app/api-reference/file-conventions/not-found) cho phép bạn xử lý các lỗi như vậy một cách duyên dáng bằng cách render UI Not Found trong đoạn đó.

```jsx filename="app/user/[id]/page.js"
import { notFound } from 'next/navigation'

async function fetchUser(id) {
  const res = await fetch('https://...')
  if (!res.ok) return undefined
  return res.json()
}

export default async function Profile({ params }) {
  const { id } = await params
  const user = await fetchUser(id)

  if (!user) {
    notFound()
  }

  // ...
}
```

> **Thông tin hữu ích**: `notFound()` không yêu cầu bạn sử dụng `return notFound()` do sử dụng kiểu [`never`](https://www.typescriptlang.org/docs/handbook/2/functions.html#never) của TypeScript.
