Hàm `forbidden` ném ra một lỗi render trang lỗi 403 của Next.js. Nó hữu ích để xử lý các lỗi ủy quyền (authorization errors) trong ứng dụng của bạn. Bạn có thể tùy chỉnh UI bằng cách sử dụng [file `forbidden.js`](/docs/app/api-reference/file-conventions/forbidden).

Để bắt đầu sử dụng `forbidden`, hãy bật tùy chọn cấu hình thực nghiệm [`authInterrupts`](/docs/app/api-reference/config/next-config-js/authInterrupts) trong file `next.config.js` của bạn:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    authInterrupts: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
module.exports = {
  experimental: {
    authInterrupts: true,
  },
}
```

`forbidden` có thể được gọi trong [Server Components](/docs/app/getting-started/server-and-client-components), [Server Actions](/docs/app/getting-started/updating-data), và [Route Handlers](/docs/app/api-reference/file-conventions/route).

```tsx filename="app/auth/page.tsx" switcher
import { verifySession } from '@/app/lib/dal'
import { forbidden } from 'next/navigation'

export default async function AdminPage() {
  const session = await verifySession()

  // Kiểm tra xem người dùng có vai trò 'admin' hay không
  if (session.role !== 'admin') {
    forbidden()
  }

  // Render trang admin cho người dùng được ủy quyền
  return <></>
}
```

```jsx filename="app/auth/page.js" switcher

  }

  // Render trang admin cho người dùng được ủy quyền

```

## Lưu ý

- Hàm `forbidden` không thể được gọi trong [root layout](/docs/app/api-reference/file-conventions/layout#root-layout).

## Ví dụ

### Bảo vệ route dựa trên vai trò

Bạn có thể sử dụng `forbidden` để hạn chế quyền truy cập vào các routes nhất định dựa trên vai trò của người dùng. Điều này đảm bảo rằng người dùng đã xác thực nhưng thiếu quyền hạn cần thiết không thể truy cập route.

```tsx filename="app/admin/page.tsx" switcher
import { verifySession } from '@/app/lib/dal'
import { forbidden } from 'next/navigation'

export default async function AdminPage() {
  const session = await verifySession()

  // Kiểm tra xem người dùng có vai trò 'admin' hay không
  if (session.role !== 'admin') {
    forbidden()
  }

  // Render trang admin cho người dùng được ủy quyền
  return (
    <main>
      <h1>Admin Dashboard</h1>
      <p>Welcome, {session.user.name}!</p>
    </main>
  )
}
```

```jsx filename="app/admin/page.js" switcher

```

### Mutations với Server Actions

Khi triển khai mutations trong Server Actions, bạn có thể sử dụng `forbidden` để chỉ cho phép người dùng có vai trò cụ thể cập nhật dữ liệu nhạy cảm.

```ts filename="app/actions/update-role.ts" switcher
'use server'

import { verifySession } from '@/app/lib/dal'
import { forbidden } from 'next/navigation'
import db from '@/app/lib/db'

export async function updateRole(formData: FormData) {
  const session = await verifySession()

  // Đảm bảo chỉ admins mới có thể cập nhật vai trò
  if (session.role !== 'admin') {
    forbidden()
  }

  // Thực hiện cập nhật vai trò cho người dùng được ủy quyền
  // ...
}
```

```js filename="app/actions/update-role.js" switcher
'use server'

import { verifySession } from '@/app/lib/dal'
import { forbidden } from 'next/navigation'
import db from '@/app/lib/db'

  }

  // Thực hiện cập nhật vai trò cho người dùng được ủy quyền
  // ...
}
```
