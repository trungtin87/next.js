Hàm `connection()` cho phép bạn chỉ ra rằng rendering nên đợi một yêu cầu người dùng đến trước khi tiếp tục.

Nó hữu ích khi một component không sử dụng [Dynamic APIs](/docs/app/guides/caching#dynamic-rendering), nhưng bạn muốn nó được render động tại runtime chứ không phải render tĩnh tại thời điểm build. Điều này thường xảy ra khi bạn truy cập thông tin bên ngoài mà bạn cố ý muốn thay đổi kết quả của một lần render, chẳng hạn như `Math.random()` hoặc `new Date()`.

```ts filename="app/page.tsx" switcher
import { connection } from 'next/server'

export default async function Page() {
  await connection()
  // Mọi thứ bên dưới sẽ được loại trừ khỏi prerendering
  const rand = Math.random()
  return <span>{rand}</span>
}
```

```jsx filename="app/page.js" switcher
import { connection } from 'next/server'

export default async function Page() {
  await connection()
  // Mọi thứ bên dưới sẽ được loại trừ khỏi prerendering
  const rand = Math.random()
  return <span>{rand}</span>
}
```

## Tham khảo

### Kiểu

```jsx
function connection(): Promise<void>
```

### Tham số

- Hàm không chấp nhận bất kỳ tham số nào.

### Giá trị trả về

- Hàm trả về một `void` Promise. Nó không có nghĩa là để được sử dụng.

## Thông tin hữu ích

- `connection` thay thế [`unstable_noStore`](/docs/app/api-reference/functions/unstable_noStore) để phù hợp hơn với tương lai của Next.js.
- Hàm chỉ cần thiết khi dynamic rendering được yêu cầu và các Dynamic API thông thường không được sử dụng.
