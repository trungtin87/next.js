`updateTag` cho phép bạn cập nhật [dữ liệu đã cache](/docs/app/guides/caching) theo yêu cầu cho một cache tag cụ thể từ bên trong [Server Actions](/docs/app/getting-started/updating-data).

Hàm này được thiết kế cho các kịch bản **read-your-own-writes**, nơi người dùng thực hiện một thay đổi (như tạo một bài đăng), và UI ngay lập tức hiển thị thay đổi đó, thay vì dữ liệu cũ.

## Sử dụng

`updateTag` **chỉ** có thể được gọi từ bên trong [Server Actions](/docs/app/getting-started/updating-data). Nó không thể được sử dụng trong Route Handlers, Client Components, hoặc bất kỳ ngữ cảnh nào khác.

Nếu bạn cần invalidate cache tags trong Route Handlers hoặc các ngữ cảnh khác, hãy sử dụng [`revalidateTag`](/docs/app/api-reference/functions/revalidateTag) thay thế.

> **Lưu ý**: `updateTag` làm hết hạn dữ liệu đã cache ngay lập tức cho tag được chỉ định. Request tiếp theo sẽ đợi để fetch dữ liệu mới thay vì phục vụ nội dung cũ từ cache, đảm bảo người dùng thấy các thay đổi của họ ngay lập tức.

## Tham số

```tsx
updateTag(tag: string): void;
```

- `tag`: Một chuỗi đại diện cho cache tag được liên kết với dữ liệu bạn muốn cập nhật. Không được vượt quá 256 ký tự. Giá trị này phân biệt chữ hoa chữ thường.

Tags trước tiên phải được gán cho dữ liệu đã cache. Bạn có thể làm điều này theo hai cách:

- Sử dụng tùy chọn [`next.tags`](/docs/app/guides/caching#fetch-optionsnexttags-and-revalidatetag) với `fetch` để cache các requests API bên ngoài:

```tsx
fetch(url, { next: { tags: ['posts'] } })
```

- Sử dụng [`cacheTag`](/docs/app/api-reference/functions/cacheTag) bên trong các hàm hoặc components được cache với directive `'use cache'`:

```tsx
import { cacheTag } from 'next/cache'

async function getData() {
  'use cache'
  cacheTag('posts')
  // ...
}
```

## Giá trị trả về

`updateTag` không trả về giá trị.

## Sự khác biệt với revalidateTag

Trong khi cả `updateTag` và `revalidateTag` đều invalidate dữ liệu đã cache, chúng phục vụ các mục đích khác nhau:

- **`updateTag`**:
  - Chỉ có thể được sử dụng trong Server Actions
  - Request tiếp theo đợi dữ liệu mới (không phục vụ nội dung cũ)
  - Được thiết kế cho các kịch bản read-your-own-writes

- **`revalidateTag`**:
  - Có thể được sử dụng trong Server Actions và Route Handlers
  - Với `profile="max"` (được khuyến nghị): Phục vụ dữ liệu đã cache trong khi fetch dữ liệu mới trong nền (stale-while-revalidate)
  - Với custom profile: Có thể được cấu hình cho bất kỳ cache life profile nào cho việc sử dụng nâng cao
  - Không có profile: hành vi cũ tương đương với `updateTag`

## Ví dụ

### Server Action với Read-Your-Own-Writes

```ts filename="app/actions.ts" switcher
'use server'

import { updateTag } from 'next/cache'
import { redirect } from 'next/navigation'

export async function createPost(formData: FormData) {
  const title = formData.get('title')
  const content = formData.get('content')

  // Tạo bài đăng trong cơ sở dữ liệu của bạn
  const post = await db.post.create({
    data: { title, content },
  })

  // Invalidate cache tags để bài đăng mới hiển thị ngay lập tức
  // tag 'posts': ảnh hưởng đến bất kỳ trang nào hiển thị danh sách bài đăng
  updateTag('posts')
  // tag 'post-{id}': ảnh hưởng đến trang chi tiết bài đăng riêng lẻ
  updateTag(`post-${post.id}`)

  // Chuyển hướng đến bài đăng mới - người dùng sẽ thấy dữ liệu mới, không phải cache
  redirect(`/posts/${post.id}`)
}
```

### Lỗi khi sử dụng bên ngoài Server Actions

```ts filename="app/api/posts/route.ts" switcher
import { updateTag } from 'next/cache'

export async function POST() {
  // Điều này sẽ ném ra lỗi
  updateTag('posts')
  // Lỗi: updateTag chỉ có thể được gọi từ bên trong một Server Action

  // Sử dụng revalidateTag thay thế trong Route Handlers
  revalidateTag('posts', 'max')
}
```

## Khi nào sử dụng updateTag

Sử dụng `updateTag` khi:

- Bạn đang ở trong một Server Action
- Bạn cần invalidate cache ngay lập tức cho read-your-own-writes
- Bạn muốn đảm bảo request tiếp theo thấy dữ liệu đã cập nhật

Sử dụng `revalidateTag` thay thế khi:

- Bạn đang ở trong một Route Handler hoặc ngữ cảnh non-action khác
- Bạn muốn ngữ nghĩa stale-while-revalidate
- Bạn đang xây dựng một webhook hoặc API endpoint cho việc invalidate cache
