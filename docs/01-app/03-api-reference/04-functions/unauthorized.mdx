Hàm `unauthorized` ném một lỗi render trang lỗi 401 của Next.js. Nó hữu ích để xử lý các lỗi authorization trong ứng dụng của bạn. Bạn có thể tùy chỉnh UI bằng cách sử dụng [tệp `unauthorized.js`](/docs/app/api-reference/file-conventions/unauthorized).

Để bắt đầu sử dụng `unauthorized`, hãy enable tùy chọn cấu hình experimental [`authInterrupts`](/docs/app/api-reference/config/next-config-js/authInterrupts) trong tệp `next.config.js` của bạn:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    authInterrupts: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
module.exports = {
  experimental: {
    authInterrupts: true,
  },
}
```

`unauthorized` có thể được gọi trong [Server Components](/docs/app/getting-started/server-and-client-components), [Server Actions](/docs/app/getting-started/updating-data), và [Route Handlers](/docs/app/api-reference/file-conventions/route).

```tsx filename="app/dashboard/page.tsx" switcher
import { verifySession } from '@/app/lib/dal'
import { unauthorized } from 'next/navigation'

export default async function DashboardPage() {
  const session = await verifySession()

  if (!session) {
    unauthorized()
  }

  // Render the dashboard for authenticated users
  return (
    <main>
      <h1>Welcome to the Dashboard</h1>
      <p>Hi, {session.user.name}.</p>
    </main>
  )
}
```

```jsx filename="app/dashboard/page.js" switcher

```

## Nên biết

- Hàm `unauthorized` không thể được gọi trong [root layout](/docs/app/api-reference/file-conventions/layout#root-layout).

## Ví dụ

### Hiển thị login UI cho người dùng chưa xác thực

Bạn có thể sử dụng hàm `unauthorized` để hiển thị tệp `unauthorized.js` với login UI.

```tsx filename="app/dashboard/page.tsx" switcher
import { verifySession } from '@/app/lib/dal'
import { unauthorized } from 'next/navigation'

export default async function DashboardPage() {
  const session = await verifySession()

  if (!session) {
    unauthorized()
  }

  return <div>Dashboard</div>
}
```

```jsx filename="app/dashboard/page.js" switcher
import { verifySession } from '@/app/lib/dal'
import { unauthorized } from 'next/navigation'

export default async function DashboardPage() {
  const session = await verifySession()

  if (!session) {
    unauthorized()
  }

  return <div>Dashboard</div>
}
```

```tsx filename="app/unauthorized.tsx" switcher
import Login from '@/app/components/Login'
```

### Mutations với Server Actions

Bạn có thể gọi `unauthorized` trong Server Actions để đảm bảo chỉ người dùng đã xác thực mới có thể thực hiện các mutations cụ thể.

```ts filename="app/actions/update-profile.ts" switcher
'use server'

import { verifySession } from '@/app/lib/dal'
import { unauthorized } from 'next/navigation'
import db from '@/app/lib/db'

export async function updateProfile(data: FormData) {
  const session = await verifySession()

  // If the user is not authenticated, return a 401
  if (!session) {
    unauthorized()
  }

  // Proceed with mutation
  // ...
}
```

```js filename="app/actions/update-profile.js" switcher
  // ...
}
```

### Fetching data với Route Handlers

Bạn có thể sử dụng `unauthorized` trong Route Handlers để đảm bảo chỉ người dùng đã xác thực mới có thể truy cập endpoint.

```tsx filename="app/api/profile/route.ts" switcher
import { NextRequest, NextResponse } from 'next/server'
import { verifySession } from '@/app/lib/dal'
import { unauthorized } from 'next/navigation'

export async function GET(req: NextRequest): Promise<NextResponse> {
  // Verify the user's session
  const session = await verifySession()

  // If no session exists, return a 401 and render unauthorized.tsx
  if (!session) {
    unauthorized()
  }

  // Fetch data
  // ...
}
```

```jsx filename="app/api/profile/route.js" switcher
import { verifySession } from '@/app/lib/dal'
import { unauthorized } from 'next/navigation'

    unauthorized()
  }

  // Fetch data
  // ...
}
```
