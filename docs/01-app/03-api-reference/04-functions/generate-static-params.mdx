Hàm `generateStaticParams` có thể được sử dụng kết hợp với [các đoạn route động (dynamic route segments)](/docs/app/api-reference/file-conventions/dynamic-routes) để [**tạo tĩnh**](/docs/app/guides/caching#static-rendering) các route tại thời gian build (build time) thay vì theo yêu cầu tại thời gian request (request time).

```tsx filename="app/blog/[slug]/page.tsx" switcher
// Trả về một danh sách `params` để điền vào đoạn động [slug]
export async function generateStaticParams() {
  const posts = await fetch('https://.../posts').then((res) => res.json())

  return posts.map((post) => ({
    slug: post.slug,
  }))
}

// Nhiều phiên bản của trang này sẽ được tạo tĩnh
// sử dụng `params` được trả về bởi `generateStaticParams`
export default async function Page({
  params,
}: {
  params: Promise<{ slug: string }>
}) {
  const { slug } = await params
  // ...
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
// Trả về một danh sách `params` để điền vào đoạn động [slug]
export async function generateStaticParams() {
  const posts = await fetch('https://.../posts').then((res) => res.json())

  return posts.map((post) => ({
    slug: post.slug,
  }))
}

// Nhiều phiên bản của trang này sẽ được tạo tĩnh
// sử dụng `params` được trả về bởi `generateStaticParams`
export default async function Page({ params }) {
  const { slug } = await params
  // ...
}
```

> **Cần biết**:
>
> - Bạn có thể sử dụng tùy chọn cấu hình segment [`dynamicParams`](/docs/app/api-reference/file-conventions/route-segment-config#dynamicparams) để kiểm soát điều gì sẽ xảy ra khi một đoạn động được truy cập mà không được tạo với `generateStaticParams`.
> - Bạn phải trả về [một mảng rỗng từ `generateStaticParams`](#all-paths-at-build-time) hoặc sử dụng [`export const dynamic = 'force-static'`](/docs/app/api-reference/file-conventions/route-segment-config#dynamic) để revalidate (ISR) [các đường dẫn tại runtime](#all-paths-at-runtime).
> - Trong quá trình `next dev`, `generateStaticParams` sẽ được gọi khi bạn điều hướng đến một route.
> - Trong quá trình `next build`, `generateStaticParams` chạy trước khi các Layouts hoặc Pages tương ứng được tạo.
> - Trong quá trình revalidation (ISR), `generateStaticParams` sẽ không được gọi lại.
> - `generateStaticParams` thay thế hàm [`getStaticPaths`](/docs/pages/api-reference/functions/get-static-paths) trong Pages Router.

## Parameters

`options.params` (tùy chọn)

Nếu nhiều dynamic segments trong một route sử dụng `generateStaticParams`, hàm `generateStaticParams` con được thực thi một lần cho mỗi tập hợp `params` mà cha tạo ra.

Object `params` chứa các `params` đã được điền từ `generateStaticParams` cha, có thể được sử dụng để [tạo `params` trong một segment con](#multiple-dynamic-segments-in-a-route).

## Returns

`generateStaticParams` nên trả về một mảng các objects, trong đó mỗi object đại diện cho các dynamic segments đã được điền của một route đơn lẻ.

- Mỗi thuộc tính trong object là một dynamic segment cần được điền cho route.
- Tên thuộc tính là tên của segment, và giá trị thuộc tính là những gì segment đó nên được điền vào.

| Ví dụ Route                      | Kiểu trả về của `generateStaticParams`    |
| -------------------------------- | ----------------------------------------- |
| `/product/[id]`                  | `{ id: string }[]`                        |
| `/products/[category]/[product]` | `{ category: string, product: string }[]` |
| `/products/[...slug]`            | `{ slug: string[] }[]`                    |

## Ví dụ

### Static Rendering

#### Tất cả các đường dẫn tại thời gian build

Để render tĩnh tất cả các đường dẫn tại thời gian build, cung cấp danh sách đầy đủ các đường dẫn cho `generateStaticParams`:

```tsx filename="app/blog/[slug]/page.tsx" switcher
export async function generateStaticParams() {
  const posts = await fetch('https://.../posts').then((res) => res.json())

  return posts.map((post) => ({
    slug: post.slug,
  }))
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
export async function generateStaticParams() {
  const posts = await fetch('https://.../posts').then((res) => res.json())

  return posts.map((post) => ({
    slug: post.slug,
  }))
}
```

#### Một tập hợp con các đường dẫn tại thời gian build

Để render tĩnh một tập hợp con các đường dẫn tại thời gian build, và phần còn lại vào lần đầu tiên chúng được truy cập tại runtime, trả về một danh sách một phần các đường dẫn:

```tsx filename="app/blog/[slug]/page.tsx" switcher
export async function generateStaticParams() {
  const posts = await fetch('https://.../posts').then((res) => res.json())

  // Render 10 bài viết đầu tiên tại thời gian build
  return posts.slice(0, 10).map((post) => ({
    slug: post.slug,
  }))
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
export async function generateStaticParams() {
  const posts = await fetch('https://.../posts').then((res) => res.json())

  // Render 10 bài viết đầu tiên tại thời gian build
  return posts.slice(0, 10).map((post) => ({
    slug: post.slug,
  }))
}
```

Sau đó, bằng cách sử dụng tùy chọn cấu hình segment [`dynamicParams`](/docs/app/api-reference/file-conventions/route-segment-config#dynamicparams), bạn có thể kiểm soát điều gì sẽ xảy ra khi một dynamic segment được truy cập mà không được tạo với `generateStaticParams`.

```tsx filename="app/blog/[slug]/page.tsx" switcher
// Tất cả các bài viết ngoài top 10 sẽ là 404
export const dynamicParams = false

export async function generateStaticParams() {
  const posts = await fetch('https://.../posts').then((res) => res.json())
  const topPosts = posts.slice(0, 10)

  return topPosts.map((post) => ({
    slug: post.slug,
  }))
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
// Tất cả các bài viết ngoài top 10 sẽ là 404
export const dynamicParams = false

export async function generateStaticParams() {
  const posts = await fetch('https://.../posts').then((res) => res.json())
  const topPosts = posts.slice(0, 10)

  return topPosts.map((post) => ({
    slug: post.slug,
  }))
}
```

#### Tất cả các đường dẫn tại runtime

Để render tĩnh tất cả các đường dẫn vào lần đầu tiên chúng được truy cập, trả về một mảng rỗng (không có đường dẫn nào được render tại thời gian build) hoặc sử dụng [`export const dynamic = 'force-static'`](/docs/app/api-reference/file-conventions/route-segment-config#dynamic):

```jsx filename="app/blog/[slug]/page.js"
export async function generateStaticParams() {
  return []
}
```

> **Cần biết:** Bạn phải luôn trả về một mảng từ `generateStaticParams`, ngay cả khi nó rỗng. Nếu không, route sẽ được render động.

```jsx filename="app/changelog/[slug]/page.js"
export const dynamic = 'force-static'
```

### Vô hiệu hóa rendering cho các đường dẫn không xác định

Để ngăn chặn các đường dẫn không xác định được render tĩnh tại runtime, thêm tùy chọn `export const dynamicParams = false` trong một route segment. Khi tùy chọn cấu hình này được sử dụng, chỉ các đường dẫn được cung cấp bởi `generateStaticParams` mới được phục vụ, và các route không xác định sẽ trả về 404 hoặc khớp (trong trường hợp [catch-all routes](/docs/app/api-reference/file-conventions/dynamic-routes#catch-all-segments)).

### Nhiều Dynamic Segments trong một Route

Bạn có thể tạo params cho các dynamic segments ở trên layout hoặc page hiện tại, nhưng **không phải bên dưới**. Ví dụ, với route `app/products/[category]/[product]`:

- `app/products/[category]/[product]/page.js` có thể tạo params cho **cả** `[category]` và `[product]`.
- `app/products/[category]/layout.js` **chỉ** có thể tạo params cho `[category]`.

Có hai cách tiếp cận để tạo params cho một route với nhiều dynamic segments:

#### Tạo params từ dưới lên (Generate params from the bottom up)

Tạo nhiều dynamic segments từ child route segment.

```tsx filename="app/products/[category]/[product]/page.tsx" switcher
// Tạo segments cho cả [category] và [product]
export async function generateStaticParams() {
  const products = await fetch('https://.../products').then((res) => res.json())

  return products.map((product) => ({
    category: product.category.slug,
    product: product.id,
  }))
}

export default function Page({
  params,
}: {
  params: Promise<{ category: string; product: string }>
}) {
  // ...
}
```

```jsx filename="app/products/[category]/[product]/page.js" switcher
// Tạo segments cho cả [category] và [product]
export async function generateStaticParams() {
  const products = await fetch('https://.../products').then((res) => res.json())

  return products.map((product) => ({
    category: product.category.slug,
    product: product.id,
  }))
}

export default function Page({ params }) {
  // ...
}
```

#### Tạo params từ trên xuống (Generate params from the top down)

Tạo các parent segments trước và sử dụng kết quả để tạo các child segments.

```tsx filename="app/products/[category]/layout.tsx" switcher
// Tạo segments cho [category]
export async function generateStaticParams() {
  const products = await fetch('https://.../products').then((res) => res.json())

  return products.map((product) => ({
    category: product.category.slug,
  }))
}

export default function Layout({
  params,
}: {
  params: Promise<{ category: string }>
}) {
  // ...
}
```

```jsx filename="app/products/[category]/layout.js" switcher
// Tạo segments cho [category]
export async function generateStaticParams() {
  const products = await fetch('https://.../products').then((res) => res.json())

  return products.map((product) => ({
    category: product.category.slug,
  }))
}

export default function Layout({ params }) {
  // ...
}
```

Hàm `generateStaticParams` của một child route segment được thực thi một lần cho mỗi segment mà `generateStaticParams` của cha tạo ra.

Hàm `generateStaticParams` con có thể sử dụng `params` được trả về từ hàm `generateStaticParams` cha để tạo động các segments của riêng nó.

```tsx filename="app/products/[category]/[product]/page.tsx" switcher
// Tạo segments cho [product] sử dụng `params` được truyền từ
// hàm `generateStaticParams` của parent segment
export async function generateStaticParams({
  params: { category },
}: {
  params: { category: string }
}) {
  const products = await fetch(
    `https://.../products?category=${category}`
  ).then((res) => res.json())

  return products.map((product) => ({
    product: product.id,
  }))
}

export default function Page({
  params,
}: {
  params: Promise<{ category: string; product: string }>
}) {
  // ...
}
```

```jsx filename="app/products/[category]/[product]/page.js" switcher
// Tạo segments cho [product] sử dụng `params` được truyền từ
// hàm `generateStaticParams` của parent segment
export async function generateStaticParams({ params: { category } }) {
  const products = await fetch(
    `https://.../products?category=${category}`
  ).then((res) => res.json())

  return products.map((product) => ({
    product: product.id,
  }))
}

export default function Page({ params }) {
  // ...
}
```

Lưu ý rằng đối số params có thể được truy cập đồng bộ và chỉ bao gồm các params của parent segment.

Để hoàn thành kiểu (type completion), bạn có thể sử dụng TypeScript `Awaited` helper kết hợp với [`Page Props helper`](/docs/app/api-reference/file-conventions/page#page-props-helper) hoặc [`Layout Props helper`](/docs/app/api-reference/file-conventions/layout#layout-props-helper):

```ts filename="app/products/[category]/[product]/page.tsx" switcher
export async function generateStaticParams({
  params: { category },
}: {
  params: Awaited<LayoutProps<'/products/[category]'>['params']>
}) {
  const products = await fetch(
    `https://.../products?category=${category}`
  ).then((res) => res.json())

  return products.map((product) => ({
    product: product.id,
  }))
}
```

> **Cần biết**: các `fetch` requests được tự động [ghi nhớ (memoized)](/docs/app/guides/caching#request-memoization) cho cùng một dữ liệu trên tất cả các hàm có tiền tố `generate`, Layouts, Pages, và Server Components. React [`cache` có thể được sử dụng](/docs/app/guides/caching#react-cache-function) nếu `fetch` không khả dụng.
