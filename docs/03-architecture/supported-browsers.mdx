Next.js hỗ trợ **các trình duyệt hiện đại** mà không cần cấu hình.

- Chrome 111+
- Edge 111+
- Firefox 111+
- Safari 16.4+

## Browserslist

Nếu bạn muốn nhắm mục tiêu các trình duyệt hoặc tính năng cụ thể, Next.js hỗ trợ cấu hình [Browserslist](https://browsersl.ist) trong tệp `package.json` của bạn. Next.js sử dụng cấu hình Browserslist sau theo mặc định:

```json filename="package.json"
{
  "browserslist": ["chrome 111", "edge 111", "firefox 111", "safari 16.4"]
}
```

## Polyfills

Chúng tôi tiêm vào [các polyfills được sử dụng rộng rãi](https://github.com/vercel/next.js/blob/canary/packages/next-polyfill-nomodule/src/index.js), bao gồm:

- [**fetch()**](https://developer.mozilla.org/docs/Web/API/Fetch_API) — Thay thế: `whatwg-fetch` và `unfetch`.
- [**URL**](https://developer.mozilla.org/docs/Web/API/URL) — Thay thế: [`url` package (Node.js API)](https://nodejs.org/api/url.html).
- [**Object.assign()**](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Object/assign) — Thay thế: `object-assign`, `object.assign`, và `core-js/object/assign`.

Nếu bất kỳ phụ thuộc nào của bạn bao gồm các polyfills này, chúng sẽ tự động bị loại bỏ khỏi bản build production để tránh trùng lặp.

Ngoài ra, để giảm kích thước gói, Next.js sẽ chỉ tải các polyfills này cho các trình duyệt yêu cầu chúng. Phần lớn lưu lượng truy cập web trên toàn cầu sẽ không tải xuống các polyfills này.

### Custom Polyfills (Polyfills tùy chỉnh)

Nếu mã của riêng bạn hoặc bất kỳ phụ thuộc npm bên ngoài nào yêu cầu các tính năng không được hỗ trợ bởi các trình duyệt mục tiêu của bạn (như IE 11), bạn cần tự thêm polyfills.

#### Trong App Router

Để bao gồm polyfills, bạn có thể import chúng vào tệp [`instrumentation-client.js`](/docs/app/api-reference/file-conventions/instrumentation-client).

```ts filename="instrumentation-client.ts"
import './polyfills'
```

#### Trong Pages Router

Trong trường hợp này, bạn nên thêm một import cấp cao nhất cho **polyfill cụ thể** mà bạn cần trong [Custom `<App>`](/docs/pages/building-your-application/routing/custom-app) hoặc thành phần riêng lẻ.

```tsx filename="pages/_app.tsx" switcher
import './polyfills'

import type { AppProps } from 'next/app'

export default function MyApp({ Component, pageProps }: AppProps) {
  return <Component {...pageProps} />
}
```

```jsx filename="pages/_app.jsx" switcher
import './polyfills'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

#### Tải polyfills có điều kiện

Cách tiếp cận tốt nhất là cô lập các tính năng không được hỗ trợ vào các phần UI cụ thể và tải polyfill có điều kiện nếu cần.

```ts filename="hooks/analytics.ts" switcher
import { useCallback } from 'react'

export const useAnalytics = () => {
  const tracker = useCallback(async (data: unknown) => {
    if (!('structuredClone' in globalThis)) {
      import('polyfills/structured-clone').then((mod) => {
        globalThis.structuredClone = mod.default
      })
    }

    /* Thực hiện một số công việc sử dụng structured clone */
  }, [])

  return tracker
}
```

```js filename="hooks/analytics.js" switcher
import { useCallback } from 'react'

export const useAnalytics = () => {

      })
    }

    /* Thực hiện một số công việc sử dụng structured clone */
  }, [])

  return tracker
}
```

## Các tính năng ngôn ngữ JavaScript

Next.js cho phép bạn sử dụng các tính năng JavaScript mới nhất ngay lập tức. Ngoài [các tính năng ES6](https://github.com/lukehoban/es6features), Next.js cũng hỗ trợ:

- [Async/await](https://github.com/tc39/ecmascript-asyncawait) (ES2017)
- [Object Rest/Spread Properties](https://github.com/tc39/proposal-object-rest-spread) (ES2018)
- [Dynamic `import()`](https://github.com/tc39/proposal-dynamic-import) (ES2020)
- [Optional Chaining](https://github.com/tc39/proposal-optional-chaining) (ES2020)
- [Nullish Coalescing](https://github.com/tc39/proposal-nullish-coalescing) (ES2020)
- [Class Fields](https://github.com/tc39/proposal-class-fields) và [Static Properties](https://github.com/tc39/proposal-static-class-features) (ES2022)
- và hơn thế nữa!
